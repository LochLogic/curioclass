# Curio Class

Free, open, interactive K-12 tools for teachers. curioclass.org

- No accounts, no ads, no tracking. Every tool is one offline HTML file.
- Content CC BY 4.0, code MIT.

Start here: `docs/PHASE0-PLAN.md`.

| Folder | What |
|---|---|
| `docs/` | Plans and decisions |
| `data/` | Catalog data: grades, bands, subjects, tool types, modules (Phase 1), tools |
| `tools/<tool-id>/` | One folder per tool: the HTML file, later notes.md, meta, preview |
| `templates/tool-starter.html` | Start every new tool from this (bands, reveal, modes, a11y) |
| `site/` | Eleventy site source (not started) |
