# Sequence fixes, grades 6 to 8 social studies, 2026-11-14

The scope and sequence fixer for world-geography-and-ancient-civilizations-i (grade 6), world-geography-and-ancient-civilizations-ii (grade 7) and civics-government-and-civic-life (grade 8). It applies the expert reads (docs/reviews/sequence-<course>-2026-11-14.md), the Codex reads (docs/reviews/sequence-<course>-codex-2026-11-14.md), each course's own For the lead items, and the lead's settled calls of 2026-11-14:

- **Readiness or retrieval.** A row used the year before, or earlier the same year, opens as a retrieval task inside a day. Every other earlier-grade row the unit assumes (last used two or more grades back) opens the unit with a readiness check on its first day. This follows the lead's clarification, which overrides the expert's "two whole grades with no use" reading where the two differ.
- **Held days.** Held look-back days stay as days.csv has them.
- **Checks.** A course-level check does not repeat the end-of-unit assessment just before it.
- **Coverage.** Every end-of-unit assessment and check asks about each part of each code it lists.

Files changed, for each course: docs/courses/<course>/scope-and-sequence.md, data/plans/<course>/days.csv and docs/courses/<course>/frame.md. No course has a source-map.csv. No day was added, and every unit keeps its length.

Changes made in every course:

- **Rule 4.** A general paragraph now states rule 4 (each part of each code, with the product or performance that stands for a code named on the day), states the readiness rule, and points to this report.
- **Shorter path.** A new section gives two shorter routes, as FOUNDATION section 5 and adoption bar C2 require: a 45-minute route on the same days, and an about-150-day route of named fold-in days.
- **For the lead.** The items are rewritten as settled where this pass settles them.
