## Verdict

Day 19 is correct mathematics in a sound shape: one fraction renamed, both marked on one printed line, the
comparison written the long way, with error D attacked at the start and A in the fixes. The biggest risk is that
the line, the day's whole proof, is never used as a proof: neither worked example marks the first fraction before
renaming it, so "the point did not move; it has a new name" points at nothing, and the display and key never
show a marked line either (the cheap read has the display half). The one change that matters most is finding 1:
mark the first fraction before cutting, in both examples' steps and in the pairs' instruction, so every renaming
is checked by a point that stays put.

## Findings, most serious first

### 1. The first fraction is never marked, so "the point did not move" has no point

- **What is wrong.** Example 1's steps: say Kai's claim, say the parts differ, cut each third into 4, then "2/3 =
  8/12. The point did not move; it has a new name", then "Mark 7/12". 2/3 is never marked. Example 2 marks only
  9/8; 5/4 is never placed, yet the last step says "Check: 5/4 is to the right of 9/8 on the line". The pairs say
  "Rename one fraction. Mark both on the line": rename first, so a child who writes 3/4 = 3/8 (error A) marks 3/8
  and the line agrees with the wrong name.
- **Evidence.** items.csv `steps` of s03-K19-1 and K19-2; d019 student page, "Your turn". The opener's own case for
  the model: "a renaming that moved a point shows at once". That only works if the point is there before the
  renaming. Grade 4 equivalence is "the same point" (Progressions, Number and Operations, Fractions, PDF page 149
  (143), via docs/courses/math-3-5-progression.md; not reopened).
- **Cost.** The line becomes a picture of the answer, drawn after it, rather than a check on it. Error A, the
  error the fix-it and the exit both target, passes the line unseen.
- **Change.** Steps (see "Settled by the expert"): Example 1 step 2 marks 2/3 before any cut; Example 2 step 1
  marks 5/4 before any cut and step 3 says "the same point, a new name". Student page, "Your turn" becomes "Mark
  the fraction to rename. Cut its parts and rename it. Mark the other. Write the sign." (3 sentences, under 15
  words each). Teacher page, "Four more pairs": "mark the fraction to rename first, then cut, rename and mark the
  other; if the new name is not on the first point, the name is wrong".
- **Confidence.** Firm.
- **LAYER:** day. **CATCH:** expert. **REPEAT:** new. **CHEAP:** missed.
