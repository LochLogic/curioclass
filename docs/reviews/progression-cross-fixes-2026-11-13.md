## The gate change

scripts/progression.py, cross-subject check: after a lean resolves to a skill id or a code the other subject names,
the gate finds when it is taught (the skill id's grade, or for a code the earliest grade of any row that owns it or
`~` contributes to it, parent and child codes included; high school by course grade, 9 Biology and Algebra I, 10
Chemistry and Geometry, 11 Physics and Algebra II). A lean taught after the leaning row's grade FAILs, unless the row's
notes carry "Just in time:" and name the same id or code; then it is a note. The module docstring says so. Before
this pass it caught 7 leans, the same seven both readers found (six social studies, one science); after it, none, and
no row needed a "Just in time:" teach. I checked the just-in-time branch on a mocked row: without the note it fails,
with it it prints a note.
