## Findings
1. **s07-E1, item ambiguous.** Stem: "Mark the land and the water in each scene." The meadow is "Dry open ground" with no water, so a child may search for water that is not there or mark something false. Fix stem: "Mark the land and any water in each scene." The key already handles the meadow as land only.
2. **s07-E10, stem and scene disagree.** scenes-day72.md says "Nothing is hidden, cut off or unclear", yet the key answer and the correct sample say "Other kinds may be hiding or outside the picture". A child who trusts the scene and says "yes, it shows every kind" can be marked wrong for being right about the picture. Fix stem: "Could the marsh have a kind that is not in this picture? Say why." Fix key and sample: "Yes. A marsh can have kinds this picture does not show." Drop "hiding" from both. The plan's item 4 also asks the child to add a comparison to the habitat model; E10 tests only the limit, so the model half is untested (student page has "The pictures show ___", which could carry it).
3. **s07-E8, a fair alternative is keyed wrong.** Steps require "a kind both show and a kind only one shows". Alike by count ("each shows four kinds") or by type ("each has plants and animals") is fair and true, but the sample says "Names only a count" fails, and wrongs.csv row E8 marks it an omission. Fix: accept any true like and any true unlike (clover, butterfly or ant only in the meadow; willow, frog or snail only at the stream), and require one kind named for the shared-kind credit.
4. **s07-E2, key narrower than the stem.** The stem does not ask for an order. A child who says "plants first, then animals" or "top to bottom" shows a usable method. Fix: state in steps that any named order or two-pass method counts.

Minor: d072.md reads E5, E8, E9 as "first scene", "first two scenes" and E10 as "marsh pictures", while the item stems say meadow, stream edge and "marsh picture". Prompts are read once with no explanation, so use the item wording. E9's correct sample ("No, only grass is on both") does not state the equal-count reason its steps require; accept the shared-kind evidence or add "each has four but not the same four".
