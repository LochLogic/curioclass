## Course ids

Three id schemes are in use for the same courses:
- **data/courses.csv** (the catalogue): band ids, one row per course family: `math-k8`, `ela-k12`, `science-k5`,
  `science-ms`, `ss-k5`, and one-to-one high school ids (`algebra-1`, `algebra-2`, `world-hist-hs`, `us-hist-1`,
  `government` ...).
- **Frame slugs** (folders under docs/courses/, data/plans/frames.csv, COURSE_ROWS in scripts/frame.py): one per year,
  descriptive (`math-grade-4`, `science-grade-7`, `english-language-arts-grade-6`, `algebra-i`, `world-history-i`).
- **Older plan ids** (data/plans/math-4/, data/units.csv `math-4-*`, courses/math-4/): grade 4 math only.

The frames' first lines also disagree among themselves: math grades 3 to 8 and science grades 6 to 8 name the slug as
the course id, the K to 2 and elementary frames name the band id ("ela-k12 (grade 4 row)"), and the high school frames
name the courses.csv id. The mapping is one-to-many for the bands (`math-k8` to nine slugs, `ela-k12` to thirteen,
`science-k5` to six, `science-ms` to three, `ss-k5` to six) and one-to-one in high school (for example `algebra-i` to
`algebra-1`, `world-history-ii` to `world-hist-2`, `us-history-ii` to `us-hist-hs`, `civics-government-and-civic-life`
to `us-hist-8`, `world-geography-and-ancient-civilizations-ii` to `world-hist-7`).

Recommended approach (a structure call for the lead; no id was changed here):
1. Keep both, each for its job: the courses.csv id is the catalogue id (subject, band, what a family sees); the frame
   slug is the per-year course id that step 3 uses for data/plans/<slug>/ and every later file. A band id cannot name
   a year's plan, and renaming the catalogue would break check_worksheets.py and course_status.py, which read it.
2. Record the mapping once, in data: add a `catalog_id` column to data/plans/frames.csv, written by `frame.py sync`
   from a `catalog` field beside each COURSE_ROWS entry, and have `frame.py check` fail a frame whose slug has no
   catalogue row.
3. Make every frame's first line say the same thing: "Course `<slug>` (catalogue id `<catalog_id>`)". One sweep across
   the 52 frames after step 2, so the gate can read it.
4. Retire `math-4` with the grade 4 scope and sequence (the math reconcile's rework list already moves data/plans/math-4/
   and the math-4 rows of data/units.csv to the frame's units).
The high school misfits (`world-hist-hs` for grade 9, `us-hist-hs` for grade 12, `us-hist-8` for civics) are old names
the catalogue keeps on purpose (the civics frame says so); step 2 makes them harmless without renaming them.
