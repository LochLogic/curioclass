## Mission

A free, complete, open K-12 classroom toolkit: interactive tools, printables, lessons and units for every standard,
so any teacher can run a full course without paying for curriculum or software. No logins, no ads, no tracking, and
every tool works offline as a single file.

The long ambition is to stand in for what schools now buy from publishers and paid learning sites. That ambition
stays here. Public copy says "a free, complete classroom toolkit" and never names other companies (BASELINE rule 15).

## How we get there

- **Quality over speed.** Each piece is really good before the next wave grows (BASELINE rules 1 and 14). There is no
  month-by-month calendar; work moves in order, through gates.
- **Grow shared parts from finished work.** A shared engine or shell feature is promoted only after three finished
  tools need the same code (rule 13). The vision's universal shell and archetype engines arrive this way.
- **Paper is a first-class product.** Worksheets, units and Supply Closet printables matter as much as screens.
- **Honest words.** We say what a thing is: practice tools are not diagnoses, score codes are not proof.

## The pillars and where each one lives

| Pillar (from the master vision) | Where it lives | When |
|---|---|---|
| Standards spine: national frameworks, leaf standards, a state crosswalk, prerequisite maps | Tools track and The Map | The state crosswalk and leaf expansion come after the curriculum ladder starts; prerequisite maps feed The Map |
| Curriculum spine | Curriculum track: units, then Tracks, then the Binder export | Unit pilot after the worksheets go live |
| Universal shell and Projector Mode | Kit, grown from finished tools; Projector slides become part of a unit day | With the cohort kit fixes, then units |
| Teacher desk utilities (timers, noise meter, group maker, chimes) | Supply Closet: Teacher Desk shelf, with classroom music and a sound board | After the closet's current items |
| Live class sync (Class Cast) | Parked | Only with funding and someone to keep a server running |
| Adaptive practice and mastery receipts | Score codes (a code and QR a student shows; scanned locally), later | After the units pilot |
| Differentiation: accessibility bar, reading-level text, word help, sentence frames | Kit (accessibility bar), Reading Room (levels), Supply Closet: Learning Supports shelf | Accessibility bar after the cohort kit fixes |
| IEP goal bank | Parked | Needs a special-education reviewer |
| Supply Closet expansion: worksheets, printables, course cartridges, district pack | Supply Closet; worksheets and a 15-generator test group live; LMS cartridges with the Binder | Worksheets now |
| Beyond school: test prep, certifications, trades | Beyond School track | Late; ACT/SAT-style practice first, never trademarked names |

## What we will not do

- Accounts, ads, tracking or student analytics, ever.
- Claims we can't stand behind: "clinically proven", "cryptographic", or "100% coverage" stated as fact.
- Copy a branded product (an exam, a game, a curriculum) in name, look or text.
