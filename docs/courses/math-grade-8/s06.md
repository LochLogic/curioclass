## 2. Standards, limits, and what is carried

- **Compelling question (frame):** "How can one quantity determine another?"

**Hook, day 93:** Compare records, invented for practice: (2, 6), (5, 15), (7, 21), and (2, 6), (2, 9). Does each input determine one output? Discuss for eight minutes, then ask the compelling question.

**Questions:** Can inputs share an output (day 94)? How do graphs tell stories (day 98)? Which dimensions stay fixed (day 113)?

**Closing claim:** Functions assign one output per input. Volume formulas model capacity. Day 114 uses Pump model, Container decisions and fresh prompts.

**Teaching:** Model inputs on day 94, graph pairs on day 96, rates on day 101 and formulas on days 107, 109 and 112. Retrieve known linearity before day 99 practice; contrast square area on day 100. Step back during applications.

## 6. Error register

| | The error or first idea | What it shows | Source |
|---|---|---|---|
| A | Requires different outputs for different inputs. | Reverses the one-output condition. Repair: trace two inputs to a shared output while checking each input separately. | From memory. |
| B | Connects points at inputs the rule does not allow. | Treats every graph as continuous. Repair: list permitted inputs beside the points. | From memory. |
| C | Uses output change alone as the rate. | Ignores input interval length. Repair: divide output change by input change and attach units. | From memory. |
| D | Uses the first displayed nonzero-input output as the initial value. | Does not seek input zero. Repair: extend the constant-rate table to zero. | From memory. |
| E | Claims every function is linear. | Confuses dependence with constant rate. Repair: compare successive rises in a square-area table. | From memory. |
| F | Calls a positive falling graph increasing. | Reads height instead of change. Repair: track outputs as inputs increase left to right. | From memory. |
| G | Draws a straight rise for a changing rate. | Treats every increase as constant. Repair: compare vertical rises over equal horizontal steps. | From memory. |
| H | Uses the diameter as the radius. | Confuses the two lengths. Repair: mark the centre and halve the diameter. | From memory. |
| I | Uses cylinder volume for a cone with the same base and height. | Omits the one-third factor. Repair: compare supplied matching-capacity simulated observations to illustrate, not verify, the one-third relationship. | From memory. |
| J | Multiplies the base by the exponent. | Misreads a power. Repair: write each equal factor before multiplying. | From memory. |
| K | Applies a power outside its written base. | Misreads exponent scope. Repair: box the base before expanding. | From memory. |
| L | Uses another solid's formula for a sphere. | Does not connect formula to solid. Repair: match each formula to a labeled drawing. | From memory. |
| M | Gives square units for volume. | Confuses area with occupied space. Repair: label a unit cube and connect three length factors. | From memory. |
| N | Accepts two different outputs for one input. | Ignores uniqueness. Repair: hold one input fixed and require one output. | From memory. |
