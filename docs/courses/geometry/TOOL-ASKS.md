# Geometry: tool asks

What the Geometry plans ask of a tool's spec, one heading for each tool (UNIT-PLAN.md, rule 10).

## Dynamic construction view (light)

- **Mark:** light. No key tool is required in the course.
- **Day and job:** day 8 (unit 1, [s01.md](s01.md), field 8): show why. A free point moves and the intersections
  that depend on it move with it, so students see which parts of a construction are fixed and which follow.
- **Verdict:** does not exist as a built Curio Class tool (free dynamic geometry is the ideal instrument).
- **Paper path:** move the point and redraw.
- **Asks (from s01.md):**
  1. One free point that can be dragged, with every construction object built from it redrawn live.
  2. Dependent intersections marked so they can be told apart from free points.
