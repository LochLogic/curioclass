**E27 (s02-X27), withheld paper exit.** "Made-up leaflet: Lake Dell has the most fun beach. It is 3 kilometers across. An independent survey map records 2 kilometers. Write a report note separating the preference from the disputed measurement."

Shape: Write a report note separating preference and conflicting measurements; practice drafts established findings.

Key: Most fun is preference; 3 conflicts with 2. Check measurement date/method/place; neither automatically true. Look for: Separates preference; acknowledges unresolved conflict. Wrong: A liking proves a fact. (C); This evidence proves an unrelated claim. (D); Checkable means true. (L).

Key: Say inland, citing marker away from coast. Look for: Source-grounded correction for listener. Wrong: Coastal sounds better. (D).

**E29 (s02-X29), withheld paper exit.** "Made-up tram map: Market and Hill stops. Depot list: three trams. Peer explanation: The route has two stops. Only one tram runs. Repair the explanation's accuracy using these records."

Shape: Repair an unsupported operating claim from an inventory; practice addresses order and missing detail separately.

Key: The map supports two stops. The depot lists three trams, but does not say how many run. Replace the unsupported one-running claim with the listed count or say the running count is unknown. Look for: Sourced repair distinguishing depot inventory from number running. Shape: repair one unsupported operating claim from a held inventory. Practice comments on order and missing details, never repairs an operating-count inference. Wrong: Good because short. (H); Three trams must run because the depot lists three. (D).
