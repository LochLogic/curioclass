- **E27, Lake Leaflet, invented:** "Lake Dell has the most fun beach. It is 3 kilometers across." An independently made survey map records 2 kilometers. "Write a report note separating the preference from the disputed measurement." Key: most fun is opinion; 3 conflicts with 2 and needs checking, not automatic acceptance of either source. Meets: "Most fun is preference. The widths disagree, so I must check the measurement." Not yet: "Printed means 3 is correct." Wrong: preference as verified information (C); unsupported measurement (D); checkable means true (L).
  Shape: draft a source-aware report note about conflict/preference. Practice drafts a six-topic country report from consistent notes, never a mixed leaflet or conflicting lake measurements. The exit measures a drafting decision.
- **E28, Research Case, invented:** a new keyed map locates Moss Town inland; a report calls it coastal. "Write a speaker note correcting the report with map evidence." Key: inland, citing its marker away from the coast. Meets: "The map puts Moss Town away from the coast, so I will say inland." Not yet: "Coastal sounds better." Wrong: unsupported location (D). Teacher also hears every child's finding/question response during the presentation block.
  Shape: prepare a source-grounded correction for a listener. Practice presents consistent findings, never corrects an inland/coastal conflict or teaches Moss Town.

The depot lists three trams, so replace one with three." Not yet: "It is good because it is short." Wrong: liking alone (H); retain unsupported count (D).
  Shape: supported strength plus sourced accuracy repair. Practice handles only order or missing detail, never this paired strength/accuracy response, tram case or count. Separate retained slips evidence order/detail, not extra exit asks.
