## 9. Supports and extension

Words: layer, a map sheet showing one kind of information; reservation, land set aside for a nation; confinement, being held without freedom to leave; forced removal, movement imposed against people's choice. Distinguish this map sense of layer from archaeological layers. Frame: "This dated layer shows __." Cards at most 70 words, read aloud; independent print within DEFAULTS. Neutral descriptions/tactile lines/dictation preserve choices. Private hard-history discussion, same goal. No personal histories/sacred designs/invented Native people. Extension tests a boundary date against another source.
