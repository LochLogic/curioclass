## 3. Checks, written first


**Owned:** Q2. Single component scale: shown, shown with help, not yet seen. All individual exits are paper, every child responds.

**Q2 Shape:** locate two sites with a dated culture-region map, classify four unseen photographs with visible support, infer coordinated work, distinguish shading from borders. No teaching/practice combines those tasks, uses C/D images, or completes a four-image classification. Cold conditional key: on the specified broad-category map, Mesa Verde is Southwest and Cahokia Eastern Woodlands; the finished map must support that key. Flaked stone edge, formed clay, built earth terraces and joined cliffside masonry support the four material identifications. Large construction suggests coordinated work, not a named ruler or belief. Shading is not a nation's border. Meets: "The joined rooms show skilled building. Shading groups cultures; it does not mark one government." Not yet: "Everyone inside the color had one religion." Wrong: region is nation (D); object proves belief (E); one object proves everyone's work (P).
