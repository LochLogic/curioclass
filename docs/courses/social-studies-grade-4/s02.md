## 6. Error register

| | The error or first idea | What it shows | Source |
|---|---|---|---|
| A | Only agreeing sources should be selected. | Different experiences are excluded. | from memory |
| B | A date, official maker or table guarantees usefulness. | Origin, structure and context are not connected to the question. | from memory |
| C | Every printed sentence states a fact. | Preference is not distinguished from a checkable statement. | from memory |
| D | A finding need not match checked source evidence. | A guessed or misread detail is accepted without checking. | from memory |
| E | Imports and exports are unrelated lists. | Specialization and increasing mutual reliance are missed. | from memory |
| F | Everyone in a country gains or loses together. | Group effects and purchase changes are missed. | from memory |
| G | An unsupported preference is a claim supported by evidence. | Evidence and reasoning are absent. | from memory |
| H | Critique means liking an explanation. | Order, supporting detail and accuracy are not evaluated. | from memory |
| I | One language, industry or identity describes everyone in a country. | A sample erases differences within a population. | from memory |
| J | The most attractive source is the most useful. | Appearance replaces relevance to the question. | from memory |
| K | One opinion invalidates every statement in a source. | Credibility is not judged statement by statement. | from memory |
| L | A checkable statement must be true. | A factual claim is accepted before verification. | from memory |
| M | Indigenous peoples belong only to the past. | Present communities and agency are erased. | from memory |
| N | Naming two sources means using evidence from both. | Titles replace distinct source details. | from memory |
| O | Each trading country supplies every need alone. | Exchange and growing reliance are missed. | from memory |
| P | The question matters only because I like it. | Another person's need is absent. | from memory |
| Q | A promotion's claim shows who benefits. | A seller's purpose replaces evidence of effects. | from memory |

## 8. Tools and supplies across the unit

**Tools: None.** No spec or TOOL-ASKS.md is needed. Supply printed maps, atlas pages, dated source cards, note logs, pencils and record sheets. Print digital sources with their metadata; a shared screen is optional. At home the adult is the partner. No student timer is shown.
