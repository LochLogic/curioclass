# Unit 4: Voyages and conquest

Course `social-studies-grade-4` (Grade 4: North America, Its Land and Peoples). **Days 60 to 79** (20 course days; school days 60 to 79, weeks 12 to 16). Sections: 4.1 (days 60 to 63); 4.2 (days 64 to 67); 4.3 (days 68 to 70); 4.4 (days 71 to 74); 4.5 (days 75 to 79). Days by kind: understanding 12, fluency 2, application 4, check 1, respond 1. A plan, not a lesson: nothing here is built or tried with children. Fields follow UNIT-PLAN.md.

This course does not assign major, supporting or additional weights.

## 2. Standards, limits, and what is carried

- **Compelling question (frame):** "What did the voyages of the 1400s and 1500s mean for the people already here?"
- **Hook, day 60:** compare Columbus's claim of possession with the Taíno public account of their homeland. Could the same arrival mean different things? Who needs an accurate account?
- **Co-write on day 60:** How do sources help us know (61 to 64)? Why sail (65)? What changed for people here (66 to 72)? What happened together (73 to 74)?
- **Closing, day 76:** answer the compelling question in two linked paragraphs using the Voyage Accounts and Living Peoples packets. Defend an emphasis on conquest, exchange or continuing Native agency with two named sources.
- **Teaching:** model sourcing on 62, independence on 67 (modelled first), a cause and its effects on 68, scale on 73 and reasoning on 75. On 76 students work without a teacher model. Return to the question board after each supporting answer.

## 6. Error register

| | The error or first idea | What it shows | Source |
|---|---|---|---|
| A | A contemporary drawing must be an eyewitness picture. | Source date is confused with the artist's access to events. | from memory |
| B | One source answers every historical question. | Specific contributions and limits are missed. | from memory |
| C | European arrival meant the land was empty. | Existing societies are erased. | from memory |
| D | Voyages had one harmless motive. | Trade, resources, colonies and empire are disconnected from incentives and power. | from memory |
| E | Exchange benefited everyone equally. | Different effects and unequal power are missed. | from memory |
| F | Equal event gaps mean equal time gaps. | Timeline space is not proportional to elapsed time. | from memory |
| G | Simultaneous events must happen in the same place. | Shared time is confused with shared location. | from memory |
| H | Today's reader was the intended audience. | Audience is not inferred from the source's historical clues. | from memory |
| I | A claim is a preference. | A liking does not answer the compelling question through evidence. | from memory |
| J | Two source titles count as evidence. | Citation replaces evidence and reasoning. | from memory |
| K | Copied accounts provide independent confirmation. | Dependence between records is overlooked. | from memory |
| L | Disease explains every Native loss. | Violence, forced labor and political decisions are omitted. | from memory |
| M | A source label alone establishes purpose. | Internal clues are not used to infer purpose. | from memory |
| N | A European claim proves Native consent. | Outside assertion is mistaken for agreement. | from memory |
| O | Native peoples vanished after conquest. | Living communities and agency are erased. | from memory |
| P | Simultaneous events caused each other. | Temporal overlap is substituted for causal evidence. | from memory |
