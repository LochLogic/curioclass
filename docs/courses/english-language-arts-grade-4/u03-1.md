## 9. Supports and extension

Words: canal, survey, route, labor, benefit, cost, point, reason, evidence. Frame: "This supports ___ because ___." Herculean means great effort; memorial means petition, not monument. Read directions aloud; scribe content without supplying reasoning. Keep independent reading independent. Read listening twice, collect paper before revealing print. Describe display layout without interpreting it. Public passing is allowed; every child returns paper. Enlarge source labels/directions and provide bilingual glossaries. One marking scale throughout: shown, shown with help, not yet seen. Keep criteria separate; no points or totals.

Printed directions, new cards and exit stems have punctuated sentences of at most fifteen words. Each student page and each separate reading leaf stays within 350 words including its stimulus. Core texts use separate registered reading leaves, divided at coherent boundaries; older primary quotations stay intact with shared reading support. No invented summary replaces a core text. Extension: support another interpretation using the same text.
