**E48.** Reserved independent paper. Print s03-X48: "Invented for practice. Spoken directions are missed across a room with background talk. A sender proposes written marks instead. Explain why this problem needs research. Explain what the receiver needs to read the marks."

Key: Research must check whether marks are distinguishable across the route and background. Sender and receiver need agreed meanings and reading order.

Wrong: Any receiver understands marks without a shared rule. (E); Success in one condition proves success everywhere. (D).
Shape: explain research need/decoding agreement from unfamiliar failed-speech proposal. Practice locates source statements and traces an already agreed chain, no failed-speech diagnosis or paired why/what template.

**E49.** Reserved independent paper. Print s03-X49: "Invented for practice. A desk sender needs WAIT and COME messages across a room. Only paper and one flashlight are available. Both messages must arrive correctly. Draw two different complete patterned solutions. Label their success criterion and material limit."

Key: For example: triangle WAIT/circle COME with blank gaps; one steady light WAIT/two displays COME with dark gaps. Both messages arrive correctly; only paper and one flashlight. Accept other feasible complete rules.

Wrong: Any receiver understands marks without a shared rule. (E); The prettier system performs better. (F).
Shape: two complete two-message sketches with criterion/limit. Practice generates three-message code tables and compares rules orally, no paired two-message drawing frame.

**E50.** Reserved independent paper. Print s03-X50a: "Invented for practice. The square picture is black-white above white-black. Use 1 for black and 0 for white. Read each row left to right, top row first. Encode this picture." Print s03-X50b: "Invented for practice. The sketches show two proposed systems. Revise both sketches so repeated messages have clear boundaries and a shared key."

Teacher stimulus: U's key shows one diamond LOOK, two LIFT, three LOWER. Its sending strip joins repeated messages without blank intervals. V uses one/two/three steady-light displays with the same meanings. Short dark gaps divide displays within messages; no longer boundary divides messages. Do not label the missing boundaries as the fault.

Key: 1001. U retains its meanings and adds blank-card intervals between messages. V retains its meanings and adds agreed dark intervals between messages. Both ends share complete keys. Accept other workable agreed boundary markers.

Wrong: Digits can be read in any order. (E); Any receiver understands marks without a shared rule. (E).
Shape: encode two-by-two picture and repair two boundaryless systems. Practice encodes only three-cell strips and assembles correct systems, no square or boundaryless pair.

## Day 49

**Goal:** I can generate and compare two patterned message solutions. **Kind:** Understanding.
Before class: print this section's teacher-key.md for the adult only. Print proposals.md and exit-d049.md. Keep future reserved cases sealed. Frame cards are stimuli on the student page; exit responses use a separate half sheet.

- **5 min. Return and repair.** E48 E with three-symbol teaching key, not exit case. Tools: None.
- **10 min. Criteria and limits.** Five minutes E48 D if needed; then agree five correct messages within 30 seconds, shared kit/safe route. Teach accuracy as number correct, duration as elapsed sending time. Systems, not children, are timed.
- **5 min. Code teaching.** BEND/ROLL/PRESS use one/two/three gentle taps. Short gaps separate taps within a message; long silence separates messages. State rule explicitly. Not a required team solution.
- **20 min. Generate and compare.** Every child proposes two three-message rule tables, one visual and one sound/visual alternative. Include small symbol sketches, meanings, boundary rule and allowed parts in each table. Compare distinguishability orally. Teacher hears six within five minutes; retain all tables. No paired two-message sketches.
- **5 min. Exit E49.** Independent reserved desk proposals.

**Shape:** Practice uses three-message rule tables with symbol cells and oral comparisons. E49 alone draws two complete two-message solutions with criterion and material limit.
