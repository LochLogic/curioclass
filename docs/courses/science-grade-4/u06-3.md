# Section 6.3: Plant parts work together


## Header

<!-- skel -->

- **s06-X107.** Invented for practice. rooted diagram shows uptake, internal paths and leaves. Separate rootless flower-stem record shows color above waterline. Explain how both sources support interacting plant parts. State what the cut stem alone cannot show.
