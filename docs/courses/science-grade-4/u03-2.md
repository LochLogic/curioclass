**E45.** Reserved independent paper. Print s03-X45: "Invented for practice. Use the fabric and linked-cart frames. Draw each dot's local motion with labels showing what travels through both materials."

Teacher stimulus: fabric dot above/below one floor mark; cart dots ahead/behind their separate fixed marks. Successive humps/bunches advance right. No motion arrows, directional words or explanation captions. Keep this two-material record separate from item 1's three fabric records.

**E46.** Reserved independent paper. Print s03-X46: "Invented for practice. Use pool records X and Y. Revise both faulty models with evidence labels comparing the waves."

Teacher stimulus: equal-scale rest lines and peak spacing; X has larger peak displacement and ring range. Ring positions remain beside fixed markers. Faulty models show wallward ring motion. Leave the observation frames uncaptained.

Key: Both rings stay local. X has greater amplitude; spacing is equal. Pattern and energy travel without carrying rings to the wall.

Shape: repair a paired drifting-ring model and explain amplitude contrast. Practice uses correct single-feature statements, no pool/ring pair or drift repair. This differs from item 1's three-pattern fabric model.

**E47.** Reserved independent paper. Print s03-X47: "Invented for practice. Use these rubber-strip frames and the faulty model. Repair the point's motion arrow using evidence from the frames."
