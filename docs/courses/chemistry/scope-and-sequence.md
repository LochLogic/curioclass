# Scope and sequence: Chemistry

Course `chemistry`, grade 10, draft, fixes applied 2026-11-15.

The day record is [days.csv](../../../data/plans/chemistry/days.csv): 160 daily meetings of 50 minutes over 32 weeks, with 149 days in the frame's 11 units and 11 course-level check and respond days. Course day and school day coincide, so `school_day` is blank. Unit order, ownership and lengths follow the frame. Section divisions wait for unit planning, so each unit currently uses `<unit>.1`.

Each unit begins with the frame's phenomenon, a question board and an initial explanatory model. New evidence changes that model before students use the consensus model in a transfer task. Daily notebook evidence informs instruction. The end-of-unit assessment uses an unseen case and has a separate respond day inside the unit. Response is counted once. No unit exceeds 25 days, so none requires a mid-unit assessment; investigations, model revisions and design trials provide evidence between the opening and final assessment.

Every code listed in an assessment row requires evidence for all its parts, including the practice, core ideas, crosscutting element and attached nature-of-science or technology elements, within its boundary. A short linked prompt or a named retained product supplies each part. Course-level checks sample the year: partial samples are named in notes and omitted from the codes column, never claimed as full performances. Practical and computational portfolios supply performances that cannot be demonstrated by a written answer alone. An unfinished practical performance is recorded as owed, never credited from interpreting supplied results. Unit plans will write items, scoring guidance and precise timing, not add days. The coverage commitments below use the progression and the expectation dimensions in `data/standards/ngss-pe-dimensions.csv`; state-framework references are crosswalks only.

## Shorter path
