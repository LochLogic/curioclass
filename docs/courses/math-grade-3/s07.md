## 2. Standards, limits, and what is carried

- **Compelling question (frame):** "How do we measure, and how do we solve problems with measurements?"
**Hook, day 117:** Invented for practice: a paper strip ends between two whole-inch marks. Can whole inches tell its length precisely? Discuss for five minutes, then pose the compelling question. Adapt source lesson 1's need for fractional measurements.
**Supporting questions:** What do ruler spaces measure (day 118)? How can a plot preserve every measurement (day 121)? Which unit fits this quantity (day 124)? How can a line show passing time (day 126)? What does each number mean (day 128)?
**Closing claim:** "I can measure, display lengths, read minute times and solve measurement problems with units." Fractional Length Record, Measurement Record and Minute Problems supply evidence on day 132.
**Teaching:** Model equal ruler intervals on days 117 to 118, scale readings on days 122 and 124, and moving clock hands on day 125. Step back for independent measuring on day 121 and operation choices on days 129 to 131. Ask students to check answers against their quantities.

| A | Starts measuring at the ruler edge rather than zero. | The origin is misplaced. Repair: align the object with zero and trace its length. | from memory |
| B | Counts ruler marks as measured lengths. | Points are confused with intervals. Repair: bracket and count the spaces from zero. | from memory |

| D | Plots only one mark for a repeated measurement. | Distinct values replace individual observations. Repair: cross off each recorded object as its mark is placed. | from memory |
| E | Chooses a mass unit that contradicts the object benchmark. | The mass unit does not fit the benchmark. Repair: compare the object with gram and kilogram reference objects. | from memory |
| F | Reads a vertical scale by counting marks without their interval value. | The increment is ignored. Repair: label successive intervals before locating the level. | from memory |
| G | Names the approaching hour before the hour hand reaches it. | The hour is rounded upward. Repair: move the hour hand continuously from the previous hour. | from memory |
| H | Reads the nearby clock numeral as the minute count. | Hour labels replace minute units. Repair: label five-minute groups and count remaining ticks. | from memory |
| I | Treats an hour boundary as one hundred minutes. | Decimal regrouping replaces clock intervals. Repair: split a minute jump at the next hour. | from memory |
| J | Chooses an operation without identifying the quantity relationship. | The unknown and problem structure are ignored. Repair: label the unknown on a tape before writing the equation. | from memory |
| K | Fails to compose a ten in an addition. | Ten ones are not exchanged for one ten. Repair: reconnect a place-value drawing to the written sum. | from memory |
| L | Omits the measurement unit from an answer. | The number is detached from its quantity. Repair: read the answer aloud with its unit and label the equation. | from memory |
| M | Renames one half as one fourth. | Subdivision changes the amount instead of its name. Repair: align equal wholes and recount the two fourths covering one half. | from memory |
| N | Writes a whole number as its reciprocal. | Whole counts are placed in the denominator. Repair: label each whole inch as one part of size 1/1. | from memory |
