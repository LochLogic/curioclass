## The day as the scope and sequence sets it

<!-- skel -->
- **Goal:** Ask and answer school-text questions and explain a character response.
- **Note:** Complete the last 15 five-minute reading/word conferences, 75 teacher minutes, with successive reading as on day 75; each child is heard only once across the window. A separate 20-minute class station uses a fresh short school story, article and teacher-read school message: compose and answer a text question for each text kind, answer across all six question words, describe the character response and recount the heard key ideas. Texts draw on earlier unit 1 content; this is no fossil narrative, edit or article-structure assessment. Record current reading range as a growth sample, not the completed year-end expectation. No second spelling station.  Reserved selection ids: g2-check1-story/article/message.
