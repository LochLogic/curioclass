## Day 160

**Application.** I can write a riddle and explain my learning.

- **5 min. Warm-up.** Return E159. Mix familiar facts and a tens sketch.
- **15 min. Riddle writing.** Choose a private card from the practice deck. Each child writes, draws or dictates two clues for their own numeral. For example, 51 has five tens and one one. Keep the answer on the back and the reserved cards out of the deck.
- **10 min. Try a partner's riddle.** Each partner gets a turn reading or showing clues and a turn testing the other riddle. Check the private numeral after both clues have been tried. Offer names 25 to 30 up to one 45-second reason turn apiece during this part while the other pairs work.
- **5 min. R2 revision.** Return feedback to every child. File the revision with the original.
- **10 min. Record closure.** Children do familiar paper puzzles. With feedback and earlier judgments already in the folders, allow twenty seconds per child to check the revised part and close the record. Carry any missing part forward as missing.
- **5 min. Exit ticket.** s08-X160. Keep the riddle in one bordered response area and the first marks unscored. Use the same picture and cue on a half slip with one bordered area. Return slips with descriptive feedback before class ends.

## 8. Practice that returns

## 9. Supports and extension

On 158, point to tens as joined groups of ten and ones as single pieces. Call one written number mark a digit. Show which group each digit counts after the trade. Review zero from Kindergarten 2.4 as none, here no loose ones. Show a trade by crossing out ten singles and joining a stick of the same amount. Name a clue as a hint the number must fit. Use “Both clues fit because ___.” Read aloud and offer high contrast, tactile strips, a pointed mark or neutral dictation. Extend by finding a second clue pair for a practice number within 99.
