## 1. Standards and practices

<!-- skel -->
- **1.NBT.A.1** (days 126, 127, 128): Count to 120, starting at any number less than 120. In this range, read and write numerals and represent a number of objects with a written numeral.
- **1.MD.A.2** (days 126, 127, 128): Express the length of an object as a whole number of length units, by laying multiple copies of a shorter object (the length unit) end to end; understand that the length measurement of an object is the number of same-size length units that span it with no gaps or overlaps. Limit to contexts where the object being measured is spanned by a whole number of length units with no gaps or overlaps.
- **1.MD.A.1** (days 126, 128): Order three objects by length; compare the lengths of two objects indirectly by using a third object.
- **1.OA.A.1** (days 127, 128): Use addition and subtraction within 20 to solve word problems involving situations of adding to, taking from, putting together, taking apart, and comparing, with unknowns in all positions, e.g., by using objects, drawings, and equations with a symbol for the unknown number to represent the problem.
- skill m1-count-to-120 (grade 1)
- skill m1-measure-length-units (grade 1)
- skill m1-order-compare-length (grade 1)
- skill m1-all-problem-types (grade 1)
