## 1. Standards and practices

<!-- skel -->
- **1.NBT.A.1** (days 118, 119, 120): Count to 120, starting at any number less than 120. In this range, read and write numerals and represent a number of objects with a written numeral.
- **1.MD.A.2** (days 118, 119, 120): Express the length of an object as a whole number of length units, by laying multiple copies of a shorter object (the length unit) end to end; understand that the length measurement of an object is the number of same-size length units that span it with no gaps or overlaps. Limit to contexts where the object being measured is spanned by a whole number of length units with no gaps or overlaps.
- skill m1-count-to-120 (grade 1)
- skill m1-measure-length-units (grade 1)
- skill mk-count-sequence (grade K, earlier grade: review, never taught as new)
- skill mk-count-to-20 (grade K, earlier grade: review, never taught as new)
- skill mk-one-to-one (grade K, earlier grade: review, never taught as new)

<!-- skel -->
> (shared across the unit) Read all prompts aloud; require no independent reading. Pair longer, shorter, unit, whole and unknown with pictures.
