## 1. Standards and practices

<!-- skel -->
- **1.MD.A.2** (days 115, 116, 117): Express the length of an object as a whole number of length units, by laying multiple copies of a shorter object (the length unit) end to end; understand that the length measurement of an object is the number of same-size length units that span it with no gaps or overlaps. Limit to contexts where the object being measured is spanned by a whole number of length units with no gaps or overlaps.
- skill m1-measure-length-units (grade 1)

>
> - **Practices:** MP.5, day 115, Valid measurement: select identical units and justify an arrangement. MP.4, day 122, Missing length: redraw matched cubes as labelled bars, locate the unknown and check the equation against the story.
