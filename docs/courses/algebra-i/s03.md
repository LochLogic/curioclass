## 2. Standards, limits, and what is carried

- **Compelling question (frame):** "When does knowing one quantity help us predict another?"
Day 47 opens with eight minutes sorting twelve shape cards, invented for practice: six blue round, two blue square, one yellow round and three yellow square. Each card occupies one cell. By day 58, students can defend a prediction while distinguishing categorical association, linear fit and causal evidence. Use the day 56 strip-length model, day 57 institution investigation and fresh frequency and interpretation items.
Model denominators before comparison and demonstrate regression after day 50's hand fit. Day 51 rehearses those operations; introduce signed residual plots on day 52. Step back for model validation on days 56 and 57.

| A | Divide a joint count by a row total. | The full population is missing. Day 49 contrast 6/12 joint with 6/8 conditional; shade the full table once. | from memory |
| B | Divide a marginal count by an opposite column total. | The marginal whole is wrong. Day 49 contrast 8/12 with 8/7; circle the grand total. | from memory |
| C | Use the grand total instead of the conditioning-group total. | The conditioning group is lost in row or column proportions. Day 49 contrast 6/12 with 6/8; cover everything outside the given group. | from memory |
| D | Reverse the conditioning direction. | The given group is misread. Day 49 contrast 6/8 with 6/7; name the given group before dividing. | from memory |
| E | Subtract observed from predicted. | Residual sign is reversed. Day 53 contrast predicted 16 minus observed 19 = -3 with observed minus predicted = 3; trace upward from the line. | from memory |
| F | Treat zero residual sum as proof of good fit. | Pattern is ignored. Day 54 contrast residuals 2,-2,-2,2 with a randomly scattered set; inspect the curved pattern. | from memory |
| G | Call a large negative coefficient weak. | Sign is confused with strength. Day 55 compare -0.88 with 0.24 using distance from zero. | from memory |
| H | Read correlation as a percentage of correct predictions. | The coefficient's meaning is replaced. Day 55 contrast that claim with negative direction and linear tightness; return to a plot. | from memory |
| I | Infer causation from association alone. | Competing explanations are absent. Day 56 contrast an observed claim with an alternative common influence; draw two arrows from that influence. | from memory |
| J | Fit a decreasing line to an increasing cloud. | Direction is ignored. Day 57 contrast positive and negative slopes on the same supplied practice plot; follow left to right. | from memory |
| K | Report a model prediction as exact. | Fit uncertainty is ignored. Day 57 contrast "must be 31 centimeters" with "about 31 centimeters"; compare predictions with observed outcomes. | from memory |
| L | Treat an out-of-range prediction as verified. | Observations' domain is ignored. Day 57 mark the observed input interval before interpreting zero or distant inputs. | from memory |
