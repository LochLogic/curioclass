## 2. Standards, limits, and what is carried

- **Compelling question (frame):** "What did 'liberty' mean in each document, and how did each writer's words change what it means?"
**Hook, day 112:** Set the Declaration's equality claim beside its charge against Native peoples, with the slur omitted and disclosed. How can one document make both claims?
**Questions:** Whose wrongs test Harper's shared liberty (113)? How does the trial's register differ from the dispatch (116)? What does Joseph's horse-sale analogy show about consent (117)? How does Roosevelt extend liberty (118)?
**Closing claim:** The day 126 argument uses Harper, Anthony, Joseph and the federal packet to judge what public voting guidance should explain.
Model related themes on 112 and cumulative diction on 115; partners reread on 116 and 119. Daily talk uses written evidence, a partner's challenge and a qualified synthesis. Seminars on 120 and 124 add student-set rules, goals, deadlines, roles and invitations; the teacher records individual evidence.
