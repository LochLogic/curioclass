## 1. Standards and practices

<!-- skel -->
- **2.MD.B.5** (days 44): Use addition and subtraction within 100 to solve word problems involving lengths that are given in the same units, e.g., by using drawings (such as drawings of rulers) and equations with a symbol for the unknown number to represent the problem.
- **2.MD.A.4** (days 44, 48): Measure to determine how much longer one object is than another, expressing the length difference in terms of a standard length unit.
- **2.MD.A.1** (days 45, 46, 47, 48): Measure the length of an object by selecting and using appropriate tools such as rulers, yardsticks, meter sticks, and measuring tapes.
- **2.MD.A.3** (days 45, 46, 47, 48): Estimate lengths using units of inches, feet, centimeters, and meters.
- **2.NBT.B.5** (days 45): Fluently add and subtract within 100 using strategies based on place value, properties of operations, and/or the relationship between addition and subtraction.
- **2.MD.A.2** (days 47): Measure the length of an object twice, using length units of different lengths for the two measurements; describe how the two measurements relate to the size of the unit chosen.

- skill m2-fluency-within-100 (grade 2)
- skill m2-unit-size (grade 2)
