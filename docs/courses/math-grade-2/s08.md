## 2. Standards, limits, and what is carried

- **Compelling question (frame):** "How can equal groups help us count?"
**Hook, day 132:** In five minutes, share eleven pictured counters between two drawn trays. Can both trays hold the same number without splitting counters? Connect the leftover to the compelling question. Adapt the first source lesson using objects rather than children or food.
**Questions:** What remains after pairing, day 133? Why do doubles give even totals, day 135? How can rows and columns describe one total, day 139? How do equal squares fill a rectangle, day 142?
**Closing claim:** Equal groups organize a count. Use P to justify parity, R to partition and count a rectangle, and A to express an array total with equal addends; close on day 143.
**Teaching:** Model pairing and record the matching sum. Compare a complete pairing with one leftover. On day 135, rehearse why another pair preserves two equal groups. Step back for explanations on day 136. Model rows before columns; on day 141 demonstrate and practise a complete rectangle partition before independent work on day 142.

<!-- skel -->
- **2.OA.C.3:** Determine whether a group of objects (up to 20) has an odd or even number of members, e.g., by pairing objects or counting them by 2s; write an equation to express an even number as a sum of two equal addends. Parts, by verb: whole standard.
- **2.OA.B.2:** Fluently add and subtract within 20 using mental strategies. By end of Grade 2, know from memory all sums of two one-digit numbers. Parts, by verb: whole standard.
- **2.G.A.2:** Partition a rectangle into rows and columns of same-size squares and count to find the total number of them. Parts, by verb: whole standard.
- **2.OA.C.4:** Use addition to find the total number of objects arranged in rectangular arrays with up to 5 rows and up to 5 columns; write an equation to express the total as a sum of equal addends. Parts, by verb: whole standard.

## 6. Error register

| | The error or first idea | What it shows and one repair | Source |
|---|---|---|---|
| A | A collection with one leftover is called even. | The unmatched object is ignored. Circle it and compare with a completely paired collection. | from memory |
| B | Unequal addends are presented as equal halves of an even total. | Equality of the parts is not checked. Match one object from each part until both end together. | from memory |
| C | Add the number of rows to the number of columns for the total. | Dimensions replace counts of objects. Circle each row and write its object count once. | from memory |
| D | Add a complete row total and a complete column total together. | The same objects are counted twice. Cross off each object after its first count. | Operations progression, page 24 |
| E | Partition with unequal widths. | The repeated square is not held constant. Trace the same paper square along each edge before joining marks. | Geometry progression, page 11 |
| F | Count only the outside squares. | Interior squares are omitted. Shade and count one complete row at a time. | from memory |
| G | Use a double for a near-double sum without adding the extra one. | The unequal addend is treated as equal. Show the known double and attach its one extra object. | from memory |
| H | Add the operands in a subtraction. | The operation's meaning is lost. Use a pictured total and cross out the subtracted part. | from memory |
| I | A remembered example is offered as a general reason. | The claim is unsupported beyond that example. Draw one new pair giving one counter to each equal group. | from memory |
