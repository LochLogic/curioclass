## 2. Standards, limits, and what is carried

- **Compelling question (frame):** "Which way to add or subtract makes the most sense here, and why does it work?"
**Hook, day 20:** Show 42 and 21 with paper tens and ones. Which method finds their difference without counting every one? Children mark paper pictures before sharing. This five-minute task opens the question.

**Supporting questions:** How does a missing part become subtraction, day 21? What stays equal when a ten is exchanged, day 24? Why do different groupings give the same sum, day 30? When are two steps necessary, day 34?

**Closing claim, day 38:** "I can choose and explain a strategy, calculate within 100 and represent a story's steps." E, M, T, S and F supply evidence.

**Teaching:** Model like-unit calculation on day 20 and exchanging on day 24. On day 26 compare 64 - 22 with 64 - 27. Day 27 models four-addend grouping; day 28 connects drawings to equations. Model every one-step subtype on days 22 and 31 to 33, including both opposite-language comparisons. Model two steps on day 34, then step back for partner stories on day 35.

## 6. Error register

| | The error or first idea | What it shows | Source |
|---|---|---|---|
| A | Drops the new ten after combining ones. | The composed ten is not included in the total. Repair: circle ten drawn ones and transfer that value to the tens. | From memory |
| B | Subtracts the smaller digit from the larger in each column. | Digits are treated as unrelated numbers. Repair: represent the whole starting amount and exchange before removing the specified amount. | From memory |
| C | Keeps the original tens after exchanging one for ten ones. | The exchanged ten is counted twice. Repair: cross out that ten when its ten ones appear. | From memory |
| D | Applies the wrong operation to the two given quantities in a one-step story. | The unknown's relationship to the total is not identified. Repair: label the total and parts before choosing a calculation. | From memory |
| E | Chooses an operation from more or fewer in an opposite-language comparison. | A keyword replaces the quantity relationship. Repair: name the larger amount and align the two tapes first. | From memory |
| F | Stops after the first action in a two-step problem. | The first result is mistaken for the requested quantity. Repair: annotate the second action on the first drawing. | From memory |
| G | Omits an addend from a four-addend total. | Not all quantities are tracked. Repair: tick each original addend once as it enters a grouping. | From memory |
| H | Gives a result or procedure without explaining preserved value. | A why question is answered only with steps. Repair: connect one written step to equal quantities in a drawing. | From memory |
| I | Splits a total into parts whose sum differs from it. | The whole is not conserved. Repair: enclose both parts in the original total's outline. | From memory |

Assign letters only when the child's work shows the stated thinking. An unexplained numerical error stays unclassified. Apply each repair separately and return to the original grade-level demand with fresh numbers.
