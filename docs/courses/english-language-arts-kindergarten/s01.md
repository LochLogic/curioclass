The opinion piece sits here because the base text teaches and first checks W.K.1 here, on the classroom toys the children prefer, and the kindergarten standard asks only a topic and an opinion, so it needs no earlier model; it starts claim-evidence-reasoning, which unit 4's author reasons build on. The informative piece needs only the main-idea-details model introduced in this unit.
