## 2. Standards, limits, and what is carried

- **Compelling question (frame):** "How have the founders' words been reasoned with in the courts, and who has won by them?"
Open 103 with Madison's definition of faction beside Brown's school-segregation holding. Ask how a constitutional safeguard becomes a reason for a judgment. Introduce the compelling question before retrieval.
Supporting questions: how does Madison narrow faction (104)? How does Walker turn the Declaration against exclusion (106)? What changes between Plessy and Brown (110)? Which assumptions divide the Tinker opinions (112)?
On 119 submit a mock opinion deciding whether the school could punish the speech described in Mahanoy, using its facts, constitutional clauses and Tinker. Defend a bounded claim and the strongest counterclaim, then explain changes after reading the actual decision.
Model premise, principle, inference and limit on 103; trace terms on 104; compare documentary purposes on 106 to 108. Model competing reasoning on 109 and structural effectiveness on 111. Students take over discussion and revision on 112 to 116.

## 6. Error register

| | The error or first idea | What it shows | Source |
|---|---|---|---|
| A | A dissent states the binding holding. | Confuses competing reasoning with disposition. On 110 contrast the majority disposition with the dissent label; relabel a fresh paragraph. | Anticipated from task analysis, untested. |
| B | A technical key term keeps its everyday meaning. | Ignores contextual refinement. On 104 compare the definition and later use; write a bounded meaning. | Anticipated from task analysis, untested. |
| C | A confident textual claim settles what remains unproved. | Overstates evidence. On 109 separate explicit claim, supported inference and uncertainty using two locations. | Anticipated from task analysis, untested. |
| D | Naming structural parts evaluates their effectiveness. | Omits the reader effect. On 111 contrast a part label with an explanation of clarity, convincingness and engagement. | Anticipated from task analysis, untested. |
| E | Dates alone explain a documentary comparison. | Omits textual relationships. On 108 connect a located rhetorical feature to changed purpose. | Anticipated from task analysis, untested. |
| F | A topic is a precise claim. | Leaves no position to test. On 114 turn a broad topic into a bounded disposition. | Anticipated from task analysis, untested. |
| G | Dismissing a counterclaim develops it fairly. | Evades opposing evidence. On 114 write the strongest supported opposing reason before answering it. | Anticipated from task analysis, untested. |
| H | A transition word guarantees a logical connection. | Masks the relationship. On 114 name the actual concession before choosing its connective. | Anticipated from task analysis, untested. |
| I | Insulting a speaker establishes an objective evaluation. | Substitutes abuse for analysis. On 115 replace the insult with an attributed textual finding. | Anticipated from task analysis, untested. |
| J | A conclusion can introduce an unsupported universal rule. | Exceeds the argument. On 115 derive the ending from the supplied record. | Anticipated from task analysis, untested. |
| K | Usage conventions never change. | Treats conventions as timeless facts. On 115 compare the 2016 manual introduction with the 2021 infinitive guidance. | Anticipated from task analysis, untested. |
| L | Personal preference resolves disputed usage. | Omits reference verification. On 115 apply a located usage entry to the draft sentence. | Anticipated from task analysis, untested. |
| M | An attributive compound never needs a hyphen. | Misses the supplied convention. On 115 contrast off-campus speech with speech off campus. | Anticipated from task analysis, untested. |

| P | Matching the outcome validates every reason. | Confuses agreement in result with sound inference. On 116 compare one supported reason with one unsupported reason leading to the same disposition; retain only the supported reason. | Anticipated from task analysis, untested. |
