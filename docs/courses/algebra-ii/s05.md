## 6. Error register

| | The error or first idea | What it shows | Source |
|---|---|---|---|
| A | Moves f(x+k) horizontally by k rather than -k. | Confuses the new input with the old argument. Repair: solve x+k=a for a marked old input a. | Base lesson 3 narrative. |
| B | Multiplies horizontal coordinates by k for f(kx). | Misses reciprocal scaling. Repair: solve kx=a for an old input a. | From memory. |
| C | Changes output coordinates when the rule changes only inputs. | Confuses the reflection axes. Repair: hold the output fixed and negate the marked input coordinate. | From memory. |
| D | Classifies a polynomial as odd because it contains an odd-power term. | Does not test the whole expression. Repair: substitute -x in every term and compare with the negative of the whole function. | From memory. |
| E | Chooses a fit from two matching points while ignoring contradictory readings. | Does not validate across the available data. Repair: compare predictions with every supplied observation. | From memory. |
