**E35, paper, operative data directions.** Original summaries: Franklin, colonial agent answering lawmakers, February 1766.
Without repeal, colonists will buy very few British goods. Parliament, repeal preamble, March 1766: Continuing this law could harm our kingdoms commercial interests. s03-X35a: "Compare these sources' information about trade." ## 9. Supports and extension

Words: audience, purpose, corroborate, testimony, engraving, repeal. Frame for practice only: "This detail supports ___ because ___." At most 140 independently read source words and 350 total print daily. Read originals aloud; preserve internal clues in summaries. Dictation, large print and neutral source descriptions retain the same evidence decisions. Extension identifies a useful question a purposeful source cannot answer.
