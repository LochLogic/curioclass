## 4. Expected errors and first ideas


- **L** Wrong: "Water." Right: "Our class should explain clean taps first." Shown 145 feedback. If many: first five minutes of 146, add the choice with "should" to three topic-only openings.
- **M** Wrong: "Clean taps are best because I like them." Right: "because a clean tap keeps dirt out of the water." Shown 145 feedback. If many: first five minutes of 146, swap liking for a source detail in three sentences.
- **N** Wrong: "The seal was found, therefore inspection causes damage." Right: "because it reveals damage." Shown 143 (peer ask), 145 feedback. If many: 6 minutes in 146, name the relationship in words, then pick the connector.
- **O** Wrong: a close about a picnic. Right: a close that returns to the position and one reason. Shown 142. If many: 5 minutes, read three closes aloud and ask "does it come back to the opinion?"
- **P** Wrong: "I learned I like wells." Right: "I learned the zone distance is not the same as safe water." Shown 145 feedback. If many: 5 minutes in 146, write one thing learned from a source, not a liking.
- **Q** Wrong: copies the whole treatment paragraph into one note. Right: "screen catches big pieces (treatment text)." Shown 145 feedback. If many: 5 minutes in 146, cut one long note to six words.
- **R** Wrong: "Three mans." Right: "Three men." Shown 142 exit, 145 audit. If many: 5 minutes, say the singular and the irregular plural together for man, foot, goose, woman, tooth, then write each.
- **AO** Wrong: "dishs." Right: "dishes." Shown 142 exit, 145 feedback. If many: 5 minutes, compare box and boxes, then dish and dishes, then edit one more.
- **AQ** Wrong: files "zone distance" under pollution. Right: files it under access. Shown 145 feedback. If many: 5 minutes in 146, sort three notes by the category question.
- **AR** Wrong: "siting." Right: "sitting." Shown 143. If many: 5 minutes, sit plus ing, then run and hop, then say the short vowel and the double letter.
- **AS** Wrong: reads "said" as "sayd." Right: "said" read as it is spoken and checked in the sentence. Shown 143. If many: 5 minutes, map the spelling to the spoken word, then reread the sentence.
