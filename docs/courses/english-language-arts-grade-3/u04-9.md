## 4. Expected errors and first ideas


- **Z** Wrong: rushes "the crew inspected the valve before reopening it" so the order is lost. Right: phrase at the meaning boundary: "The crew inspected the valve, before reopening it." Shown 155 (return and repair). If many: 5 minutes, read one sentence in two chunks and in one rush and say which the listener can follow.
- **AA** Wrong: "Before there, stuff." Right: "The screen removes leaves before water enters storage." Shown 155. If many: 5 minutes, restate three fragments with a subject and a verb.
- **AB** Wrong: says "pause here" aloud. Right: a pause with no cue words. Shown 155. If many: 5 minutes, the teacher reads a line with the cue spoken and then paused; children say which is right.
- **AC** Wrong: the adult typed while the child watched. Right: the child types and revises an attributed line. Shown 155. If many: one more four-minute turn on 155 for those children, typed by the child.
- **AK** Wrong: reads remembering as river. Right: reads every syllable, then checks the sentence. Shown 155. If many: 5 minutes, break two long words into syllables and blend.
- **AD** Wrong: waits for the teacher to read the hard part. Right: reread silently and name one strategy first. Shown 155. If many: 5 minutes, one hard sentence, the strategy card, then ask.
- **A** Wrong: "A says shorter distance means safe." Right: "A says distance cannot answer both questions." Shown 155 feedback. If many: 5 minutes, find the sentence that says it or say the text does not answer.
- **B** Wrong: "The farm notice is mainly about roots." Right: "It is mainly about covered soil reducing runoff." Shown 155 feedback. If many: 5 minutes, name the main idea, then match each detail to it.
- **F** Wrong: lists differences only. Right: says what both texts share, then what differs. Shown 155 feedback. If many: 5 minutes, fill a two-row chart, shared above, different below.
- **S** Wrong: pipe as an abstract noun. Right: safety. Shown 155 (return and repair). If many: 5 minutes, sort ten nouns, touch or idea.
- **T** Wrong: a clean copy. Right: one change responding to written feedback. Shown 155. If many: 5 minutes, show one change.
- **U** Wrong: mixes unrelated facts in a group. Right: sort by the named subtopic. Shown 155. If many: 5 minutes, sort six facts.
- **V** Wrong: "Filters are important." Right: add a definition and a source detail. Shown 155. If many: 5 minutes, add both to two sentences.
- **W** Wrong: invites before the reader knows the purpose. Right: add the background first. Shown 155. If many: 5 minutes, write what the reader needs above the letter.
- **X** Wrong: one sitting as the evidence. Right: the dated plan, draft and revision. Shown 155. If many: 5 minutes, locate three dates in the folder.
- **Y** Wrong: no comma after the city. Right: Lake Bend, MT 59000. Shown 155. If many: 5 minutes, mark the boundary, then edit two addresses.
- **AE** Wrong: "four." Right: "Repairs cut leaks from four to one; the circle shows one leak remains." Shown 156 (final response). If many: 5 minutes, say the change using both bars and the drawing.
- **AF** Wrong: a preference with no passage. Right: points to the located passage. Shown 156. If many: 5 minutes, find one sentence that backs the preference.
- **AG** Wrong: talks over another speaker. Right: uses the agreed signal. Shown 156. If many: 3 minutes, rehearse the signal.
- **AH** Wrong: changes the subject. Right: begins with the peer's claim. Shown 156. If many: 5 minutes, write "You said ... and I ..." for one claim.
- **AI** Wrong: repeats the first claim. Right: says what the other talk confirmed or changed. Shown 156. If many: 5 minutes, add "Now I think ... because ..."
- **AJ** Wrong: "Yes." Right: names the source and its detail. Shown 156. If many: 5 minutes, answer one question with a source and a detail.
