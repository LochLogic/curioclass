## The day as the scope and sequence sets it

<!-- skel -->
- **Goal:** Compare groups to ten using two joined 5-frames as a 10-frame.
- **Note:** Base K.2.10. Join two 5-frames for counts 6 to 10; show five and some more. Picture data concern classroom objects, never children or home features. Daily oral count to ten, growing toward twenty.

**Skills:**

- mk-compare-groups (grade K): taught or practised here
- mk-how-many (grade K): taught or practised here

**Codes, in our words where the standards file has them:**

- **K.CC.C.6:** Identify whether the number of objects in one group is greater than, less than, or equal to the number of objects in another group, e.g., by using matching and counting strategies.
- **K.CC.B.4b:** Understand that the last number name said tells the number of objects counted. The number of objects is the same regardless of their arrangement or the order in which they were counted.
- **K.CC.B.5:** Count to answer “how many?” questions about as many as 20 things arranged in a line, a rectangular array, or a circle, or as many as 10 things in a scattered configuration; given a number from 1–20, count out that many objects.
- **K.CC.A.3:** Write numbers from 0 to 20. Represent a number of objects with a written numeral 0-20 (with 0 representing a count of no objects).
