## The day as the scope and sequence sets it

<!-- skel -->
- **Goal:** Count a set in a different order and start an oral count from a given number.
- **Note:** Base K.6.3. Daily oral count by tens to 100, with ones practice. Five-minute spaced addition and subtraction game within five, untimed; objects may be dropped as facts become known. Data: authored section blocks control timing; exit: half. Read all print aloud. Everyone marks paper; six rotating 45-second oral samples, three per panel when two. Formation and unheard words recorded separately. Original masters separate from practice; familiar games untimed. Day 106: leaf count s06-X106a stays on the half slip; s06-X106b is a judged paper practice item in the student Exit box, first seen during the same eight-minute exit slot. Three children heard per item; return both papers day 107.

**Skills:**

- mk-count-to-20 (grade K): taught or practised here
- mk-count-on-from (grade K): taught or practised here

**Codes, in our words where the standards file has them:**

- **K.CC.A.3:** Write numbers from 0 to 20. Represent a number of objects with a written numeral 0-20 (with 0 representing a count of no objects).
- **K.CC.B.5:** Count to answer “how many?” questions about as many as 20 things arranged in a line, a rectangular array, or a circle, or as many as 10 things in a scattered configuration; given a number from 1–20, count out that many objects.
- **K.CC.A.2:** Count forward beginning from a given number within the known sequence (instead of having to begin at 1).
