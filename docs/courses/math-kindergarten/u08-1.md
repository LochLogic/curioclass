MP.1 day 137 repairs a story model; MP.8 day 138 relates one change to neighboring count words. Explain tracking versus total and spacing versus amount. Geometry days 135/136 responds to unit 7.

## Day 135

**Shape: s08-X135.** Independently sort whole new set and order mats; practice corrects partial sorts.

- **8 min. Hook.** I can organize groups. Supplied partial classroom-card sort; two 45-second suggestions, everyone marks a proposed move. Ask compelling question, no complete independent sorted display.

- **25 min. Response centers.** Five unit 7 priority repair and five late day 134 feedback revision, five game, eight partial counting/sorting, two tidy. Review u07-4 D133 adult-started partial room model feature-label correction for a color-only choice; use its supplied cylinder label, not a transfer card. Priority component only, unit 7 letters. Retain records, no repeated battery.

- **8 min. Exit ticket.** E135, all paper, six optional 45-second observations included; tools None.

## 9. Supports and extension

Review count, sort, category, fewest, most, more, fewer, equal and one more with objects. New day 137 vocabulary has the definitions in that day; do not test a word before that demonstration. Frame: "This has ___ because ___." Independent reading zero. Read labels/stems aloud. Tactile lines, large icons, directed adult marks, home language/signs/usual aids preserve math. Extension: another tracking route on the same single practice collection within twenty.
