## 1. Standards and practices

<!-- skel -->
- **K.MD.B.3** (days 41, 42, 44): Classify objects into given categories; count the numbers of objects in each category and sort the categories by count.
- **K.CC.B.4** (days 41, 42, 43): Understand the relationship between numbers and quantities; connect counting to cardinality.
- **K.CC.B.4b** (days 41, 42, 43): Understand that the last number name said tells the number of objects counted. The number of objects is the same regardless of their arrangement or the order in which they were counted.
- **K.CC.B.5** (days 41, 42, 43): Count to answer “how many?” questions about as many as 20 things arranged in a line, a rectangular array, or a circle, or as many as 10 things in a scattered configuration; given a number from 1–20, count out that many objects.
- **K.CC.A.3** (days 41, 42, 43): Write numbers from 0 to 20. Represent a number of objects with a written numeral 0-20 (with 0 representing a count of no objects).
- **K.CC.C.6** (days 41, 42, 43, 44): Identify whether the number of objects in one group is greater than, less than, or equal to the number of objects in another group, e.g., by using matching and counting strategies.
- **K.CC.C.7** (days 43, 44): Compare two numbers between 1 and 10 presented as written numerals.
- **K.CC.B.4c** (days 44): Understand that each successive number name refers to a quantity that is one larger.
