## 1. Standards and practices

<!-- skel -->
- **K.MD.B.3** (days 135): Classify objects into given categories; count the numbers of objects in each category and sort the categories by count.
- **K.CC.A.3** (days 135, 136, 139): Write numbers from 0 to 20. Represent a number of objects with a written numeral 0-20 (with 0 representing a count of no objects).
- **K.CC.B.5** (days 135, 136, 139): Count to answer “how many?” questions about as many as 20 things arranged in a line, a rectangular array, or a circle, or as many as 10 things in a scattered configuration; given a number from 1–20, count out that many objects.
- **K.CC.C.6** (days 136): Identify whether the number of objects in one group is greater than, less than, or equal to the number of objects in another group, e.g., by using matching and counting strategies.
- **K.OA.A.2** (days 137): Solve addition and subtraction word problems, and add and subtract within 10, e.g., by using objects or drawings to represent the problem.
- **K.CC.B.4c** (days 137, 138): Understand that each successive number name refers to a quantity that is one larger.
- **K.CC.A.2** (days 138, 139): Count forward beginning from a given number within the known sequence (instead of having to begin at 1).

### U9. Supports and extension

<!-- skel -->
> (shared across the unit) Read all directions aloud; no independent reading is required. Teach more, fewer, equal, part, whole and ten ones with gestures: "I know ___ because ___." Accept home-language reasoning and usual communication methods. Offer large tactile pieces and adult movement at the child's direction. Seated picture trays replace a hunt; symbols replace color cues. Extend by finding two different representations for the same count or story, within the same limits.
