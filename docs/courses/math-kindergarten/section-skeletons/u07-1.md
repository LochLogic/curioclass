## 1. Standards and practices

<!-- skel -->
- **K.G.B.5** (days 120, 121, 122): Model shapes in the world by building shapes from components (e.g., sticks and clay balls) and drawing shapes.
- **K.G.B.6** (days 120, 121, 122): Compose simple shapes to form larger shapes. For example, “Can you join these two triangles with full sides touching to make a rectangle?”
- **K.CC.A.3** (days 120): Write numbers from 0 to 20. Represent a number of objects with a written numeral 0-20 (with 0 representing a count of no objects).
- **K.CC.B.5** (days 120): Count to answer “how many?” questions about as many as 20 things arranged in a line, a rectangular array, or a circle, or as many as 10 things in a scattered configuration; given a number from 1–20, count out that many objects.
- **K.CC.C.6** (days 121): Identify whether the number of objects in one group is greater than, less than, or equal to the number of objects in another group, e.g., by using matching and counting strategies.
- **K.OA.A.2** (days 122): Solve addition and subtraction word problems, and add and subtract within 10, e.g., by using objects or drawings to represent the problem.
- skill mk-build-compose-shapes (grade K)
- skill mk-count-to-20 (grade K)
- skill mk-add-sub-expressions (grade K)
- skill mk-compare-groups (grade K)
- skill mk-story-problems (grade K)

### U9. Supports and extension

<!-- skel -->
> (shared across the unit) Read everything aloud. Teach flat, solid, face, side, corner and position words with gestures: "Both have ___; this one has ___." Accept home-language reasoning before restating English names. Use tactile outlines, large stable pieces and adult movement at the child's direction. Extend by proposing and testing two different feature-based sorts of the same objects.
<!-- /skel -->

### U10. Two rooms

<!-- skel -->

A thirty-five-minute path uses counting five, model five, building ten, discussion and recording ten, exit five; include within-five practice in recording. Spread assigned evidence across the same window. One shared device is optional.
