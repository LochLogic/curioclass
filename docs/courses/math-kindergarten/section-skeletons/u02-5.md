## 1. Standards and practices

<!-- skel -->
- **K.CC.B.4** (days 34, 35): Understand the relationship between numbers and quantities; connect counting to cardinality.
- **K.CC.B.4b** (days 34, 35, 36): Understand that the last number name said tells the number of objects counted. The number of objects is the same regardless of their arrangement or the order in which they were counted.
- **K.CC.B.5** (days 34, 35, 36): Count to answer “how many?” questions about as many as 20 things arranged in a line, a rectangular array, or a circle, or as many as 10 things in a scattered configuration; given a number from 1–20, count out that many objects.
- **K.CC.A.3** (days 34, 35, 36): Write numbers from 0 to 20. Represent a number of objects with a written numeral 0-20 (with 0 representing a count of no objects).
- skill mk-how-many (grade K)
- skill mk-one-more (grade K)
- skill mk-compare-numerals (grade K)

### U9. Supports and extension

<!-- skel -->
> (shared across the unit) Read everything aloud; no independent reading is required. Pair gestures with more, fewer, same and category. Rehearse "This has more because ___." Use large high-contrast pictures or tactile pieces, a counter mat instead of fingers, and directed adult movement. Keep numeral writing observable. Extend by finding two arrangements that mislead sight but preserve the comparison, within ten.
