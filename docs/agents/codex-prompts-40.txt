CURIO CLASS: 40 CODEX BUILD PROMPTS

Each tool has two steps.
1. In a terminal, run the START line. It makes the tool's worktree from the latest main, then opens Codex there.
2. Paste the PROMPT block into Codex.

Each build holds in S:\CurioClass-codex-<tool-id>, uncommitted, until Refine. When Codex says "Build done", mark [x] here.

Up to three can run at once if you pick one from each group: A, B and C use different ports.
If a command hangs for about 20 minutes, press Esc and paste:

That command hung, so I stopped it. Close any Chrome or server you started, note it under Left open in the report, and carry on with the next step. Do not rerun it with no time limit.

If it says it is reconnecting, wait. If the model is at capacity, send: carry on
