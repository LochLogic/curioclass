### C01. Passport stamps twice in K-2

- **Tools:** festival-passport (social studies, g1, planned, wave 1); art-passport (arts, K-2, live); me-on-the-map (social studies, K, live)
- **Kind:** clash
- **Tags matched:** festival-passport and art-passport: action (explore) and setting (a world tour with passport stamps). The tag groups differ (travel map vs museum) only because art-passport's stops are artworks; the picture the class sees is the same. festival-passport and me-on-the-map: action (explore) and setting group (travel map).
- **Why it matters:** a K-2 class would collect passport stamps around a world map twice, once live. It is in wave 1, so it needs a decision before its spec is written.
- **Fix:** reshape festival-passport. New concept: "Festival Parade: Floats from festivals around the world roll past on the projector; the class guesses what is being celebrated from the food, music and clothes, then hears the story behind it and joins in one song or move." (action predict-reveal, setting parade)
