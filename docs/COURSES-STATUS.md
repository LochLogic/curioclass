# Course status: which layers exist for every course

Generated by scripts/course_status.py on 2026-11-26. Do not edit by hand; run the script again.

**What this is.** A status table, not a plan. It shows the gap between what exists and a finished course. Every course on it is to be finished to the bar (Cory, 2026-11-11). The build order is docs/PRODUCTION-PATH.md; the current state is docs/HANDOFF.md.

**How courses are counted.** As a school would schedule them: math, English language arts, science and social studies by grade and then by named high school course; every other subject by discipline and grade band, except computer science (one per grade K to 12) and library (one per grade K to 5, then one each for middle and high school); world languages by language. The catalog has 93 pages (a subject at a grade or band), which is a different count: some pages hold several courses and some hold none.

**The layers** (docs/ROADMAP.md, "The layers"). Standards are loaded for every subject, the shared approach (docs/APPROACH.md) is a draft that serves every course, and every catalog page is shaped, so those have no column. The columns are the layers that differ by course:

- **Rubric file**: our own-words file of what a published review rubric asks. Where none is written, the bar for that course is only the general one in docs/ADOPTION-BAR.md, and for subjects with no published rubric the bar still has to be stated.
- **Approach**: the subject page that says how the shared approach is carried out. For science and social studies, the subject lens (docs/agents/lenses/) and the rubric stand in until days are written (Cory, 2026-11-14).
- **Progression**: what the grade inherits and hands on (rows for the grade in data/progressions/<subject>.csv).
- **Scope and sequence**: every day of the year in order (docs/courses/<course>/scope-and-sequence.md). "yes" means the file is on file; docs/HANDOFF.md says which have been read and fixed.
- **Plans**: unit plans and section plans on file, as a count.
- **Topics** and **Tools**: what the catalog holds. Tools are counted as spec / built / live. A spec or a built tool is not yet tied to a section plan anywhere except the trial sections.

No course has lessons, print, checks with keys or teacher pages yet. That is layer 7; it starts after the unit plans, with the probe and guard (docs/PRODUCTION-PATH.md).
