# Dated reports keep the words of their day

The reports in this folder are history and are not edited. Those dated before 2026-11-12 use the course words of
their day. On 2026-11-12 (Desk card 112) the words changed, as recorded in [../GLOSSARY.md](../GLOSSARY.md):

| Old word | Word now |
|---|---|
| unit (the 1 to 6 day package), unit plan, unit opener | section, section plan, section opener |
| stretch, stretch sheet | unit, unit plan |
| spine, year spine | scope and sequence |
| end check, check day | end-of-unit assessment (unit assessment), assessment day |
| exit slip | exit ticket |
| day kind "Use" | application |
| module (a topic page) | topic |
| tool role "lesson" | teach |
