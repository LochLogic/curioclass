Describe observed grains leaving the patch, or accurately state no detected movement.I wrote expected readings without observing.: error x, any other wrong answer: no group (Error x: Unsupported or incomplete evidence; silence alone is not a misconception.)
24-ESS2-1 (change)Use today's repeated slope records. Explain the proposed slope effect using comparisons, controls and one limitation.Use all valid repeats; support a slope effect only if observed. Match sand, moisture, water and pouring. A tray cannot give a canyon-cutting rate.One trial proves slope caused it even if water changed.: error C, a cause is established despite changed controls or conflicting repeats. (Error C: One trial proves slope caused it even if water changed.)
34-ESS2-1 (change)Invented for practice. Matched damp stones begin with equal cracks. Frozen and unfrozen stones develop equally wider cracks. Evaluate whether this isolates freezing as the cause.Both weathered, but the control changed equally, so freezing alone is not established.Neither weathered because pieces did not travel.: error A, weathering requires travel. (Error A: Neither weathered because pieces did not travel.)
44-ESS2-1 (change)Invented for practice. Before-and-after drawings track marked grains into a new pile. Grain sizes remain visibly unchanged. Identify the process these observations establish.Carrying: marked grains moved into the pile. New size changes or breakage were not shown.Moving grains prove new rock breakage.: error x, any other wrong answer: no group (Error x: Unsupported or incomplete evidence; silence alone is not a misconception.)
54-ESS2-1 (change)Invented for practice. Repeated pictures show an animal bringing soil onto a marked bare surface. An adjacent animal-excluded patch stays unchanged. Evaluate whether a plant is required for this land change.No plant is needed here: the animal redistributes soil while the excluded patch stays unchanged.Only plants can change land.: error D, living things cannot change land. (Error D: Only plants can change land.)
64-ESS2-1 (change)Invented for practice. Matched plots begin with upright water-needing seedlings. Rain brings new grooves and upright seedlings to one plot. The rain-excluded plot has no new grooves; seedlings wilt, then recover with watering. Explain the two effects supported by these records.Rain made new grooves. Excluded seedlings wilted and recovered with watering, supporting a plant-water link as well as land reshaping.Rain changes grooves but cannot affect which plants live.: error E, rainfall cannot affect which plants grow. (Error E: Rain changes grooves but cannot affect which plants live.)
