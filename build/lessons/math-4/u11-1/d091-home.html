Example 1 (side 1)A school field is 264 feet long and 158 feet wide. How much fence goes all the way around?264 + 158 = 422; 422 + 422 = 844; 844 feet
  1. Sketch the field: a rectangle, 264 feet on both long sides and 158 feet on both short sides. No grid, just labels.
  2. The fence goes all the way around: 264 + 158 + 264 + 158.
  3. Length plus width first: 264 + 158 = 422. That is half the fence.
  4. The other half is the same, so add the sum to itself: 422 + 422 = 844.
  5. The fence is 844 feet. It goes around, so the unit is feet, not square feet.
  6. Check: 264 + 264 = 528 and 158 + 158 = 316. 528 + 316 = 844.
Example 2 (side 1)A picture frame is 634 inches long and 234 inches wide. Find its perimeter.6 3/4 + 2 3/4 = 8 6/4; 8 6/4 + 8 6/4 = 16 12/4 = 19; 19 inches (16 12/4, 18 4/4 and 76/4 are also right)
  1. Sketch the frame: 6 3/4 inches on both long sides, 2 3/4 inches on both short sides.
  2. Length plus width: add the wholes, 6 + 2 = 8, and the fourths, 3/4 + 3/4 = 6/4. That is 8 6/4.
  3. Add the sum to itself: 8 6/4 + 8 6/4. Wholes: 8 + 8 = 16. Fourths: 6/4 + 6/4 = 12/4.
  4. 12/4 is 3 wholes, because 4/4 + 4/4 + 4/4 = 12/4. So 16 + 3 = 19.
  5. The perimeter is 19 inches.
  6. Check: four sides have 6 + 2 + 6 + 2 = 16 wholes and four 3/4, which is 12/4, or 3. 16 + 3 = 19.
