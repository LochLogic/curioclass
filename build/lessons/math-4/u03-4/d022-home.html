Day 22: Pick a way, then compare

At home

GoalI can pick a way, compare, and write it with the right sign
Time35 minutes, one parent and one child (a teaching day)
Printthe student page and one exit ticket; this page and its answers are for you

Swap. No projector: point at side 1. No red pen: any other colour.

Skip. The warm-up, set C and the challenge.

  • 8 min. One pair, two ways. Read Example (side 1) together; the child fills the frame.

  • 5 min. Fix it. Fix it (side 1).

    Say. "Read Rio's sign aloud as words. Is that what Rio found?" Expect: no; 3/10 is less, so 3/10 < 2/5.

  • 12 min. Two short sets. Set A (Set A, row 1 (side 1), row 2, row 3), then set B (Set B, row 1 (side 2), row 2, row 3): the child writes the renamed fractions and the sign. Mark each set together against the answers before the next.

    Say. "Read each sign aloud. Does the open side face the greater number?" Expect: yes, for each.

  • 5 min. Two ways. Two ways (side 2). Ask which way was quicker, and why.

  • 5 min. Exit ticket. The child answers the ticket question alone.

Example (side 1)Compare 35 and 68 two ways. Write the sign.3/5 < 6/8: 24/40 < 30/40, and 3/5 < 3/4
  1. Way 1, same size parts. List the multiples of 8: 8, 16, 24, 32, 40. 40 is also a multiple of 5.
  2. Cut each fifth into 8 and each eighth into 5: 3/5 = 24/40 and 6/8 = 30/40.
  3. Fortieths are the same size, so compare the counts: 24 fortieths is less than 30 fortieths.
  4. Way 2, same count. Put each 2 eighths together into one fourth: 6/8 = 3/4. Now both have 3 parts.
  5. Fifths are smaller than fourths, so 3 fifths is less than 3 fourths.
  6. Both ways say the same: 3/5 < 6/8. Read it aloud: 3/5 is less than 6/8. The open side faces 6/8.
  7. Which way was quicker here? Way 2: one step, and no big numbers.

Look-fors:
  1. each renaming is right (5/20 and 4/20; 2/8 and 2/10)
  2. both ways give 1/4 > 2/10
  3. a reason for the choice
