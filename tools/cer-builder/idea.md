# CER Builder (idea card)

- Module: eld-6-8-lab-reports-and-claims, grade 6-8. Codes: WIDA.ELD-4, WIDA.Argue
- Format / family: builder / evidence. Fit: good: the student builds a claim, evidence and reasoning paragraph and tests it against the data.
- One idea: Run a quick virtual experiment (which paper towel soaks up the most water, which color of cup heats fastest in the sun), then write the lab report's conclusion as claim, evidence and reasoning with language frames, and see that evidence is the numbers while reasoning is the science idea that connects them to the claim.
- How it plays (solo student by default):
  - First screen: a lab bench with the setup and a question. "Run it. Then tell me what you found and why."
  - Core loop: the student runs three trials and gets a data table. Then builds the paragraph: claim (The ___ absorbed the most water.), evidence with numbers (In three trials, it held an average of ___ mL.), reasoning (This is because ___, which means ___.). Checks: a claim the data does not support is flagged; evidence with no numbers is flagged; reasoning that only repeats the evidence gets "That says what happened. Why did it happen?" and a science-idea card to draw on.
  - The aha or the end state: the paragraph with the three parts colored, and the same paragraph next to a weaker version, so the student sees what reasoning adds.
  - Class mode or extras (optional): Help Lots / Some / Little; four experiments.
- Standards, one line per code:
  - WIDA.ELD-4: the language of science: investigation, measurement and explanation words in lab contexts.
  - WIDA.Argue: making a claim, supporting it with evidence, and connecting the two with reasoning.
- Not like: claim-quote-comment (ELA, claims about an article); cause-and-effect-rewind (grade 3-5 cause chains); argument-builder-pro (grade 9 full argument).
- Art: drawn in code for the lab bench and data; generated scenes for experiment setups.
- Proposed title: keep
- Proposed concept line: Run a quick virtual experiment, then write the conclusion as claim, evidence and reasoning with language frames; the tool flags claims the data do not support and reasoning that only repeats the evidence.
- Flags: experiment results checked for real-world plausibility at spec; home-language glossary may matter (open question, not decided).
