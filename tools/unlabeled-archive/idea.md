# Unlabeled Archive (idea card)

- Module: social-studies-7-unlabeled-archive, grade 7. Codes: D2.His.11.6-8, D2.His.13.6-8
- Format / family: puzzle / none. Fit: good
- One idea: An archive box holds four real but unlabeled sources (a map fragment, a letter, a coin and a woodcut); the student uses dated reference sources (a list of rulers, a timeline of maps, printers' marks, a dictionary of old spellings) to work out who made each, when, where and for whom, then decides which ones help answer the archivist's question.
- How it plays (solo student by default):
  - First screen: an archivist's note with a question (What did Europeans know about the Americas by 1650?) and a closed box.
  - Core loop: pick a source, find a clue (a ruler's face on the coin, California drawn as an island on the map, a printer's mark on the woodcut), check it against the reference shelf, and fill the label (maker, date range, place, audience). Puzzles get harder: later sources have fewer clues and need two references.
  - The aha or the end state: a usefulness rating for each source against the question, with reasons drawn from the label; a beautiful source can be useless for this question.
  - Class mode or extras (optional): a second box with a new question.
- Standards, one line per code:
  - D2.His.11.6-8: using references to infer maker, date, place and audience.
  - D2.His.13.6-8: rating each source's relevance and usefulness from its label and purpose.
- Not like: historians-disagree (secondary accounts); source-scout (grade 5, fact and opinion); evidence-corkboard (building an argument).
- Art: public domain (real objects and pages from Met open access and the Library of Congress, ids to check at spec), because the clues must be real.
- Proposed title: keep
- Proposed concept line: keep
- Flags: needs a data source (four objects with known makers and dates to check answers)
