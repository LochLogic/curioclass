# Graph Glow-Up (idea card)

- Module: math-3-scaled-graphs, grade 3. Codes: 3.MD.B
- Format / family: builder / graphs. Fit: good.
- One idea: A club's crowded, hard-to-read graphs need a makeover: pick a scale (each picture is 5 votes, each bar step is 10) so the graph fits and still tells the truth, and turn a messy list of measurements to the quarter inch into a clean line plot.
- How it plays (solo student by default):
  - First screen: a school newsletter with an overflowing picture graph (84 stickers in a row) and an editor, Jo. "This graph runs off the page. Can you fix it?"
  - Core loop: the child chooses a key (1 picture = 2, 5 or 10) and the graph rebuilds; half-pictures appear when needed. The goal card asks for a graph that fits the page and can answer the newsletter's questions ("How many more votes did soccer get than chess?"), so the child tests the redesign by answering them. Bar graphs get the same treatment with axis steps.
  - Line plot job: the science club measured 15 bean pods with rulers marked in halves and fourths of an inch; the child measures a few on screen, then builds a line plot with quarter-inch marks.
  - The aha or the end state: before-and-after side by side; the right scale makes the comparison readable without changing the data.
  - Class mode or extras (optional): a "misleading scale" round where a bar axis that starts at 50 makes a small gap look huge.
- Standards, one line per code:
  - 3.MD.B: drawing scaled picture and bar graphs and solving one- and two-step how-many-more and how-many-fewer problems from them (3.MD.3), and measuring to halves and fourths of an inch and showing the data on a line plot (3.MD.4).
- Not like: lunch-line-data (grade 2, scale of one, whole inches), class-poll (grade 1 picture graphs), data-desk-distributions (grade 12).
- Art: drawn in code for the graphs (they must be exact), generated scenes for the newsroom and bean pods.
- Proposed title: keep
- Proposed concept line: Give crowded graphs a makeover: choose a scale (each picture is 5 votes) so a picture or bar graph fits and still answers "how many more?", and build a line plot from bean pods measured to the quarter inch.
- Flags: none
