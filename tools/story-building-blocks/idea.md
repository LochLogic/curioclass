# Story Building Blocks (idea card)

- Module: ela-3-chapters-scenes-and-stanzas, grade 3. Codes: RL.3.5
- Format / family: builder / none. Fit: good.
- One idea: A short story, a short play and a short poem have been knocked into scrambled blocks; the child stacks them back in order, naming each block (chapter, scene or stanza), and each block only locks when the child taps what it builds on from the block below, so they see that every part rests on the parts before it.
- How it plays (solo student by default):
  - First screen: three tumbled towers labeled Story, Play, Poem. "Each tower fell down. Rebuild it, and name every block."
  - Core loop: drag blocks to stack them; label each (chapter, scene, stanza); then link it to the earlier block it builds on (a clue introduced in chapter 1 pays off in chapter 3). Wrong order makes the tower lean, with a note on what is missing.
  - The aha or the end state: one block is pulled out of each tower and the child sees which later block no longer makes sense, then puts it back.
  - Class mode or extras (optional): teacher texts. Texts: a three-chapter original story, a short public-domain play adaptation in three scenes, and a public-domain poem in stanzas (Rossetti or Stevenson).
- Standards, one line per code: RL.3.5: using the words chapter, scene and stanza, and describing how each part builds on earlier parts (the link step and the pulled-block test).
- Not like: Two Sides Theater (grade 2 beginning and ending). Genre Remix (grade 4 poem, drama and prose features). Story Map Treasure (grade 1 plot).
- Art: generated scenes (block faces carry small scene illustrations), because stacked blocks should look solid and inviting.
- Proposed title: keep
- Proposed concept line: A story, a play and a poem fell into scrambled blocks; stack each back in order, name every block a chapter, scene or stanza, and link it to what it builds on. Pull one out to see what breaks.
- Flags: none
