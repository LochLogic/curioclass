# Multiplication Dungeon (idea card)

- Module: math-3-times-tables-fluency, grade 3. Codes: 3.OA.C
- Format / family: arcade / none. Fit: good.
- One idea: Explore a retro dungeon where every door opens with a multiplication or division fact; a missed fact returns as a sleepier, bigger guardian with a strategy hint, until it is truly known.
- How it plays (solo student by default):
  - First screen: a pixel-art castle gate and a hero with a lantern. "Each door has a fact. Answer to open it."
  - Core loop: doors show 7 x 8 or 56 / 7; a quick answer opens them. Missed facts come back on later doors as guardians that fall asleep (no fighting) when answered, each time showing a hint: an array split (7 x 8 = 5 x 8 + 2 x 8), a known neighbor fact (7 x 7 + 7), or the related multiplication for a division.
  - Floors follow strategy families: 2s, 5s and 10s first, then 3s, 4s and 6s, then 7s, 8s and 9s.
  - The aha or the end state: a map of all 100 products lights up as facts are mastered; division doors use the same map.
  - Class mode or extras (optional): a daily three-minute run with a personal best.
- Standards, one line per code:
  - 3.OA.C: fluent multiplication and division within 100, using strategies and the multiplication-division relationship, toward knowing all products of two one-digit numbers from memory (3.OA.7).
- Not like: fact-rally (grade 2 addition facts on a tennis court), equal-groups-zoo (meaning of multiplication), pattern-painter (patterns in the table).
- Art: drawn in code (pixel art), because the retro dungeon is the look; rule 3 is met by a carefully made pixel set, not placeholders.
- Proposed title: keep
- Proposed concept line: Explore a retro dungeon where every door opens with a multiplication or division fact; a missed fact returns as a sleepy guardian with a strategy hint until the whole times table lights up.
- Flags: overlap risk (fact-rally also repeats missed facts; keep the repeat mechanic visibly different)
