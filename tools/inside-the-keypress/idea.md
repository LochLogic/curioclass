# Inside the Keypress (idea card)

- Module: computer-science-3-5-hardware-and-software-together, grade 3-5. Codes: E3-SYS-HW-12, E4-SYS-HW-12, E5-SYS-HW-12
- Format / family: explorer / none. Fit: good, because the student opens a cutaway computer and follows one signal through its layers.
- One idea: Press a key or snap a photo and ride the signal through a cutaway laptop (keyboard or camera, processor, memory, the app's instructions, the screen), swap the app (drawing, typing, a game) to see the same hardware do a different job, then find the broken step when the screen stays blank.
- How it plays (solo student by default):
  - First screen: a laptop sliced open like a dollhouse, each part labeled. "Press the A key and follow it."
  - Core loop: the keypress becomes a glowing token; it travels from the key to the processor, which reads the app's instruction ("show the letter"), stores it in memory, and lights pixels on the screen. Every stop is tappable for a one-line explanation.
  - Swap the app: the same A key in a drawing app picks the eraser; in a game it makes the character jump. Hardware path the same, instructions different.
  - Fix-it rounds: the screen stays blank; the student checks each stop in order (cable loose, app frozen, memory full, brightness at zero) and fixes the one that is stuck.
  - The aha or the end state: hardware carries the signal and software decides what it means; finding a problem means checking each step in order.
- Standards, one line per code:
  - E3-SYS-HW-12: follow a keypress through the parts and say what each part does.
  - E4-SYS-HW-12: swap apps and explain how software gives the same hardware a new job.
  - E5-SYS-HW-12: trace a blank screen step by step to the part (hardware or software) that failed, and fix it.
- Not like: computer-builder (grade 1, parts and what each does); input-or-output (grade 2 inputs and outputs); network-help-desk (grade 4 network and account problems).
- Art: generated cutaway scenes in a bright, clean style; signal token drawn in code.
- Proposed title: keep

- Flags: overlap risk (network-help-desk also lists E4-SYS-HW-12 and troubleshooting; this one stays inside one device)
