# Resource Map (idea card)

- Module: science-7-earth-s-resources, grade 7. Codes: MS-ESS3-1
- Format / family: map / none. Fit: good
- One idea: Turn on geology layers for a real map (old seas, buried swamps, volcanic zones, porous rock), predict where oil, coal, copper and groundwater will be, then reveal where they really are, so the student sees that past and present Earth processes put resources unevenly.
- How it plays (solo student by default):
  - First screen: a map of the United States with switchable geology layers and four resource cards.
  - Core loop: for each resource, a short "how it forms" story (oil from sea plankton buried and cooked over millions of years, coal from swamp forests, copper ore from hot fluids near old volcanoes, groundwater held in porous rock and refilled by rain); the student drops prediction pins using the layers, then reveals the real deposits and sees the match.
  - The aha or the end state: the student explains one resource's map with the processes behind it. The human side: towns that grew around mines, and farms that pump the High Plains aquifer faster than rain refills it.
  - Class mode or extras (optional): a world view with the same layers.
- Standards, one line per code:
  - MS-ESS3-1: the student explains each resource's uneven distribution from the past and current geologic processes shown in the layers.
- Not like: plate-puzzle (plate motion evidence); biome-atlas (grade 12 climate and biomes); population-dashboard (grade 12 resource use by country).
- Art: map drawn in code from public domain USGS data; generated scenes for each formation story.
- Proposed title: keep
- Proposed concept line: keep
- Flags: needs a data source (USGS mineral, energy and aquifer maps, public domain, checked); sensitive if mining on Native lands is shown (fresh review agent, rule 5)
