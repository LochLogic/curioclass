# Box Plot Builder (idea card)

- Module: math-6-summarizing-data, grade 6. Codes: 6.SP.B
- Format / family: data / data-desk. Fit: good.
- One idea: Take real data sets (daily high temperatures for two cities, points per game for a team), switch between dot plot, histogram and box plot, and drag single points to watch the mean chase an outlier while the median barely moves.
- How it plays (solo student by default):
  - First screen: a data desk with one month of daily highs for a coastal city, already in a dot plot, and a reporter, Sam, asking: "What's a typical day here? One number, and how sure are you?"
  - Display rounds: the same data as a dot plot, a histogram with adjustable bins, and a box plot; the student builds the box plot step by step (order, median, quartiles, whiskers).
  - Summary rounds: the student reports the count, what was measured and its units, the median and mean, the IQR and the mean absolute deviation (MAD computed as a visual of each distance to the mean).
  - Drag rounds: drag one hot day to a heat-wave record; the mean jumps, the median stays, the IQR barely moves. The student explains which measure fits a lopsided set.
  - Story round: two cities with the same mean but different spreads; the student writes Sam's headline with the right summary.
  - The aha or the end state: the shape of the data decides which summary tells the truth.
  - Class mode or extras (optional): enter the class's own data (stays on the device).
- Standards, one line per code:
  - 6.SP.B: dot plots, histograms and box plots of real data (6.SP.4); summarizing a data set by count, attribute and units, median, mean, IQR and MAD, patterns and striking departures, and choosing measures by shape (6.SP.5).
- Not like: question-lab (grade 6 statistical questions and the idea of spread), data-detective (same desk engine, grade 8 scatter plots), data-desk-distributions (grade 12 distributions).
- Art: generated scenes (a newsroom desk); people (illustrated) for Sam; all charts drawn in code.
- Proposed title: keep
- Proposed concept line: Switch real temperature and sports data between dot plot, histogram and box plot, report median, mean, IQR and MAD, and drag one point to watch the mean chase an outlier while the median holds still.
- Flags: needs a data source (public daily temperatures, for example NOAA climate records, and a public-domain or openly licensed sports box score set)
