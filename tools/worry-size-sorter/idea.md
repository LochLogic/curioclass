# Worry Size Sorter (idea card)

- Module: health-pe-3-5-worries-and-coping, grade 3-5. Codes: NHES.S1, NHES.S6, NHES.S7
- Format / family: sort / none. Fit: good, because sizing worries by how much help they need is the core move.
- One idea: Sort everyday worries by how much help they need (small: I can handle it; medium: a tool plus a friend; big: tell a trusted adult now), try a real coping tool on each small and medium one, and set a one-week coping goal you check off each day.
- How it plays (solo student by default):
  - First screen: three baskets labeled small, medium and big, each with a short line on what it means. "Every worry is real. Its size is about how much help it needs."
  - Core loop: worry cards from a kid's life (a spelling test, a friend who seems mad, a new school, someone at home is very sick, a grown-up asked me to keep a secret that feels wrong); drag each to a basket. Big worries always end with "tell a trusted adult" and a list of who that can be.
  - Try a tool: for small and medium worries, try one tool right there (box breathing with an animated square, a talk-back line to the worry, a short stretch, writing it down) and rate how you feel after.
  - Coping goal: pick one tool and one time of day; a seven-day chart lets you check it off. A line on screen says the chart stays on this device and never leaves it.
  - The aha or the end state: you know which worries you can work on yourself, which tools help you, and that big ones go to an adult, every time.
- Standards, one line per code:
  - NHES.S1: learn what worry does in the body and what coping tools are.
  - NHES.S6: set a one-week coping goal and check it off each day.
  - NHES.S7: practice coping tools and choose the ones that help.
- Not like: calm-corner (K-2 calm-down tools); feelings-weather-report (feeling words); mind-map (grade 9-12 mental health conditions).
- Art: generated scenes with soft illustrated worry cards; the breathing square drawn in code.
- Proposed title: keep
- Proposed concept line: keep
- Flags: sensitive (worries can include abuse or a sick family member; teacher notes name this, rule 8, and say what to do with a disclosure; the tool never asks the student to type their own worries); stores a week of check-offs on the device (rule 7 line)
