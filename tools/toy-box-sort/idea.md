# Toy Box Sort (idea card)

- Module: math-k-sort-and-count, grade k. Codes: K.MD.B, EK-ALG-ML-02
- Format / family: sort / none. Fit: good.
- One idea: Dump a toy box and sort the toys by color, shape or size; each bin counts its toys and the bins line up by count, and Robo the toy robot learns to sort by watching which feature you used.
- How it plays (solo student by default):
  - First screen: a bedroom floor, a full toy box and three empty bins. "Tap the box to dump it."
  - Core loop: each bin wears a picture label (red, blue, yellow). The child drags each toy into its bin (10 or fewer per bin) and the bin counts aloud. "Which bin has the most?" The bins line up from most to fewest. Later rounds switch the rule to shape, then size.
  - Robo rounds: Robo watches the child sort five toys, then guesses where the next toy goes, using the same feature. Then Robo sorts a new pile by a secret feature, and the child says which one.
  - The aha or the end state: the same pile sorts three ways, each with different counts, and Robo only knows the feature you showed it.
  - Class mode or extras (optional): "make your own bins" with the child's own labels.
- Standards, one line per code:
  - K.MD.B: sorting toys into given categories, counting each bin (10 or fewer) and ordering the bins by count.
  - EK-ALG-ML-02: grouping objects by an attribute, seeing that a sorter groups by the attribute it was shown, and naming Robo's secret attribute.
- Not like: class-poll (grade 1 survey data and tallies), shape-spy (naming shapes), sheep-count (counting one set).
- Art: generated scenes (a bright bedroom, toys in clear colors, shapes and sizes, Robo), because sorting needs varied, readable objects.
- Proposed title: keep
- Proposed concept line: Dump a toy box and sort by color, shape or size; each bin counts its toys and the bins line up by count. Then Robo the robot sorts by a secret rule, and you name it.
- Flags: none (the CS code on a math module is a recorded gap-fill choice)
