# Blueprint Builder (idea card)

- Module: ela-4-text-structures, grade 4. Codes: RI.4.5
- Format / family: puzzle / none. Fit: good.
- One idea: The student gets one pile of facts about a real event and builds it to four different blueprints (chronology, comparison, cause and effect, problem and solution), and sees that the same facts become four different texts, so they learn that a text's structure decides what a reader notices first.
- How it plays (solo student by default):
  - First screen: an architect's table, a pile of fact bricks about one topic (a town that keeps flooding, the first transcontinental railroad, beavers changing a river) and four rolled-up blueprints.
  - Core loop: unroll a blueprint; its frame has slots that only accept bricks of the right job (a cause, an effect, a problem, a fix, a date) and signal-word mortar (because, as a result, in contrast, the solution was, by 1869). Leftover bricks are fine; a missing slot means the building won't stand. Later levels flip it: a finished passage arrives with no blueprint, and the student picks the blueprint, marks the signal words and describes the structure in one sentence.
  - The aha or the end state: four buildings stand side by side made of the same bricks, and a question card ("Which version helps a reader who wants to know why the town flooded?") shows each structure's job.
  - Class mode or extras (optional): a mixed-structure text where two blueprints share one wall.
- Standards, one line per code:
  - RI.4.5: building and then reading passages, the student describes the overall structure (chronology, comparison, cause and effect, problem and solution) of events, ideas and information.
- Not like: structure-spotter (grade 3, sorting found paragraphs); essay-train (grade 5, ordering the student's own essay); how-it-works-diagrams (placing sentences on a diagram).
- Art: drawn in code for blueprints and bricks, with generated scenes for each topic.
- Proposed title: keep
- Proposed concept line: Build one pile of facts about a real event to four blueprints (chronology, comparison, cause and effect, problem and solution), then read passages with no blueprint and name the structure from its signal words.
- Flags: none
