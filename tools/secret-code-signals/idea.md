# Secret Code Signals (idea card)

- Module: science-4-waves-and-information, grade 4. Codes: 4-PS4-1, 4-PS4-3
- Format / family: puzzle / none. Fit: good
- One idea: Make waves in a pond tank and see a floating buoy bob up and down without traveling, change their height (amplitude) and spacing (wavelength), then use patterns of waves, light flashes and beeps to send coded messages across a lake to a friend's cabin, and compare which code gets through fastest and with fewest mistakes.
- How it plays (solo student by default):
  - First screen: a lake at dusk with two cabins and a dock; a wave paddle in the water near a buoy. "Push the paddle. Watch the buoy."
  - Wave puzzles: set the paddle's push and speed; a ruler shows amplitude and wavelength. Levels ask for a wave tall enough to ring the buoy's bell, waves spaced to match the posts on the dock, and show that the buoy moves up and down while the wave travels on.
  - Code puzzles: the friend across the lake sends messages as flashes, beeps and wave patterns; the student decodes with a key, then invents a code (short and long, on and off, a grid of lights) to send back.
  - Compare: fog, wind and noise make some signals hard to read. The student tries two or three codes for the same message and compares speed and errors in a table, then picks the best for each condition.
  - The aha or the end state: waves have amplitude and wavelength and can move things, and patterns can carry information over a distance.
- Standards, one line per code:
  - 4-PS4-1: the wave puzzles model amplitude and wavelength and show waves can move objects.
  - 4-PS4-3: inventing several codes and comparing them for speed and errors.
- Not like: vibration-station (grade 1 building a sound or light device); how-animals-see (light and eyes).
- Art: generated scenes for the lake, cabins and weather; waves, rulers and code keys drawn in code.
- Proposed title: keep
- Proposed concept line: Make waves in a lake to see amplitude, wavelength and a buoy bobbing in place, then send messages across the water with flashes, beeps and wave patterns, invent your own code and compare which works best.
- Flags: none
