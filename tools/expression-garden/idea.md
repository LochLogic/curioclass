# Expression Garden (idea card)

- Module: math-6-expressions-and-exponents, grade 6. Codes: 6.EE.A
- Format / family: builder / algebra-tiles. Fit: good.
- One idea: Lay out a community garden with beds whose sizes are expressions (x-long rows, square beds of s^2, cube planters of s^3); two gardens are equivalent only if they hold the same number of plants for every value of x, which a plant counter checks.
- How it plays (solo student by default):
  - First screen: an empty plot, a bin of bed tiles (unit squares, x-strips, square beds) and the gardener, Mr. Delgado. "Plant 3 rows of (x + 2). How else could you lay that out?"
  - Building: the student drags beds; the expression writes itself and names its parts (terms, coefficients, factors). 3 rows of (x + 2) can be regrouped into 3 x-strips and 6 single plants: 3(x + 2) = 3x + 6.
  - Count rounds: set x = 4 and the plant counter fills each bed; formulas like V = s^3 and A = 6s^2 are evaluated for a cube planter (the soil it holds, the boards to cover it).
  - Exponent rounds: square beds of 3 by 3 and cube planters of 2 by 2 by 2 make 3^2 and 2^3 real; the student writes and evaluates expressions with exponents and order of operations.
  - Equivalence rounds: is 24x + 18y the same as 6(4x + 3y)? Rearrange into 6 identical plots. A trap pair: x + x and x^2 agree at x = 2, but the counter at x = 3 shows they are different gardens.
  - The aha or the end state: equivalent expressions are the same garden arranged differently, and one matching value is not proof.
  - Class mode or extras (optional): a gallery of different layouts for the same expression.
- Standards, one line per code:
  - 6.EE.A: numerical expressions with whole-number exponents (6.EE.1); writing, reading with vocabulary, and evaluating expressions with variables, including formulas (6.EE.2); generating equivalent expressions with the distributive property and combining like terms (6.EE.3); deciding whether two expressions are equivalent for every value (6.EE.4).
- Not like: expression-match (same tile engine, grade 7 rational coefficients), algebra-tile-studio (grade 9 factoring), expression-escape (grade 5 numerical expressions).
- Art: generated scenes (a community garden, sun and paths); people (illustrated) for Mr. Delgado; beds and tiles drawn in code so sizes stay exact.
- Proposed title: keep
- Proposed concept line: Lay out a community garden with beds sized by expressions (x-rows, square beds, cube planters); regroup 3(x + 2) into 3x + 6, evaluate with a plant counter, and learn that one matching value does not make two gardens equivalent.
- Flags: none
