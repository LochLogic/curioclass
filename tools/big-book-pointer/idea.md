# Big Book Pointer (idea card)

- Module: ela-k-print-concepts-and-the-alphabet, grade k. Codes: RF.K.1
- Format / family: showdown / big-book. Fit: good, with a solo default: a narrator voice and a pointer puppet stand in for the teacher, and the class projector game is the extra.
- One idea: The child moves a pointer (a small illustrated mouse) through a giant picture book while the narrator reads only the word under it, so the child finds out that reading goes word by word, left to right, top to bottom, page by page, and that spaces are where words end.
- How it plays (solo student by default):
  - First screen: a big closed book. "Tap the front of the book." Then: "Where do I start reading? Put Mouse there."
  - Core loop: on each page the child drags Mouse to the first word; the narrator reads one word per hop, and a wrong hop (right to left, or into a picture) makes the narrator read nonsense, which the child fixes. Space rounds: tap the gaps to count the words in a line. Letter rounds: tap every b on the page, then every B.
  - The aha or the end state: the last page is a jumble with no spaces; the child adds the spaces and hears it turn back into words. The book closes on an alphabet page the child reads by naming each letter.
  - Class mode or extras (optional): projector mode with class shout-outs and a class pointer.
- Standards, one line per code: RF.K.1: direction and return sweep (pointer hops), page order, spoken words matched to printed words (one word per hop), spaces between words (gap counting and the no-space page), naming upper and lowercase letters (letter hunt rounds).
- Not like: Sentence Train (builds sentences with capitals and end marks; this one reads an existing page). Windblown Pages (pictures versus words; this one is the mechanics of print). Letter Lanterns (letter sounds; this one names letters).
- Art: generated scenes (full picture-book pages) plus an illustrated mouse pointer, because a big book has to look like a real one.
- Proposed title: keep
- Proposed concept line: A mouse pointer hops word by word through a giant picture book while the narrator reads only the word it lands on; kids find where to start, which way to go, where words end, and every letter by name.
- Flags: none
