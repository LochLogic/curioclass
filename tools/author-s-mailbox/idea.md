# PIE Sort (idea card)

- Module: ela-2-author-s-purpose, grade 2. Codes: RI.2.6
- Format / family: sort / none. Fit: good, with a change of categories.
- One idea: The child reads short informational texts and sorts each by the author's job (to answer a question, to explain how something works, or to describe what something is like), then taps the sentence that gave the job away, so they learn to ask "What did this author want me to know?"
- How it plays (solo student by default):
  - First screen: three mailboxes labeled Answer, Explain, Describe and a stack of letters from authors. "Each author wrote for a reason. Deliver each letter."
  - Core loop: read a short text (Why do cats purr? How a kite flies. What the desert is like at night.), drop it in a mailbox, then tap the sentence that shows the job. Mixed texts ask for the main job, and the child picks the purpose that the most sentences serve.
  - The aha or the end state: the child gets a topic (owls) and picks which job to give three different authors, then sees three short texts on owls that each do a different job.
  - Class mode or extras (optional): teacher text sets.
- Standards, one line per code: RI.2.6: identifying the main purpose of a text, including what the author wants to answer, explain or describe, with the sentence that shows it.
- Not like: Main Idea Umbrella (what the text is about, not why it was written). Persuasion Poster (grade 3 opinion writing). Rhetoric Spotter (grade 9).
- Art: generated scenes (a small post office and text illustrations), because the mailboxes need to read instantly as a sort.
- Proposed title: Author's Mailbox (the old persuade-inform-entertain sort does not match RI.2.6, which asks what the author wants to answer, explain or describe)
- Proposed concept line: Short fact texts arrive as letters from authors; deliver each to the right mailbox (to answer a question, to explain how, or to describe what) and tap the sentence that gives the author's job away.
- Flags: none
