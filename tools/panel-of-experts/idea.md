# Panel of Experts (idea card)

- Module: social-studies-7-panel-of-experts, grade 7. Codes: D1.1.6-8, D1.2.6-8, D1.3.6-8
- Format / family: explorer / none. Fit: good
- One idea: The student produces a radio show where one big question (Was the Black Death a turning point?) goes to a historian, an economist, a geographer and a political scientist; while the panel talks, the student marks each field's key ideas, pins points of agreement, and writes the smaller questions each expert would ask, then compares their notes with the experts' own.
- How it plays (solo student by default):
  - First screen: a radio studio with four labeled microphones and a producer's board (Key ideas / Agree / Smaller questions).
  - Core loop: play each expert's short segment (text with optional audio); drag key words to that expert's column; when two experts say the same thing in their own terms (fewer workers, so higher wages), pin it to Agree. Before the next segment, write a smaller question that expert would ask; the expert's own question appears after.
  - The aha or the end state: the big question is really four questions; the board shows where all four fields agree (fewer people changed work, wages and power) and what each would study next.
  - Class mode or extras (optional): a second big question (Did the printing press change everything?).
- Standards, one line per code:
  - D1.1.6-8: tagging each field's key ideas in how it hears the big question.
  - D1.2.6-8: pinning where experts agree on the big question.
  - D1.3.6-8: writing each expert's smaller questions, and where experts agree on them.
- Not like: historians-disagree (two historians, comparing arguments); manor-life (daily life, avoids the plague on purpose); house-of-wisdom.
- Art: people (illustrated) for the host and four experts, generated studio scene; the experts are fictional and labeled so.
- Proposed title: keep
- Proposed concept line: keep
- Flags: needs a data source (death-toll estimates and wage findings, checked and given as ranges)
