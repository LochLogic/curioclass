# Windows and Mirrors Shelf (idea card)

- Module: library-3-5-windows-and-mirrors-shelf, grade 3-5. Codes: AASL.Include, AASL.Explore
- Format / family: sort / none. Fit: good, because sorting blurbs into mirrors and windows is the core move.
- One idea: Answer a few "about me" cards, then sort book blurbs into mirrors (lives like mine) and windows (lives different from mine), see that the same book is a mirror for one kid and a window for another, notice what your own shelf is missing, and build a balanced stack across genres and formats.
- How it plays (solo student by default):
  - First screen: an empty shelf with a mirror at one end and a window at the other. A line names the idea's source: educator Rudine Sims Bishop described books as windows, mirrors and sliding glass doors (1990).
  - About me: pick a few cards (city, small town or farm; big family or small; languages at home; things you love). A line on screen says these answers stay on this device and never leave it.
  - Core loop: blurbs of made-up books arrive (a graphic novel about a girl in a Navajo Nation town learning to herd sheep with her grandmother; a mystery set in a Lagos market; a sports story about a boy who uses a wheelchair and plays basketball); drag each to mirror or window for you.
  - Three readers: the same ten blurbs sorted by three illustrated kids show different shelves; one book is a mirror for one and a window for another.
  - Build a stack: pick five books with both mirrors and windows across at least three genres and two formats, and write one line on what you hope to find in a window book.
  - The aha or the end state: a good reading life has both, and your shelf shows which you need more of.
- Standards, one line per code:
  - AASL.Include: sort books by how close they are to your own life and see that others' shelves differ.
  - AASL.Explore: build a stack across genres and formats and name what you hope to find.
- Not like: many-voices-book (K-2 class book); rabbit-hole-notebook (grade 6-8 research questions); library-adventure (finding books in the library).
- Art: generated book covers for made-up books, each in its own style; people (illustrated) for the three readers.
- Proposed title: keep
- Proposed concept line: keep
- Flags: sensitive (cultural portrayals in blurbs: fresh review agent per rule 5); stores "about me" answers on the device only (rule 7 line)
