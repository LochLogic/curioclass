# Class Pet Pitch (idea card)

- Module: ela-3-opinion-and-informative-writing, grade 3. Codes: W.3.1, W.3.2
- Format / family: studio / none. Fit: good, as a two-piece studio: a care guide that informs and a poster that persuades, made from the same facts.
- One idea: A class wants a pet and the principal will decide, so the student writes a care guide that explains the pet and a poster that argues for it from the same fact cards, and sees that informing groups facts while persuading picks reasons and links them to an opinion.
- How it plays (solo student by default):
  - First screen: the principal holds a sign: "Pet requests need two things: a care guide and a poster." Three pets to pick from (guinea pig, betta fish, leopard gecko), each with a stack of illustrated fact cards.
  - Core loop: care guide first: drag facts under headings (food, home, daily care), add a picture and a "what it means" box for one word, write an opening and an ending, link facts with also, another, and, but. Then the poster: write one opinion, choose the three facts that work as reasons, snap a linking word to each (because, since, for example, therefore), and add a closing line.
  - The aha or the end state: the principal reads both aloud and reacts: a reason with no fact behind it gets a frown, a fact on the poster with no link to the opinion gets a shrug, and a guide that sneaks in "you should" gets the note "a guide explains, a poster argues".
  - Class mode or extras (optional): print both as a two-page spread; the class votes on posters.
- Standards, one line per code:
  - W.3.1: the poster: an opinion, listed reasons backed by facts, linking words and a concluding statement, checked by the principal.
  - W.3.2: the care guide: an opening, facts grouped under headings with a picture, a defined word, linking words and a conclusion.
- Not like: hamburger-paragraph (grade 2, paragraph parts); quote-picker (grade 4, quotes behind reasons); headline-writer (main idea of a news story).
- Art: people (illustrated) for the principal and class; generated scenes for the three pets, because real-looking animals make the facts concrete.
- Proposed title: Class Pet Pitch (the poster is now only half of the tool)
- Proposed concept line: The class wants a pet: write a care guide that groups facts under headings, then a poster that argues for the pet with reasons and linking words, and the principal reacts to each.
- Flags: none (pet care facts need checking at spec time)
