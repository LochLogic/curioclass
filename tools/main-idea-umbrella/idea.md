# Main Idea Umbrella (idea card)

- Module: ela-2-main-idea-and-connections, grade 2. Codes: RI.2.2, RI.2.3
- Format / family: builder / none. Fit: good.
- One idea: Details fall as raindrops, and the child builds an umbrella (a main topic) big enough to cover them all but no bigger, first one small umbrella per paragraph and then one big umbrella for the whole text; then a rain chain links steps or causes in order, so the child sees both what a text is about and how its parts connect.
- How it plays (solo student by default):
  - First screen: a three-paragraph text about honeybees and a gray sky. "Here comes the rain. Build an umbrella that covers every drop."
  - Core loop: for each paragraph, pick or build an umbrella label from word tiles (what bees eat); drops it misses splash, and an umbrella too big ("animals") covers drops from other texts too and wobbles. Then a big umbrella for the whole text. Rain chain round: drag sentences onto a chain in the order that shows how one step leads to the next (how bees make honey; how a seed becomes a tree; how a law was passed in a town).
  - The aha or the end state: the paragraph umbrellas sit under the big one, and the child reads the text's main topic and each paragraph's focus in one line each.
  - Class mode or extras (optional): teacher text sets.
- Standards, one line per code: RI.2.2: main topic of a multi-paragraph text and the focus of each paragraph (the umbrellas); RI.2.3: connections between steps, scientific ideas or historical events (the rain chain).
- Not like: Headline Writer (grade 3 main idea from news with supporting details). Main Idea Pinboard (grades 3-5, quoting evidence). Question Cube (question words).
- Art: generated scenes (a rainy storybook street and the texts' illustrations), because weather gives the metaphor its charm.
- Proposed title: keep
- Proposed concept line: Details fall as raindrops; build an umbrella label for each paragraph and a big one for the whole text, sized to cover every drop. Then hang the steps or causes on a rain chain in order.
- Flags: none (facts in the texts must be sourced)
