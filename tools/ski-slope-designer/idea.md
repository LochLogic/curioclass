# Ski Slope Designer (idea card)

- Module: math-8-slope-and-proportional-relationships, grade 8. Codes: 8.EE.B
- Format / family: builder / graphing. Fit: good.
- One idea: Lay out ski runs on a mountain profile graph, where a straight run's drop is proportional to its horizontal distance; slope triangles drawn anywhere on a run are similar, so the slope is the same everywhere, and a run that starts at a mid-mountain lodge becomes y = mx + b.
- How it plays (solo student by default):
  - First screen: a side view of a mountain on a grid, a top station at the origin, and the trail designer, Ana. "Kids' run first: gentle. Draw it."
  - Build rounds: the student drags a straight run; a skier tests it. Too steep and the skier tumbles into soft snow; too flat and the skier stops. Real ratings guide the goal (beginner, intermediate, expert ranges).
  - Triangle rounds: the student draws slope triangles at different places and sizes on one run; the tool shows they are similar, and their rise over run is the same number.
  - Compare rounds: one run is given as a graph, another as an equation (drop = 0.4 x distance), a third as a table from a survey crew; the student ranks them by steepness and names the unit rate (meters of drop per meter across).
  - Lodge rounds: a run starts at a lodge 300 m below the top; the student writes y = mx + b and sees the graph shift without changing slope.
  - The aha or the end state: slope is one number for a whole straight line, and similar triangles are why.
  - Class mode or extras (optional): design a whole resort map and trade it with a partner to rate.
- Standards, one line per code:
  - 8.EE.B: graphing proportional relationships and reading the unit rate as slope, comparing runs given as graph, equation and table (8.EE.5); similar slope triangles explaining why slope is constant, and deriving y = mx through the origin and y = mx + b from the lodge (8.EE.6).
- Not like: two-trains (same graphing family, grade 8 systems), story-graphs (grade 8 functions from stories), ramp-and-roof (grade 10 trig ramps).
- Art: generated scenes (mountain, snow, lodge); people (illustrated) for Ana and skiers of varied looks; graph and triangles drawn in code.
- Proposed title: keep
- Proposed concept line: Lay out ski runs on a mountain profile graph: test steepness with a skier, draw slope triangles anywhere to see they are similar, compare runs given as graphs, equations and tables, and start one at a lodge to get y = mx + b.
- Flags: needs a data source (typical slope ranges for beginner, intermediate and expert runs, sourced)
