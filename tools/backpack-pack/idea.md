# Backpack Pack (idea card)

- Module: social-studies-k-needs-and-wants, grade k. Codes: D2.Eco.1.K-2, D2.Eco.6.K-2
- Format / family: sort / none. Fit: good for scarcity and needs vs wants; a camping trip can't teach how people earn income.
- One idea: Pack a backpack with only six pockets for a camping trip, so every item you add means leaving another behind, and the trip itself shows which were needs (water, jacket) and which were wants (a toy truck).
- How it plays (solo student by default):
  - First screen: an open backpack with six glowing pockets and a pile of twelve things. "Drag something you will need into a pocket."
  - Core loop: drag items in; when the pockets are full, the student must take one out to add another. A strip below sorts each item as Need or Want.
  - The aha or the end state: the trip plays out (a cold night, a rain shower, snack time). A missing need makes a sad moment and a hint; wants are fine once the needs are packed. The student repacks once and sees the difference.
  - Class mode or extras (optional): a second trip (beach day) with different needs; class vote on the projector.
- Standards, one line per code:
  - D2.Eco.1.K-2: limited pockets (scarcity) force a decision each time something new goes in.
  - MOVE D2.Eco.6.K-2: to community-helpers-village, where each helper's card shows the work they do, how they earn pay for it, and what that pay buys.
- Not like: piggy-bank-planner (saving money toward a goal); market-day (spending tokens on goods and services).
- Art: generated scenes (camp site, items in one sticker style), because K students need clear, friendly objects.
- Proposed title: keep
- Proposed concept line: Pack a camping backpack with only six pockets; each item you add means leaving another behind, and the trip shows which were needs and which were wants.
- Flags: none
