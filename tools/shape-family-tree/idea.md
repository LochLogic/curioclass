# Shape Family Tree (idea card)

- Module: math-3-quadrilaterals, grade 3. Codes: 3.G.A
- Format / family: sort / none. Fit: good.
- One idea: Sort quadrilaterals into a family tree where a shape can belong to more than one branch, and settle the family argument with evidence: a square has four square corners, so it is a rectangle too.
- How it plays (solo student by default):
  - First screen: a family reunion picnic with a tree banner (Quadrilaterals at the top, then rhombuses and rectangles, squares where they meet). "Each guest is a shape. Seat them on the tree."
  - Core loop: the child drags shape guests to branches; a checker tool measures sides and corners so the child can test each one. Some guests fit two branches; the square sits on both.
  - Argument cards: "Grandma says a square isn't a rectangle." The child picks the evidence (four sides, four square corners) to settle it.
  - Outsiders: the child draws a quadrilateral that is not a rhombus, rectangle or square (a kite, a lopsided four-sided shape) on a dot grid, and it gets its own seat on the main branch.
  - The aha or the end state: names describe what shapes share, so one shape can have several names.
  - Class mode or extras (optional): a debate prompt for whole-class discussion.
- Standards, one line per code:
  - 3.G.A (categories, 3.G.1): sorting rhombuses, rectangles and squares as quadrilaterals by shared attributes, and drawing quadrilaterals outside those groups.
  - MOVE 3.G.A (equal areas, 3.G.2): tile-the-floor, which can teach equal-area parts with tiles (split a floor among four painters, each gets 1/4 even when the shapes differ); a family tree has no honest place for it.
- Not like: shape-spy (kindergarten naming), garden-grid (grade 2 attributes), shape-courtroom (grade 5 hierarchy on trial; watch for overlap).
- Art: people (illustrated) for the reunion frame; shapes drawn in code so sides and angles are exact.
- Proposed title: keep
- Proposed concept line: Seat quadrilaterals on a family tree where a square sits on two branches; test sides and corners to settle family arguments, and draw a quadrilateral that belongs to none of the named groups.
- Flags: overlap risk (shape-courtroom, grade 5, also argues whether a square is a rhombus); keep this one about the grade 3 categories and leave the hierarchy argument to grade 5. Trapezoid is left out on purpose (inclusive and exclusive definitions differ).
