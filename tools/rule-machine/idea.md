# Rule Machine (idea card)

- Module: math-4-number-patterns, grade 4. Codes: 4.OA.C
- Format / family: puzzle / function-machine. Fit: change the mechanic, keep the format: 4.OA.5 is about a pattern made from a starting number and a rule, and noticing features the rule never mentions; the old "guess the in-out rule" is the grade 8 function-machine-factory idea.
- One idea: Set a start and a rule, and the machine prints a pattern of numbers or shapes; before it runs you predict a hidden feature (will every number be odd? will 100 appear?) and then explain why it happens.
- How it plays (solo student by default):
  - First screen: a ticker-tape machine in a workshop, with two dials (Start and Rule) and a robot helper, Cog. "Start at 1. Rule: add 3. Before you pull the lever, guess: will the numbers be odd, even or both?"
  - Core loop: the child sets the start and the rule, makes a prediction from a short menu, pulls the lever, and the tape prints the terms. Cog highlights the feature (odd, even, odd, even) and asks why; the child builds a reason from cards ("odd + 3 is even, and even + 3 is odd").
  - Shape rounds: a rule like "add a row of 2 tiles" grows a shape pattern; the child predicts the 10th shape.
  - Mystery tapes: Cog prints a pattern with a hidden start and rule, and the child finds both.
  - The aha or the end state: the rule says "add 3" but never says "alternate odd and even"; that feature comes from the start number and the rule together.
  - Class mode or extras (optional): make a tape for a friend to crack.
- Standards, one line per code:
  - 4.OA.C: generating number and shape patterns from a given rule, and naming and explaining features of the pattern that the rule does not state (4.OA.5).
- Not like: function-machine-factory (grade 8 input-output functions), pattern-painter (grade 3 patterns in the multiplication table), two-rule-race (grade 5 two patterns on a grid).
- Art: generated scenes (a cozy workshop with a ticker-tape machine and Cog); tape and tiles drawn in code.
- Proposed title: keep
- Proposed concept line: Set a start number and a rule, then predict what the machine's pattern will do (all odd? will 100 appear?) before it prints; explain the features the rule never mentions, and crack Cog's mystery tapes.
- Flags: overlap risk (function-machine family: the old concept duplicated function-machine-factory's in-out guessing)
