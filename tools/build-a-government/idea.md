# Build a Government (idea card)

- Module: social-studies-12-foundations-of-government, grade 12. Codes: D2.Civ.3.9-12, D2.Civ.8.9-12
- Format / family: builder / none. Fit: good
- One idea: Write the constitution for a new island nation by choosing its parts (presidential or parliamentary, federal or unitary, a bill of rights, courts, how to amend it, which treaties to sign), then test it against crises and compare it with real countries that made the same choices.
- How it plays (solo student by default):
  - First screen: an island map with three regions, two languages and a neighbor across the strait, and a blank constitution with eight empty articles.
  - Core loop: fill each article from option cards, each citing a real country that uses it (the US, the UK, Germany, India, South Africa, Switzerland). Then run crises: a contested election, a region wants to secede, a leader declares an emergency, a minority's rights are threatened, a fishing dispute that a treaty could settle. The constitution's rules decide what happens, shown step by step.
  - The theory shelf explains where each choice came from (Locke, Montesquieu, the Federalist Papers, the Iroquois Confederacy's influence as debated by historians).
  - The aha or the end state: a scorecard on stability, rights, representation and peace with the neighbor, with the real-world country whose results match, and the student's note on what they would change.
  - Class mode or extras (optional): rival designs face the same crisis.
- Standards, one line per code:
  - D2.Civ.3.9-12: the crises show how the constitution's rules, laws and the treaty choice keep order at home and with the neighbor.
  - D2.Civ.8.9-12: the scorecard and real-country matches evaluate each design against democratic principles and civic virtues.
- Not like: constitutional-convention (grade 8 delegates bargaining); checks-and-balances (the US branches as a card game); federal-or-state (sorting US powers).
- Art: generated scenes (the island, a new capitol) and people (illustrated) citizens affected by each crisis, because the human stakes make the tests matter.
- Proposed title: keep
- Proposed concept line: Write a constitution for a new island nation from real countries' options, test it against crises from a contested election to a border treaty, and see which real nation's results yours resembles.
- Flags: none
