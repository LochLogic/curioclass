# Fence Builder (idea card)

- Module: math-3-perimeter, grade 3. Codes: 3.MD.D
- Format / family: builder / area. Fit: good.
- One idea: Build a dog pen with a fixed roll of fencing; every rectangle uses all of it, but some give the dog far more room, so perimeter and area stop being the same idea.
- How it plays (solo student by default):
  - First screen: a backyard, a roll of 24 meters of fence, and Biscuit the dog. "Use all 24 meters of fence. Drag the corners."
  - Core loop: the child drags pen corners on a grid; side lengths, perimeter and the count of square meters inside update live. Biscuit runs happily in a big pen and looks squished in a skinny one. A table logs each pen tried.
  - Fix-the-fence jobs: three sides are built; how long must the last side be to use 30 meters? A garden bed's perimeter is known, find the missing side.
  - Same-room jobs: build pens with 16 square meters inside but different fence lengths; which is cheapest?
  - The aha or the end state: the log shows 24 meters of fence making areas from 11 to 36 square meters, and the square pen wins.
  - Class mode or extras (optional): compare tables with a partner.
- Standards, one line per code:
  - 3.MD.D: finding perimeter from side lengths, finding an unknown side, and showing rectangles with the same perimeter and different areas, or the same area and different perimeters (3.MD.8).
- Not like: tile-the-floor (area by tiling), optimization-workshop (grade 12, calculus), area-model-builder (grade 4 multiplication).
- Art: generated scenes (a backyard and an expressive dog); the grid and fence drawn in code.
- Proposed title: keep
- Proposed concept line: Build a dog pen with a fixed roll of fencing; every pen uses all of it, but some give the dog more room. Find missing sides, and compare pens with the same fence or the same space.
- Flags: none
