# World Layers Map (idea card)

- Module: science-4-earth-s-features-on-maps, grade 4. Codes: 4-ESS2-2
- Format / family: map / none. Fit: good
- One idea: Turn on world map layers (mountains, ocean trenches, volcanoes, earthquakes, ocean depth) and find that they line up in patterns, like the ring around the Pacific; the plate explanation waits for grade 6.
- How it plays (solo student by default):
  - First screen: a world map with layer switches. "Turn on volcanoes. Now earthquakes. What do you notice?"
  - Core loop: turn layers on and off (mountains, ocean trenches, volcanoes, earthquakes, ocean depth) and find where they line up, like the ring around the Pacific; describe each pattern.
  - The aha or the end state: patterns in Earth's features show up on maps; the plate explanation waits for grade 6.
  - Class mode or extras (optional): none.
- Standards, one line per code:
  - 4-ESS2-2: analyze and interpret data from maps to describe patterns of Earth's features.
- Not like: erosion-table (weathering); plate-puzzle (grade 6 plates).
- Art: real data (public map layers), because the patterns must be true.
- Proposed title: keep
- Proposed concept line: keep
- Flags: needs a data source (USGS earthquakes and volcanoes, NOAA bathymetry)
- Origin: new tool from the 2026-10-27 overlap and gap audit (docs/agents/audit/gaps.md); codes from erosion-table (4-ESS2-2).
