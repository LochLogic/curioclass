# Theme Tracker (idea card)

- Module: ela-4-theme-and-summary, grade 4. Codes: RL.4.2, RL.4.1
- Format / family: explorer / none. Fit: good.
- One idea: The student reads a public-domain story with three candidate themes lit as lamps, and every detail they highlight feeds oil to the lamp it supports, so as they read some lamps grow bright and some fade, and they learn that a theme is what the details add up to, not what one line says.
- How it plays (solo student by default):
  - First screen: the opening of a short public-domain story (for example Aesop's "The Ant and the Grasshopper" extended, or an Andersen tale such as "The Ugly Duckling") with three lamps on a shelf: "Hard work pays off", "Be kind to others", "Plan for winter".
  - Core loop: highlight a detail, then drag it to the lamp it supports and say why in a few words: what the text says, or what it lets you infer. A detail can feed two lamps. Midway, a fourth empty lamp lets the student write their own theme.
  - The aha or the end state: the brightest lamp is tested: the student writes a short summary of the story using only the highlighted details, and the summary must fit the theme. A lamp built on one flashy line goes dark when the ending contradicts it.
  - Class mode or extras (optional): compare which lamp each student lit brightest.
- Standards, one line per code:
  - RL.4.2: building a theme from details and writing the summary that holds it up.
  - RL.4.1: every highlight is labeled as stated or inferred and backed by the detail.
- Not like: theme-evidence-ladder (grade 6-8, ranking quotes against rival themes); theme-ledger (high school, two themes over a whole story); moral-of-the-story (grade 2 fables).
- Art: public domain illustrations for the story (Met or AIC object ids to be checked at spec), drawn in code for the lamps.
- Proposed title: keep
- Proposed concept line: Read a public-domain story while three candidate themes burn as lamps; each detail you highlight fuels the lamp it supports, and the brightest theme must survive a summary built only from your highlights.
- Flags: none
