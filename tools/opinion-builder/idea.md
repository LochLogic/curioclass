# Opinion Builder (idea card)

- Module: eld-3-5-opinions-with-reasons, grade 3-5. Codes: WIDA.ELD-2, WIDA.Argue
- Format / family: builder / none. Fit: good: the student builds a paragraph and tests it on a reader.
- One idea: Write a letter to the school library committee about which book the class should read next: build an opinion, two reasons with because, a result with so, and a closing from frames and word banks, then hear it read back and watch a committee member decide whether your reasons really support your opinion.
- How it plays (solo student by default):
  - First screen: three book covers with short blurbs read aloud, and a note from the committee: "Which one should we buy? Tell us why."
  - Core loop: the student picks a book and builds the letter in slots: opinion (I think we should read...), reason 1 (because...), reason 2 (Also,...), result (so...), closing (That is why...). Word banks come from the blurbs. Each slot can be read back. The committee member tests each reason: a reason about the book's content holds; a reason that is only a feeling ("because I want it") or that fits any book gets a polite "Would that be true for every book?"
  - The aha or the end state: the student sees that because points back to a reason and so points forward to a result, shown as arrows in their own letter, and the committee reads the finished letter aloud and votes.
  - Class mode or extras (optional): Help Lots / Some / Little (frames fade to starters, then to the slot names); a second topic set (class pet, field trip).
- Standards, one line per code:
  - WIDA.ELD-2: the language of language arts: talking about books, characters and why a story is worth reading.
  - WIDA.Argue: stating an opinion, supporting it with reasons using because, and stating a result with so.
- Not like: i-choose-because (K-2, spoken single reason); talk-moves-trainer (discussion moves); then-what-happened (narrating events, not opinions).
- Art: illustrated committee and library (people, illustrated); book covers drawn as made-up titles.
- Proposed title: keep
- Proposed concept line: Write to the library committee about which book to buy next; build an opinion, reasons with because and a result with so from frames and word banks, hear it read back, and see whether your reasons hold.
- Flags: home-language glossary may matter for word banks (open question, not decided); overlap risk with ELA grade 3-5 opinion writing tools (audit: keep the language frames focus).
