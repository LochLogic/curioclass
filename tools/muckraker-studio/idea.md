# Muckraker Studio (idea card)

- Module: social-studies-11-the-progressive-era, grade 11. Codes: D2.His.3.9-12, D2.Civ.14.9-12, D2.Civ.6.9-12
- Format / family: studio / none. Fit: good
- One idea: Investigate one Progressive Era problem (meatpacking, child labor, Standard Oil, lynching, tenements) from real notes and photographs, write and lay out an expose in a 1906 magazine template, then see which reforms followed the real muckrakers and how their reputations changed over time.
- How it plays (solo student by default):
  - First screen: a reporter's desk with five case files, each tied to a real muckraker (Upton Sinclair, Lewis Hine, Ida Tarbell, Ida B. Wells, Jacob Riis).
  - Core loop: read the file (interviews, figures, photos), pick the strongest evidence, write a headline, lede and three paragraphs in the studio, and choose a photo; an editor character checks that every claim has a source.
  - Reform layer: after publishing, a timeline shows the real response (Meat Inspection Act, child labor laws, the Standard Oil breakup, anti-lynching campaigns that failed in Congress), and how business, government and citizens' groups each acted.
  - The aha or the end state: a "then and now" panel: how each muckraker was seen in their time and how historians see them now (Riis's own prejudices, Wells's long-delayed recognition), with the student's note on why significance shifts.
  - Class mode or extras (optional): a class magazine issue.
- Standards, one line per code:
  - D2.His.3.9-12: the then-and-now panel shows how the significance of each reformer changed over time and context.
  - D2.Civ.14.9-12: the reform layer compares means of change (exposes, lawsuits, laws, boycotts) and which worked.
  - D2.Civ.6.9-12: each case shows the relationship among government, civil society and markets (regulators, reformers, companies).
- Not like: colonial-newsroom (grade 8 headline spin); behind-the-podcast (critiquing a secondary work).
- Art: public domain photographs (Lewis Hine, Jacob Riis via Library of Congress, checked) and a generated 1906 magazine layout, because the real photos were the evidence.
- Proposed title: keep
- Proposed concept line: Investigate a Progressive Era problem from real notes and photographs, write an expose in a 1906 magazine layout, then see which reforms followed and how the real muckrakers' reputations changed.
- Flags: sensitive (lynching case; fresh review agent per rule 5; stored drafts stay on the device, stated on screen)
