Every hole is patched.

  1. Find the flag. It looks like flag{...}
  2. Type it in the Flag box and press Submit.
  3. Then patch the hole it came from.

Flags score 100, 200 or 300. A hint takes half, and each wrong flag or check takes a quarter, never below a quarter. A patch right on the first try adds 50.

Larkspur Freight and everyone in it are made up, so you can practice here. Only ever test a real system you own or have written permission to test.

Progress is saved on this device only: which tiles are done, never what you type.

Shift moves every letter the same number of places. Keyword shifts each letter by a letter of a key. Base64 is an encoding: it has no key. Strength estimates how long guessing would take.

Nothing you type here is saved or sent.
