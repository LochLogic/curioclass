# Sentence Diagram Builder (idea card)

- Module: ela-7-phrases-clauses-and-sentence-types, grade 7. Codes: L.7.1
- Format / family: puzzle / none. Fit: good: snapping phrases and clauses onto a tree is a structure puzzle with clear goal states.
- One idea: The student builds sentences as trees, snapping clauses to the trunk and phrases onto the branch of the word they describe, and the tree shows what each piece does: two trunks for a compound sentence, a grafted branch for a dependent clause, and a phrase hung on the wrong branch makes the sentence say something absurd, so they learn how phrases and clauses work and how sentence type signals how ideas relate.
- How it plays (solo student by default):
  - First screen: a bare trunk labeled with a simple sentence ("The fox ran") and a basket of pieces: phrases ("across the frozen pond"), clauses ("because the hounds were close", "and the hunters gave up").
  - Core loop: the student snaps pieces onto the tree. Each piece names its job when placed (phrase or clause, what it modifies). Puzzles ask for a target type: make it compound, then complex, then compound-complex with the same ideas, and choose the joiner that signals the right relationship (because for cause, although for contrast, when for time). Misplaced and dangling modifier levels: "Running across the ice, the hunters' horn sounded" hangs the phrase on "horn", and a small picture shows a running horn; the student moves the branch or rebuilds the sentence.
  - The aha or the end state: one set of four ideas built four ways, with the student choosing which type best shows how the ideas connect and explaining why.
  - Class mode or extras (optional): a "tallest sensible tree" challenge.
- Standards, one line per code:
  - L.7.1: explaining each phrase's and clause's function, choosing among simple, compound, complex and compound-complex sentences to signal relationships, and fixing misplaced and dangling modifiers.
- Not like: sentence-remixer (grade 6, variety and pronouns); parallel-parking (grade 9, parallel structure); comma-chameleon (grade 5, comma meaning).
- Art: drawn in code for the tree, with small illustrated vignettes for the modifier mix-ups (generated scenes).
- Proposed title: Sentence Tree Builder (a sentence diagram usually means the Reed-Kellogg line diagram, which this tool does not use; the tree is clearer and the title should say so)
- Proposed concept line: Build sentences as trees: snap clauses to the trunk and phrases onto the word they describe, turn the same ideas into simple, compound, complex and compound-complex sentences, and move a misplaced branch before it says something absurd.
- Flags: none
