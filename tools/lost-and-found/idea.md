# Lost and Found (idea card)

- Module: math-2-two-step-word-problems, grade 2. Codes: 2.OA.A
- Format / family: mystery / none. Fit: good.
- One idea: A favorite toy is missing from the school lost and found; each day's log of what came in and went out is a two-step problem, and solving them tells you which box the toy must be in.
- How it plays (solo student by default):
  - First screen: a cluttered lost-and-found closet with five numbered boxes and a worried first grader, Sam. "Sam's stuffed fox is missing. Read the log to find which box it's in."
  - Core loop: each clue is a log entry ("Box C had 14 mittens. 6 were picked up, then 5 more came in. How many now?"). The child draws a bar model (drag bars that snap to the numbers) and writes an equation with a box for the unknown. The answer matches a sticker on one box, which rules boxes in or out.
  - Clues vary: start unknown ("Some hats were in Box A..."), change unknown, and compare ("Box D has 9 more scarves than Box B").
  - The aha or the end state: the last clue leaves one box; the child opens it and Sam gets the fox back. Wrong answers point to the wrong box, so the check is built in.
  - Class mode or extras (optional): a case maker for teachers.
- Standards, one line per code:
  - 2.OA.A: one- and two-step add and subtract problems within 100 with the unknown in every position, solved with bar drawings and equations with a symbol for the unknown (2.OA.1).
- Not like: story-problem-theater (grade 1, one step within 20), pattern-painter (grade 3 two-step with all four operations), fact-rally (fluency, no stories).
- Art: generated scenes (the closet and boxes), people (illustrated) for Sam and the school staff.
- Proposed title: keep
- Proposed concept line: keep
- Flags: none
