# Class Poll (idea card)

- Module: math-1-picture-graphs-and-tallies, grade 1. Codes: 1.MD.C
- Format / family: data / class-poll. Fit: good, with a solo default: a ready-made class of illustrated kids votes, and a real class poll is the extra.
- One idea: Votes come in one by one; you tally them, build a picture graph with up to three choices, and answer how many in all, how many each and how many more.
- How it plays (solo student by default):
  - First screen: a classroom of 18 illustrated kids and a question card ("Cats, dogs or fish?"). "Each friend will vote. Make a tally mark for each vote."
  - Core loop: each kid holds up a picture; the child adds a tally (every fifth crosses the four). Then the child drags one picture per tally into a picture graph. Questions follow: How many voted? How many chose fish? How many more chose dogs than cats?
  - New polls change the question and the class (a soccer team, a family reunion).
  - The aha or the end state: the picture graph answers "how many more?" at a glance; the child lines up rows to see the difference.
  - Class mode or extras (optional): live mode where the teacher enters a real class vote; nothing is stored beyond the device.
- Standards, one line per code:
  - 1.MD.C: organizing votes in up to three categories as tallies and a picture graph, and answering total, how many in each, and how many more or fewer (1.MD.4).
- Not like: toy-box-sort (kindergarten sorting objects), lunch-line-data (grade 2 bar graphs and line plots), graph-glow-up (grade 3 scaled graphs).
- Art: people (illustrated): varied classmates holding vote cards, because the data comes from people.
- Proposed title: keep
- Proposed concept line: A class votes on pets or snacks one kid at a time; tally the votes, build a picture graph with up to three choices, and answer how many in all and how many more. Run it with your real class too.
- Flags: none
