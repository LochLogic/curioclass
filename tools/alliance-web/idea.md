# Alliance Web (idea card)

- Module: social-studies-9-world-war-i, grade 9. Codes: D2.His.14.9-12, D2.His.15.9-12
- Format / family: simulator / none. Fit: good
- One idea: Pull the trigger event of June 1914 through Europe's web of alliances, mobilization timetables and war plans, then cut or loosen threads to test which long-term causes turned an assassination into a world war.
- How it plays (solo student by default):
  - First screen: Europe in 1914 as a web: nations as nodes, threads for alliances, rivalries, empires and war plans. A spark sits in Sarajevo.
  - Core loop: run the July Crisis day by day (the ultimatum, mobilizations, the march through Belgium, Britain's entry); each step lights the thread that carried it. Then rewind, change one long-term cause (no naval race, a war plan that allowed delay, a calmer Balkans) and replay.
  - Every tweak cites real evidence (a telegram, a war plan), and every replay outcome is labelled as one side of a historians' debate, not a fact.
  - The aha or the end state: the student sorts causes into long-term (militarism, alliances, imperialism, nationalism) and triggering (the assassination, the ultimatum) and writes a short argument about which mattered most. A last step shows what the peace settlement changed and what it set up next.
  - Class mode or extras (optional): teams defend different "most important cause" claims.
- Standards, one line per code:
  - D2.His.14.9-12: the replayable web shows many causes interacting and their effects through 1919.
  - D2.His.15.9-12: the long-term vs trigger sort and the argument the student builds from it.
- Not like: claim-repair-shop (repairs broken explanations; its card proposes a different topic so WWI causes live here); ideas-that-spread (ideas on a map).
- Art: drawn in code (the web, animated threads) over a generated period map, with illustrated portraits of leaders, because the web is a diagram.
