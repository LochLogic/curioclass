# Explainer Studio (idea card)

- Module: ela-7-informative-writing, grade 7. Codes: W.7.2
- Format / family: studio / none. Fit: good: the student writes and lays out a magazine explainer and sees it as a finished page.
- One idea: The student writes a one-page magazine explainer comparing two things readers mix up (alligators and crocodiles, weather and climate), and the studio makes them develop each section with a precise definition, a classification, a comparison chart and a quoted expert, then previews it as a printed page where a "skimmer" and a "close reader" each test it, so they learn to develop a topic with the right kinds of content, not just arrange it.
- How it plays (solo student by default):
  - First screen: a magazine layout with empty slots (headline, definition box, chart, sections, pull quote) and a topic shelf with fact cards for each topic.
  - Core loop: the student writes the definition (with the help of a "too vague" check: "an animal that lives in water" fits fifty animals), sorts facts into a classification, fills a comparison chart that the tool checks against the fact cards, and writes sections using precise domain words and a formal style. The skimmer reads only headings, chart and captions and says what they learned; the close reader flags any claim without a fact behind it.
  - The aha or the end state: the printed page preview, and the skimmer's summary matches what the student meant to teach; a concluding section ties the comparison back to why it matters.
  - Class mode or extras (optional): a class magazine issue with one page per student.
- Standards, one line per code:
  - W.7.2: introducing the topic, organizing with definition, classification and comparison, adding a chart and headings, developing with facts, quotes and examples, using precise language and formal style, and concluding.
- Not like: explainer-sections (6-8, the structure and order of sections, read and built); fact-fusion (grade 5, combining sources); pitch-deck-studio (grade 8, persuasive slides).
- Art: generated scenes for each topic's magazine photos, drawn in code for the layout.
- Proposed title: keep
- Proposed concept line: Write a magazine explainer comparing two things people mix up (weather and climate): sharpen a definition, sort a classification, fill a comparison chart, then preview the page while a skimmer and a close reader test it.
- Flags: overlap risk (explainer-sections also carries W.7.2; keep section structure there and section content here)
