# Story Map Treasure (idea card)

- Module: ela-1-story-elements-and-lessons, grade 1. Codes: RL.1.1, RL.1.2, RL.1.3
- Format / family: map / story-map. Fit: good.
- One idea: After reading a short story, the child plots it as a trail on a treasure map (start, problem, events, solution), marks how the character feels at each stop, and the X at the end only opens when they name the story's lesson.
- How it plays (solo student by default):
  - First screen: a blank map with a ship at the start. "Read the story, then map the trail."
  - Core loop: read a short public-domain story (The Elves and the Shoemaker, The Lion and the Mouse). Place stops in order: who and where (start), the problem, events, the solution. At each stop the child answers a key-detail question and sets the character's face (scared, proud, sorry).
  - The aha or the end state: the X chest asks "What did the character learn?"; the child picks the lesson and the key detail that shows it, and the chest opens. A feelings line under the trail shows how the character changed.
  - Class mode or extras (optional): retell aloud by walking the trail.
- Standards, one line per code: RL.1.1: key-detail questions at each stop; RL.1.2: retelling in order and naming the lesson with a detail; RL.1.3: characters, setting and major events placed on the map, with feelings at each stop.
- Not like: Story Stage (kindergarten staging, no lesson). Moral of the Story (grade 2 fables across cultures). Plot Rollercoaster (grade 6 sibling, plot arc).
- Art: generated scenes (a hand-drawn-looking treasure map and story pictures), because the map is the frame for every story.
- Proposed title: keep
- Proposed concept line: Read a short story, then map it as a treasure trail: start, problem, events, solution, with the character's feelings at each stop. The X opens only when you name the lesson and a detail that shows it.
- Flags: overlap risk (moral-of-the-story, lesson naming; this one is grade 1 retell with feelings)
