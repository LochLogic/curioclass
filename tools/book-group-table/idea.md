# Discussion Dashboard (idea card)

- Module: ela-6-collaborative-discussions, grade 6. Codes: SL.6.1
- Format / family: showdown / none. Fit: change to roleplay, because a projector tracker does nothing for a student alone (rule 4). The solo default is a seat at a small group's table; the projector tracker becomes class mode.
- One idea: The student joins a four-person book group (three illustrated classmates) discussing a short story, prepares notes first, then picks each turn's talk move (ask, answer with evidence, build on, paraphrase, invite a quiet member), and the group's talk deepens or stalls depending on the move, so they learn what makes a discussion go somewhere.
- How it plays (solo student by default):
  - First screen: a prep card: read a one-page public-domain story and jot two questions and one line of evidence. The group's three agreed rules are on the table tent ("one voice at a time", "back it up", "everyone talks").
  - Core loop: the discussion plays as speech bubbles. At each turn the student chooses a move and writes or picks the words: a question, a response that points to a line, a paraphrase of what Maya just said ("So you're saying..."), or turning to Omar, who hasn't spoken. Each choice changes the next bubbles: a paraphrase that gets Maya wrong earns a correction; asking Omar surfaces an idea nobody had. A small meter tracks whether the talk is still on the question and whether every voice is in.
  - The aha or the end state: the closing round asks the student to review the key ideas, say whether anyone changed their mind (including them), and name the move that opened the best moment. A replay shows the same discussion with a different first move.
  - Class mode or extras (optional): the projector dashboard: tally who has spoken, talk move stems for students to use aloud, and a timer, for a real class discussion.
- Standards, one line per code:
  - SL.6.1: preparing from the text, following group rules, posing and answering questions with evidence, paraphrasing others, and reflecting on new information.
- Not like: socratic-seminar-board (grade 10, drawing who answers whom in a real seminar); podcast-listening-club (6-8, judging a speaker's claims); counterclaim-rally (arguing, not discussing).
- Art: people (illustrated) for the three group members, each with a clear personality; generated scene for the story.
- Proposed title: Book Group Table
- Proposed concept line: Join a small book group as the fourth member: prepare notes, then choose each turn's move (ask, answer with evidence, build on, paraphrase, invite the quiet one) and watch the talk deepen or stall; a projector tracker serves real class talks.
- Flags: none
