# Economy Dashboard (idea card)

- Module: social-studies-12-macroeconomics, grade 12. Codes: D2.Eco.10.9-12, D2.Eco.11.9-12
- Format / family: data / data-desk. Fit: good
- One idea: Read the real US economy from 1948 to the latest quarter on one dashboard (GDP, unemployment, inflation, spending, the money supply), mark recessions yourself before the official dates are shown, then use leading indicators to forecast the next year and check it later.
- How it plays (solo student by default):
  - First screen: a dashboard of unlabeled lines; "Somewhere in here are 12 recessions. Find them."
  - Core loop: shade the periods you think were recessions; the official recession dates then appear, with a short story for each (the 1970s oil shocks, 1981, 2008, 2020). Investigation cards ask how changes in spending, production and the money supply moved the indicators (for example, why 2021 inflation followed big spending and money growth).
  - Forecast step: read leading indicators (yield curve, new jobless claims, building permits) and forecast the next four quarters; the forecast stays on the device and is checked against new data when the tool updates.
  - The aha or the end state: the student writes a short "state of the economy" brief with evidence from three indicators.
  - Class mode or extras (optional): compare class forecasts.
- Standards, one line per code:
  - D2.Eco.10.9-12: the investigation cards use real data to explain how spending, production and money supply changes moved conditions.
  - D2.Eco.11.9-12: recession spotting and the forecast use indicators to analyze the current and future economy.
- Not like: fed-chair (setting policy in a model); data-desk-distributions (family sibling, describing distributions); stock-market-1929 (one crash).
- Art: drawn in code (the dashboard) plus generated scenes for each recession story, because the data is the picture and the stories add the human side.
- Proposed title: keep
- Proposed concept line: Read the real US economy since 1948 on one dashboard, find the recessions yourself before the official dates appear, explain what moved each indicator, then forecast the next year from leading indicators.
- Flags: needs a data source (BEA, BLS and Federal Reserve series, bundled with a scheduled refresh)
