# Who Wins? (idea card)

- Module: math-k-longer-heavier-bigger, grade k. Codes: K.MD.A
- Format / family: showdown / none. Fit: good, if the guess-then-check runs for one child with a narrator; the thumbs vote is class mode.
- One idea: Two animals face off on one attribute at a time (longer, taller, heavier); you guess, then line them up from the same start or set them on a balance, and a different attribute can crown a different winner.
- How it plays (solo student by default):
  - First screen: a zoo stage with a referee hippo. "Who is longer? Tap your guess."
  - Core loop: two animals stand on the stage (a crocodile and a giraffe). The child taps a guess, then drags both to the start line and the tool marks the longer one. Heavier rounds use a big balance; the heavier animal sinks.
  - Fair-start rounds: one animal stands ahead of the line; the hippo asks "Is that fair?" and the child slides it back. Lining up the ends is the rule.
  - The aha or the end state: the crocodile wins "longer" and the giraffe wins "taller." "Bigger" needs a word: longer, taller or heavier.
  - Class mode or extras (optional): thumbs-up vote before each reveal; "what can we measure?" cards where the child names the attributes of one animal.
- Standards, one line per code:
  - K.MD.A: naming the measurable attributes of one animal (length, height, weight) and directly comparing two animals on one attribute, saying which has more or less, with the line-up-the-ends rule.
- Not like: snack-scale (compares how many, not how heavy), paperclip-ruler (grade 1, measuring with units), estimation-station (grade 2 rulers).
- Art: generated scenes (realistic, friendly animals drawn to true relative scale), because the comparison must look honest.
- Proposed title: keep
- Proposed concept line: Two animals face off: who is longer, taller or heavier? Guess, then line them up from the same start or set them on a balance; the croc wins longer, the giraffe wins taller.
- Flags: needs a data source (typical adult length, height and weight for each animal, checked against zoo or natural history museum pages so the scale is true)
