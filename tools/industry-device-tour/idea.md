# Industry Device Tour (idea card)

- Module: computer-science-6-8-computing-in-industry, grade 6-8. Codes: MS-SOC-CE-44, MS-SYS-HW-31
- Format / family: explorer / none. Fit: good, because each site is a place to tour and each machine opens in layers.
- One idea: Tour a dairy farm, a hospital imaging room and a car plant, open each machine (a milking robot, a CT scanner, a paint-inspection camera) to trace its input, processing, storage and output, then match each worker's real problem to the thinking move they used: break it down, spot a pattern or leave out details.
- How it plays (solo student by default):
  - First screen: three site cards on a tour bus window. "Pick your first stop."
  - Core loop: at each site, tap a machine; it opens in four layers. The milking robot reads a cow's ID tag (input), checks her milk record (storage), decides whether to milk (processing), and sends a sick-cow alert (output). The CT scanner turns many X-ray slices into one 3D picture. The camera spots a paint drip on a car door.
  - Workers: each site has a worker with a problem (a herd manager with 200 cows' records, a radiologist with thousands of images, a line lead with one door in fifty failing). The student picks the thinking move that cracked it and sees how.
  - The aha or the end state: every machine follows input, processing, storage and output, and the people who run them use computational thinking even when they aren't programmers.
- Standards, one line per code:
  - MS-SOC-CE-44: match each worker's problem to the computational thinking move they used.
  - MS-SYS-HW-31: trace input, processing, storage and output through each machine.
- Not like: who-uses-this-device (K-2 workers' devices); job-shadow-day (grade 3-5 day of choices); computing-team-stories (grade 9-12 teams and people).
- Art: generated scenes of each site with cutaway machine layers; people (illustrated) workers.
