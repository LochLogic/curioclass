# Area Model Builder (idea card)

- Module: math-4-multi-digit-multiplication-and-division, grade 4. Codes: 4.NBT.B
- Format / family: sandbox / area. Fit: good for multiplication and division; see MOVE for the standard algorithm.
- One idea: Split a big multiplication into rectangles you can compute (23 x 14 as 20 x 10, 20 x 4, 3 x 10, 3 x 4), add the pieces back, and run division backward: the area and one side are known, find the missing side.
- How it plays (solo student by default):
  - First screen: a big blank rectangle labeled 23 by 14 on a workbench. "Slice it where the numbers break apart."
  - Core loop: the child drags cut lines at place-value breaks; each piece shows its partial product, and the equation strip writes 23 x 14 = (20 + 3) x (10 + 4) = 200 + 80 + 30 + 12 = 322. Four-digit by one-digit (3,215 x 6) slices into four strips.
  - Division mode: a rectangle with area 852 and one side 4; the child builds the other side in chunks (200, then 10, then 3) until the area is used up; leftovers show the remainder.
  - Compare slicings: two different cuts of the same rectangle give the same total.
  - The aha or the end state: every multiplication and division here is the same rectangle seen from two sides.
  - Class mode or extras (optional): write the matching equation for a slicing someone else made.
- Standards, one line per code:
  - 4.NBT.B (multiplication and division parts): multiplying up to four digits by one digit and two digits by two digits with area models and equations (4.NBT.5), and dividing up to four digits by one digit with remainders as a missing side (4.NBT.6).
  - MOVE 4.NBT.B (standard algorithm for adding and subtracting, 4.NBT.4): new tool: a grade 4 column-addition tool, for example a road-trip logbook where you add and subtract mileage in columns and regroup like an odometer rolling over. An area model cannot teach the addition algorithm.
- Not like: tile-the-floor (grade 3 area itself), algebra-tile-studio (grade 9 factoring), equal-groups-zoo (grade 3 meaning of multiplication).
- Art: drawn in code (precise rectangles); generated scene only for the workbench frame.
- Proposed title: keep
- Proposed concept line: Slice big multiplications into rectangles at place-value breaks (23 x 14 is four pieces), add the pieces back, and divide by building the missing side of a rectangle until the area is used up.
- Flags: too thin for the whole 4.NBT.B cluster (needs the MOVE above)
