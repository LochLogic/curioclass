# Two Authors, One Event (idea card)

- Module: ela-7-comparing-authors, grade 7. Codes: RI.7.9, RI.7.4, RI.7.6
- Format / family: explorer / none. Fit: good: two articles side by side with layers for emphasis, word choice and point of view.
- One idea: Two articles report the same town event (the night a flood closed Main Street) with the same facts, and the student lays them side by side, links each shared fact, and finds where they part: what each puts first, which facts one leaves out, which words color the same fact, so they learn that authors shape the same information to lead readers to different conclusions.
- How it plays (solo student by default):
  - First screen: two front pages from made-up newspapers, the Riverside Gazette and the Valley Business Weekly, both about the flood.
  - Core loop: the student links matching facts between the two (same numbers, same quotes); a fact with no partner glows as an omission. An emphasis layer shows where each fact sits (headline, first paragraph, last paragraph). A word layer lets them tap loaded words ("the city's failure" versus "a rare storm") and see their neutral swap. A point-of-view panel asks what each author wants readers to do and where each sets their view apart from others ("Critics say...").
  - The aha or the end state: the student writes a neutral version of the headline and lede using only the facts both share, and compares it with both originals. A historical pair (two 1900s newspaper reports of the same event, public domain, chosen at spec) is the second level.
  - Class mode or extras (optional): a "which paper wrote this?" quiz using sentences from both.
- Standards, one line per code:
  - RI.7.9: analyzing how the two authors shape the same information through emphasis, omission and interpretation.
  - RI.7.4: the word layer: how connotative and loaded words change meaning and tone.
  - RI.7.6: each author's point of view and how they distinguish it from others'.
- Not like: fact-check-desk (grade 8, texts that disagree on facts); memoir-and-biography (6-8, how people are presented); word-thermometer (grade 6, connotation scale).
- Art: drawn in code for the newspapers; generated scenes for the flood photos in each paper (one dramatic, one calm, same street).
- Proposed title: keep
- Proposed concept line: Two newspapers report the same flood with the same facts; link the shared facts, find what each puts first, leaves out and colors with loaded words, then write a neutral headline from what both agree on.
- Flags: needs a data source (public-domain historical newspaper pair from Chronicling America, chosen at spec)
