# Community Plot Planner (idea card)

- Module: math-4-area-and-perimeter-formulas, grade 4. Codes: 4.MD.A
- Format / family: builder / none. Fit: good
- One idea: Lay out a community garden where each family's plot has a set area or fence length, find the missing side (a 48 square foot plot that is 6 feet wide), and see why the formulas work.
- How it plays (solo student by default):
  - First screen: an empty lot with fence posts. "The Lee family needs 48 square feet and the plot is 6 feet wide. How long is it?"
  - Core loop: lay out family plots with a set area or a set fence length, find a missing side, and see the unit squares and fence pieces that show why the formulas work.
  - The aha or the end state: every family gets a plot that fits, and the student states the rule for area and for perimeter.
  - Class mode or extras (optional): class lot with plots for each student.
- Standards, one line per code:
  - 4.MD.A (4.MD.3): area and perimeter formulas for rectangles in real problems, including a missing side. 4.MD.1 and 4.MD.2 stay with unit-ladder.
- Not like: garden-grid (grade 2, by look only); tile-the-floor (grade 3 area).
- Art: generated scenes (a community lot), because plots should feel real.
- Proposed title: keep
- Proposed concept line: keep
- Flags: overlap risk (garden-grid, by look; title avoids "garden")
- Origin: new tool from the 2026-10-27 overlap and gap audit (docs/agents/audit/gaps.md); codes from unit-ladder (4.MD.3).
