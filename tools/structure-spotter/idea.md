# Structure Spotter (idea card)

- Module: ela-3-text-structure-and-search-tools, grade 3. Codes: RI.3.3, RI.3.5, RI.3.8
- Format / family: sort / text-features. Fit: good, if the paragraphs live on a small kids' fact site the student has to search, so the search-tool code is taught in the same play.
- One idea: The student hunts through a little kids' fact site (search box, sidebar, links) to find the paragraph that answers each question, then sorts it by how it is built (sequence, cause and effect, comparison) by tapping the words that link its sentences, so they learn that how a text is built tells you where an answer is and how to find it fast.
- How it plays (solo student by default):
  - First screen: a kid site called "Fact Finder" with three topics (volcanoes, frogs, bridges). A question card: "Why does a volcano erupt? Find the answer." A hint: "Try the search box or the sidebar."
  - Core loop: search by key word, open a sidebar box or follow a link to reach the right paragraph; then drag it into one of three bins (first-next-last steps, this-makes-that-happen, alike-and-different). The sort only sticks when the student taps the linking words that prove it (first, then, because, so, both, but).
  - The aha or the end state: a timer shows that key words and links found the answer faster than scrolling; then a "same facts, three builds" page shows one frog fact written as a sequence, a cause and a comparison, and the student says which question each version answers best.
  - Class mode or extras (optional): a race mode where teams hunt for the same answer with different tools.
- Standards, one line per code:
  - RI.3.3: the time, sequence and cause words the student taps describe how steps, events and science ideas connect.
  - RI.3.5: every question is answered by using key words, sidebars and links on the fact site, with the finding time shown.
  - RI.3.8: each sort is justified by the logical link between sentences (first/second/third, cause and effect, comparison).
- Not like: how-it-works-diagrams (drags sentences onto a diagram that animates); text-feature-makeover (grade 1, adds features to a page); blueprint-builder (grade 4, builds paragraphs to a plan).
- Art: generated scenes for the fact site's photo-style images (volcano, frog life stages, bridge types); drawn in code for the site frame and bins.
- Proposed title: keep
- Proposed concept line: Hunt through a small kids' fact site with key words, sidebars and links to find each answer, then sort the paragraph by its build (sequence, cause and effect, comparison) by tapping the words that link it.
- Flags: none
