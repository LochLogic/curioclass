# Setting Swap (idea card)

- Module: ela-7-setting-plot-and-character-interplay, grade 7. Codes: RL.7.3
- Format / family: simulator / none. Fit: good: the setting is the input, and the student sees which events and choices still work.
- One idea: The student moves a short public-domain story to a new time, place or season with setting dials, predicts which plot events and character choices will break, and then sees the story's chain of causes light up where the new setting snaps it, so they learn how setting, plot and character hold each other up.
- How it plays (solo student by default):
  - First screen: Jack London's "To Build a Fire" (1908) as a chain of eight event cards, each linked to the setting details and character traits it depends on (seventy-five below, alone, a man who ignores the old-timer's advice).
  - Core loop: the student turns a dial (place: Yukon, city, desert; time: 1898, today; season; who comes along) and predicts which cards will break before pressing Run. The chain replays: cards whose links depend on the changed setting crack (no fire matters in July; a phone changes "alone"). For each crack the student explains the dependency, then repairs it by rewriting the event so it fits the new setting, which often changes the character's choice too.
  - The aha or the end state: the student finds the one setting detail that, if changed, breaks the most cards, and writes how the story's setting shapes the man and his fate. A second story ("The Gift of the Magi") shows a setting that shapes characters through poverty and season.
  - Class mode or extras (optional): a class challenge to find a swap that breaks nothing, and a debate on whether that story is still the same story.
- Standards, one line per code:
  - RL.7.3: predicting and explaining how changing the setting changes the plot and the characters' choices, and how each element depends on the others.
- Not like: tone-dial (grade 10, rewriting tone); rhetorical-situation-simulator (grade 11, speeches in new situations); plot-rollercoaster (grade 6, tension across episodes).
- Art: generated scenes for each setting version of the stories, so each swap looks different; drawn in code for the cause chain.
- Proposed title: keep
- Proposed concept line: Move a short public-domain story to a new time, place or season, predict which events and choices will break, and watch the story's chain of causes snap where the setting held it up; then repair the broken links.
- Flags: sensitive (light: the man dies in "To Build a Fire"; told plainly, with a content note)
