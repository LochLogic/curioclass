# Text Feature Makeover (idea card)

- Module: ela-1-text-features, grade 1. Codes: RI.1.5 (plus RI.2.5 if the windblown-pages MOVE is applied, making this grade 1-2)
- Format / family: explorer / text-features. Fit: good.
- One idea: A plain page about ocean animals is hard to use, so a curious reader (an octopus) asks questions and times how long each answer takes to find; the child adds one text feature at a time and watches the finding time drop, so they learn what each feature is for.
- How it plays (solo student by default):
  - First screen: a wall of plain text and the octopus: "Where does it say what a shark eats? This takes forever!"
  - Core loop: the child picks a feature from a toolbox (heading, table of contents, glossary, icon, menu, caption, label) and adds it; the octopus asks a new question, and a timer shows how quickly the child finds the answer with it. Each feature has a matched question (What does "school" mean here? goes to the glossary).
  - The aha or the end state: a side-by-side of the plain page and the made-over page, with each feature tagged by the question it answers.
  - Class mode or extras (optional): a second topic (the moon).
  - If RI.2.5 moves here: a grade 2 level with bold words, subheadings, an index and an on-screen menu, on a longer multi-page text.
- Standards, one line per code: RI.1.5: adding and using headings, a table of contents, a glossary, icons and an electronic menu to find facts. RI.2.5 (if moved): captions, bold words, subheadings, glossary, index and menus on a longer text.
- Not like: Windblown Pages (pictures and diagrams with words). Structure Spotter (grade 3 sibling, text structures). How It Works Diagrams (grades 3-5 sibling).
- Art: generated scenes (realistic ocean animal illustrations) and an illustrated octopus guide, because captions and labels need real pictures to label.
- Proposed title: keep
- Proposed concept line: A plain page about ocean animals is hard to use; add a heading, table of contents, glossary, icons and a menu one at a time and watch how fast each one lets you answer the octopus's questions.
- Flags: none (facts must be sourced)
