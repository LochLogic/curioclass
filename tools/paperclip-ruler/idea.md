# Paperclip Ruler (idea card)

- Module: math-1-measuring-length, grade 1. Codes: 1.MD.A
- Format / family: lab / none. Fit: good.
- One idea: Measure a cartoon classroom with paperclips, cubes and shoes, and find out the hard way that gaps, overlaps and mixed-size units give wrong answers, while a string can compare two things that cannot touch.
- How it plays (solo student by default):
  - First screen: a classroom with a lab notebook. "Measure the pencil with paperclips. Drag them end to end."
  - Core loop: the child lines up units along an object and records the count. A helper, Milo, measures too and sometimes leaves gaps or overlaps; the child spots the mistake and fixes it. A shoe round uses Milo's big shoe and a small shoe, so the counts disagree.
  - Order rounds: put three objects (scissors, crayon, glue stick) in order from longest to shortest.
  - String rounds: the bookshelf and the door can't be moved next to each other; the child stretches a string along one and holds it to the other.
  - The aha or the end state: the notebook shows the same table measured as 12 small shoes and 9 big shoes; only same-size units make counts you can trust.
  - Class mode or extras (optional): a printable card for measuring real classroom objects with real paperclips.
- Standards, one line per code:
  - 1.MD.A: ordering three objects by length and comparing two lengths with a string as the go-between (1.MD.1), and measuring as a count of same-size units with no gaps or overlaps (1.MD.2).
- Not like: who-wins (kindergarten direct comparison), estimation-station (grade 2 rulers and standard units), tile-the-floor (grade 3 area).
- Art: generated scenes (a classroom with real-looking objects), people (illustrated) for Milo.
- Proposed title: keep
- Proposed concept line: Measure classroom objects with paperclips, cubes and shoes; spot Milo's gaps and overlaps, order three things by length, use a string to compare things that can't touch, and see why units must match.
- Flags: none
