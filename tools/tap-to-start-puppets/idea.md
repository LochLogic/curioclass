# Tap-to-Start Puppets (idea card)

- Module: computer-science-k-2-what-the-code-does, grade k-2. Codes: EK-PRO-RD-06, E1-PRO-RD-06, E2-PRO-RD-06
- Format / family: sandbox / none. Fit: good, because tapping and watching is free play; predictions are a light layer, not a test.
- One idea: Each puppet on a little stage holds a short picture-block program that starts when you tap it; say what the blocks will make it do, tap to watch it run, then (grade 2) retell how the show was built, step by step, from its credits card.
- How it plays (solo student by default):
  - First screen: a toy theater with three puppets (a frog, a dragon, a moon) and a program strip under each. "Tap a puppet to start its program."
  - Core loop: before tapping, pick the picture that shows what will happen (jump, say hello, spin twice); tap; the blocks light up one by one as the puppet acts; the picture you picked gets a check or a "look again".
  - Later puppets mix events: the moon starts when the frog finishes; the dragon waits for a tap on the drum.
  - The aha or the end state: the show is just these blocks running in order when something starts them; nothing happens until the event.
  - Class mode or extras (optional): rearrange blocks and see the show change (still no wrong answers).
- Standards, one line per code:
  - EK-PRO-RD-06: tell what a three-block program will make a puppet do.
  - E1-PRO-RD-06: say which event starts each program (a tap, another puppet finishing).
  - E2-PRO-RD-06: retell how the show was built, in order, from its credits card ("first Mia drew the frog, then Leo made it jump"), naming who helped.
- Not like: robot-dance (debug a sequence); input-or-output (grade 2 device parts); snowy-mail-route (arrow cards on a grid).
- Art: generated scenes, a handmade-puppet look on a toy stage.
