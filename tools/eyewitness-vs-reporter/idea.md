# Eyewitness vs Reporter (idea card)

- Module: ela-4-firsthand-and-secondhand-accounts, grade 4. Codes: RI.4.6
- Format / family: mystery / none. Fit: good.
- One idea: The student holds two accounts of the same storm (a diary written by someone who lived through it, and a newspaper article written later from interviews and records) and works a case file of questions, deciding which account can answer each and why, so they learn what being there gives a writer and what it takes away.
- How it plays (solo student by default):
  - First screen: a case file on a desk: "Case: the Great Storm. Two witnesses. Which one can tell us what?" The diary on the left, the article on the right.
  - Core loop: question cards come up (What did the wind sound like? How many towns lost power? How did the writer feel at 2 a.m.? What caused the storm?). The student files each under diary, article, both or neither, and highlights the line that proves it. A focus meter fills for each account: feelings and senses for the diary, numbers and causes for the article.
  - The aha or the end state: the student writes the case report: one thing only the eyewitness knew, one thing only the reporter could know, and one thing the reporter got from someone like the eyewitness.
  - Class mode or extras (optional): a second case on a real event with public-domain accounts.
- Standards, one line per code:
  - RI.4.6: comparing a firsthand and a secondhand account of one event and describing how their focus and information differ.
- Not like: fact-fusion (grade 5, three sources into one report); swap-the-teller (narrators in fiction); history-or-fiction (grade 7).
- Art: generated scenes for the storm and the diary's pages, people (illustrated) for the writers.
- Proposed title: keep
- Proposed concept line: keep
- Flags: needs a data source (lean toward a real storm with public-domain accounts by rule 9, for example the 1888 blizzard; written for grade 4); sensitive (storm deaths, told plainly and with care, rule 5)
