# Picky Robot Shapes (idea card)

- Module: math-1-shapes-and-their-attributes, grade 1. Codes: 1.G.A
- Format / family: builder / none. Fit: good
- One idea: Compose pictures from flat shapes and from solids (cubes, cones, cylinders), then help a picky robot that accepts only true triangles and squares whatever their color, size or turn, and reuse a shape you built to make a bigger one.
- How it plays (solo student by default):
  - First screen: a robot at a gate holding up a sign: "Only triangles may pass." A tall thin triangle, a blue one and an upside-down one wait.
  - Core loop: help the robot sort shapes by what makes them that shape (three sides, closed) and not by color, size or turn; compose pictures from flat shapes and from solids (cubes, cones, cylinders); reuse a shape you built to make a bigger one.
  - The aha or the end state: the robot's rule card shows the defining attributes the child found.
  - Class mode or extras (optional): two players build for each other's robot.
- Standards, one line per code:
  - 1.G.A (1.G.1): defining versus non-defining attributes at the robot gate; drawing shapes with given attributes.
  - 1.G.A (1.G.2): composing two- and three-dimensional shapes and making new shapes from composites. 1.G.3 stays with pizza-party.
- Not like: pattern-block-windows (K composing); pizza-party (halves and fourths).
- Art: generated scenes (a friendly robot), because the character carries the rule.

- Proposed concept line: keep
- Flags: overlap risk (pattern-block-windows, K composing)
