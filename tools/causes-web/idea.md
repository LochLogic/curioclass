# Causes Web (idea card)

- Module: social-studies-12-causes-web, grade 12. Codes: D4.2.9-12, D4.6.9-12
- Format / family: builder / none. Fit: good
- One idea: Pick a problem that is local and global at once (high rents, plastic waste, a closed factory) and build a web of causes from economics, geography, civics and history cards backed by real data, then test whether the explanation holds up as a timeline, a chain or a loop and name its weak spots.
- How it plays (solo student by default):
  - First screen: a problem card with a real local case and its global twin (rents in one real city and housing costs worldwide), and four lens decks.
  - Core loop: draw cards from each lens (zoning rules, interest rates, migration, past policy decisions), each with a data point or source; place them and draw links. The tool then lays the same web out three ways (a timeline, a cause chain, a feedback loop) and flags gaps: a link with no evidence, an order that breaks the timeline, a lens left out.
  - Challenge step: see how people who tried to fix the problem over time fared, and what made it hard.
  - The aha or the end state: the student writes a short explanation, picks the layout that fits its purpose, and names one strength and one weakness of the explanation.
  - Class mode or extras (optional): groups each own one lens, then merge webs.
- Standards, one line per code:
  - D4.2.9-12: the explanation, with sequence, data and named strengths and weaknesses for its purpose.
  - D4.6.9-12: the four lenses and the local and global twin show the problem's causes across contexts and the challenges faced by those who tried to address it.
- Not like: who-decides (taking action on a local problem); claim-repair-shop (fixing others' claims); alliance-web (one historical cause chain).
- Art: drawn in code (the web and its three layouts) plus generated scenes for each case, because the layouts are the thinking tool.
- Proposed title: keep
- Proposed concept line: keep
- Flags: needs a data source (real data for three or more problem cases, each a real place, checked)
