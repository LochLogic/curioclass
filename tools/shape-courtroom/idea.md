# Shape Courtroom (idea card)

- Module: math-5-classifying-2d-figures, grade 5. Codes: 5.G.B
- Format / family: roleplay / none. Fit: good.
- One idea: Argue cases in a courtroom where every verdict is about inheritance: if all rectangles have four right angles and a square is a rectangle, the square must have them too; each verdict adds a branch to the court's official hierarchy of shapes.
- How it plays (solo student by default):
  - First screen: a small courtroom, Judge Okoye, a shape in the witness box (a square), and the charge: "This shape claims to be a rhombus."
  - Core loop: the student is the lawyer. They call evidence (measure sides, measure angles, test parallel sides) and pick the definition from the court's rulebook. The opposing lawyer objects with a near-miss ("but it has right angles, so it can't be a rhombus"), and the student answers with the rule: a rhombus only needs four equal sides.
  - Inheritance rounds: once "a square is a rectangle" is ruled, the judge asks what else is true of every square without measuring; the student lists the inherited properties.
  - Cases grow: triangles (is an equilateral triangle isosceles? can a right triangle be isosceles?), parallelograms, kites, trapezoids. Each verdict pins a shape onto a hierarchy diagram on the courtroom wall.
  - Final case: a mystery shape is described only by properties; the student places it at the lowest branch it belongs to.
  - The aha or the end state: categories nest, and anything true of a category is true of everything inside it.
  - Class mode or extras (optional): two students argue opposite sides; the class is the jury.
- Standards, one line per code:
  - 5.G.B: properties of a category belong to all its subcategories, argued in court (5.G.3); classifying two-dimensional figures in a hierarchy by properties, built verdict by verdict (5.G.4).
- Not like: shape-family-tree (grade 3 quadrilateral sorting; here triangles join, and the point is inherited properties), courtroom-statistics (grade 12 trial frame for p-values), mirror-studio (grade 4 lines and angles).
- Art: people (illustrated) for the judge and lawyers, varied; generated scene for the courtroom; shapes drawn in code with measurable sides and angles.
- Proposed title: keep
- Proposed concept line: Argue shape cases in court: is a square a rhombus, is an equilateral triangle isosceles? Measure the evidence, cite the definition, and pin each verdict onto a hierarchy where every shape inherits its parents' properties.
- Flags: one definition call for the spec: trapezoid as "at least one pair of parallel sides" (inclusive, which makes a parallelogram a trapezoid) vs "exactly one pair"; textbooks differ. Recommend inclusive in the rulebook, with a teacher note naming the other.
