# Road Trip Logbook (idea card)

- Module: math-4-adding-and-subtracting-multi-digit-numbers, grade 4. Codes: 4.NBT.B
- Format / family: simulator / none. Fit: good
- One idea: Log a family road trip's mileage in columns: add each day's miles and subtract to find what is left, regroup like an odometer rolling over, and check each answer with an estimate.
- How it plays (solo student by default):
  - First screen: a logbook and a map of a five-day family road trip. "Day 1: 386 miles. Day 2: 457. How far so far?"
  - Core loop: add and subtract mileage in columns with the standard algorithm; an odometer rolls over to show regrouping; estimate first and check each answer against the estimate.
  - The aha or the end state: the trip total matches the odometer, and the miles left to the end are found by subtracting.
  - Class mode or extras (optional): pick your own route lengths.
- Standards, one line per code:
  - 4.NBT.B (4.NBT.4): fluent multi-digit addition and subtraction with the standard algorithm. 4.NBT.5 and 4.NBT.6 stay with area-model-builder.
- Not like: area-model-builder (multiplication and division).
- Art: generated scenes (a road trip map and logbook), because the trip makes the numbers real.
- Proposed title: keep
- Proposed concept line: keep
- Flags: none
