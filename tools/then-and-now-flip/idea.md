# Then and Now Flip (idea card)

- Module: social-studies-k-then-and-now, grade k. Codes: D2.His.1.K-2, D2.His.2.K-2
- Format / family: sort / none. Fit: good
- One idea: Flip picture pairs of the same everyday thing (a phone, a classroom, a lunchbox, a toy) to sort then from now, then line up three versions of one thing from Grandma's time to today, so the student sees life changed in steps.
- How it plays (solo student by default):
  - First screen: two cards face down, "Which one is from long ago?" Tap to flip.
  - Core loop: drag each card to Then or Now; after each sort a clue is spoken (a cord on the phone, a chalkboard), plus what stayed the same (kids still ride bikes; the bikes look different).
  - Second step: three cards of one object (rotary phone, flip phone, smartphone) go on a three-step track: Grandma was little, a parent was little, now. A wrong order wobbles and the clue is spoken.
  - The aha or the end state: a "my day" strip compares a long-ago kid's day with the student's own (getting to school, lunch, play).
  - Class mode or extras (optional): the class calls Then or Now together; teacher notes suggest asking a grown-up at home.
- Standards, one line per code:
  - D2.His.1.K-2: build three-step chronological sequences of one object and of a kid's day.
  - D2.His.2.K-2: compare life in the past with today through then/now pairs, naming what changed and what stayed the same.
- Not like: capsule-from-1965 (reading one set of sources for maker, date and questions); my-life-timeline (the student's own life, not objects and eras).
- Art: generated scenes (paired object illustrations in one style, old ones in period look), because found photos vary in quality and rights.
- Proposed title: keep
- Proposed concept line: Flip picture pairs (phones, classrooms, toys) to sort then from now, then line up three versions of one thing from Grandma's time to today and compare a long-ago kid's day with yours.
- Flags: overlap risk (capsule-from-1965 also compares kids then and now; keep this one object-and-era, that one source-reading)
