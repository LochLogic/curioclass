# Quote Picker (idea card)

- Module: ela-4-writing-with-evidence, grade 4. Codes: W.4.1, W.4.2, W.4.9, RI.4.1
- Format / family: builder / evidence. Fit: good.
- One idea: The student writes two short pieces from the same article, an opinion paragraph and an explainer, and for each point chooses the quote or fact that backs it and the sentence that introduces it, while a quote that only repeats the point fades out, so they learn that evidence has to add something and that opinion and explaining use it differently.
- How it plays (solo student by default):
  - First screen: a short article ("Should our town build a skate park?" or "How do sea otters keep warm?") and a writing desk with two drafts: Opinion and Explain.
  - Core loop: Opinion: state an opinion, list reasons, and for each reason pick one of three quotes (one strong, one that just repeats, one off topic); write an introducing phrase (According to the article..., The park manager said...). Explain: group facts under two headings, add a definition and a quote to each group, and link with another, for example, also, because. Both end with a concluding sentence.
  - The aha or the end state: an editor reads each paragraph aloud; a repeat-quote fades and the editor says "You already said that," and a quote with no introduction lands with a thud. The student then checks every quote against the article to see it was copied exactly.
  - Class mode or extras (optional): swap articles for a social studies or science text.
- Standards, one line per code:
  - W.4.1: the opinion paragraph: reasons in order, facts and details behind each, linking words, conclusion.
  - W.4.2: the explainer: grouped facts with headings, a definition and a quote, linking words, conclusion.
  - W.4.9: every point drawn from the article.
  - RI.4.1: each quote is checked against the article's exact words and used to say what the text says.
- Not like: main-idea-pinboard (pinning proof for a main idea); claim-court (judging an author's evidence); persuasion-poster (grade 3 poster).
- Art: generated scenes for each article, drawn in code for the desk and drafts.
- Proposed title: keep
- Proposed concept line: Write an opinion paragraph and a short explainer from the same article; for each point, choose the quote that backs it and write the sentence that introduces it, and a quote that only repeats the point fades out.
- Flags: none
