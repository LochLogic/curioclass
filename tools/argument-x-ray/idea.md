# Argument X-Ray (idea card)

- Module: ela-6-tracing-an-argument, grade 6. Codes: RI.6.8
- Format / family: explorer / evidence. Fit: good, as a light table: the op-ed is a body to scan, and the X-ray shows its skeleton.
- One idea: The student puts a kid-relevant op-ed under an X-ray and tags each sentence as claim, reason or evidence, then connects each bone to what it holds up, and the skeleton shows cracks wherever a claim stands on nothing or on evidence that does not fit, so they learn to trace an argument and tell supported claims from unsupported ones.
- How it plays (solo student by default):
  - First screen: a light box with an op-ed from a made-up student paper ("Our school should switch to a four-day week") and a radiologist's note: "Tell me if this argument can stand."
  - Core loop: the student taps each sentence and tags it claim (red), reason (blue) or evidence (green). Then they drag connectors from each piece of evidence to the reason it supports and from each reason to the claim. The X-ray view builds a skeleton from those links. A sentence tagged evidence that has no link, or a link the student judges off topic, shows as a loose bone; a claim with no support shows a crack. For each crack the student picks why: no reason, a reason with no evidence, or evidence that does not match.
  - The aha or the end state: the diagnosis card: which claims are supported, which are not, and the one fix the author most needs. Then the student's tags are compared to the radiologist's, with the disagreements explained line by line.
  - Class mode or extras (optional): a second op-ed on the other side of the same question, so students see both skeletons.
- Standards, one line per code:
  - RI.6.8: tracing the argument sentence by sentence, linking evidence to reasons to claims, and naming which claims are and are not supported.
- Not like: claim-court (grade 5, matching evidence to an author's points, with no unsupported claims to find); logic-gym (grade 7, judging relevance and sufficiency in quick rounds); argument-map (grade 12, load-bearing claims in a complex essay).
- Art: generated scenes for the op-ed topics and an illustrated radiologist (people, illustrated); drawn in code for the skeleton overlay.
- Proposed title: keep
- Proposed concept line: Tag an op-ed's claims, reasons and evidence and link what holds up what; the X-ray skeleton cracks wherever a claim stands on nothing, and you name which claims are supported and which are not.
- Flags: none
