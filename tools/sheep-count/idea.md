# Sheep Count (idea card)

- Module: math-k-how-many, grade k. Codes: K.CC.B
- Format / family: showdown / none. Fit: good, as long as Farmer Bo's voice plays the teacher so one child can run every round alone; the class showdown is the projector extra.
- One idea: Tap each sheep once as it trots into the pen and it wears your number; the last number you say is how many, and it stays that many when the sheep move, scatter or hide in the barn.
- How it plays (solo student by default):
  - First screen: a green hill, an empty pen and Farmer Bo with a bell. "Tap each sheep as it comes in. Tap Start."
  - Core loop: sheep walk in one at a time; each tap gives one sheep a number tag and a bleat. A sheep tapped twice says "Baa, I'm already counted!" When the gate shuts, Bo asks "How many?" and the child picks the number from a row of cards.
  - Rounds get harder: sheep in a line, then a circle (the first sheep tapped wears the bell, so you know where you started), then scattered (counted sheep sit down), up to 20 in a line and 10 scattered. Then Bo asks the child to count out a number: "Put 7 sheep in the pen."
  - The aha or the end state: the barn door closes on 8 sheep, they shuffle inside, and the door opens: still 8. Then one more sheep jumps the fence: "Now how many?" The child can say 9 without counting again.
  - Class mode or extras (optional): class thumbs-up vote on "still 8?" before the door opens; a quiet mode with no timer.
- Standards, one line per code:
  - K.CC.B: tapping one sheep per number word (one-to-one), naming the last number as how many, the barn door rounds (the count stays when sheep move), "one more jumps in" (each next number is one more), and counting out a given number up to 20 in lines, circles and scattered sets.
- Not like: hundred-hop (says the counting sequence to 100; here each word matches one object), ten-frame-spillover (teen structure), toy-box-sort (sorting first, counting second).
- Art: generated scenes (warm farm hillside, sheep with expressive faces and a few breeds), because kindergartners count longer when the animals are charming; number tags drawn in code.
- Proposed title: keep
- Proposed concept line: Tap each sheep once as it trots into the pen; the last number you say is how many. Count lines, circles and scattered flocks to 20, count out a flock, then the barn door closes: still 8 inside?
- Flags: none
