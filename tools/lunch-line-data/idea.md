# Lunch Line Data (idea card)

- Module: math-2-line-plots-and-bar-graphs, grade 2. Codes: 2.MD.D
- Format / family: data / class-poll. Fit: good, if the data is clearly labeled as made up for the lesson and includes measured lengths, which a line plot needs.
- One idea: Help the cafeteria plan: graph what kids chose for lunch as picture and bar graphs, and measure carrots from the school garden to build a line plot, then answer "how many more?" questions from each.
- How it plays (solo student by default):
  - First screen: a cafeteria counter with a cook, Mrs. Lin. "We need to know what to make next week. Can you graph it?"
  - Core loop: lunch-choice cards (up to four choices) become a picture graph or a bar graph the child builds by dragging bar heights; questions follow (How many more chose tacos than soup? How many in all?).
  - Carrot crates: the child measures 12 garden carrots to the nearest inch with an on-screen ruler and stacks an X over each length on a line plot. "Which length is most common? How many carrots are 6 inches or longer?"
  - The aha or the end state: a bar graph shows choices, a line plot shows measurements; the child sees which kind of data needs which graph.
  - Class mode or extras (optional): measure real objects and enter the lengths.
- Standards, one line per code:
  - 2.MD.D: measuring lengths to the nearest whole unit and showing them on a line plot (2.MD.9), and picture and bar graphs with up to four categories answering put-together, take-apart and compare questions (2.MD.10).
- Not like: class-poll (grade 1, tallies and up to three categories), graph-glow-up (grade 3 scaled graphs), estimation-station (measuring without graphing).
- Art: generated scenes (a cheerful cafeteria and garden harvest), people (illustrated) for Mrs. Lin and the students.
- Proposed title: keep
- Proposed concept line: Help the cafeteria plan: turn kids' lunch choices into picture and bar graphs, measure garden carrots to the nearest inch for a line plot, and answer "how many more?" questions from each.
- Flags: none
