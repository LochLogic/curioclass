# Layers and Scales (idea card)

- Module: social-studies-9-layers-and-scales, grade 9. Codes: D2.Geo.1.9-12, D2.Geo.2.9-12, D2.Geo.3.9-12
- Format / family: map / none. Fit: good
- One idea: Build real thematic maps (median income, rainfall, languages spoken at home) at world, country and county scale, change the class breaks and the scale to watch patterns appear or vanish, then explain one place with the map plus satellite images and photos.
- How it plays (solo student by default):
  - First screen: one data set, two maps of the same US counties with different class breaks that tell opposite stories: "Which map is lying?"
  - Core loop: pick a variable and a scale; choose the map type (choropleth, dot, proportional symbol), the number of classes and the break method (equal, quantile, natural breaks); a small histogram shows where the breaks fall. Zoom from world to country to county and see averages hide local patterns.
  - Place case: pick a highlighted place (a river delta, a border region, a mining town) and stack the map with satellite views and photos to explain its economy and politics in a short caption.
  - The aha or the end state: the student publishes a map with an honest legend and one sentence about what changes at another scale.
  - Class mode or extras (optional): a "mislead on purpose" challenge, then classmates spot the trick.
- Standards, one line per code:
  - D2.Geo.1.9-12: students create the maps themselves from real data, choosing type, classes and breaks.
  - D2.Geo.2.9-12: the place case ties map, satellite image and photo to the place's political and economic dynamics.
  - D2.Geo.3.9-12: the scale zoom shows the same variable's pattern change from world to county.
- Not like: region-compare (grade 6 charts, not maps); me-on-the-map (scale for K); where-s-my-phone-from (flows, not thematic maps).
- Art: drawn in code (the maps themselves) plus public domain satellite imagery (NASA, USGS Landsat), because the data is the picture.
- Proposed title: keep
- Proposed concept line: keep
- Flags: needs a data source (Census ACS county data, World Bank, NOAA rainfall, public domain imagery; bundled offline)
