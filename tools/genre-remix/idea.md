# Genre Remix (idea card)

- Module: ela-4-poetry-drama-and-prose, grade 4. Codes: RL.4.5
- Format / family: studio / none. Fit: good.
- One idea: The student remixes one short prose scene into a script and then into a poem, moving each piece of the scene into the parts each form uses (description into stage directions, talk into lines, feeling into rhythm and line breaks), so they learn the structural parts of prose, drama and poetry by building with them.
- How it plays (solo student by default):
  - First screen: a short original prose scene (a girl and her grandfather fixing a kite in the wind) and three tabs: Story, Script, Poem.
  - Core loop: Script tab: drag sentences into a cast list, setting line, stage directions and character lines, and fix narration that no actor could say. Poem tab: pick the strongest images, break them into lines and stanzas, and choose a rhythm from a beat bar; the poem is read aloud with the beat. Each tab has a parts checklist (verse, rhythm, meter, stanza; cast, setting, dialogue, stage directions).
  - The aha or the end state: the three versions sit side by side, and the student answers "What could the script show that the story couldn't?" and "What did the poem have to leave out?" with tagged examples.
  - Class mode or extras (optional): perform the script with friends.
- Standards, one line per code:
  - RL.4.5: naming and using the structural elements of poems (verse, rhythm, meter) and drama (cast, settings, descriptions, dialogue, stage directions), and explaining how they differ from prose.
- Not like: story-building-blocks (grade 3, ordering chapters, scenes and stanzas); shakespeare-remix (grade 9 source changes); dialogue-director (comic to prose).
- Art: generated scenes for the kite scene; drawn in code for the script page and poem page.
- Proposed title: keep
- Proposed concept line: Remix one short prose scene into a script and a poem by moving its pieces into cast lists, stage directions, lines and stanzas, then compare what each form could show and what it left out.
- Flags: none
