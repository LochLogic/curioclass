# Made for Whom? (idea card)

- Module: social-studies-4-made-for-whom, grade 4. Codes: D2.His.6.3-5, D2.His.11.3-5, D2.His.13.3-5
- Format / family: explorer / none. Fit: good
- One idea: Three sources about the same years of settlement open one at a time (a settler's diary, a railroad poster selling land, a newspaper editorial); infer who each was made for and why, spot what the maker's view put in or left out, and rank which source is most useful for a given question.
- How it plays (solo student by default):
  - First screen: a desk with three closed folders. "Open the first one. Who do you think it was made for?"
  - Core loop: for each source the student reads clues inside it (the poster's big promises and prices, the diary's private worries, the editorial's arguments) and picks the audience and purpose. A highlighter marks words that show the maker's view (the poster says "empty land"; the student checks a map that shows the nations who lived there).
  - Usefulness ranking: given a question ("What was the first winter really like?" or "Why did people move here?"), the student ranks the three sources and says why, using maker, date, place, audience and purpose.
  - The aha or the end state: the same source can be most useful for one question and least for another.
  - Class mode or extras (optional): a fourth source from the perspective of a Native nation, as a teacher-assigned extension.
- Standards, one line per code:
  - D2.His.6.3-5: the highlighter shows each maker's view shaping what they wrote or drew.
  - D2.His.11.3-5: infer audience and purpose from clues inside each source.
  - D2.His.13.3-5: rank sources' usefulness for a topic using their maker, date, place, audience and purpose.
- Not like: inquiry-ladder (building questions); then-and-now-overlay (place change); history-article-review (grade 5 secondary articles).
- Art: public domain (Library of Congress railroad land posters, diaries and newspapers; specific items chosen and checked at spec).
- Proposed title: keep
- Proposed concept line: keep
- Flags: sensitive (settler sources that erase Native nations; frame plainly and check with a fresh review agent per rule 5); needs a data source (real public-domain sources); consider making the Native perspective a core fourth source, not an extra
