# How Do You Know? (idea card)

- Module: social-studies-2-how-do-you-know, grade 2. Codes: D3.1.K-2, D3.2.K-2, D4.4.K-2
- Format / family: showdown / none. Fit: change to mystery, because a solo student answering one question with clues fits better than a class vote; the class call becomes the extra.
- One idea: Help a talking backpack answer "What do pandas eat?" by choosing between a zoo keeper's fact page and a toy shop poster, calling each line fact or opinion, and asking the backpack "How do you know?" until you can tell which source to trust.
- How it plays (solo student by default):
  - First screen: Pockets the backpack, two sources on the table (a zoo fact page with headings, a photo and a caption; a bright toy poster). "Our question is: What do pandas eat? Which one should we read first?"
  - Core loop: the student picks a source by who made it and how it is built (headings and captions vs big sale words); Pockets reads lines aloud and the student calls Fact or Opinion. For each, tap "How do you know?" and Pockets says whether it can be checked.
  - Arguments: the poster says "Pandas are the cuddliest! Buy yours today!"; the student picks questions to ask about that argument and answers Pockets' questions about the zoo page's claim.
  - The aha or the end state: the answer card to the class question uses only the checkable facts, with the source named.
  - Class mode or extras (optional): new question sets (Why do leaves fall? What do firefighters do?).
- Standards, one line per code:
  - D3.1.K-2: choose which of two sources helps by its origin (zoo keeper vs toy shop) and structure (headings, captions).
  - D3.2.K-2: judge each source by sorting its lines into fact and opinion.
  - D4.4.K-2: ask and answer questions about the poster's and the fact page's arguments.
- Not like: source-scout (grade 5 multiple sources for credibility); wonder-kite (building questions, not judging sources).
- Art: generated scenes and a drawn character (Pockets), because the sources must look like real kinds of print.
- Proposed title: keep
- Proposed concept line: Help a talking backpack answer "What do pandas eat?" by choosing between a zoo fact page and a toy poster, calling each line fact or opinion, and asking "How do you know?" until you know which to trust.
- Flags: none
