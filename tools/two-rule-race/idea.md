# Two Rule Race (idea card)

- Module: math-5-patterns-and-relationships, grade 5. Codes: 5.OA.B
- Format / family: simulator / coordinate. Fit: good.
- One idea: Two garden snails start at 0 and each follows its own rule (add 3 each minute, add 6 each minute); their positions fill a table of matched terms, become ordered pairs and land on a grid, where the student spots that one snail is always twice the other.
- How it plays (solo student by default):
  - First screen: a garden path with a ruler along it, two snails (Pip and Moss), and two rule cards: "Start at 0, add 3" and "Start at 0, add 6."
  - Core loop: press go; each minute both snails step forward and the table grows (Pip 0, 3, 6, 9; Moss 0, 6, 12, 18). The student predicts the next pair before it appears, then plots (Pip, Moss) as ordered pairs on a first-quadrant grid.
  - Relationship rounds: the student types what is true for every pair ("Moss is always 2 times Pip") and the tool tests it against all terms. New rule pairs: add 2 vs add 8, add 5 vs add 10, add 4 vs add 6 (a harder relationship: 3/2 times).
  - Build round: the student writes two rules that give a goal relationship (Moss always 4 times Pip) and races them.
  - The aha or the end state: two patterns made by rules have a relationship you can see in the table and as a straight row of points on the grid.
  - Class mode or extras (optional): a projector race where the class bets on the relationship before the go.
- Standards, one line per code:
  - 5.OA.B (5.OA.3): generating two numerical patterns from two rules, finding the relationship between corresponding terms, forming ordered pairs and graphing them on the coordinate plane.
- Not like: two-trains (grade 8 lines that meet; here both start at 0 and the point is the ratio of terms), rule-machine (grade 4 single patterns), sea-search-grid (same grid engine, grade 5 reading coordinates).
- Art: generated scenes (the garden path); snails illustrated with character; table and grid drawn in code.
