# Illusion Lab (idea card)

- Module: social-studies-12-sensation-perception-and-memory, grade 12. Codes: APA.Biological, APA.Cognition
- Format / family: lab / none. Fit: good
- One idea: Run yourself through classic perception and memory experiments (a line-length illusion, a shadow-and-color illusion, change blindness, a false-memory word list, the forgetting curve), measure your own results, and learn what each one reveals about how the senses and memory build, and sometimes invent, what we experience.
- How it plays (solo student by default):
  - First screen: a lab bench with six experiment stations and the on-screen line that results stay on this device.
  - Core loop: at each station, do the task first (adjust a line until it looks equal, spot the change between flickering photos, recall a word list), then see your data plotted against typical published results, then the explanation (receptors and pathways for the sensation side; attention, encoding and reconstruction for memory).
  - Sense station: how the eye's receptors and the brain's processing produce the illusion, linking sensation to perception.
  - The aha or the end state: the false-memory station shows the student confidently "remembering" a word that was never shown, and a closing card connects this to eyewitness testimony.
  - Class mode or extras (optional): pool anonymous class results on the board.
- Standards, one line per code:
  - APA.Biological: the sense stations explain sensation and perception through receptors and neural processing.
  - APA.Cognition: the memory stations teach encoding, storage, retrieval, forgetting and reconstructive memory with the student's own data.
- Not like: brain-explorer (anatomy through cases); conformity-experiments (social pressure); jury-room (deliberation, though it may cite eyewitness memory).
- Art: drawn in code (illusions must be precise and original versions, not copies of copyrighted images) plus generated photo pairs for change blindness, because exact geometry makes the illusions work.
- Proposed title: keep
- Proposed concept line: Run yourself through classic illusion and memory experiments, see your own results next to typical ones, and learn how the senses and memory build, and sometimes invent, what we experience.
- Flags: none
