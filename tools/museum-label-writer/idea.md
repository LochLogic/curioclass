# Museum Label Writer (idea card)

- Module: social-studies-6-museum-label-writer, grade 6. Codes: D4.2.6-8, D4.5.6-8, D4.3.6-8
- Format / family: studio / none. Fit: good
- One idea: Write the museum label for a real cuneiform clay tablet that explains how writing began (counting tokens, marks pressed in clay, signs for words, then signs for sounds), fix sample labels whose steps jump around, then rewrite your label for a kids' trail card, an audio guide and the museum website.
- How it plays (solo student by default):
  - First screen: a museum case with the tablet under glass and an empty label card beside it.
  - Core loop: gather fact cards from a curator's drawer, put the steps in order and write the label (reason, sequence, example, detail); a "what we don't know" line names a debated point honestly. Then repair two sample labels with steps out of order or missing links.
  - The aha or the end state: the same explanation reshaped three ways: a 40-word trail card, an audio script read aloud, and a web page with images; each audience gets the same truth in a different shape.
  - Class mode or extras (optional): a gallery wall of finished labels.
- Standards, one line per code:
  - D4.2.6-8: the label explains with reasoning, order, examples and details, and names its limits.
  - D4.5.6-8: repairing the sample labels' structure.
  - D4.3.6-8: adapting the explanation for three audiences outside the classroom.
- Not like: river-kingdom (life in Mesopotamia, not writing an explanation); colonial-newsroom (writing with a point of view); history-article-review (reviewing, not writing).
- Art: public domain (a cuneiform tablet from Met open access, id to check at spec), because the real object is the subject.
- Proposed title: keep
- Proposed concept line: keep
- Flags: if the student records the audio guide, the screen says the recording never leaves the device, and no browser speech recognition is used
