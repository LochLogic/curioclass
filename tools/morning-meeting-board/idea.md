# Morning Meeting Board (idea card)

- Module: computer-science-k-2-signs-and-changing-values, grade k-2. Codes: EK-PRO-VD-05, E1-PRO-VD-05, E2-PRO-VD-05
- Format / family: showdown / none. Fit: good, with a solo default: one student makes every prediction, and the class vote is class mode.
- One idea: Read the picture signs on a classroom's morning board (weather, lunch choice, today's helper, the day, the class name), name each box, predict which values will change by lunch, by tomorrow or never, then drag a time slider and watch the board update.
- How it plays (solo student by default):
  - First screen: a bright morning board with six labeled boxes, each holding a picture sign (a sun, a taco, a smiling helper, "Monday", "Room 4 Owls").
  - Core loop: tap a box to hear its name and what its sign means; drag each box to "changes by lunch", "changes tomorrow" or "never changes"; slide time to lunch, then to tomorrow, and see which signs swapped (clouds roll in, the helper changes tomorrow, "Room 4 Owls" stays all year).
  - The aha or the end state: a box keeps its name while the sign inside it changes, and a few boxes never change at all.
  - Class mode or extras (optional): the class votes by standing or sitting for each box before the slider moves.
- Standards, one line per code:
  - EK-PRO-VD-05: read what each picture sign stands for (a symbol carries information).
  - E1-PRO-VD-05: name each box and tell its name apart from what is in it today.
  - E2-PRO-VD-05: predict which named values change and which stay the same, then add a box of their own and decide whether it will change.
- Not like: score-keeper (grade 3 variables in a game); robot-dance (a sequence of steps); feelings-weather-report (feeling words).
- Art: generated scenes (classroom board, picture signs), clear and high contrast for projectors.
- Proposed title: keep
- Proposed concept line: keep
- Flags: none
