# Function Machine Factory (idea card)

- Module: math-8-defining-functions, grade 8. Codes: 8.F.A
- Format / family: puzzle / function-machine. Fit: good.
- One idea: Work quality control at a factory of input-output machines: reject any machine that gives two outputs for one input, compare machines described in different ways (a table, a graph, an equation, a sentence), and sort the ones that draw straight lines from the ones that curve.
- How it plays (solo student by default):
  - First screen: a factory floor with a conveyor, three machines waiting for inspection, and the floor manager, Mr. Boateng. "Every input gets exactly one output. Test them."
  - Inspection levels: the student feeds inputs and watches outputs; a machine that gives 4 then 7 for the same input fails. Each machine's results become ordered pairs on a graph, and a failed machine shows two dots stacked on one input.
  - Compare levels: two machines described differently (one by a table, one by a graph, one by an equation, one in words); the student decides which grows faster or starts higher, and picks the machine an order needs.
  - Straight or curved levels: build machines from y = mx + b and see straight lines; a square-area machine (side in, area out) makes a curve. The student sorts machines into linear and nonlinear and gives a table-based reason (equal steps in, equal steps out).
  - The aha or the end state: a function is a rule with one output per input, and the same function can wear four disguises.
  - Class mode or extras (optional): build a mystery machine for a partner to classify.
- Standards, one line per code:
  - 8.F.A: a function assigns exactly one output to each input, and its graph is its ordered pairs (8.F.1); comparing two functions given in different representations by rate of change and starting value (8.F.2); y = mx + b as linear with a straight graph, and nonlinear examples like area = s squared (8.F.3).
- Not like: rule-machine (same family, grade 4 patterns), undo-machine (grade 11 inverse functions), story-graphs (grade 8 modeling from stories).
- Art: generated scenes (the factory floor, illustrated machines); people (illustrated) for Mr. Boateng and workers; graphs and tables drawn in code.
- Proposed title: keep
- Proposed concept line: Work quality control at a factory of input-output machines: reject any machine with two outputs for one input, compare machines given as tables, graphs, equations and words, and sort straight-line machines from curved ones.
