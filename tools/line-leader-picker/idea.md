# Line Leader Picker (idea card)

- Module: computer-science-k-2-fair-rules-for-turns, grade k-2. Codes: EK-ALG-IM-03, E1-ALG-IM-03, E2-ALG-IM-03
- Format / family: simulator / none. Fit: good, because the rule is the input and a month of turns is the output.
- One idea: Choose the rule a class uses to pick the line leader, run a pretend month of 20 school days in a few seconds, and count who led many times and who never got a turn, so the student sees that a person chose the rule and the rule chose who was left out.
- How it plays (solo student by default):
  - First screen: a row of 20 illustrated animal classmates by the door and an empty rule card slot. "Pick a rule, then run a month."
  - Core loop: rule cards: "first in ABC order" (Ant leads all 20 days, Zebra never), "draw a name and put it back" (some lead 3 times, several never), "draw a name and keep it out" (everyone once), "take turns around the circle" (everyone once, in order). Press Run and a calendar flips day by day while each leader gets a sticker.
  - Counting: a sticker chart lines up the turns per classmate; the student taps whoever never led to hear how they feel.
  - The aha or the end state: the same class, four rules, four very different months; "fair" depends on the rule, and someone had to choose it.
- Standards, one line per code:
  - EK-ALG-IM-03: run two rules and say which one gave every friend a turn.
  - E1-ALG-IM-03: compare all four rules on the sticker chart and name who each one leaves out.
  - E2-ALG-IM-03: build a new rule from parts (order, draw, skip someone who is absent) and test it, including a twist month when Bee is out sick on her turn.
- Not like: three-route-rules (grade 3-5, route rules and travelers); sorting-showdown (grade 9-12 algorithm speed); robot-dance (following steps).
- Art: generated illustrated classmates; sticker chart and calendar drawn in code.
