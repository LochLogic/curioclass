# Push the Pumpkin (idea card)

- Module: science-k-pushes-and-pulls, grade k. Codes: K-PS2-1, K-PS2-2
- Format / family: showdown / none. Fit: change to lab, because a kindergartner alone must be able to choose a push, watch it and compare; the class vote becomes the extra, not the main play.
- One idea: Push or pull a pumpkin, a ball and a wagon along a farm path with a gentle, medium or strong push from either side, see that a harder push sends it farther and a push from the other side sends it back, then place a ramp or a hay bale to steer a rolling ball into the barn.
- How it plays (solo student by default):
  - First screen: a fall farm path with a pumpkin, a hand and three push sizes shown as arrow lengths; a narrator says "Pick a push, then tap the hand."
  - Core loop: choose push strength and side (push from the left, pull from the right), predict with a thumbs up or down ("Will it pass the scarecrow?"), tap, and the object rolls; a stop mark stays, so tries sit side by side.
  - Design part: a ball rolls toward a fence; the student drags a ramp, a bale or a board into its path to change its speed or direction so it reaches the barn door, and tries again until it works.
  - The aha or the end state: a picture chart of the stop marks shows "bigger push, farther" and "push from the other side, it goes the other way"; the barn door opens when the design works.
  - Class mode or extras (optional): showdown mode where the class votes on the push before the teacher taps.
- Standards, one line per code:
  - K-PS2-1: fair side-by-side tries comparing push strength and push direction on the same object, with stop marks to compare.
  - K-PS2-2: the ramp and bale challenge; the student checks whether the design changed the ball's speed or direction as intended, and fixes it if not.
- Not like: shade-builder (designs a shelter against sunlight, not motion); tug-of-war-arena (grade 3 balanced and unbalanced forces).
- Art: generated scenes (a warm farm path, the barn, a real-looking pumpkin and wagon), because young students read real objects faster than icons.
- Proposed title: keep
- Proposed concept line: Push or pull a pumpkin, a ball and a wagon with small and big pushes from either side, compare how far and which way each rolls, then place ramps and bales to steer a ball into the barn.
- Flags: none
