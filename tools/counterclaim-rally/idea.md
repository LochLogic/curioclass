# Counterclaim Rally (idea card)

- Module: ela-7-argument-with-counterclaims, grade 7. Codes: W.7.1
- Format / family: roleplay / none. Fit: good, as long as the rally ends in a written argument; the volley is the prewriting.
- One idea: The student volleys an argument with a scripted opponent across a table tennis table, and each return has to answer the point just played (a reply that ignores it goes into the net), and the rally record then becomes an essay that acknowledges the other side and answers it, so they learn that a strong argument meets the opposing claim instead of talking past it.
- How it plays (solo student by default):
  - First screen: a table tennis table, the opponent (an illustrated eighth grader named Reza), and a topic card ("Should our school replace paper textbooks with tablets?").
  - Core loop: the student serves a claim. Reza returns an opposing point; the student picks or writes a return that answers it: concede and turn, show it is outweighed, or show it is false, with evidence from a card deck of sources. A return that only repeats the claim or answers a different point goes into the net with a replay of what Reza actually said. Rallies get longer at higher levels; Reza's best returns get harder to answer.
  - The aha or the end state: the rally sheet shows each exchange; the student turns it into an essay: claim, reasons in logical order, the strongest opposing claim acknowledged fairly, the answer to it, transitions, formal style and a conclusion. A checker flags an essay that skips the counterclaim or only mentions it.
  - Class mode or extras (optional): pairs play the rally live with the same topic cards.
- Standards, one line per code:
  - W.7.1: acknowledging and answering opposing claims, organizing reasons logically, citing credible evidence, and writing the argument with transitions, formal style and a conclusion.
- Not like: debate-prep-desk (grade 6, strengths and limits of sources); claim-vs-claim (grade 8, distinguishing claims in formal style); usage-panel (grade 11, a panel debate on usage).
- Art: people (illustrated) for Reza and the referee; drawn in code for the table and ball.
- Proposed title: keep
- Proposed concept line: Rally an argument with a scripted opponent across a table tennis table; every return must answer the point just played or it hits the net, and the rally record becomes an essay that acknowledges and answers the other side.
- Flags: none
