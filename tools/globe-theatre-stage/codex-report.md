# Codex report: globe-theatre-stage

## Built

Built in S:\CurioClass-codex, only in the assigned tool and Scratch folders. Build only, no commits, shared edits, publication or polish round.

Grade 12 students compare twelve invented productions of four fixed excerpts, classify staging choices with linked evidence, then direct and defend their own production. The painted stage is central. Switching productions changes bodies, sight lines, props and written delivery scores while preserving the selected script line.

Deliverables include readable src.html, scenes.json, the self-contained bundle, draft metadata marked built, notes, handoff, preview, voice metadata, audit states, prompts, originals and all finished art. The original spec was left unchanged.

The owner's stop-on-report instruction overrides the guide's request for an early report stub. This report is written once, at completion.
