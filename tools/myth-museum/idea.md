# Myth Museum (idea card)

- Module: ela-4-myths-and-allusions, grade 4. Codes: RL.4.4, RL.4.9
- Format / family: explorer / myths. Fit: good.
- One idea: The student walks a museum where each Greek myth exhibit ends at an everyday phrase that points back to it (Achilles' heel, a Herculean task, Pandora's box), and a second wing sets myths from different cultures side by side on one theme, so they learn that old stories still live in our words and that people everywhere told stories about the same big questions.
- How it plays (solo student by default):
  - First screen: the museum lobby with a modern sign: "Fixing this bug was a Herculean task." A guide asks: "What does that mean? The answer is in the Hall of Heroes."
  - Core loop: Greek wing: each exhibit tells a short myth through a vase or sculpture and a retelling, then shows the phrase in a modern sentence (a news headline, a coach's speech); the student explains what it means using the story. Second wing, "Same Question, Many Stories": two or three myths on one theme (why there are seasons, how fire came to people, a great flood), from Greek, Norse and other traditions, compared on what happens and what it teaches.
  - The aha or the end state: the gift shop quiz: everyday sentences full of allusions, and the student tags each with the exhibit it came from and what it means here.
  - Class mode or extras (optional): an allusion scavenger list for books at home.
- Standards, one line per code:
  - RL.4.4: each exhibit's phrase explained from the myth it comes from, then used in a new sentence.
  - RL.4.9: the second wing compares how myths from different cultures treat the same theme and pattern of events.
- Not like: allusion-hunter (grade 7, allusions in ads and headlines from many sources); side-by-side-reader (two texts, any genre); moral-of-the-story (grade 2 fables).
- Art: public domain objects (Greek vases and sculptures from the Met or AIC open access; ids to be checked at spec), plus generated scenes for retellings, because real museum objects make it a museum.
- Proposed title: keep
- Proposed concept line: Walk a museum where each Greek myth ends at an everyday phrase it gave us (Achilles' heel, Herculean, Pandora's box), then a second wing compares myths from several cultures on one question, like where fire came from.
- Flags: sensitive (non-Greek myths, and any Native stories, get a fresh review per rule 5; prefer traditions with published public-domain sources); needs a data source (museum object ids)
