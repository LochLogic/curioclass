# Square Root Hunt (idea card)

- Module: math-8-irrational-numbers, grade 8. Codes: 8.NS.A
- Format / family: puzzle / number-line. Fit: good.
- One idea: Trap numbers on a zooming number line: a repeating decimal can be caught as a fraction, but the square root of 2 slips between closer and closer decimals forever, and those squeezes are how we compare and place irrational numbers.
- How it plays (solo student by default):
  - First screen: a number line from 0 to 3, a net tool, and a puzzle master, Wen. "Somewhere here is a number that times itself makes 2. Squeeze it."
  - Squeeze levels: the student picks two decimals that trap the root (1 and 2, since 1 x 1 < 2 < 2 x 2), zooms in, and traps it again (1.4 and 1.5, then 1.41 and 1.42). Each zoom adds a digit; the digits never settle into a repeat.
  - Catch levels: repeating decimals like 0.272727... are caught as fractions by shifting and subtracting (100x - x = 27, so x = 27/99 = 3/11). The student sees every fraction's decimal either ends or repeats.
  - Compare levels: place sqrt(50), 7.1, pi and 22/7 on one line by squeezing each; estimate pi squared by squeezing pi first.
  - Sort level: a bin of numbers sorted into rational and irrational, with the reason (ends, repeats, or neither).
  - The aha or the end state: every number has a decimal; rational ones end or repeat, and irrational ones can only be approached, which is enough to compare and place them.
  - Class mode or extras (optional): a race to trap a root to three decimals in the fewest zooms.
- Standards, one line per code:
  - 8.NS.A: rational vs irrational by decimal expansion, and converting repeating decimals to fractions (8.NS.1); rational approximations to compare irrationals, place them on a number line and estimate expressions like pi squared (8.NS.2).
- Not like: deep-sea-dive (same number-line engine, grade 6 signed numbers), exponent-rule-builder (grade 9 rational exponents), size-of-everything (grade 8 scientific notation).
- Art: drawn in code for the zooming line (precision matters); people (illustrated) for Wen; generated scene for a quiet puzzle room.

- Proposed concept line: Trap numbers on a zooming number line: catch repeating decimals as fractions, then squeeze the square root of 2 between ever-closer decimals that never repeat, and use the squeezes to compare and place irrational numbers.
