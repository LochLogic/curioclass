# Expression Escape (idea card)

- Module: math-5-expressions-and-order-of-operations, grade 5. Codes: 5.OA.A
- Format / family: escape / none. Fit: good; solo by default, with team play as the extra.
- One idea: Escape a clockmaker's locked workshop where each lock reads an expression: place parentheses or brackets to make its code, turn the clockmaker's spoken notes into expressions, and say which lock is bigger without computing.
- How it plays (solo student by default):
  - First screen: a cluttered clock shop after closing time, a locked door and a note from the clockmaker, Mr. Okafor. "My locks open for anyone who reads my numbers right."
  - Lock type 1 (grouping): a dial shows 3 + 5 x 2 - 1 and the code 15; the student drags parentheses (and later brackets and braces) until the expression evaluates to the code. Wrong placements show their own value so the student sees what changed.
  - Lock type 2 (writing): a voice note, "add 8 and 7, then double it," must be built as 2 x (8 + 7) from tiles.
  - Lock type 3 (reading without computing): two drawers, 3 x (18,932 + 921) and 18,932 + 921. "Which drawer holds three times as many gears?" No calculator, no scratch work: the student explains with the structure.
  - The aha or the end state: grouping symbols change the order, and an expression tells a story before you work it out.
  - Class mode or extras (optional): a team mode with a shared timer and roles (reader, builder, checker).
- Standards, one line per code:
  - 5.OA.A: evaluating expressions with parentheses, brackets and braces, and placing them to hit a target (5.OA.1); writing expressions from words and interpreting them without evaluating, such as 3 x (18,932 + 921) being three times as large (5.OA.2).
- Not like: rule-machine (grade 4 patterns), expression-garden (grade 6 expressions with letters), expression-match (grade 7 equivalent linear expressions).
- Art: generated scenes (the clock shop, drawers, locks); people (illustrated) for Mr. Okafor; dials and tiles drawn in code.
- Proposed title: keep
- Proposed concept line: Escape a clockmaker's workshop: place parentheses and brackets to make each lock's code, build expressions from his spoken notes, and say which drawer holds more without computing.
- Flags: none
