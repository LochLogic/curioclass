# Erosion Table (idea card)

- Module: science-4-weathering-and-erosion, grade 4. Codes: 4-ESS2-1, 4-ESS2-2
- Format / family: simulator / none. Fit: good for 4-ESS2-1; 4-ESS2-2 moves (see below).
- One idea: Run a stream table of sand, clay and rock with controls for water flow, slope, wind, freezing nights and plant cover, measure how much land each one moves in a fast-forwarded season, and see canyons, deltas, dunes and cracked rock form at different rates.
- How it plays (solo student by default):
  - First screen: a long sand table on a tilt stand, a water tap, a fan, a freezer switch and a tray of plants. "Pick one thing to change. Predict how much sand will move."
  - Core loop: set one variable, run a season, and the table measures sediment caught in the end tray and the depth of the channel; results go on a bar chart. Fair-test prompts keep other settings fixed.
  - Weathering bench: rocks with water in the cracks freeze and thaw; roots grow into a crack; the student counts cycles until the rock splits.
  - Real-world check: each result links to a real photo of the same process (a gully on a bare hillside, a delta from the air, a frost-split boulder).
  - The aha or the end state: a results board ranks which agents moved the most land and which slowed it (plants hold soil), using the student's own measurements.
- Standards, one line per code:
  - 4-ESS2-1: measuring the effects of water, ice, wind and plants on weathering and the rate of erosion.
  - MOVE 4-ESS2-2: new tool: a grade 4 map tool where students turn on world map layers (mountain ranges, ocean trenches, volcanoes, earthquakes, ocean floor depth) and find that they line up in patterns, such as the ring around the Pacific; it describes patterns from maps and leaves the plate explanation to plate-puzzle at grade 6.
- Not like: fast-or-slow (grade 2 timing of changes and protecting land); island-maker (grade 2 shapes of land); canyon-reader (reading layers, not carving).
- Art: drawn in code for the sand table (it must respond to every setting), with a realistic texture; public domain USGS photos for the real-world checks, checked per photo.
- Proposed title: keep
- Proposed concept line: Run a sand table with water, wind, ice and plant controls, change one thing at a time over fast-forwarded seasons, and measure how fast each one weathers rock and carves land.
- Flags: none
