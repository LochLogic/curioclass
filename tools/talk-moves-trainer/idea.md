# Talk Moves Trainer (idea card)

- Module: eld-3-5-academic-conversations, grade 3-5. Codes: WIDA.ELD-1, SL.3.1, SL.4.1, SL.5.1
- Format / family: roleplay / eld-talk. Fit: good: a book group of animated classmates is a real discussion to join.
- One idea: Join a four-person book group discussing a short story, and at each pause choose which move the talk needs (agree and add on, disagree politely, ask a question, connect to someone's idea, sum up), then the phrase that does it, so you learn when each move helps a discussion and not just how it sounds.
- How it plays (solo student by default):
  - First screen: the group sits around a table with the short story they all read (read aloud first, so everyone comes prepared). The leader asks the first question.
  - Core loop: classmates talk in turns. At each pause the student picks a move and then a phrase ("I agree with Ana, and I want to add...", "I see it differently because...", "Can you say more about...?"). The group reacts honestly: a good question gets a fuller answer, a reply that ignores what was just said gets a confused look, and repeating the last speaker gets "Yes, that's what I said."
  - The aha or the end state: at the end the student sums up the key ideas and explains how their own thinking changed, and a talk map shows how their turns connected the group.
  - Class mode or extras (optional): grade setting (3, 4, 5) adds the grade's discussion goals; Help Lots / Some / Little fades the phrase choices to frames, then to the move alone.
- Standards, one line per code:
  - WIDA.ELD-1: social and instructional language for joining an academic discussion.
  - SL.3.1: coming prepared, asking questions to check understanding, linking comments, explaining own ideas in light of the talk.
  - SL.4.1: posing and responding to specific questions, contributing comments that link to others, reviewing key ideas and explaining own ideas.
  - SL.5.1: the same moves plus drawing conclusions from the discussion in the closing summary.
- Not like: counterpoint-frames (grade 9-12, one-on-one argument with counter moves); i-choose-because (K-2, a single reason); opinion-builder (writing, not talk).
- Art: illustrated classmates (people, illustrated) with clear facial reactions.
- Proposed title: keep
- Proposed concept line: Join a book group of animated classmates; at each pause choose the move the talk needs (add on, disagree politely, ask, connect, sum up) and the phrase that does it, then sum up the discussion at the end.
- Flags: home-language glossary may matter for frames (open question, not decided); shares the eld-talk engine with counterpoint-frames (no loss for either).
