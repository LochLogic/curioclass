# Word Problem Decoder (idea card)

- Module: eld-6-8-word-problems-decoded, grade 6-8. Codes: WIDA.ELD-3, WIDA.Explain
- Format / family: puzzle / none. Fit: good: each problem is a puzzle where the obvious keyword is a trap.
- One idea: Decode grade 6-8 word problems by highlighting the math language (per, each, times as many, less than, percent of), and find out that keywords lie: "each" can mean multiply or divide, and "5 less than x" is x minus 5, so the structure of the sentence, not the keyword, decides the operation.
- How it plays (solo student by default):
  - First screen: a problem card read aloud, with a highlighter. "Find the words that tell you the math. Careful: some of them try to trick you."
  - Core loop: the student highlights math phrases, then builds a picture of the situation (a bar model or a ratio table), then writes the expression. Puzzle pairs use the same keyword in two problems that need different operations ("Each box holds 12" versus "Share 36 so each gets..."). Reversal phrases (less than, more than, percent of, per) are shown as before-and-after diagrams. Then the student explains with frames: "The problem says ___, so I ___ because ___."
  - The aha or the end state: a "keyword trap" collection the student has caught, and a final problem with no familiar keywords at all, solved from the meaning of the sentence.
  - Class mode or extras (optional): Help Lots / Some / Little; the student writes a trap problem for a classmate.
- Standards, one line per code:
  - WIDA.ELD-3: the language of mathematics: ratio, rate, percent and comparison phrases in grade 6-8 problems.
  - WIDA.Explain: explaining how the words of the problem lead to the operation, with cause and sequence frames.
- Not like: math-explainer (grade 3-5, explaining your steps); idiom-island (literal versus real meaning of idioms); cer-builder (science claims).
- Art: drawn in code for bar models and diagrams; generated scenes for problem contexts.
- Proposed title: keep
- Proposed concept line: Highlight the math language in grade 6-8 word problems (per, each, less than, percent of), draw what the sentence means, and catch the keyword traps where the same word calls for different operations.
- Flags: home-language glossary may matter (open question, not decided); none else.
