# Plot Rollercoaster (idea card)

- Module: ela-6-plot-and-character-development, grade 6. Codes: RL.6.3, RL.6.5
- Format / family: builder / story-map. Fit: good.
- One idea: The student builds a rollercoaster track from a story's episodes, setting each one's height by how much tension it adds, and rides the coaster with the main character, whose face and thoughts change at each drop; pulling out a scene makes the track collapse where it was holding something up, so they learn how episodes build a plot and how one scene can carry a character's change.
- How it plays (solo student by default):
  - First screen: a short public-domain story (for example a chapter-length adapted O. Henry or Jack London story fit for grade 6) as a stack of episode cards, and an empty coaster yard.
  - Core loop: place each episode as a track piece and set its height (exposition flat, rising climb, climax peak, falling and resolution); at each piece the student picks how the character responds and what changes in them, backed by a line. Ride the coaster: the character's portrait changes at each piece.
  - The aha or the end state: a "remove a piece" test: pull one scene and the coaster shows what breaks (the climax has no build, the change at the end comes from nowhere, the setting is never set); the student explains what that scene did for the plot, the character or the theme.
  - Class mode or extras (optional): build a coaster for a book the class is reading, with custom cards.
- Standards, one line per code:
  - RL.6.3: placing episodes and tracking how the character responds and changes on the way to the resolution.
  - RL.6.5: the remove-a-piece test: how one scene fits the whole and adds to plot, setting or theme.
- Not like: story-map-treasure (grade 1, story elements on a map); story-building-blocks (grade 3, ordering blocks); character-web (grade 9 motivations).
- Art: drawn in code for the track and ride; illustrated character portraits for each emotion, because the change has to show on a face.
- Proposed title: keep
- Proposed concept line: Build a rollercoaster track from a story's episodes, set each one's height by its tension, and ride it as the main character changes; pull out a scene to see what part of the plot, character or theme collapses.
- Flags: needs a data source (a public-domain story right for grade 6, checked for content)
