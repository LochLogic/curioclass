## A 5-minute start

1. Garden 1: point to the seed spot. Ask the class how the gardener can get there. Tap **Step**, **Step**, **Plant**, then **Run**.
2. Garden 2 has six seeds in a row. Build it the long way first if the class wants to (twelve blocks), and run it.
3. Then tap **Repeat**. Blocks you tap now go *inside* the loop: tap **Step** and **Plant**, set the number to 6, and run it again. Three blocks did the work of twelve.

## The big idea

A program is a list of steps the computer follows in order. A **loop** (the Repeat block) does the same steps again and again, so a long program can become a short one. To write a loop, find the part that keeps repeating.

## Talk about it

- Before you run it: where will the gardener end up? Trace it with your finger.
- What part of the job happens over and over?
- The gardener bonked into a rock. Which block was the mistake? (Finding and fixing it is called debugging.)

## Good to know

- Each block lights up while it runs, and the Repeat block counts its turns (1/4, 2/4...).
- Fewer blocks earn more stars. Three stars means the shortest program we know of. Stars are saved on this device only.
- Tap **✕** on a block to remove it, **Undo** to remove the last one, **Clear** to start over. **Done with loop** sends new blocks back outside the loop. Tap inside a loop to add more blocks to it.
- One loop can't go inside another here. That keeps it right for grade 2.
- The 🎨 garden has no seed spots: plant anywhere and make a picture.
- Sound starts on.
