# Rigid Motion Twins handoff

Build only. No commit or polish round. The tool uses the starter's shared header, grade 9 to 12 theme, Curio.voice, sound and Motion controls. All local implementation is readable in src.html.

## Structure

CSS defines the field station, square rock, notebook and compact layouts. JavaScript begins with affine arithmetic, then level content, voice/state, rock rendering, animation, proof validation, measurements, real pointer and keyboard input, Criteria and the test hook. The graphing Plane draws the coordinate system and supplies coordinate conversion. Painted textures are clipped to the original polygon inside a transformed group, so the plaster itself slides, turns and mirrors with the cast.

State commits before animation. Every action that changes context calls finish(), cancels the pending animation frame, renders its exact endpoint and continues immediately. Symmetry discoveries compare affine maps, not descriptions or vertex permutations. Every symmetry experiment returns to the original shape. Level 10 requires unequal distances for the same unordered pair of vertex indices on the two shapes. Only stars are persisted; all localStorage operations are guarded.
