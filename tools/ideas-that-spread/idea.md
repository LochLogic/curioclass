# Ideas That Spread (idea card)

- Module: social-studies-9-revolutions-and-enlightenment, grade 9. Codes: D2.His.5.9-12, D2.Civ.8.9-12, D2.His.14.9-12
- Format / family: map / none. Fit: good
- One idea: Carry five Enlightenment ideas (natural rights, consent of the governed, separation of powers, equality, liberty) across an Atlantic map from 1690 to 1830 and watch each revolution (America, France, Haiti, Spanish America) read the same idea differently, then judge the governments each one built.
- How it plays (solo student by default):
  - First screen: an Atlantic map in 1750 with five idea tokens in Europe and presses, salons and ports marked: "Where will 'all men are created equal' go, and who will it include?"
  - Core loop: send an idea along a real route (a book, a newspaper, a returning soldier, a ship's crew, enslaved people's own networks in Saint-Domingue). At each revolution a short source shows how local people used it, and a context card (slavery, debt, class, the Church, Napoleon's invasion of Spain) explains why their reading differed.
  - Causes panel: each revolution gets a cause web (ideas, debt and taxes, war, elite rivalry, uprisings) that the student weights and links, so ideas show up as one cause among several.
  - The aha or the end state: four founding documents side by side (US Constitution 1787, French Declaration 1789, Haitian Constitution 1805, a Spanish American charter), scored by the student on who could vote, who was free and how power was checked. Haiti is the one that ended slavery outright.
  - Class mode or extras (optional): an "1830 report card" the class debates.
- Standards, one line per code:
  - D2.His.5.9-12: context cards show how slavery, class and empire shaped each group's reading of the same idea, and how those readings still shape views today.
  - D2.Civ.8.9-12: the founding-documents scorecard evaluates each new system against democratic principles and civic virtues.
  - D2.His.14.9-12: the weighted cause web per revolution, with effects that ripple into the next revolution.
- Not like: expansion-map (US territory, grade 8); constitutional-convention (one convention, roleplay); alliance-web (cause chain of one war).
- Art: generated scenes (period-style map, ports, salons) and people (illustrated) for Toussaint Louverture, Olympe de Gouges, Bolivar and others, because the travelers carry the story.
- Proposed title: keep
- Proposed concept line: Carry Enlightenment ideas across an Atlantic map to the American, French, Haitian and Spanish American revolutions; see how each place read them differently, weigh the other causes, then score the governments each revolution built.
- Flags: sensitive (slavery and the Haitian Revolution's violence, told plainly with care; fresh review agent per rule 5)
