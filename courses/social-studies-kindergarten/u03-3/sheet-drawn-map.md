# The unclear-key map and the drawn-map page (day 26)

Two pieces for day 26. Pictures only, with at most one word under a picture. Neither shows a case used on an exit (rule 4).

## The teacher's map with an unclear key

A teacher-made picture map of a classroom corner on a page with a thick border: a table, a shelf and a rug, each with a small symbol, and a boxed key. Two key pictures are alike on purpose: a small circle with a dot for the table and a small circle with a line for the rug. The children say which two are unclear and how to fix them: make the symbols look more different, for example a square for the table and a wavy line for the rug. Then one claim and because is modeled: "I can find the rug because the key picture matches this one."

## The drawn-map page

A pre-printed page for each child: a thick border, a boxed key area along the bottom with two empty rows, and room for two features above. The child chooses a place from the class list (playground, library, entrance or a place the class visited), draws two features of it where they really are, and draws a key picture for each in the key box. No home. The page is practice: it gets written feedback on one feature, position or key picture, and it is redrawn on day 28 from that feedback.

**Written task (day 26):** the picture key beside the drawn map. The teacher scribes the child's sentence "I can find it because ..." under the map.

**Look-fors the teacher marks on the redrawn map (day 28):** a seen feature is placed where it was seen; the key picture matches its place; counts match marks; a source detail follows "because".
