# State and street map pairs (day 28)

Three pairs of original, simplified diagrams, each pair showing one place at two sizes: a state map with one dot for the town, and a separate street map of that town with the building on its street. They are our own drawings, not copies and not traced from any map, so no commercial map screenshot is used. The state outlines are redrawn from the public-domain Natural Earth data (terms read 2026-11-19; geometry not inspected). Printed large, one pair for each table group of four. Labels are read aloud.

**What each diagram states and what it does not.** Each state map shows the state's outline and one dot with the town's name beside it. The maker places the dot from the town's coordinates and checks it against an official state map before printing; this piece states no direction or distance. Each street map shows one named street, the building on it and the town's name at the top. It is a diagram, not to scale, and shows no other streets. The only facts printed are the ones the sources support: the building's street, town and state.

**Pair 1, the Massachusetts State House.** State map of Massachusetts with the dot labeled Boston. Street map titled Boston with a building on Beacon Street. Source row 27A.

**Pair 2, the Washington State Legislative Building.** State map of Washington with the dot labeled Olympia. Street map titled Olympia with a building on Sid Snyder Avenue Southwest. Source row 27B.

**Pair 3, our school.** State map of the school's own state with a dot for the school's town, and a street map of that town with the school on its street, both made by the teacher from the school's printed address and checked against an official state map. Original or public domain only, school location verified, no commercial screenshots. This is the pair children use in table groups; day 29 uses fresh extracts cropped or scaled differently (see the response rows).

**Use:** model the State House (find the Boston dot, then Beacon Street on the Boston street map), then the Legislative Building the same way in Olympia. Error F: a puppet touches the whole outline of Washington and says "the Legislative Building is here." Right: Olympia is a dot on the state map; the building is on a street in Olympia's street map. Each child then finds the school's town and the school with help, in turn; record the help given.

**Extension (not assessed, dropped if time is short):** after the supported example, find our state on a map of the United States. No scale, no compass directions.

## Key (teacher)

The state map answers "which town"; the street map answers "which street, which building." Pointing at the whole state outline for the building is error F.
