# Day 30: Fix it and try again

## Teacher page

### Before class

Sort day 29's record by part. Set four tables. For the address table hand-letter strips for 21, Maple Court, Brook Town, Nevada, United States.

### The day

#### 2 min. Reconnect

Hand back day 29's assessment: each child sees one cell, privately. If many missed one part, teach it to the whole class first.

#### 8 min. Four tables, and pairs

Name tables by task, never by who missed. Words: error A, error J, error K. Key: error B, error C, error H, error I. Map: error D, error L. Address: error E, error F; the puppet says "Brook Town is the street" and "Nevada is the country"; set the strips in rings and name each part. Lead one table 2 minutes at a time; the others use their card's move with a partner. Pairs, changed each day, work on error G.

#### 10 min. Fresh tries

Each child tries a new card for the part missed, by pointing or token: [[s03-X30]] map and key; [[s03-X30a]] words; [[s03-X30b]] globe and map; [[s03-X30c]] graph; [[s03-X30d]] address; [[s03-X30e]] town and school. Hear six closing claims, a minute each (item 7); write each beside its named source. A child may pass. Each names one corrected relation. Unheard parts stay not yet observed.

**Ask.** How can we show someone where things are? Expect: "A key helps because its picture matches the one on the map." "Maps help because maps help" is error G: ask for a detail.

### Other rooms

The materials line names each stand-in.

### At home

**Swap.** No tokens: use buttons. No crayons: use a pencil.

**Skip.** The tables.

- **5 min. Fix one.** Look at yesterday's drawing. Pick one thing to change.
  **Say.** "What did you change? Why?" Expect: one change, with a because.
- **5 min. Again.** Draw a map with a key for a barn and a fence, with a different small picture for each.
- **5 min. Exit ticket.** Ask the one that fits: [[s03-X30]] [[s03-X30a]] [[s03-X30b]] [[s03-X30c]] [[s03-X30d]] [[s03-X30e]]. For the map: use the key.
  **Say.** "Where is the barn? How could someone find it?" Expect: the key's picture, then its match on the map.

### Shorter or longer

Shorter: the part missed. Longer: a second part.

### Words and supports

Key, street, town, between. Frames: "I can find it because ___." "The street is ___."

### Tomorrow

Day 31 is the course check, heard one to one or in small groups: why a class rule exists, why a rule outside school exists, and an "I think ..., because ..." answer.
