# Moth and poppy sheet (day 41 exit ticket)

For each child, on its own sheet. Read it aloud. Invented for practice.

## Moth Z

Boxes in a row, each with an arrow to the next. The arrow labels all say "6 days".

Day 0 egg. Day 5 larva. Day 20 pupa. Day 32 adult. Day 45 new eggs. Day 60 first moth dead.

One more arrow runs from the dead moth back to the egg.

## Poppy

Boxes in a row, each with an arrow to the next. The arrow labels all say "6 days".

Day 0 seed. Day 6 seedling. Day 42 flowering adult. Day 60 seed pod. Day 70 new seeds growing. Day 76 new seedlings. Day 84 first poppy dead.

## Questions

Which arrows or labels lack support? How would you repair the models? Draw the repair or write it.
