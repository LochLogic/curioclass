# Unit 3 record sheet: our class list

Write each child's name down the left. This unit has a readiness look on day 36. Each exit column holds one tick for each look-for the child shows, or the error letter if a gap shows. A blank answer is an incomplete part, not a letter. Mark the rotating six heard each day beside the name. Days 37 to 54 and day 58 are not scored. The End columns hold the three scored fresh checks: day 55 (End 1 to 3), day 56 (End 4 to 6) and day 57 (End 7 and 8), scored after class from that day's own work. Score each look-for 1 when complete and 0 when not, as on the score sheet. Beside each End cell, mark the revised day 53 record shown or not yet: repair evidence, never the score. A child absent on a check day is unscored, never zero. Put the date in any cell tried again later.
