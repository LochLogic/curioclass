# Unit 3 record sheet: our class list

Write each child's name down the left. This unit has a readiness look on day 36. Each exit column holds one tick for each look-for the child shows, or the error letter if a gap shows. A blank answer is an incomplete part, not a letter. Mark the rotating six heard each day beside the name. Days 37 to 54 and day 58 are not scored. The End columns hold the three scored records. Day 55 scores the revised day 53 record 1 (End 1 to 3). Day 56 scores the revised day 53 record 2 (End 4 to 6). Day 57 scores the revised day 53 record 3 (End 7 and 8). Score each look-for 2 when met alone, 1 when met with a prompt, 0 when not met and blank when not yet seen. A missing component, or a record with no feedback and revision, is unscored, never zero. Put the date in any cell tried again later.
