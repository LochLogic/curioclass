# Gap and arrow cards, day 17

Each card is labeled "invented for practice" in small letters at the bottom. Plain line drawings, no brands, no names.

## Card 1: the parcel (unit 1 retrieval)

A parcel rests on a smooth table. Two equal arrows touch it from opposite sides, one pointing right and one pointing left. A second drawing shows the same parcel with a longer arrow pointing right and a short arrow pointing left.

## Card 2: the gap

A steel clip hangs from a thread taped to a table edge. A magnet is held to the left of the clip. A gap is marked between them with a dotted line. The clip leans toward the magnet. Nothing touches the clip but the thread.

## Card 3: three arrows

The same clip. Three arrows start on it. One points toward the magnet. One points straight down. One points up along the thread toward the table edge. Each arrow has a small label: magnet pull, gravity, thread pull.

## Card 4: pull and push arrows

Two plain gray blocks, A and B, side by side. A pull card: arrows on each block point toward the other. A push card: arrows on each block point away from the other. A gap is marked between them.
