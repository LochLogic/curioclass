# Unit 2 record sheet: our class list

Write each child's name down the left. This unit has no readiness check. Each E column holds one tick for each look-for the child shows in that exit, or the error letter if a gap shows. A blank answer is an incomplete part, not a letter. The rotating six heard each day are noted by a mark beside the name. Days 17 to 28 are not scored. The End columns hold the two scored checks: day 31's fresh question sheet (End 1 to 3) and day 32's fresh toy cars statement (End 4 to 6). Score each point 1 when met and 0 when not met; leave it blank when not seen. Beside each End cell write R and a tick or a dash: the repair mark for the revised day 29 record, shown or not yet. It is repair evidence, never the score. A child absent on a check day is unscored, never zero. Never replace seen data with expected data. Put the date in any cell tried again later.
