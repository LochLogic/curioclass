# Unit 2 record sheet: our class list

Write each child's name down the left. This unit has no readiness check. Each E column holds one tick for each look-for the child shows in that exit, or the error letter if a gap shows. A blank answer is an incomplete part, not a letter. The rotating six heard each day are noted by a mark beside the name. Days 17 to 28 are not scored. The End columns hold the two scored records: day 31 scores the revised day 29 interaction record (End 1 to 3) and day 32 scores the revised day 29 lid record (End 4 to 6). Score each look-for 2 when met alone, 1 when met with a prompt, 0 when not met and blank when not yet seen. A missing component, or a record with no feedback and revision, is unscored, never zero. Never replace seen data with expected data. Put the date in any cell tried again later.
