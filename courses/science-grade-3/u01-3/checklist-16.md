# Look-for checklist (days 14 and 15, back on day 16)

The teacher fills one strip a child after each check day, about 1 minute a child: a tick for each look-for shown, a blank for not yet, and one question stamped at the bottom. No score is written here. The scored papers come back on day 17.

Name ______

## Day 14, the basket record

- [ ] Turns written in the order seen, two cycles or more.
- [ ] A center crossing between the turns.
- [ ] The repeating order marked.
- [ ] The next side is opposite the last turn.
- [ ] Two earlier cycles used as the reason.

## Day 15, the sled

- [ ] One change, how strong one push is; the rest kept the same.
- [ ] Each way tried more than once.
- [ ] My initials on my own trial.
- [ ] My own reading for each way, in whole centimeters.
- [ ] Equal opposite pushes cancel, so it stays.
- [ ] A push not cancelled can change the motion.
- [ ] Arrows match the pushes each way.
- [ ] A reading used as evidence.
