# Day 66: What do the counts say?

## Teacher page

### Before class

Hang the class table with day 65's totals. Draw the cause-and-effect model on large paper: a cause box, an arrow marked so, an effect box. Print the two backgrounds for each pair. Check conditions for the weather record.

### Safety and set-up

No moths or cloth are handled today except to point at. The thermometer is non-glass, the jar is plastic and no one looks at the sun. Only the two helpers touch the equipment; the adult empties the jar. In a weather warning the class stays indoors. Clean-up is 2 minutes.

### The day

#### 3 min. Return and repair

Hand back day 65's pages, s04-P65-1, s04-P65-2, s04-P65-3 and s04-P65-4, and tickets, s04-X65, 1 minute. Error D (bright colours hide best), 2 minutes: point to yellow moths on the yellow cloth and on the green cloth in the class table. Hiding depends on the cloth.

#### 32 min. Counts to explanation

5 minutes: the camouflage viewer is not built yet, so use the two printed backgrounds. Predict first, [[s04-P66-1]], 2 minutes. Then read the three supplied trials aloud as invented, and pairs write [[s04-P66-2]], 3 minutes. Background and counts stay the same each trial.

10 minutes: pairs use the class counts and write [[s04-P66-3]] and [[s04-P66-4]], 4 minutes, then say each aloud. Hear the rotating six, 30 seconds each.
**Ask.** Which colour was picked less on the yellow cloth, and how do you know? Expect: yellow, from the class table.

8 minutes: revise the model in a second colour. Add a row: part, colour; job, can match the cloth, so it is harder to see; background, the cloth it sits on. The arrow changes with the background, so draw a second background box. Children write [[s04-P66-5]]. Error D sounds like: a bright colour hides on every cloth. Point to the second box.

9 minutes: two sentences, [[s04-P66-6]]: what the counts show, and what a paper trial cannot show.
**Ask.** What would you need to see to say real moths live longer? Expect: records of real moths living, not paper picks. Error C sounds like: matching real moths always live longer. A trial with paper can suggest; it does not show real survival.

#### 3 min. Exit E66

Read the card aloud twice. Alone, [[s04-X66]]. Look for: matching bugs were picked less, which could help real bugs hide; paper is not alive, so it cannot show how long real bugs live. Error C says matching real bugs always live longer. Note letters on the record sheet.

#### 5 min. Weather record

Two helpers from the rotating six read the thermometer and the rain jar, 30 seconds each, while the class writes [[s04-P66-7]]. Below zero is said in words. If a reading fails, read the dated adult record and say it is supplied.

#### 2 min. Clean-up

Backgrounds collected, desks cleared, helpers wash hands.

### Other rooms

No printer: read both backgrounds and the three trials aloud, draw the table on the board and children write on notebook paper. One projector: show the backgrounds and the class table; children write on paper. No weather tools: read the dated adult record aloud.

### At home

**Swap.** No class table: use your day 65 totals, or the supplied row, 8 and 22 then 21 and 9, which is invented. No second colour: use a pen.

**Skip.** The weather record and the clean-up.

- **5 min. Backgrounds.** The parent reads both backgrounds and the three trials aloud. The child does [[s04-P66-1]] and [[s04-P66-2]].
- **8 min. Because and so.** The child does [[s04-P66-3]] and [[s04-P66-4]].
  **Say.** "Which colour was picked less on the yellow cloth?" Expect: yellow, because it matched.
- **7 min. The model.** [[s04-P66-5]]
- **8 min. Two sentences.** [[s04-P66-6]]
  **Say.** "What would you need to see to say real moths live longer?" Expect: records of real moths living.
- **4 min. Exit ticket.** [[s04-X66]], answered alone.

### Shorter or longer

Shorter: write one because and so, the model row and the two sentences. Never cut the model row, the not-shown sentence or the exit. Longer: name a place where a green moth would be easy to see.

### Words and supports

Counts, match, background, show, cannot show. Frame: "The ___ moths were picked less because ___, so ___." "This does not show ___." Home-language answers count. Read the trials aloud; accept spoken, pointed or drawn answers and a scribe.

### Tomorrow

Day 67 opens with a 4-minute Return and repair. Error C from today's exit takes 2 minutes: matching real bugs always live longer; say what a paper trial cannot show about real animals. Then the class reads two new records of differences within one kind: shrub thorns and a bird's colour.
