# Day 62: Can an animal do well alone?

## Teacher page

### Before class

Set out the moose card, the frame sheets, the item G cards and each child's day 59 drawing. Plan 90 minutes after class for item G feedback, 3 minutes a child. Check conditions for the weather record.

### Safety and set-up

The thermometer is non-glass, the jar is plastic, and no one looks at the sun. An adult prechecks the weather, goes with the two helpers, who alone touch the equipment, empties the jar and handles any ice. In a weather warning the class stays indoors. Clean-up is 2 minutes.

### The day

#### 3 min. Return and repair

Hand back day 61's pages, s04-P61-1, s04-P61-2, s04-P61-3, s04-P61-4 and s04-P61-5, and tickets, s04-X61. Run the commoner of two repairs for 2 minutes; 1 minute is for handing out materials. Error C (more gulls always means more fish): read the bar for six gulls aloud, 3 trips of 10, below three gulls' 8. Error B (one gull cannot catch fish): one gull still had 4 trips of 10.

#### 20 min. Argument and model

6 minutes: read the moose card aloud and say it is invented for practice. **Ask.** What does it show? Expect: it found food, rest and safety on its own, so not every animal needs a group. Children write [[s04-P62-1]]. A group can help; it is not a need.

8 minutes: each child writes one sentence about a day 60 card, [[s04-P62-2]], 5 minutes. A claim says what the group does; the evidence says what was seen; the so says how it helps. Then a partner checks the so and ticks it or fixes it, [[s04-P62-3]], 3 minutes. Error B sounds like: all animals need groups.

6 minutes: alone, add one arrow to the day 59 drawing in a second color, from a group action to what it gives, with so written on it, [[s04-P62-4]]. For example, the ring, so the calves stay safe.

#### 12 min. Item G

Alone, with no help. Read the meerkat card and the penguin card aloud once, then children write [[s04-P62-5]]. Say aloud that the cards are invented for practice. This draft is not scored; it is scored after revision on day 76. Four look-fors, each worth 1 point: a food link, a protection link and a cold wind link, each supported by a record on the cards, and a comparison of the small and large groups and their jobs. A support names the record, not only the claim. Collect every paper.

After class, give each child written feedback, 3 minutes: mark each look-for supported or not yet, and write one question for the weakest. Never write the answer.

#### 3 min. Exit E62

Read the card aloud twice. Alone, [[s04-X62]]. Look for: a claim that a group can help animals stay safe, one barked from the mound, so the others were warned. Error B says all animals need groups. Error C says the warning always saves every one. Note letters.

#### 5 min. Weather record

Two helpers from the rotating six read the thermometer and the rain jar, 30 seconds each, while the class writes [[s04-P62-6]]. If a reading fails, read the dated adult record aloud and say it is supplied.

#### 2 min. Clean-up

Papers are collected. The adult empties the jar; the helpers wash hands at two sinks.

### Other rooms

No printer: read both cards aloud and write the frame on the board; children answer on notebook paper. No second color: use a pen or a different line. No weather tools: read the dated adult record aloud.

### At home

**Swap.** No partner: the parent checks the so. No second color: use a pen. No day 59 drawing: draw one animal with one arrow.

**Skip.** The repair and the weather record.

- **4 min. Moose.** The parent reads the moose card aloud. The child does [[s04-P62-1]].
  **Say.** "What does the moose card show?" Expect: it found food, rest and safety alone, so not every animal needs a group.
- **8 min. A sentence.** The child does [[s04-P62-2]]. The parent does [[s04-P62-3]].
- **5 min. Arrow.** The child does [[s04-P62-4]].
- **12 min. Item G.** The parent reads both cards aloud once. The child does [[s04-P62-5]] alone, with no help.
- **6 min. Exit ticket.** [[s04-X62]], answered alone.

### Shorter or longer

Shorter: write the sentence and item G; do the arrow aloud. Never cut item G or the exit. Longer: write one more claim about a day 60 card.

### Words and supports

Alone, lookout, jobs, claim, evidence, so. Frame: "I think ___, because I saw ___, so ___." Home-language answers count. Read the cards aloud; accept spoken, pointed or drawn answers and a scribe.

### Tomorrow

Day 63 hands back the item G feedback and the claim sentence, and opens with a 4-minute Return and repair. Item G feedback takes 2 minutes. Error B from today's exit takes 2 minutes: all animals need groups. Error C reads: the warning always saves every one. Then partners question each other's evidence and each child revises.
