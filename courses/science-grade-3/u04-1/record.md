# Unit 4 record sheet: our class list

Write each child's name down the left. This unit has no readiness check. Each exit column holds one tick for each look-for the child shows, or the error letter if a gap shows. A blank answer is an incomplete part, not a letter. Mark the rotating six heard each day beside the name. Days 59 to 74 and day 78 are not scored. The End columns hold the three scored records. After day 75, score the revised day 68 item V (End 1 to 4). After day 76, score the revised day 62 item G (End 5 to 8). After day 77, score the revised day 71 item H (End 9 to 12). Score each look-for 1 when the component is complete and 0 when it is not. Leave a cell blank when not yet seen. A missing component, or a record with no feedback and revision, is unscored, never zero. Put the date in any cell tried again later.
