# Plan table for the fair box test (day 3)

## The class plan, built on the board

Question: "Do equal pushes from opposite sides change how a box moves?" Copy this table.

| Our plan | |
|---|---|
| What we change | How strong one of the two pushes is |
| What we keep the same | The box, the tray, the start line, where the pushes touch, and that both pushes go toward the box |
| What we watch | Where the box ends, in whole centimetres |
| How many tries | Three tries of each |

"Stayed" means it moved less than 1 cm. Words: balanced, unbalanced, cancel.

## Day 3 warm-up, an invented plan

Said aloud to be invented. Rin rolls a marble down a board. Then Rin rolls a heavy ball down a longer board. Pairs say what Rin changed. They say how to make it fair.
