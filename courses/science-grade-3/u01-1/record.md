# Unit 1 record sheet: our class list

Write each child's name down the left. The R columns are the day 1 readiness look: write a tick for a pass, or note the support used, with no score. Each E column holds one tick for each look-for the child shows in that exit, or the error letter if a gap shows. A blank answer is an incomplete part, not a letter. The rotating six heard each day are noted by a mark beside the name. The End columns are the two end-of-unit records: day 14 scores the revised day 12 record, and day 15 scores the revised day 7 record. Score each look-for 2 when met alone, 1 when met with a prompt, 0 when not met and blank when not yet seen. Never write 0 for a part not yet taught. Never replace seen data with expected data. Put the date in any cell tried again later.
