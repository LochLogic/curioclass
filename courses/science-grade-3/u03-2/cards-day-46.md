# Cards, day 46

Each card says "invented for practice" in small letters at the bottom. Plain line drawings, no brands, no names of real children.

## Lettuce

Lettuce parents have frilly leaves. Six offspring are all frilly. Height bands: short 3, medium 1, tall 2.

## Hamster

Hamster parents have short tails. Six young are all short-tailed. Coat colours: cream 4, brown 2.

Each child graphs both cards. Then write a likeness and a variation for each. No new content is taught.
