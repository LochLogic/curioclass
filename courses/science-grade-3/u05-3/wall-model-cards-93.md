# Wall model cards (day 93)

Each card says "invented for practice" in small letters at the bottom. Plain line drawings, no brands, no names of real children.

One card or arrow for each child to place on the wall model, 20 seconds each.

## Card kinds

- Find cards: a kind, a size and a place, from the days 82 to 86 records.
- Guide cards: what a living kind needs today.
- Arrow cards: shows (solid) or infers (dotted).
- Order cards: older, younger.
- Short-record cards: one week of the class log.

## Frame

I think ______, because I saw ______ (kind, size, place), so ______.

The one-week log strip is set beside the model. Ancient change and a week of weather are different records.
