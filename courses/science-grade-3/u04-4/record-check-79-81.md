# Record sheet with a heard column, days 79 to 81

Write each child's name down the left. One column for each item, with one mark: shown (S), shown with help (H) or not yet seen (N), and the error letter if a gap shows. Keep a watched column and a heard column. Record the day 81 exits apart and never rescore an earlier day. A child may pass; leave the cell blank.
