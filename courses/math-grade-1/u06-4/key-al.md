# Length record key

Teacher copy. Use shown, shown with help, or not yet seen. Date later help and retain the first paper.

## s06-AL-order

How would you arrange these from shortest to longest?

**Answer.** Y, Z, X from shortest to longest. Keep an aligned trace on paper; both ends matter.

- X first because its staggered far tip is farthest left. Error A. Orders by the far tips alone.

## s06-AL-compare

How does this strip tell you which is longer?

**Answer.** X passes the fixed strip; Y stops before it. X is longer. Paper trace captures both comparisons. Record one separate private reason per child, on 125 or 126.

- Equal after trimming the reference to fit each card. Error B. Changes the length between comparisons.
