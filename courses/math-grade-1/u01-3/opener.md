# Section 1.3: Questions and claims

A tally mark stands for one response. Four vertical strokes and a fifth across them form a five bundle. Count all responses for the total; count unmatched responses or steps from smaller to larger for how many more or fewer. The last word of counting on is the total in addition and the stopping point in subtraction; the subtraction answer counts the steps.

Days 11 to 13 have 60 minutes each. Day 11 stays within 10; day 12 extends the already taught counting method to 20. No number line, written algorithm or graph axes. Day 13 composes a total question on an already-seen display; comparison practice fills one missing category in a supplied question. Independent comparison composition is held for the exit. Picture frames make a question without requiring a sentence written by the child; any words can be scribed. Each frame asks one thing, its answer is separate.

Error H counts groups instead of responses. Touch every response once. Error B gives the endpoint for subtraction; use 18 - 13, five steps, so the C1 start of 11 or 12 is never rehearsed. Error F uses the larger count instead of the extras. Match pairs. Error A counts the starting total as an added step. Name and hold it. Every wrong line is spoken by one folded-paper puppet after the correct method.

Before class print displays.md and claim-cards.md for day 11, only the games/hats/blocks panels for day 12, and question-frames.md plus practice-question-frame.md for day 13. Practice uses card sorting, supplied partial tally labels and existing displays; the fresh two-way claims and full independent label/total exit formats stay closed. Use the teacher-only practice answer key in u01-1/key-practice.md. Exit pictures and key-exits.md are here. Day 11's third paper ask is exit-box-11.md, revealed in the same five-minute slot and collected with the half slip. Day 13's four judged written-task components return during day 14 Partner question and fact cards.

All displays are invented choices, not claims about real animals. No live pet, visitor, photo or local page is required. Hand-copy the figures; large paper tally sticks and squares replace purchased pieces. Day 12 practice provides a first-step cue; children complete it orally, not the full reserved observation card. Keep scraps on trays and supervise handling. Everyone marks paper; one shared display is optional. All stems read aloud, with public passing allowed.


## Hearing and return

Use the rotating-six schedule in u01-1/record.md: one 45-second ask each within five-minute Synthesis, all pairs otherwise work concurrently. Names not heard today have their next slot five days later; hearing is new evidence. Each child marks a paper exit now. Before class name the current teacher-only answer key, and reveal no held item or whole assessment format in practice. Return every judged paper on the day in handbacks.csv, using only the named part's minutes. The ten-minute group for kindergarten retrieval is distinct from the five-minute exit repair. At home the adult is the partner and may hear the child privately.
