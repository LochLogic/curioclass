# Section 1.1: Counting on keeps a group

A counted group stays counted when it is covered. Name its size once, then move one new square per new word. Counting back removes one object per word after the start. Counting up to subtract ends at the larger count, but the answer is the number of steps. Strategies come before any algorithm. Stay within 10; no number line or story-type lesson.

The kindergarten ledger contains count on and ten-frame as planned entries. Re-establish their meanings with real squares before using the words. Use the ledger's total and altogether. A plus expression is introduced beside the frame day 1; the written sum follows day 2. Step boxes are introduced day 3, a back arrow day 4. Day 6 the frame is optional, restored for access; it leaves the shared display day 7.

Each day has 60 minutes. Day 1 puts a five-minute hook before five-minute retrieval; later days start with five minutes of repair or mixed retrieval. Six paper exits stay closed until their own five-minute slot. Day 3 uses the fresh 8 + 1 case; no deck shows it.

Error A counts the start as a step. Tap the cover before moving. Error B reports the ending word instead of counting steps. Touch a dot per step. Error C recounts the starting group. Name it and cover it. Right count first, then one folded-paper puppet's wrong count; never use a child as the mistake.

Before class, print ten-frame.md, retrieval-strip.md, collection-record.md, the current deck from cards-counting.md, and later step-boxes.md, method-mats.md and partner-record.md. Print each day's half-sheet exit and keep it closed; key-exits.md and key-practice.md are teacher only. Day 1 has no readiness check. Keep the family note and unit record here.

All manipulatives have a paper path: large adult-cut squares, hand-drawn frames, folded cover cards, marked second sides and large arrow cards. Inspect pieces, keep them on trays and out of mouths; no food, sharp edges or unattended handling. One shared device is optional; point to paper instead.


## Hearing and return

Use the rotating-six schedule in u01-1/record.md: one 45-second ask each within five-minute Synthesis, all pairs otherwise work concurrently. Names not heard today have their next slot five days later; hearing is new evidence. Each child marks a paper exit now. Before class name the current teacher-only answer key, and reveal no held item or whole assessment format in practice. Return every judged paper on the day in handbacks.csv, using only the named part's minutes. The ten-minute group for kindergarten retrieval is distinct from the five-minute exit repair. At home the adult is the partner and may hear the child privately.
