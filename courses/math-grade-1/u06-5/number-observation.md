# Number observation

Use the same cues once per child. On day 126 hear children 1 to 15. On day 127 hear 16 to 30. Take one minute per child: about 22 seconds for the counts, 12 for readings, 8 for ten more, and 18 for cues, transition and recording. Leave unfinished components open. Show the reading cards one at a time.

| Cue | Actual words | Help and date |
| --- | --- | --- |
| Can you count from 88 through 102? | | |
| Can you count from 117 through 120? | | |
| What number is this? | | |
| What number is on this card? | | |
| What number does this card name? | | |
| What is ten more than 96? | | |

Keep the three written inventory slips from day 126. If the child later corrects an oral slip on paper, keep that separate from the original observation.
