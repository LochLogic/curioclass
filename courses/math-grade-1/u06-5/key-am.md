# Measurement record key

Teacher copy. Use shown, shown with help, or not yet seen. Date later help and retain the first paper.

## s06-AM-length

How long is this rectangle in these units?

**Answer.** 9 units. Retain nine equal touching copies and a drawing with matching unit boundaries.

- 8 copies spaced across the whole. Error C. Accepts gaps.

## s06-AM-space

Would you use this count for the rectangle's length?

**Answer.** No. There is uncovered space between the pieces. Mark one gap in the row.

- Yes, because all pieces are equal. Error C. Accepts a gapped row.

## s06-AM-overlap

Would this row give the rectangle's length?

**Answer.** No. Some length is covered twice. Mark an overlap in the row.

- Yes, because the pieces touch. Error D. Accepts overlapping units.

## s06-AM-mixed

Can this count go on a label for the rectangle's length?

**Answer.** No. Some pieces have different lengths. Mark two unequal pieces.

- Yes, because all the ends touch. Error E. Treats unequal pieces as one size.
