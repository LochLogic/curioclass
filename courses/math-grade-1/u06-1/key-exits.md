# Exit ticket key

Teacher copy. Use shown, shown with help, or not yet seen. Keep papers private.

## s06-X111

Which strip is longer when you line them up?

**Answer.** R is longer. Align the two starts in the trace; mark the farther tip.

- P is longer. Error A. Compares staggered far ends.

## s06-X112

Which card is longer?

**Answer.** Q is longer. P falls short of the fixed strip; Q passes it. Circle Q; accept a trace of the two aligned comparisons.

- P is longer. Error A. Reads the far tips in page position.
- Same length after shortening the reference separately for each card. Error B. Changes the reference span.

## s06-X113

How could you use one of these to tell which card is longer?

**Answer.** K is longer. One unchanged span compares J and K. Accept a span equal to either card or between their lengths. The starts line up in each comparison. Accept yarn only if held at the same marks without stretching.

- Slides the second mark between comparisons. Error B. The reference length changes.

## s06-X114a

How would your drawing help someone check 47 + 6?

**Answer.** 53. Four old tens, one new ten, three ones. Connect seven original ones and six incoming ones to a new ten and three ones. Moving three to make 50, then adding three, also works. A bare final drawing leaves the method open.

- 17 from 4 + 7 + 6. Error K. Counts forty as four ones.
- 54 after recounting an incoming one. Error G. Counts one object twice.

## s06-X114b

Do both sides show the same amount?

**Answer.** Yes. Both complete sides make 17. The left makes 8 then 17; the right makes 15 then 17. Accept marks or counters that account for both sides.

- False, 17 should come next. Error L. Reads equals as an instruction.
