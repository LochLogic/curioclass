# Compare lengths from the same start

Line up the near ends. Only after they share a start do the far ends tell which object is longer. Children order three classroom lengths after that first comparison. When the two objects cannot move, use one fixed comparison strip twice. A span that is between the lengths, or that matches one of them, can settle the comparison. A span longer than both might leave the order open.

Have pairs take turns handling and checking. Each child can make a trace on paper. Use large precut strips for string, a straight paper edge for a table edge and drawn tens and dots for cubes. Ask “What stayed fixed?” after the second comparison. Use shorter, longer, shortest and longest after children line up real objects.

Error A comes from looking at far ends without checking starts. Error B comes from changing the reference. Rebuild the comparison using a fresh pair. On day 114, show which ones formed a new ten. For error K, keep whole tens intact. For error L, compare the complete quantities. When a count repeats a piece (error G), move or mark it once. Days 111 and 112 return the prior unit’s private records in Centers.
