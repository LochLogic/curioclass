# Exit ticket key

Teacher copy. Use shown, shown with help, or not yet seen. Keep papers private.

## s06-X115

How long is this rectangle in units this size?

**Answer.** 6 units. Six equal lengths touch and span the rectangle. Use the stated single length. Mark both ends and the joints.

- 5 equal units with gaps. Error C. Counts open spaces as covered.
- 7 overlapping units. Error D. Counts some length twice.
- 5 units using four singles and a double. Error E. Counts unequal pieces as the same length.

## s06-X116

How would you fix one row that measures the strip the wrong way?

**Answer.** 5 equal units touching across the whole span. Accept fixing one faulty row: close gaps and add one, remove overlap and one excess piece, or swap the double for two singles.

- Four units, gaps left open. Error C. Accepts gapped measurement.
- Six units, overlaps left in. Error D. Accepts overlapped measurement.
- Four single units including the double. Error E. Combines sizes into one count.

## s06-X117a

What count goes on the small-piece row?

**Answer.** 8 small units. Trace each small piece once.

- 9 after pointing to one unit twice. Error G. Counts a unit twice.

## s06-X117b

How can the second row measure that very same length?

**Answer.** 4 large units cover the same span as 8 small units. Mark one large piece matching two small pieces, or show the same pairing across the row. Exploratory evidence.

- Counts three large pieces and two small pieces as five large units. Error E. Mixes sizes in a count.
