# Six card pieces (day 1 readiness)

Cut six pieces from cereal-box card, no cost. Put them in an envelope for each child. Day 2 uses six large blocks instead, rebuilt the same way.

Task for day 1: six stiff card pieces made a bridge. Use the same six pieces to make a different object. Draw it and label all six pieces. Then write how one piece's shape or stiffness helps its new job.
