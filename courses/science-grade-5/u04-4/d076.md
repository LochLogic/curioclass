# Day 76: Checking the light comparison

## Teacher page

### Before class
Read opener.md and teacher-only-answer-keys.md; prepare the footprint key. Bring day 75 papers. Set two matching flashlights, distance markers at 90/180 cm and opaque screen with the same outlined receiving patch. Check ruler's 1 cm marks and lit routes. Prepare light-log.md and L76.md separately from actual observations. Keep correct light-path-card.md available and current exit covered.

### The day

#### 5 min. Return and repair
Return day 75 s04-X75, s04-K75-1, s04-P75-actual and s04-P75-control. Review return and repair. Error F: compare near/far fixed-patch evidence for two minutes, trace the correct spreading component for two, explain for one. More than ten matching misses makes this whole-class. Others check a model limit. Describe control/path omissions privately without inventing error letters.

#### 7 min. Recall
Review apparent brightness from 75 and grade 4 source, object, receiver. Retrieve the correct spreading light-path-card without asking anyone to revise it. Review fair test: keep the same, change one thing, watch one thing. Children locate the fixed patch and output setting. Hold distance evidence apart from the seeing path. The model explains less light per equal patch, not light disappearing.

#### 18 min. Control audit
Six seated groups observe simultaneously. Adult reads the 90/180 cm marks to 1 cm. Repeat one enclosed lamp at both distances, keeping output, receiving patch, room light and observation position fixed. Swap lamps and repeat both positions to check output. Keep light-log dates and brighter/dimmer/unclear observations. Retry contrast once; retain unclear, then announce L76 as invented for practice. No sensor readings are claimed for eyes.

Alone, complete [[s04-P76-audit]] and [[s04-P76-footprint]]. Outline footprints without ray revision or equal-total arrays. **Ask.** Why does your selected control matter? Expect changing only distance allows the comparison to test distance. If outlines disagree, keep actual observations and discuss visibility rather than erasing them.

#### 8 min. Evidence discussion
Three minutes: pairs compare one control explanation, one minute each and one tracing the record. Five minutes: review rotating six heard, record sheet names who. Hear six forty-five-second reports; passing is allowed. All thirty return paper. Teacher tags the shared correct model with actual or supplied evidence. Do not join control selection with a competing-record seeing-path question.

#### 4 min. Fresh evidence
Reveal [[s04-X76]] now. Three minutes independent paper, one collecting slips. After class, thirty forty-five-second exits and sixty fifteen-second practice entries take thirty-seven-and-a-half minutes. Review formative scale: shown, shown with help, not yet seen. Error F denies a distance effect. Light-disappearance claims or incomplete paths get descriptive notes. Return on 77.

#### 3 min. Cleanup
Adult stores lights. Children collect papers and distance marks with room lighting restored.

### Other rooms
No equipment: use L76, announced as invented for practice. Trace supplied footprints qualitatively from the correct card; retain any actual unclear record. No printer: copy today's frame and held exit.

### At home
**Swap.** Without apparatus, use invented L76 and the correct path card. Draw the page if needed.

**Skip.** Public reports.

- **5 min. Return.** Read day 75 notes beside the correct spreading component.
- **7 min. Recall.** Locate fixed output and receiving patch.
- **13 min. Audit.** Adult moves one enclosed lamp. Child completes [[s04-P76-audit]] and [[s04-P76-footprint]].
  **Say.** "Why keep that condition fixed?" Expect a comparison that changes only distance.
- **5 min. Exit ticket.** Give [[s04-X76]] alone; discuss the separate key afterward.

### Shorter or longer
Shorter: hear fewer reports, keeping the audit and exit. Longer: describe what an unclear footprint prevents us from concluding.

### Words and supports
Review apparent brightness, spreading and fixed condition. Frame: "Keeping __ fixed lets us compare __." Read records neutrally; supply outlines if contrast is inaccessible, labeled invented.

### Tomorrow
Day 77 returns E76, audit and footprint papers in five-minute Return and repair. Error F gets fixed-patch evidence; other gaps receive descriptive notes. Then compare travel times and a separation scale, with disk images separately.

### Credit
Ours. Source S04-light supports the distance explanation; supplied readings are invented for practice.
