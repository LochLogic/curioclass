# Day 109: connect a proposed change to recorded failure evidence

## Teacher page

### Before class
Use the current-day data key for all items; it supersedes shared keys. Separate teacher-keys.md and today's held-exits.md with held-graph-109.svg. Cover these until the exit. Retrieve A/B slips, plots, versioned sketches and the listening roster from 108. Set proposal-notes.md, dot-audit.md, pencils, second color and folders. Use shared pieces as component prompt masters; children write on today's page. Keep graph-linked repair cases out of practice.

### The day

#### 10 min. Return and repair
Return privately: s06-X108, s06-P108-audit, s06-P108-fault, s06-P108-repair-F, s06-P108-repair-G, s06-P108-route.
Honor day 108's Tomorrow. Review return and repair. Return E108, component pages including s06-P108-route, and repair slips privately. First five minutes: error F, one good result versus repeatability, [[s06-P109-repair-F]]. Next five: error G, deleting versus preserving stopped-flow evidence, [[s06-P109-repair-G]]. More than ten misses uses that whole-class round; otherwise assigned repairs run beside single-dot audits. Collect corrections and log unresolved needs.

#### 5 min. Failure components
Review failure: observed goal not met under a stated test condition. Review criterion: a way to check the need is met; constraint: the familiar limit on a design. Separately point to one actual graph mark, then one water-route observation. Review system-model arrows linking parts by actions. A graph shows amounts; a fault note supplies observed route evidence. Neither alone proves an unseen cause.

#### 20 min. Design components
Pairs inspect A/B slips, or separate T107 labeled invented for practice. Use [[s06-P109-locator]] to locate one recorded blocked/bypassed route. If actual slips name none, retain uncertainty and use the labeled archive for discussion. Each child marks a fault locator. Separately use [[s06-P109-fixed]] to name one fixed condition.

Use [[s06-P109-change]] to propose one A/B feature change within the earlier media limit. Keep original sketches; annotate in a second color. Partners inspect one feature at a time. Review design-cycle: define, sketch, build, test, compare. No change has succeeded until retested. Do not supply a complete graph-linked repair paragraph or reserve-case drawing. Teacher holds proposals and separate control notes. Error H changes an unrelated feature; point back to the recorded route and let the child reconsider.

#### 5 min. Share and handoff
Review rotating six heard. Continue day 108's roster: six 45-second component reports, 30 seconds collection. All thirty return paper; a pass remains unheard. Tomorrow dry-revises A/B proposals; a different prototype supplies fresh retest evidence. Keep these evidence streams separate.

#### 5 min. Paper exit
Cover practice. Reveal [[s06-X109]] with held-graph-109.svg on a half slip. Read exactly, invented for practice. Four independent minutes, one collection. After class: thirty drawings at 35 seconds take 17.5 minutes; component pages at ten seconds take five. Review one scale: shown, shown with help, not yet seen. Error H proposes an unrelated change. Constraint or graph-link gaps get descriptive feedback.

### Other rooms
No actual trials: use separate T107, with supplied evidence labeled. No devices: paper plots suffice. No printer: draw component prompts; copy exact exit/graph only at release.

### At home
**Swap.** Missing actual slips: use T107, labeled invented for practice. No printer: draw response spaces and copy the held graph at release.
**Skip.** Public reports.
- **8 min. Repair.** Return day 108 work; use [[s06-P109-repair-F]] and [[s06-P109-repair-G]].
- **5 min. Inspect.** Adult points separately to one graph mark and one fault.
- **15 min. Propose.** Use [[s06-P109-locator]], [[s06-P109-change]] and [[s06-P109-fixed]] separately.
  **Say.** "Name one condition to keep fixed during your proposed classroom change." Expect input, mixture, position, interval or reset.
- **5 min. Exit ticket.** Cover practice; complete [[s06-X109]] alone. Return feedback on day 110.

### Shorter or longer
Shorter: inspect fewer duplicate slips, keeping one fault and fixed-condition decision. Longer: name a future trial that could distinguish two possible causes.

### Words and supports
Review failure, criterion, constraint and design-cycle. Enlarge routes or provide tactile dry parts. Neutral reading/scribing preserves the child's proposed change.

### Tomorrow
Day 110 returns E109 and component/repair pages. If many changed unrelated features, error H gets five minutes on a fresh fault. Carry A/B proposals into dry revision. Their performance remains untested; fresh independent retests come later that day.
