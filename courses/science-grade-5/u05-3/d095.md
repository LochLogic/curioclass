# Day 95: Small stores on a shared scale

## Teacher page

### Before class
Return s05-X94 and s05-P94 labels. Separate teacher-only exit-key.md. Cover the Archive C ticket and Side 2 Exit box. Prepare the single swamp axis. The student-page axis supplies small ticks for reading only. Enlarge without changing relative positions. These are supplied estimates, not classroom instrument readings; an unreadable copy needs enlargement, never an invented measurement.

### The day

#### 10 min. Return and repair
Review return and repair. If day 94's tickets showed error E, spend five minutes tracing the fresh subset back to its parent. Next five minutes: error F, restore surface and other fresh water, including ground ice and soil moisture. Over ten gaps makes the matching route whole-class; otherwise support that group while others reread feedback. Return all papers without extra conferences. Do not rehearse the cabinet display.

#### 3 min. Decimal retrieval
Read the invented ribbon aloud as invented for practice. Alone, [[s05-P95-2]]. Read 0.04 as four hundredths and 0.18 as eighteen hundredths. If decimal reading is unavailable, align the hundredths columns directly; eighteen hundredths exceeds four. No prior math teaching is presumed.

#### 9 min. Teach small endpoints
Introduce inset: an enlarged graph showing small quantities. Read supplied fresh-lake, river and swamp values from today's table. Say 0.006 is six thousandths, above zero. Point to individual ticks on the reading axis; do not construct paired lake/river bars. Model [[s05-K95-1]] on the single swamp axis. [[steps:s05-K95-1]] Review day 92's equal-unit convention: lengths compare amounts only when zero, units and scale match. This inset magnifies a view; it adds no water. If a value seems invisible, enlarge the axis, never round it to zero.

#### 10 min. Component practice
Pairs use [[s05-P95]] with a loose strip, then each records the swamp endpoint independently. Each partner reads it for forty-five seconds, ninety seconds per pair. Teacher circulates during the remaining time. Children retain the source label; teacher retains the single-store consensus. If error H compares lengths alone, point to the unit and scale. No faulty paired display or whole-comparison package is practiced.

#### 5 min. Share
Review rotating six heard, record sheet names who. Hear the next six endpoint readings, forty-five seconds each; passing is allowed. All thirty return endpoint slips in the last half minute. Record listening only for those heard.

#### 8 min. Paper exit
Reveal [[s05-X95-1]] and its unused axes, then the Side 2 Exit box [[s05-X95-2]]. Read both exactly; say Archive C is invented for practice. Children independently draw on the half ticket and explain in the Exit box. Collect both. After class: thirty paired records at forty seconds, twenty minutes; thirty endpoint slips at ten seconds, five minutes. Review one scale: shown, shown with help, not yet seen. Error H changes scales; error E keeps the all-water whole. Return on day 96.

### Other rooms
No printer: copy the reading axis and swamp axis proportionally, then copy the held axes separately. Neutral reading or scribing preserves the child's choices. Keep the whole-response box separate from the ticket.

### At home
**Swap.** No printed axes: copy their relative tick positions onto separate paper. Enlarge if needed.

**Skip.** Public sharing and class collection.

- **5 min. Return.** Review day 94's whole and remainder feedback.
- **3 min. Decimals.** Child uses [[s05-P95-2]].
- **9 min. Model.** Read the table; use [[s05-K95-1]] on the swamp axis.
- **10 min. Practice.** Child completes [[s05-P95]].
  **Say.** "Which endpoint does this strip reach?" Expect 0.03 parts per 100 fresh-water shares.
- **8 min. Exit ticket.** Cover practice. Give [[s05-X95-1]] and the separate Exit box [[s05-X95-2]], alone. Keep both for feedback.

### Shorter or longer
Shorter: reduce repeated partner readings, preserving the model and exit. Longer: partners discuss [[s05-C95-1]] orally, without a new written record.

### Words and supports
Review whole, share and scale. Use large high-contrast ticks and neutral reading; remove hints before independent work.
