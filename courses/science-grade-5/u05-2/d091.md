# Day 91: Explain an existing display

## Teacher page

### Before class
Return day 90 papers s05-X90-1 and s05-X90-2, plus s05-P90. Place retained tray records beside the teacher's day 89 water-land arrow. Prepare unit 5 existing display rehearsal; fill its source locator with each child's existing record label. Leave other writing fields unused. Cover the new exit; separate teacher-only exit-key.md. Keep earlier exits closed during practice. Lay out retained action strips, not full assessment cases.

### The day

#### 10 min. Return and repair
If many made error A in day 90's exit, spend five minutes pointing through the returned route orally. Otherwise support that group while others find their record labels. Next five minutes: error G, review day 88's distinction between little salt and tested safety. Point to the absence of testing results; no samples or new safety content. Over ten gaps makes the corresponding route whole-class. Return s05-P90 without added conferences. Review return and repair and the one scale: shown, shown with help, not yet seen. No practice writing is drafted or revised.

#### 8 min. Reopen existing displays
Review land and water as system parts and the arrow as their observed action. Place familiar component words beside the existing tray arrow. Students point to the part affected and its record label. Keep actual and supplied-invented evidence separate. An unclear actual view cannot become a claimed measurement. Review day 89's action evidence and day 88's separate water-land action. Students neither copy nor revise a drawing. Teacher alone retains consensus notes.

#### 15 min. Accurate explanation rehearsal
Partners use [[s05-P91]]. **Ask.** [[s05-P91]] Expect an existing action linked to its observation, such as lower grain marks supporting water carrying sand. Two simultaneous forty-five-second turns take ninety seconds per pair. Allow ninety seconds for pointing feedback; repeat this three-minute cycle twice. Next six minutes: privately point through retained evidence, then explain again with the partner. Final three minutes: the teacher records consensus wording while children check it against the existing records. If only names appear, point back to the action label. No new case, display draft or speed score.

#### 5 min. Share
Review rotating six heard, record sheet names who. Hear the next six on the class list, forty-five seconds each; children may pass. Each points to an existing arrow and its evidence. All thirty return the prefilled locator slips in the last half minute. Claim oral evidence only for children actually heard; a locator alone cannot establish explanation quality. Keep other oral observations unavailable, not assumed wrong. The independent exit supplies paper evidence from everyone.

#### 7 min. Paper exit
Reveal [[s05-X91]], invented for practice, for independent paper work. This new display is separate from oral fluency practice. Collect thirty half tickets. After class allow thirty seconds per child, fifteen marking minutes. Check thirty locator slips for ten seconds each, five additional minutes; give descriptive locator feedback, not an inferred oral mark. Use the one formative scale. Error A lists parts without an action; error C denies unseen air's effects. Return tickets, slips and s05-P91 feedback on day 92.

### Other rooms
No printer: point through retained notebook evidence; copy only the new exit onto separate covered paper. Enlarge existing labels or read neutrally. No outdoor observation is needed.

### At home
**Swap.** No copies: use the retained drawing and raw record; copy the exit separately.

**Skip.** Public reporting and class collection. Leave rehearsal writing fields unused.

- **5 min. Return.** Point through day 90's feedback; distinguish low salt from testing.
- **8 min. Reopen.** Place the existing tray drawing beside its evidence.
- **15 min. Explain.** Child uses [[s05-P91]], pointing while speaking. Adult is the partner.
  **Say.** "What supports the arrow you are pointing to?" Expect a specific matching observation, honestly labeled actual or supplied.
- **7 min. Exit ticket.** Give [[s05-X91]] alone on separate paper. Child draws independently; keep it for feedback.

### Shorter or longer
Shorter: reduce repeated rehearsal, preserving repair and exit. Longer: orally identify a limit of the existing tray evidence.

### Words and supports
Review evidence tags and action labels. Point to enlarged existing words. Withdraw oral prompts for the independent exit.

### Tomorrow
Day 92 returns s05-X91 and s05-P91 locator slips. Its ten-minute Return and repair uses five minutes for error A, disconnected names, and five for error C, unseen air excluded. Then locate water stores on maps, including underground water and ice.
