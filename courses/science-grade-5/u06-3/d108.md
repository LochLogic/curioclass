# Day 108: graph trials and locate recorded failures before changing designs

## Teacher page

### Before class
Use the current-day data key for all items; it supersedes shared keys. Separate teacher-keys.md and today's held-exits.md. Retrieve all day 107 serial slips, keeping actual records separate from T107. Prepare blank line-plot paper, dot-audit.md, pencils, second color, folders and the formative record. Cover exit liner records. Carry day 105's rotating-six listening roster. Keep every original reading and unresolved reason.

### The day

#### 10 min. Return and repair
Honor day 107's Tomorrow. Review return and repair. Return E107, component pages and repair slips privately. First five minutes: contrast one result with all repeats, error F, [[s06-P108-repair-F]]. Next five: erasing versus retaining a fault, error G, [[s06-P108-repair-G]]. More than ten misses uses that whole-class round; otherwise assigned repairs run beside single-slip audits. Collect corrections; log unresolved needs.

#### 5 min. Plot components
Review line plots from grade 4: one mark per trial, stacked when values match. Review day 105's half-cup intervals. Draw a cup axis from zero with equal half-cup steps. Place one actual volume, adding its identifier and unit; trace it to its slip. Review data-graph: labels connect marks to observations. Between-mark estimates remain labeled. Unresolved volumes receive an adjacent note rather than a mark at zero.

#### 20 min. Evidence audit
Teacher builds separate complete A/B plots from original slips before discussing changes. Do not pool groups with incompatible conditions. Use T107 only as a separate record labeled invented for practice. Pairs audit one dot at a time, [[s06-P108-audit]], using dot-audit.md as prompt master; write on this student page. Then inspect a separate fault note, [[s06-P108-fault]]. Switch single components, rather than compiling replacement plots with faults. If no fault was recorded, say so; invent no leak.

Review failure: observed goal not met under a stated test condition. Keep cloudiness ordered and separate, without averaging. A blocked-outlet zero collection is a recorded result; an unreadable volume stays unresolved. Discuss the water route indicated by a fault, without claiming an untested cause. Review system-model: [[s06-P108-route]] traces one observed component route. Teacher retains plots and slips for 109.

#### 5 min. Share and handoff
Review rotating six heard. Continue day 105's exact listening roster: six 45-second component reports take 4.5 minutes, with 30 seconds collecting. All thirty submit paper; a pass remains unheard. Send plots and fault locators to 109. No redesign or complete replacement-graph rehearsal today.

#### 5 min. Paper exit
Cover practice plots. Reveal [[s06-X108]] on a half slip with room for two line plots. Read exactly, invented for practice. Four independent minutes, one collection. After class: thirty plots at 40 seconds take twenty minutes; component pages at ten seconds take five. Review one scale: shown, shown with help, not yet seen. Error F selects one favorable result; error G deletes N2. Plotting gaps get descriptive feedback.

### Other rooms
No actual measurements: plot separate T107 evidence, labeled supplied. No devices: draw teacher plots. No printer: copy response spaces and the held exit at release.

### At home
**Swap.** No actual trials: use separate T107, labeled invented for practice. No plot paper: draw equally spaced half-cup ticks.
**Skip.** Six public reports.
- **8 min. Repair.** Return day 107 work; use [[s06-P108-repair-F]] and [[s06-P108-repair-G]].
- **5 min. Plot.** Adult models one mark from one slip, with identifier and unit.
- **15 min. Audit.** Adult plots all original volumes; child completes [[s06-P108-audit]], [[s06-P108-fault]] and [[s06-P108-route]] separately.
  **Say.** "Find one recorded fault on a retained trial slip." Expect a recorded fault/identifier, or none recorded.
- **5 min. Exit ticket.** Cover practice; child completes [[s06-X108]] alone. Return feedback on day 109.

### Shorter or longer
Shorter: audit fewer duplicate marks, preserving every plotted trial and exit. Longer: inspect whether two group records used matching conditions.

### Words and supports
Review line plot, data-graph, failure and system-model. Enlarge axes and describe marks neutrally. A scribe records the child's placement decisions.

### Tomorrow
Day 109 returns E108 and component/repair pages. If many chose one favorable trial, error F gets five minutes; removed failures, error G, get five more. Carry plots and fault locators into proposed improvements. Keep original observations unchanged.
