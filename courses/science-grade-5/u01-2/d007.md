# Day 7: One account across familiar evidence

## Teacher page

### Before class
Keep d007-key.html teacher-only. Gather familiar drawings and original records. Return day 6's s01-X6 and practice tasks; reopen day 5's error B feedback. Prepare three separate panels: ball, syringe, salt. Keep observations and invented alternatives distinct. Use the formative class list: shown, shown with help, not yet seen. Add error notes separately, without points. No dish or lens is needed.

### The day

#### 5 min. Reopen
Review day 6's residue evidence and day 5's unseen-scale labels. Return s01-X6, s01-P6-1 and s01-P6-2. Revisit s01-X5 feedback for error B. If many showed error B on day 5, compare an existing grain drawing with its unseen-part enlargement. Relabel orally; dots are symbols for much smaller parts. If error C is larger, reconnect retained salt with the recovered residue instead. Choose one five-minute route; offer the other during group rehearsal. No new case or written revision.

#### 20 min. Consensus model 1
Review: consensus is a shared explanation supported by evidence, from grade 4. Keep the three familiar panels separate. Five minutes: children locate original records in model evidence folders for [[s01-P7-1]]. Retain actual uncertainty; invented records remain labeled invented for practice.

Next nine minutes: six concurrent groups rehearse three separate components orally. Each child has one 30-second turn per component, 7.5 minutes per group in all; anyone may pass. Use each existing model label, then point to its supporting record. Ball readings support added air; syringe readings support retained air in less space; the dish comparison supports retained dissolved salt. These are model explanations, not sightings of tiny parts. The teacher circulates without claiming an individual oral check of all 30.

Final six minutes: hear one volunteer per group, six 30-second reports, and join their existing panels on the wall. Name this shared account consensus model 1. Use existing labels; children neither draft nor revise a written model during practice. Keep unresolved readings beside the account. The teacher retains this wall copy until day 15; children keep personal drawings.

#### 14 min. Grains and parts
Review day 5's visible-grain versus unseen-part distinction. Use the existing enlargement on each panel, not a new drawing. Partners point to the visible-scale view and the proposed unseen-scale view. They explain orally what stays and how the record supports it: three 45-second turns per partner take 4.5 minutes, concurrently.

Finish [[s01-P7-1]] by circling evidence on each original record, separately. No combined two-case practice model. Error B: the lens reveals grains or residue, never these unseen parts. Error C: clear liquid alone does not establish absence. Collect locator pages and relevant records for day 8. After class allow 30 times 10 seconds, 5 minutes, for descriptive feedback.

#### 4 min. Exit ticket
Cover familiar panels. Reveal [[s01-X7]] for an independent paper model. First sight of both invented cases. After class: 30 tickets times 18 seconds, 9 minutes marking. Use the class list's three categories; note errors separately. Return day 8 in Return with the locator page.

#### 2 min. Put away
Store dry panels and folders; retain consensus model 1 and the question board. No wet cleanup or lens queue today.

### Other rooms
No projector: point to paper panels. Missing original records: use the earlier days' explicitly invented fallbacks, never claim firsthand observations. No printer: copy the locator; reveal the exit at its turn.

### At home
**Swap.** Without class records, use the earlier days' invented records, labeled as such. No printer: copy the locator and hide the exit.

**Skip.** Group reports and classroom feedback queues.

- **5 min. Reopen.** Read feedback from days 5 and 6.
- **12 min. Rehearse.** Use [[s01-P7-1]] with the ball, syringe and salt records separately.
  **Say.** Which evidence supports each existing label? Expect added-air readings, reduced syringe space, and salt residue.
- **10 min. Compare scales.** Point to familiar grain and unseen-part views. Explain each orally; circle supporting evidence.
- **3 min. Store.** Keep drawings for tomorrow's weighing plan.
- **5 min. Exit ticket.** Hide practice panels and reveal [[s01-X7]]. Work alone, then discuss with the teacher answer key.

### Shorter or longer
Shorter: reduce public reports, preserving individual evidence location and exit. Longer: rehearse a familiar component again using its exact observation record.

### Words and supports
Review: consensus, evidence, grain and unseen parts. Pointing may replace public speech. Allow a scribe for the independent exit without hints; enlarged records preserve the same demand.

### Tomorrow
Day 8 returns s01-X7 and s01-P7-1 in Return. Errors A/I need retained-air evidence; errors B/C need scale or retained-salt evidence. Use the existing feedback routes. Consensus model 1 then supports planning a complete-system weighing comparison; keep pot logs stored for unit 2.
