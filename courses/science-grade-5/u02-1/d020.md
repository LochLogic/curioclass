# Day 20: Measure a plant, keep the limits

## Teacher page

### Before class

Prepare exit-20.md using exits-18-22.md; keep teacher-keys.md, practice-teacher.md and current answer keys private. Use record.md. Stage class bean pots, ruler sets, shadow stick and chalk. Check allergies and direct safe viewing access; otherwise use H20 from measurement-log.md. Lay out hand-washing supplies, damp wipes and waste bag; eye protection, nonlatex gloves and aprons protect adult handlers. Keep historical-card.md and day 19 papers ready. No safe handling kit: use paper.

### The day

#### 10 min. Return and repair

Return day 19's s02-X19. If many overclaim a source from growth, error I, spend five minutes contrasting H18's measurements and missing controls. Ready children locate omissions. For error C, spend five comparing M19's mineral treatments; soil-free does not mean mineral-free. Each move has two contrast minutes, two for an individual correction, one collection. Reuse familiar components, not today's held height/routes package.

#### 5 min. Measurement reminder

Review day 3's ruler zero and whole centimeter. Align zero with the soil surface, not the pot base; read the highest tip without stretching it. Read to the nearest whole centimeter. Unreadable tip: record unclear.

Separately review day 18's structure-function model: water enters roots; part of air enters leaves. Sunlight supplies food-making energy. No height calculation or combined routes model in this oral reminder.

#### 18 min. Height observations

Return day 19's s02-P19-1/2/3, two minutes. Six groups work simultaneously. Each child gets a 45-second ruler turn: five turns take three minutes forty-five seconds per group. Teacher moves pots; children touch only exteriors and rulers. **Ask.** [[s02-P20-1]] Record independently; repeat a reading within remaining group time.

Review day 8's one retry: retain failed readings separately, then label H20 supplied if still unclear. Its 6 cm then 9 cm gives 3 cm increase. Compare earlier heights only if zero/top definitions match; otherwise start a baseline. H20 never fills an actual blank. Height indicates size change, not matter sources. Remaining time compares methods and records discrepancies, without drawing incoming routes.

#### 5 min. Shadow record

Review day 3's monthly shadow routine: same fixed stick, place and sun time; note clock changes. Teacher demonstrates one shared reading in whole centimeters using the ruler and chalk. Class stays in the prechecked supervised viewing area; transitions must fit this slot. Look only at the shadow, never the sun. No thirty-child measuring queue.

**Ask.** [[s02-P20-2]] Clouds, unsafe access or indistinct tip: retain the failure, retry once if feasible, then announce H20 invented for practice. Record its 32 cm separately. One point cannot establish a seasonal pattern.

#### 3 min. Clean-up

Teacher stores pots and rulers, wipes surfaces and washes hands with soap, running water and towels. Paper-only observers do not queue. Accidental soil/water contact stops for washing; no tasting or sniffing. Collect both observation responses.

#### 4 min. Exit ticket

Reveal [[s02-X20]] now, exact stem, invented for practice. Everyone responds alone on the half slip. After class: 30 times 20 seconds, ten minutes exit marking; ten more for descriptive log feedback. Use shown, shown with help, not yet seen; blanks stay missing evidence. Record arithmetic slips separately. Error D treats light as matter; error I makes height locate a source. All papers return day 21.

### Other rooms

No safe pots, rulers or outdoor access: H20 supplies readings, labeled invented for practice. Record unavailable firsthand measurement honestly. No printer: copy today's log frames and covered exit.

### At home

**Swap.** No pot, ruler or safe outdoor place: use H20. No printer: draw two log rows. Handle no soil.

**Skip.** Group rotations. Use one adult-managed pot or the supplied record.

- **5 min. Repair.** Read day 19 feedback using the historical or mineral comparison.
- **15 min. Height.** Do [[s02-P20-1]]. Keep soil-line zero and highest tip consistent. Retry once; retain unclear readings. Supplied H20 is separate.
  **Say.** "What does height leave uncertain?" Expect: which inputs supplied added matter.
- **10 min. Shadow.** Do [[s02-P20-2]] with H20 or a safe shared reading. Never look at the sun. Record place and time.
- **5 min. Exit ticket.** Give [[s02-X20]] alone. Discuss later using the answer key.

### Shorter or longer

Shorter: reduce method reports, retaining each ruler turn, shadow record, cleanup and exit. Longer: compare repeat readings and explain uncertainty, without a combined routes rehearsal.

### Words and supports

Review zero, whole centimeter and baseline. Read unclear as useful evidence about measurement. Provide enlarged ruler markings or a partner positioning the ruler; each child records independently.

### Tomorrow

Day 21 returns day 20's exit: error D, light-energy distinction, first five minutes; error I, height's limits, second five. Logs s02-P20-1/2 return in Single-study evidence, two minutes. Compare supplied air treatments, keeping invented data distinct from published evidence.
