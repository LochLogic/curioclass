# Day 73: Three motions, separate tests

## Teacher page

### Before class

Read opener.md and teacher-only-answer-keys.md. Prepare today's generated answer key for the evidence tags. Bring day 72's exit, direction arrows and tags. Lay out fifteen cutout kits from earth-sun-moon-pieces.md. Add an observer mark to Earth. Retain orbit-locator.md for repair. Use component-tags.md's evidence and inference fields on today's page, without its later question. Prepare current-day half slips; keep all future cases covered. Paper stays on desks in normal light.

### The day

#### 5 min. Return and repair

Return day 72 s04-X72, s04-P72-view and s04-P72-tag privately. Review return and repair. If many tickets show error D, use five minutes with the consistent locator: two locating the sun, two tracing outward views at changed Earth positions, one noting the changed direction. Far markers stay fixed. Over ten matching misses makes this whole-class. Others trace correct views independently. Reversed arrows alone get descriptive notes.

#### 7 min. Moon instruction

Review grade 1: the moon can be in the day sky. Review yesterday's orbit: a path around another object. Teach background stars as far markers used to compare a position, not physically joined lights.

Hold Earth stationary. Place the moon above Earth; trace from Earth through moon toward the upper background marker. Move moon below Earth; trace toward the lower marker, then finish its circuit. The changing direction needs the moon's own orbit around Earth. A return relative to background stars takes about a month. This desk movement represents a model, not a measured sky record. No phases are needed.

#### 19 min. Separate model tests

Four minutes set up three separate tests at each pair's desk. Then five minutes each; partners switch mover and observer halfway. No class waits for one shared kit.

First: [[s04-P73-spin]]. Review day 69 spin: hold Earth's center and the far marker fixed; turn only the observer mark. Expect changing viewing direction within a night.

Second: [[s04-P73-earth]]. Review day 72 orbit: move Earth above/below the sun; keep distant markers fixed. Expect different outward midnight directions.

Third: [[s04-P73-moon]]. Hold Earth still, move only moon around it. Expect its background direction to change and return. Keep the tests separate; no combined sky-record matching card. If many confuse motions, hold the other centers still and repeat that test.

#### 8 min. Evidence review

One minute: each tags the moon test as a model inference, not firsthand astronomy. Review grade 4 observation, inference. Five minutes: review rotating six heard, record sheet names who. Hear six forty-five-second component reports, with passing allowed. Everyone submits all three component tags; teacher retains the shared moon-orbit addition. Two minutes: store pieces. Preserve original notes.

#### 6 min. Fresh evidence

Reveal [[s04-X73]] only now. Five minutes alone, one to collect. After class, thirty sixty-second exits plus thirty forty-five-second component scans take fifty-two-and-a-half minutes. Review scale: shown, shown with help, not yet seen. Error D confuses seasonal views with spin; error H omits moon orbit; error I assigns nightly motion to yearly orbit. Letters require stated claims. Return all work on 74.

### Other rooms

No printer: draw labeled circles and fixed markers; copy current exit separately. Desk tests require neither night viewing nor a digital tool.

### At home

**Swap.** Draw and cut paper circles for Earth, sun and moon.

**Skip.** Public reporting and class rotation.

- **5 min. Return.** Read day 72 notes; trace an outward view.
- **7 min. Moon.** Hold Earth still and move moon around it.
  **Say.** "What moves in this test?" Expect moon around Earth, with background markers fixed.
- **12 min. Tests.** Child completes [[s04-P73-spin]], [[s04-P73-earth]] and [[s04-P73-moon]] separately.
- **6 min. Exit ticket.** Give [[s04-X73]] alone. Discuss the answer key afterward.

### Shorter or longer

Shorter: reduce reports; retain moon instruction, all separate tests and exit. Longer: distinguish desk movement from a directly observed night-sky change.

### Words and supports

Background stars, orbit; review spin. Read neutrally; raised fixed markers and a scribe preserve choices. Any child may pass publicly.

### Tomorrow

Day 74 returns E73 and three component tags in fifteen-minute Return and repair: five each for errors D, H and I. Retrieve each graph set separately before a fresh sky-model exit.
