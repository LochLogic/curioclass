# Day 74: Keeping sky evidence connected

## Teacher page

### Before class

Read opener.md and teacher-only-answer-keys.md; prepare the generated locator answer key. Bring day 73's exit and three component tags. Prepare separate correct graphs: class hourly lengths, D70 daylight, N71 Harbor winter/summer counts. If class graphs are absent, graph S67 lengths only; label supplied values invented for practice. Keep direction records beside their own graph. Use component-tags.md's locator on today's page. Set out earth-sun-moon-pieces.md and orbit-locator.md for repair. Cover current half slips.

### The day

#### 15 min. Return and repair

Return day 73 s04-X73, s04-P73-spin, s04-P73-earth and s04-P73-moon privately. Review return and repair; three five-minute moves. Error D: move Earth above/below sun, far markers fixed. Error H: hold Earth still, move moon around it. Error I: fix Earth center, turn observer past a fixed star marker. Each round: two minutes locating, two tracing, one oral explanation. Over ten matching misses makes that round whole-class; otherwise visit one parallel group. Ready children inspect separate correct diagrams. No written revision.

#### 5 min. Recall

Review shadow length/direction from days 67/68 and star visibility from 71. Review grade 4 duration: elapsed sending time; here compare daylight hours from day 70. Show each correct graph separately, then cover it. Recall labels and one observation at a time. Supplied fallback graphs remain invented for practice, never class observations. Review spin and orbit before rehearsal; introduce no new cause.

#### 11 min. Untimed rehearsal

Six minutes in pairs: three rounds of two minutes, one graph set per round. Each partner points to one plotted observation, thirty seconds each; use the remaining minute to trace its raw entry. Return each set before the next. No written explanation drafting.

Five minutes: review rotating six heard, record sheet names who. Hear six forty-five-second reports on single sets; anyone may pass. Everyone marks [[s04-P74-locate]] on the daylight-only graph, using the locator line on side 1. Collect all thirty locator papers; keep each marked graph with its locator.

#### 10 min. Sky consensus

Teacher retains supported links as separate model components: four minutes revisit shadow evidence with spin; three revisit daylight duration; three revisit matched night direction with Earth orbit. Children point to evidence; teacher records agreed links. Cover each component before the next, without a combined three-pattern model or synthesis rehearsal. Longer summer daylight is a description, not explained by orbit alone. Seasonal cause remains beyond today's model. Keep moon's own orbit distinct. Close with the brightness question for tomorrow, without explaining it.

#### 4 min. Exit ticket

Reveal [[s04-X74]] now: three minutes alone, one to collect. After class: thirty sixty-second exits plus thirty fifteen-second locators take thirty-seven-and-a-half minutes. Review scale: shown, shown with help, not yet seen. Error C states equal monthly daylight; error D uses spin alone for seasonal stars; error G uses yearly orbit for daily cycling. Omissions get private descriptive notes. Return all work on 75.

### Other rooms

No printer: draw the separate graphs on paper and copy only today's held exit. No live apparatus or digital tool is needed.

### At home

**Swap.** Draw the separate graphs using S67, D70 and N71 if earlier papers are absent.

**Skip.** Public reports and group rotation.

- **10 min. Return.** Read day 73 notes. Repeat each needed motion separately.
- **5 min. Recall.** Point to labels on each separate graph.
- **9 min. Rehearse.** Take one graph at a time; child completes [[s04-P74-locate]].
  **Say.** "Where is that observation recorded?" Expect a matching plot mark and raw entry.
- **6 min. Exit ticket.** Give [[s04-X74]] alone. Discuss its answer key afterward.

### Shorter or longer

Shorter: fewer public reports; retain all repair components and exit. Longer: identify one question the desk model cannot settle from these records.

### Words and supports

Review spin, orbit, daylight duration and visible. Read labels neutrally; enlarge graphs. A scribe marks only the location the child chooses.

### Tomorrow

Day 75 returns E74 and locator papers in fifteen-minute Return and repair: five each for errors C, D and G. Then compare equal flashlights at different distances and draw a brightness explanation.

### Credit

Ours. Supplied fallback values are invented for practice. Background: Sources S04-spin, S04-stars and S04-moon.
