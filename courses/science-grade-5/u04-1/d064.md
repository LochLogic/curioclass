# Day 64: Which cord is evidence?

## Teacher page

### Before class

Read current item answers before teacher-only-answer-keys.md. Prepare today's half slip from exits. Sort day 63 A/C notes for two five-minute repairs. Inspect enclosed weight, cord, low tray, ball and observer line. Set goggles and wipes. Display only slanted-site practice, never the held survey. Cover correct arrow cards' explanatory text during labeling.

### The day

#### 10 min. Return and repair

Return day 63 s04-X63, s04-P63-gap, s04-P63-path and s04-P63-day together. Review return and repair. If many day 63 tickets show error A, spend five minutes rotating a correct tilted disk and locating center. Error C gets five minutes comparing complete-day boundaries on daylight-strips. Each move: compare two, annotate two, retain one. Over ten matching misses makes that component whole-class. Ready children locate limits; no extra minutes or repeated readiness check.

#### 7 min. Evidence instruction

Review day 62 plumb line and gravity. A stationary free cord aligns with local down; support holds the weight still while gravity acts. A side tie or rail can set direction instead. Show drop-cord-records' slanted site. **Ask.** [[s04-P64-free]] Wait, then reveal [[steps:s04-P64-free]]. Select unconstrained evidence before explaining cause. Do not draw or derive a force arrow from this record in practice.

#### 14 min. Cord observation

Eight minutes: teacher demonstrates below waist over tray, comparing free cord with one held sideways. No swinging or throwing. Teacher and nearby observers wear impact goggles behind the observer line. Briefly release the soft ball separately. Six groups then inspect the stationary free cord for one minute each. Everyone records [[s04-P64-observe]]; others work quietly. No child handles cord. No numeric readings. Repeat an obscured view once; unresolved stays missing. If unsafe or unavailable, read drop-cord-records as invented supplied fallback. Retain actual failure separately in actual-log.

#### 7 min. Model review

Use the existing correct slanted arrow without cord data beside it. Alone, [[s04-P64-label]]. **Ask.** Name its force after locating the origin. Expect Earth's pull, starting on the object, centerward. Review force arrow versus motion trace. Hear rotating six, forty-five seconds each within five minutes; record who and permit passing. Everyone returns paper. Teacher keeps correct model separate from observations.

#### 4 min. Fresh evidence

Reveal [[s04-X64]] only now. Three minutes alone, one collecting thirty slips and pages. Read neutrally without supplying direction. After class, thirty thirty-second exit readings plus thirty twenty-second practice scans take twenty-five minutes. Review scale: shown, shown with help, not yet seen on the formative record. Return on 65.

#### 3 min. Cleanup

Adult contains cord and retrieves ball. Goggle users wipe and bag in parallel using approved wipes.

### Other rooms

No kit: use supplied drop-cord-records, never claim firsthand measurement. Without a printer, copy current practice and exit separately. Original diagrams replace unavailable photographs.

### At home

**Swap.** Use supplied cord/drop records instead of apparatus or goggles. Copy without a printer.

**Skip.** Group inspection and public reports.

- **5 min. Return.** Use day 63 notes for its largest gap.
- **10 min. Evidence.** Read supplied slanted-site records. Child does [[s04-P64-free]].
  **Say.** "Which cord can align freely?" Expect: the hanging cord without a side tie.
- **10 min. Observe.** Do [[s04-P64-observe]], marking records supplied. Label the existing correct arrow with [[s04-P64-label]].
- **5 min. Exit ticket.** Give [[s04-X64]] alone. Check its new arrow and reason afterward.

### Shorter or longer

Shorter: fewer public reports; retain evidence selection and exit. Longer: distinguish a still weight from absence of gravity.

### Words and supports

Review gravity, center, plumb line and force arrow. Enlarge the disk; scribing preserves chosen direction and reason.

### Tomorrow

Day 65 returns E64 and all practice notes in Return and repair. If many tickets show error A, rotate the correct disk for five minutes. Missing origin or cord evidence gets descriptive feedback. Then use argument fragments.

### Credit

Ours. Supplied fallback records are invented for practice.
