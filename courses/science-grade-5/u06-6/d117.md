# Day 117: Repair reasoning and preserve evidence

## Teacher page

### Before class
Separate teacher-keys.md and held-exits.md; use current-day data answer keys. Prepare private priority checklists from days 114/115/116, original response pages and unchanged action roster. Repair packet masters supply route order; use today's data prompts on the student page, including the clarified dust component. Assign at most four five-minute moves. Keep R117 concealed. Separate formative, assessment, assistance and original-observation records.

### The day

#### 5 min. Read feedback
Honor day 116's Tomorrow. Return day 114's U3, timing/reset, instrument/reason and fresh repair pages with days 115/116 originals: three source-feedback minutes, two testing-feedback minutes. Review source-location notes and original-preserving second-color revision. Each child reads a private priority checklist; untouched originals remain visible. No public score comparison. Unfinished conducting stays unobserved.

#### 20 min. Parallel return and repair
Review return and repair. Four routes run simultaneously: sources, errors A/C; links, errors B/I; limits, error D; testing, errors E/F/G/H. Each assigned letter gets five minutes: inspect feedback, answer its data prompt, compare with private feedback, record the corrected component. Use [[s06-P117-A]], [[s06-P117-C]], [[s06-P117-B]], [[s06-P117-I]], [[s06-P117-D]], [[s06-P117-E]], [[s06-P117-F]], [[s06-P117-G]] or [[s06-P117-H]] as assigned. These are separate components, never the held stockpile composite. Testing can use all four moves. Multiple-route children still get at most four moves; log remaining needs. Ready children strengthen source locators.

Teacher spends three minutes per route, three transitioning and five inspecting slips, totaling twenty. More than ten with the same letter receives its move in that parallel route. Review source, cause and effect, projection, fair test, trial, criterion, constraint and failure in assigned components. No retest changes day 116's observation.

**Ask.** Which observation supports this improvement? Expect a specific recorded failure with its trial identifier, rather than claimed future success.

#### 10 min. Revise originals
Five minutes source report/impact/status explanations; five test plan/model explanations. Children revise in a second color without erasing values or observed actions. Review system-model and design-cycle through existing originals only. Collect revisions separately. After class finalize the original assessment once: thirty children at one minute take thirty minutes, 32 possible points. Unobserved practical components remain blank, total pending. Keep assistance/action notes separate from numerical marks.

#### 10 min. Fresh response evidence
Cover repair materials. Reveal [[s06-R117]], printed and said invented for practice, on a half ticket. Nine independent minutes, one collection minute. No feedback during response. This unscored transfer uses a separate formative scale: shown, shown with help, not yet seen. Thirty at 40 seconds take twenty minutes after class; component pages at ten seconds take five. Return both privately after class today. File transfer, revisions, originals and unresolved needs separately.

### Other rooms
No printer: copy assigned prompts with labeled answer spaces; conceal R117 until release. No practical evidence: repair reasoning without claiming conducting. No devices needed.

### At home
**Swap.** No printer: copy assigned prompts and answer spaces. Adult uses private feedback and keeps originals.
**Skip.** Public reports and route changes.
- **5 min. Feedback.** Return days 114/115/116 papers. Child reads the private priority checklist.
- **20 min. Repair.** Complete up to four assigned letter prompts from today's page. Retain further needs.
  **Say.** "Which observation supports this improvement?" Expect an identified failure in retained trials.
- **5 min. Revise.** Child repairs explanations in a second color; old values/actions stay unchanged.
- **10 min. Exit ticket.** Cover packets; reveal [[s06-R117]] alone. Return it and component work privately afterward today.

### Shorter or longer
Shorter: reduce extra source locating, never an assigned repair or fresh response. Longer: record a needed observation without another assessment.

### Words and supports
Review source, projection, system-model, design-cycle, fair test and original-preserving revision. Read neutrally; scribes record decisions without correcting. No personal disclosures.

### Tomorrow
Day 118 begins new plant/land model and reservoir-graph evidence. Insert no return or conference into that sitting. Send day 116's unchanged practical record forward for day 119, with conducting gaps and unresolved source/control needs. R117 feedback returns today.
