# Written moves, day 93

One strip for each group, read by the pairs that are waiting. Large print.

| Group | The move |
|---|---|
| 1 (items 1 to 5) | Sort the report parts. Add the source label. Use the key to find the water. |

| 4 (resource, some and many) | Put the resource first, then what is made. Say "some" or "many", not "everyone". |
