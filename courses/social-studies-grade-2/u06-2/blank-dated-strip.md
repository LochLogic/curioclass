# Dated strip

Print on one page, landscape, one for each table. A long strip with ten year marks at equal spacing and the years left blank for the table to fill. Beside it, a box labeled "I do not know when".

| | | | | | | | | | |
|---|---|---|---|---|---|---|---|---|---|
| ____ | ____ | ____ | ____ | ____ | ____ | ____ | ____ | ____ | ____ |

Box: **I do not know when** (cards with no year go here, never between two years).

Rule printed at the foot: "The smaller year comes first."

Use: day 76 with six cards; day 79 for the revised dated event.
