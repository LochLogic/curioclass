# Bag or person cards, day 77 (invented)

Eight small cards for each pair, to choose from when saying "A ___ can be packed in a bag. A ___ moves in a person, because ___." Every card prints "invented for practice". The art is described here and has not been drawn or looked at yet (planned only, not yet written). Plain black line drawing on white.

| Card | Place (teacher sheet only) |
|---|---|
| game rhyme | in a person |
| dance step | in a person |
| a word | in a person |
| a recipe told aloud | in a person |
| a spoon | in a bag |
| a blanket | in a bag |
| a photograph | in a bag (what it shows can be told, too) |
| a coat | in a bag |

**Teacher note:** a recipe written down can go in a bag; told aloud it moves in a person. Accept "both" with a reason.
