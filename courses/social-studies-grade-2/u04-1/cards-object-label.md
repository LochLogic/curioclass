# Classroom object label, days 48 and 53

The teacher uses one real classroom object that has a readable origin label. If there is none, use this model label. A model label prints "invented for practice" and names no brand.

**Object:** a pencil cup.
**Label transcript (model, invented for practice):** "Pencil cup. Made in Portugal."
**Observation date:** written beside the label by the teacher on the day it is first shown, or "date not on the label". The label does not carry a date.

## Said aloud

The three questions, from unit 1: Who made it? The label names a place, Portugal, and no person; "the label does not say who". When was it made? "Date not on the label." Where was it made? Portugal. "A label proves the stated origin, not the whole journey." On day 53 the same label is read again with the frame "Made in ___, used in ___, so ___."

## Key (teacher)

No name of a company, brand or person is printed on a model label. If a real label carries a brand, the teacher reads it without the brand and the transcript omits it.
