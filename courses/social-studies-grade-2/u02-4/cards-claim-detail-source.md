# Claim, detail and source cards (day 27 repair, error I)

Three sets of three cards. Pairs match each claim to a detail and a source. Every card prints "invented for practice".

## Set 1

**Claim:** I choose Terrace Row because it is mild.
**Detail:** The thermometer reads mild.
**Source:** The Terrace Row Place Card, made by Curio Class.

## Set 2

**Claim:** I choose Lantern Market because there is a library.
**Detail:** The picture shows a library.
**Source:** The Lantern Market Place Card, made by Curio Class.

## Set 3

**Claim:** I choose Frost Basin because I like snow.
**Detail:** The picture shows a snowy valley.
**Source:** The Frost Basin Place Card, made by Curio Class.

## Pip's claim card (day 27)

**Card:** Pip says: I choose Cove Harbor because it is nice. Below it, three lines: a detail the Cove Harbor Place Card shows, the card's name, and who made it. Invented for practice.

## Key (teacher)

Each set holds one claim, one detail from the card and one named source with a maker. Ask for a set that is only a preference: "Because I like it" has no detail and no source. Pip's claim card: no, it names no detail; the card shows cranes, ships, a ferry and shops; the Cove Harbor card; Curio Class.
