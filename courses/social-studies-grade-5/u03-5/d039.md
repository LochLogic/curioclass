# Day 39: What an action can show

## Teacher page

### Before class

Bring every day 38 paper. Prepare navigation-notes.md through today's integrated panels. Draw four-stop outlines from map-access.md. Prepare covered locator-exit.svg and its separate factual reference. Cut X39b alone from exit-masters.md onto half slips. Read teacher-only keys. Do not fetch blocked map images by another route.

### The day

#### 10 min. Return and repair

Hand back `s03-X38a`, `s03-X38b`, `s03-P38`, `s03-F38`.

If many day 38 tickets show error F or error N, review documented activity versus unknown motive. Model five minutes with [[s03-K39-1]], asking before revealing [[steps:s03-K39-1]]. Say Jo is invented. Everyone then answers [[s03-F39]] independently for five minutes. More than ten sharing a gap: teach together; otherwise meet one group, others use cues. Keep unresolved needs recorded.

#### 10 min. Map navigation

Review day 38 reference-to-outline transfer and legend, the map key. Review map-scale calibration from day 30: matching size matters before measuring. Today's invented diagram has no scale and establishes no distance. Use four labeled dots arranged irregularly. **Ask.** [[s03-P39-2]] All trace alone; discuss the order together. No Boston exit targets appear here.

#### 12 min. Influence notes

Review influence from day 38: how an action changes events or understandings. Review source-sourcing: maker, date, audience, purpose. Recall Adams's organizing letters from day 32 and Attucks's later public memory from day 34. Use only today's teaching summaries, keeping funeral and deliverance selections covered.

**Ask.** [[s03-P39]] Fifteen pairs talk simultaneously, 45 seconds each way, then everyone writes one isolated action/evidence note. Expect a supported action with its evidence type. Location alone cannot establish allegiance, error L; later commemoration cannot establish Attucks's private intention, error O. No combined map-and-influence paragraph is practiced.

#### 8 min. Exit ticket

Release the separate locator reference with the covered Exit box [[s03-X39a]]. Then reveal today's profiles and give [[s03-X39b]] alone on the half slip. All thirty write independently; dictation is transcribed as paper. Collect both pieces and practice. After class: 30 times 80 seconds for exit components plus 30 times 20 seconds for practice/retry, 50 minutes. Review one component scale: shown, shown with help, not yet seen; access support separately. Authentic historic-map reading stays not yet seen. Return all on day 40, Return and repair.

### Other rooms

No screen: point to paper. No printer: copy today's panels and separate outlines exactly. Preserve covered sources.

### At home

**Swap.** No printer: copy today's panels and draw separate locator outlines.

**Skip.** Public sharing and class grouping.

- **10 min. Repair.** Read yesterday's cue, discuss the translation model, then do [[s03-F39]].
- **10 min. Navigation.** Trace [[s03-P39-2]] on an invented four-stop diagram.
- **12 min. Influence.** Read the teaching summaries. Do [[s03-P39]].
  **Say.** "Does later remembrance establish Attucks's private intention?" Expect no; those need different evidence.
- **8 min. Exit ticket.** Reveal the locator with [[s03-X39a]] and the profiles with [[s03-X39b]]. Your child writes alone.

### Shorter or longer

Shorter: reduce discussion, keeping repair and independent work. Longer: identify evidence needed for an unknown intention.

### Words and supports

Review influence, source-sourcing, legend and map-scale. Read neutrally; accept dictation and large print. Public talk may be passed. No personal disclosures.

### Tomorrow

Day 40 returns all day 39 papers. If many show error L, separate location and intention; error O, separate public memory and motive; error F, identify documented agency. Repair one priority before new evidence selection.
