# Day 47: Requests, places, and wartime changes

## Teacher page

### Before class

Prepare returned papers and one assigned fresh repair card per child from current item-row stems. Keep teacher-key.md and corrected current item-row keys separate from student copies. Cover today's exit-47.html and all later forms. This student page replaces duplicate teaching-selection, recording and practice masters.

### The day

#### 10 min. Return and repair

Return day 46's s04-X46, s04-P46, s04-P46-alt and s04-F46-A/B/J/W papers, including day 46 practice notes. Review the gap between a promise and what happened. If many day 46 tickets show error A, model [[s04-K47-A]], then reveal [[steps:s04-K47-A]]. Use five minutes for the model and five for [[s04-F47-A]]. Give remaining needs written cues. Honor alternative users' unsampled historical components.

#### 10 min. Teaching first

Show the labeled teaching map. Modern state boundaries orient places, not colonial authority. Review map-scale: source and response retain matching calibration; use each map's own bar after resizing. No distance calculation is judged.

Read the dated action fragments separately. Locate Trenton in New Jersey beside the Delaware, then Saratoga in eastern New York. Hessian troops fought for Britain; allegiance differs from where soldiers came from. Describe actions and consequences aloud without completing a paired written response. Review alliance: an agreement between groups to help one another. Explain French assistance before the formal 1778 alliance.

#### 12 min. Separate records

Review source-sourcing: maker, date, audience, purpose. These are modern interpretations, not eyewitness testimony. Model separating an event date from the source date on blank labels. **Ask.** [[s04-P47]]. Children add dates beside already labeled sites, then trace river lines with a finger on the displayed or shared map. No blank-map placement practice. Review timeline: equal gaps for equal years and ten-year marks; add separate dates.

Fifteen pairs work concurrently, each child taking one 45-second turn. Public passing is allowed. Collect all thirty individual notes.

#### 8 min. Exit ticket

Reveal [[s04-X47a]] [[s04-X47b]] on the independent half-sheet master. Allow six minutes for paper responses, two for collection. Neutral reading and private dictation give no content cues. After class: thirty times 30 seconds, 15 minutes, for exits; fifteen more for notes and repairs. Use one component scale: shown, shown with help, not yet seen. Record access separately. Return everything on day 48.
