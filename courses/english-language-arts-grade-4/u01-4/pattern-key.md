# Teacher-only pattern answer key

Returning: re-turn-ing, familiar base turn, prefix re- meaning again, suffix -ing.
Carefully: care-ful-ly, base care, familiar suffixes -ful and -ly.
Preserve all letters and sounds; confirm against the sentence after decoding.
The silent e stays in care before -ful. This is familiar grade 3 review.

Five oral samples at one minute each across the existing ten-minute word block.
The five-minute paper probe runs concurrently; do not add a second teacher screen.
Record children actually heard. Other oral samples use existing later rotations.
