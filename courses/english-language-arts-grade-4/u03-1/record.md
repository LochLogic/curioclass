# Unit 3 record sheet: The Erie Canal debate

Record each independent exit and assessment component on the same scale. Enter **2** for shown independently, **1** for shown with help or in part, or **0** when an observed attempt does not yet show it. Leave the cell blank when evidence is missing. Date the next observation. Keep paper responses and observed turns separate. Record retrieval without a score.

Keep the student's original work, dated feedback and later correction together. Use the discussion and rereading records for actual individual observations. Reading prose does not establish evidence for poetry. A used printed source documents print research. Mark digital work when the child actually uses the digital source.

Write the item ID and one specific next move on the returned piece. If several items need attention, choose one priority at the named repair. Keep all other needs in the student's dated record.
