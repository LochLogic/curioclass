# The vote: unit record

Use the same scale for each criterion: **shown**, **shown with help**, **not yet seen**. Record the help the child used. Leave an unobserved criterion blank and date the next opportunity. Keep the first independent response beside later feedback and changes. Return one next move privately on the scheduled day.

Copy one grid per group and criterion. Enter the item ID or observed action for each judgment. Paper responses and live observations have separate entries. Record the actual selection and supports for reading. Keep known, independent and retained evidence identifiable by date. Use actual publication and prior device records when a technology criterion calls for them.
