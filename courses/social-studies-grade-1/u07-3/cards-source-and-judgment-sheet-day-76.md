# Source cards and the judgment sheet (day 76, item 2 practice)

Each child gets one source card. About a third of the class gets each:

1. **An invented story card.** Read aloud: "Tala hears a little child crying about a lost hat. Tala helps look for it until it is found." Print "invented for practice".
2. **An invented school record card.** Read aloud: "The lunch helpers wipe the tables and return the trays so the next class can sit down." Print "invented for practice".
3. **A line from the class's own action log** (the teacher copies one dated line).

## Judgment sheet (one for each child)

Date: ______________

My card: story / record / our log (circle one)

Quality card: caring / fair / helpful / respectful / honest / cooperate (circle one)

The detail from the card (draw or dictate):

(a large empty box)

The teacher draws one stamp on each sheet after class, a small calendar (add a detail) or a swap arrow (change the quality), and returns it on day 78 for a change or an addition. No frame is shown on the wall during this work.
