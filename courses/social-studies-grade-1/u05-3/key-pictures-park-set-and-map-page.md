# Teacher key, pictures park set and map page

Teacher only. Keep apart from pictures-park-set-and-map-page.md; never hand to children.

## Key

### The park photograph set

**Teacher key.** The photographs say what is where. Children name the land and the water aloud first (the grass, the path, the trees, the pond) and then draw them in the places the photographs show. The class does not need any fact about the park beyond what the photographs show.

### The map page

**Teacher key.** Four things a good map has: where things are, land and water, symbols with a key, the four directions. A good map is one a stranger could use. Judge spatial meaning, not drawing skill. Keep the page for day 94.
