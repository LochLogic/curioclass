# Day 81: I can explain adding zero or one.

## Teacher page

### Before class

Keep teacher-key.md private; generated answer key holds new practice steps. Prepare student pages, practice-81.md, counters, frames, mats, record.md and thirty covered exit-81.md half slips. Have day 79 originals ready. Adult cuts large pieces; count in/out, no mouthing. Replace unsafe pieces with drawn marks. Never move children as objects. Read all print aloud at 18 point; no independent reading.

### The day

For worked and repair rows, read scene first; reveal solution steps after the ask.

#### 5 min. Warm-up: Oral count

Review count and keep track, day 1; total, day 19; Paper count-dot record, day 1. **Ask.** [[s04-K-count-81]] Count together first, then continue from the supplied word. No individual round or required counting-on strategy.

#### 5 min. Return and repair

Review Return and repair, day 2. Return day 80's exit and recorded practice feedback. If day 80's tickets showed the matching action, select one priority. **Ask.** [[s04-F-81]] Then [[steps:s04-F-81]] Two guided minutes and three for a fresh supplied-cue retry. More than ten sharing it: class repair; otherwise one group while peers correct familiar paper. No extra group or check replay.

#### 5 min. Feedback and revision

Return day 80 conference originals and written picture-cued feedback. Read cues to roster 1 to 10 while others finish day 79 feedback. Children revise; retain first paper, dated feedback and changes.

#### 2 min. Rehearsal launch

Review zero, day 30; one more, day 36; Zero arrival and one arrival on a quantity mat, day 67. **Ask.** [[s04-P81]] Then [[steps:s04-P81]]. Move nothing from empty mat; cross invented fifth result mark. Error F invents an arrival. Rehearsal, no new teaching.

#### 35 min. Conferences and centers

Use day 79 originals; hear only roster 11 to 20. Read each ask separately: **Ask.** [[s04-F2a-talk-81]] **Ask.** [[s04-F2b-talk-81]] **Ask.** [[s04-F1a-talk-81]] **Ask.** [[s04-F1b-talk-81]] Four 45-second asks per child: ten times three minutes = thirty; five minutes allow pauses, transitions and two-minute tidy. Observe child-directed object action within the same turn if needed. Listen for initial/change/result, question location, operation meaning and equal quantities in either order. Keep components separate. No secure interview repeated; unfinished explanations stay pending.

Others independently correct supplied familiar records or apply picture-cued feedback. Their five-minute untimed within-five game overlaps conferences; no second teacher group. Everyone retains corrected paper. After class reserve thirty teacher minutes for written conference/paper feedback, returned day 82 before day 83 judgment.

Review one-arrival effect, day 67: **Ask.** [[s04-K-one-81]] Then [[steps:s04-K-one-81]] Use supplied corrections, never fresh cups. Review day 71 game: **Ask.** [[s04-P-game-81]] Then [[steps:s04-P-game-81]]

#### 8 min. Exit ticket

First show exit-81.md at each child's own turn. Say "Invented for practice." Read exact stimulus from private key, then **Ask.** [[s04-X81]] Read exact stem. All children leave resulting-quantity marks on paper. Hear roster 13 to 18 only: six times 45 seconds = 4.5 minutes; reading, concurrent marking and collection get 3.5. No public answer or practice frame.

Carry pending components for s04-X77, s04-X78, s04-X79, s04-X80 only when this fresh evidence fits. No extra ask or old check repeated; unheard explanations stay pending. Use shown, shown with help, not yet seen; log names heard and access separately from mathematical help.

After class: thirty papers times twenty seconds = ten teacher marking minutes. Return exit and recorded practice feedback day 82 Return and repair.

### Other rooms

Unscored corrected practice stays in the folder. Recorded observations return in the next named feedback slot.

Hand-copy original masters. Large paper squares replace counters, drawn frames replace printing, folded paper replaces mats/cards. No device needed; one shared screen may enlarge teaching only.

### At home

**Swap.** Adult-cut squares, folded mats and drawn frames replace class equipment. Hand-copy original masters.

**Skip.** Class rotations and repeated centers.

- **3 min. Count.** Count through ten, then from today's supplied word.
- **5 min. Return.** Use day 80 feedback with one supplied square correction.
- **7 min. Together.** [[s04-P81]] Read scene; ask before revealing solution. Child directs pieces and corrects marks.
  **Say.** "Did any square join?" Expect: none; four remain.
- **7 min. Practice.** Use day 79 originals for four separate conference asks, three minutes, and prior feedback/revision, four minutes. Keep original and changed paper.
- **8 min. Exit ticket.** [[s04-X81]] Read exact fresh stimulus from private key, then stem. Child marks alone; keep paper and words.

### Shorter or longer

Shorter: reduce familiar repetitions; retain repair, core connections, paper evidence and exit. Longer: rearrange supplied incomplete square model, correct same missing component; stay within ten.

### Words and supports

Review square, day 45; counter, day 3; group and mark, day 6; total, day 19; altogether, day 64. Review 10-frame, day 26, and one counter for each story object, day 71. Read all print aloud. Offer high contrast, tactile boundaries, broad pencils, usual communication aids and child-directed movement/scribing. Public talk may be passed; record access separately from mathematical help. Review expression, equation, plus, minus, equals and same quantity, day 78.

### Tomorrow

Day 82 returns day 81's exit in Return and repair. Error F invents an arrival for zero; move nothing from empty mat. If practice showed error G, include incoming one and say next counting word. Select one priority. Return day 81 conference feedback before roster 21 to 30 conferences, then apply story/equation connections.
