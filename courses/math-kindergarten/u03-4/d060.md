# Day 60: I can recognize shapes after a turn.

## Teacher page

### Before class

Keep teacher-key.md private. Set practice-records.md, practice-60.md; select repair-60-E.md or repair-60-K.md; set repair-60-N.md for the model. Reserve exit-60.md choices. Prepare assessment-labels.md, display/tub/heft-pour pieces. Cut single practice triangle/matching opening and larger similar triangle/enlarged outline. Set pretested tubs/cups, water/tray/towel. Adult cuts/pours; read aloud.

### The day

#### 5 min. Warm-up: oral count

Review count and keep track, day 1. **Ask.** [[s03-W60]] Touch or move each of 5 squares once. Count together to ten, supported toward twenty; no timer. Review Paper count-dot record, day 1: mark one dot per square on scrap paper.

#### 5 min. Return and repair

Review Return and repair, day 2. Return day 59's tickets and practice feedback. Return day 59's written tasks s03-P59-puzzle and s03-P59-count with recorded feedback; correction uses this same priority slot. If many left gaps on day 59, error E, [[s03-F60-E]] with repair-60-E.md moves triangle to full-edge contact. For priority overlap, error K, instead [[s03-F60-K]] with repair-60-K.md: lift, separate, fit. Return component feedback; revise one blocked record. One action only; queue others. More than ten of thirty: whole class; otherwise small group while others revise familiar paper. Keep original/helped versions separate.

#### 12 min. Labels and single-mat model

First four minutes reveal labels, [[s03-F2-paper]]. Keep independent joins, no supplied names/extra interview. Next eight: review turn, day 47, triangle, day 45. **Ask.** [[s03-P60-mat]] Wait, rotate triangle to opening, track sides/corners. Show larger similar copy/enlarged outline: size changes, three joined sides remain. Turning preserves shape/length. Review square as special rectangle, day 51. New words with gestures: gap is space between pieces meant to meet; overlap is one covering another; compose means put shapes together. **Ask.** [[s03-P60-fills]] Compare teacher-completed six-triangle/three-piece hexagons, follow matching outside edges. Name outline as the outside edge: different pieces can make the same whole. Use [[s03-F60-N]] with repair-60-N.md: compare one slanted equal-sided tile with one square, overlay corners; only square corners match. This is a correction of a supplied claim, never the reserved target/three-choice task. No independent two-way fill in practice.

#### 28 min. Final conferences and centers

Review Counting centers and Partner turns, day 1. Roster 13 to 18 only. Read separately: [[s03-F1-talk-60]], [[s03-F2-talk-60]], [[s03-F5-talk-60]], [[s03-F6-weight-60]], [[s03-F6-capacity-60]]. Show oral pieces first at that child's turn. No writing in spoken prompts; teacher scribes. F1 uses viewing arrow; F2 names actual labels, accepting square also as rectangle. Tub attributes concern same real tub. Child hefts sealed tubs/swaps hands, then directs adult's full tall-to-empty-wide cup pour over tray; stop at rim, dry spills/floor immediately.

Five 45-second asks plus thirty seconds setup/reset: 4.25 minutes per child, 25.5 for six; 2.5 reserve. Use reserve for pauses/unclear methods, never rush. Unfinished components pending for day 63. Others use familiar practice panels/returned corrections; no water centers or teacher interruptions. Retain originals. Credit names/relationships/method only when heard/observed, never weight/capacity from pictures. Write feedback after class for next-day revision.

#### 2 min. Tidy

Collect practice concurrently in table trays. Keep reserved papers separate; adult empties/dries water area and checks floor.

#### 8 min. Exit ticket

Reveal exit-60.md target/choices. Join target to choice, mark corresponding sides/corners on both. Six demonstrate correspondence; equal sides alone insufficient. **Ask.** [[s03-X60]] Exact stem aloud; response format adds no ask. Launch/concurrent paper 2.5 minutes, roster 1 to 6 six 45-second turns 4.5 minutes, collection one minute. Private teacher-key.md. Scale: shown, shown with help, not yet seen; record heard date/help, unheard components pending. Thirty slips at twenty seconds: ten teacher minutes after class; five more for conferences. Return day 61 in Return and repair. No credit for unheard speech.

### Other rooms

Hand-copy exact panels/exit before class. Paper shapes/strips replace blocks/straws; folded paper replaces clay. No device needed; one shared screen can enlarge teaching. Tactile boundaries/usual communication aids, adult follows child directions; record access separately from math help. Capacity requires real cups, water/tray/towel; otherwise pending. No glass, food, tasting, small joins or body comparisons.

### At home

**Swap.** Hand-draw panels; paper pieces replace blocks. Real sealed tubs/cups, water/tray/towel; adult pours.

**Skip.** Class rotations/repeated centers.

- **3 min. Count.** Touch five squares, mark dots.
- **5 min. Repair.** Return day 59 feedback; fix one familiar partial join.
- **7 min. Practice.** [[s03-P60-mat]]
  **Say.** "Turn this piece to fit the space." Expect: triangle fits after turning. Show bigger similar copy: still triangle.
- **5 min. Records.** Keep class label sheet; if absent, use same student labels independently once, then keep original.
- **2 min. Tidy.** Clear practice.
- **8 min. Exit ticket.** [[s03-X60]] Reveal reserved target/choices. Read exactly. Child joins/marks sides and corners alone. Expect: larger square, corresponding corners. Record help, return feedback tomorrow.

### Shorter or longer

Shorter: fewer center repetitions; preserve independent work, feedback and exit. Longer: repeat same partial correction, check joins. Never practice reserved cases.

### Words and supports

Review shape names/positions, day 45; side/corner, day 48; join, day 51; turn, day 47; length, day 51; height/weight/capacity, day 53, where used. Read all print aloud at 18 point. Public talk may be passed; no child models error. Frame: "This edge meets ___." Remove frames for checks.

### Tomorrow

Day 61 returns day 60 tickets/conference feedback. Error B, square rejected after turn, or N, equal sides alone, needs fresh square-corner overlay; queued K may instead take single Return and repair slot. Then F4/partial hexagon corrections; never reserved exit-square packet as repair.
