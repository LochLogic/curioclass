# Day 57: I can draw a shape that matches a build.

## Teacher page

### Before class

Keep teacher-key.md private. Prepare practice-57.md, one queued repair card and the covered exit slip. Set large paper squares, adult-cut practice shapes and broad pencils. Prepare the covered observation master and retained paper marks for today's named children only. Use the viewing arrow for positions. Read child print aloud at 18 point; draw copies if needed. Keep all other assessment panels covered. Large intact pieces only; no mouth contact.

### The day

#### 5 min. Warm-up: oral count

Review count and keep track, day 1. **Ask.** [[s03-W57]] Touch or move each of 5 squares once. Count together to ten, supported toward twenty; no timer. Review Paper count-dot record, day 1: mark one dot per square on scrap paper.

#### 5 min. Return and repair

Return day 56's written task records with the existing feedback packet. Use one priority correction only.

Review Return and repair, day 2. Return day 56's tickets and practice feedback. If many chose height on day 56, error I, [[s03-F57-I]] with repair-57-I.md: adult performs pretested full-to-empty practice transfer. Children mark actual space left, correct tall-cup claim. No reserved bowl/pot replay. One action only; queue others. More than ten of thirty: whole class; otherwise small group while others revise familiar paper. Keep original/helped versions separate.

#### 8 min. Model drawing

Yesterday's comparison records lead to drawing built boundaries. Review enclosing boundary, day 46. Draw names making pencil lines showing build's shape. Lay rectangular frame beside supplied three-edge diagram. **Ask.** [[s03-P57-dots]] Pause before modeling fourth edge. [[steps:s03-P57-dots]] Overlay build on completed drawing; corners/closure matter, not neatness. First drawing unscored.

#### 12 min. Connected drawing correction

Review Partner turns, day 1, below/beside, day 45. Fifteen concurrent pairs: [[s03-P57-position-below]], then [[s03-P57-position-beside]], card/cup on paper mat. Two 45-second turns plus thirty seconds handling use two minutes. Remaining ten: finish rectangle; **Ask.** [[s03-P57-join]] Move right square left until full sides meet, trace outside/seam. No unfamiliar six-edge build.

#### 20 min. Centers

Use assessment-pairs.md for F2 cells 141 to 150, children 29 and 30. Show only one pair per prompt, with a separate response and paper feature marks on both variants. Rows s03-F2-57-1 through s03-F2-57-5. Ten 45-second asks plus half a minute reset take eight teacher minutes. Other children revise yesterday's written feedback for five independent minutes, then repeat familiar closure corrections and count-dot records. No repeated secure naming interview. Remaining teacher minutes cover launch/help.

#### 2 min. Tidy

Collect practice concurrently in table trays. Keep reserved papers separate; adult empties/dries water area and checks floor.

#### 8 min. Exit ticket

Reveal packet-57.md frame. Blank slip only, no complete outline to trace. Approximate lengths accepted; six corners/closure. First drawing unscored, descriptive feedback. **Ask.** [[s03-X57]] Exact stem aloud; response format adds no ask. Launch/concurrent paper 2.5 minutes, roster 13 to 18 six 45-second turns 4.5 minutes, collection one minute. Private teacher-key.md. The formative scale describes observed evidence only, no final first-drawing score: shown, shown with help, not yet seen; record heard date/help, unheard components pending. Thirty slips at twenty seconds: ten teacher minutes after class. Return day 58 in Return and repair. No credit for unheard speech.

### Other rooms

Hand-copy exact panels/exit before class. Paper shapes/strips replace blocks/straws; folded paper replaces clay. No device needed; one shared screen can enlarge teaching. Tactile boundaries/usual communication aids, adult follows child directions; record access separately from math help. Capacity requires real cups, water/tray/towel; otherwise pending. No glass, food, tasting, small joins or body comparisons.

### At home

**Swap.** Hand-draw panels; paper strips replace kit. Real practice cups, water/tray/towel; adult pours.

**Skip.** Class rotations/repeated centers.

- **3 min. Count.** Touch five squares, mark dots.
- **5 min. Repair.** Return day 56 feedback. Adult pours full tall practice cup into empty wider cup; mark space left.
- **7 min. Drawing.** [[s03-P57-dots]] Finish supplied edge, overlay strips.
  **Say.** "Finish the missing edge." Expect: closed rectangle.
- **5 min. Join.** [[s03-P57-join]] Move square to neighbor; trace join.
- **2 min. Tidy.** Clear practice.
- **8 min. Exit ticket.** [[s03-X57]] Reveal frame/blank slip. Read exactly; child draws alone. Expect: closed six-edge boundary. Record help, give feedback tomorrow.

### Shorter or longer

Shorter: fewer center repetitions; preserve independent work, feedback and exit. Longer: repeat same partial correction, check joins. Never practice reserved cases.

### Words and supports

Draw means pencil lines showing a shape. Review enclosing boundary, day 46; rectangle/square and below/beside, day 45; side/corner, day 48; join, day 51; capacity, day 53; holds more, day 55. Read all print aloud at 18 point. Public talk may be passed; no child models error. Frame: "This edge meets ___." Remove frames for checks.

### Tomorrow

Day 58 returns day 57 drawings with descriptive feedback, no first-drawing score. Error D, open boundary called complete, gets fresh four-edge correction in Return and repair. Then room-shape corrections/reserved records; no hallway pennant rehearsal. Unheard explanations pending on record.md rotation.
