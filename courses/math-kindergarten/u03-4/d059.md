# Day 59: I can join shapes to make a larger shape.

## Teacher page

### Before class

Keep teacher-key.md private. Set practice-records.md, practice-59.md, repair-59-C.md. Reserve packet-59.md/exit-59.md. Prepare assessment-build.md, assessment-draw.md, assessment-build-pieces.md, assessment-length.md, assessment-height.md, assessment-equal.md, assessment-comparison-pieces.md, same-scale set per child. Set display/labels/tub, pretested heft/pour apparatus, water/tray/towel. Adult cuts/pours; read aloud.

### The day

#### 5 min. Warm-up: oral count

Review count and keep track, day 1. **Ask.** [[s03-W59]] Touch or move each of 6 squares once. Count together to ten, supported toward twenty; no timer. Review Paper count-dot record, day 1: mark one dot per square on scrap paper.

#### 5 min. Return and repair

Review Return and repair, day 2. Return day 58's tickets and practice feedback. Return day 58's written tasks s03-P58-room and s03-P58-features with recorded feedback; correction uses this same priority slot. If many rejected narrow triangle, error C, [[s03-F59-C]] with repair-59-C.md: trace three straight joined sides of fresh triangle. Return day 58 conference feedback; revise one blocked component. Other relationships queue. One action only; queue others. More than ten of thirty: whole class; otherwise small group while others revise familiar paper. Keep original/helped versions separate.

#### 12 min. F3 and F6 paper records

Reveal reserved pieces. Three minutes [[s03-F3-build]], then three [[s03-F3-draw]], exact stems separately. Construct with strips/folded joins, trace construction, draw tent boundary. Next two minutes each: [[s03-F6-length]], [[s03-F6-height]], [[s03-F6-equal]]. Cut strips start apart/turned; towers stand on table. Children directly align, then trace starts/far ends. Teacher supervises, flags ambiguous methods for reserve; marks alone cannot prove alignment. Keep originals before feedback. Center directions now: [[s03-P59-puzzle]] move loose triangle into supplied three-piece trapezoid; [[s03-P59-count]] count three pieces. No independent two-rectangle practice.

#### 28 min. Final conferences and centers

Review Counting centers and Partner turns, day 1. Roster 7 to 12 only. Read separately: [[s03-F1-talk-59]], [[s03-F2-talk-59]], [[s03-F5-talk-59]], [[s03-F6-weight-59]], [[s03-F6-capacity-59]]. Show oral pieces first at that child's turn. No writing in spoken prompts; teacher scribes. F1 uses viewing arrow; F2 names actual labels, accepting square also as rectangle. Tub attributes concern same real tub. Child hefts sealed tubs/swaps hands, then directs adult's full tall-to-empty-wide cup pour over tray; stop at rim, dry spills/floor immediately.

Five 45-second asks plus thirty seconds setup/reset: 4.25 minutes per child, 25.5 for six; 2.5 reserve. Use reserve for pauses/unclear methods, never rush. Unfinished components pending for day 63. Others use familiar practice panels/returned corrections; no water centers or teacher interruptions. Retain originals. Credit names/relationships/method only when heard/observed, never weight/capacity from pictures. Write feedback after class for next-day revision.

#### 2 min. Tidy

Collect practice concurrently in table trays. Keep reserved papers separate; adult empties/dries water area and checks floor.

#### 8 min. Exit ticket

Reveal packet-59.md unequal rectangles without whole outline. Join pieces, trace outside/seam on slip; hear six whole names. **Ask.** [[s03-X59]] Exact stem aloud; response format adds no ask. Launch/concurrent paper 2.5 minutes, roster 25 to 30 six 45-second turns 4.5 minutes, collection one minute. Private teacher-key.md. Scale: shown, shown with help, not yet seen; record heard date/help, unheard components pending. Thirty slips at twenty seconds: ten teacher minutes after class; five more for conferences. Return day 60 in Return and repair. No credit for unheard speech.

### Other rooms

Hand-copy exact panels/exit before class. Paper shapes/strips replace blocks/straws; folded paper replaces clay. No device needed; one shared screen can enlarge teaching. Tactile boundaries/usual communication aids, adult follows child directions; record access separately from math help. Capacity requires real cups, water/tray/towel; otherwise pending. No glass, food, tasting, small joins or body comparisons.

### At home

**Swap.** Hand-draw panels, paper strips/folded joins replace kit. Real sealed tubs/cups, water/tray/towel; adult pours.

**Skip.** Class rotations/repeated centers.

- **3 min. Count.** Touch six squares, mark dots.
- **5 min. Repair.** Return day 58 feedback; trace fresh practice triangle.
- **7 min. Practice.** [[s03-P59-puzzle]]
  **Say.** "Fix this partial puzzle." Expect: three triangles with full-edge joins.
- **5 min. Records.** Keep independent class paper. If absent, spread today's five original tasks across skippable sessions; use exact panels/pieces once. Observe alignment, not pictures alone.
- **2 min. Tidy.** Clear practice.
- **8 min. Exit ticket.** [[s03-X59]] Reveal reserved rectangle pieces/slip, matching scale. Read exactly. Child joins/traces alone. Expect: longer rectangle, full short-edge join. Record help, return feedback tomorrow.

### Shorter or longer

Shorter: fewer center repetitions; preserve independent work, feedback and exit. Longer: repeat same partial correction, check joins. Never practice reserved cases.

### Words and supports

Review shape names/positions, day 45; side/corner, day 48; join, day 51; turn, day 47; length, day 51; height/weight/capacity, day 53, where used. Read all print aloud at 18 point. Public talk may be passed; no child models error. Frame: "This edge meets ___." Remove frames for checks.

### Tomorrow

Day 60 returns day 59 tickets/component feedback. Error E, gap, or K, overlap, gets one fresh partial-puzzle correction in Return and repair; queue other. Labels/one-piece rotation follow. Unresolved methods stay pending; correct selection never proves method.
