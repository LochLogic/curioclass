# Conference directions

Keep this card with the teacher. Present reserved paper and actual models, never answers. Read one ask and wait. A child may pass or use usual communication. Record names heard and exact short phrases.

Tell how this whole object differs from this face.

Tell where each marked object is.

Name these shapes.

Each ask has 45 seconds; transition 15 seconds. If unfinished, record missing components for later response, never rush or infer them. Use a truly cubic plain box and a square face panel for the first ask. This conference has no fourth ask. No keys on this card.
