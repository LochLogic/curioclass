# Three-ask solid-shape conference

Before class: open teacher-key.md privately. Prepare a new truly cubic plain box with one removable square face panel and the two reserved same-kind pairs in naming-cards-130.md. Retain earlier paper and exact words; conceal answers.

Read one ask, wait forty-five seconds, then move to the next.

1. Tell how this whole object differs from this face.
2. Name this shape.
3. Name this shape.

Ask 2 indicates only the cylinder pair; ask 3 only the cone pair. Fifteen seconds reset gives 2.5 minutes per child. Six children on 130 use fifteen minutes; eight daily on 131 to 133 use twenty. The whole/face description and two names have separate cells. There is no new position ask: all six positional cells already have their own roster. Never fill an unheard cell from another child or a mark.

Written feedback after class, later child revision, then retained-record judgment. Missing remains not yet seen with one named priority and next date. A child may pass or use usual communication. Record access and mathematical help separately.
