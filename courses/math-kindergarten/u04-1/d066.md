# Day 66: I can keep track.

## Teacher page

### Before class

Keep teacher-key.md and today's generated answer key private. Prepare student pages from practice-66.md, three-and-three/four-and-four supplied route cards, large squares, frames, thirty covered exit-66.md half slips and record.md. Set day 65 exit/W65 feedback and matching unit 3 response apparatus. Draw familiar partial game records in the response panel. Adult cuts pieces, counts in/out and prohibits mouthing; replace unsafe pieces with drawn marks.

### The day

#### 5 min. Warm-up: Oral count

Review count and keep track, day 1; total, day 19; Counted-uncounted boundary, day 12. **Ask.** [[s04-R66-count]] Then **Ask.** [[s04-R66-start]] Children speak or gesture simultaneously. Review Paper count-dot record, day 1: touch one familiar square and match one mark. No individual round, timed recall or new count range.

#### 10 min. Return and repair

Review Return and repair, day 2. Return day 65's exit, W65, recorded practice and unit 3 notes with feedback; remaining unit 3 action uses Centers. If day 65's tickets showed skipping, error A, **Ask.** [[s04-F66-A]] Then [[steps:s04-F66-A]]. Five minutes guided boundary movement; five fresh supplied-route retry. If many, more than ten, share it, repair together; otherwise one teacher group while others correct familiar partial records. For observed first-group exclusion, error B, **Ask.** [[s04-F66-B]] Then [[steps:s04-F66-B]]. Choose this familiar correction instead of A, not in addition. Never rehearse the animal exit. No additive repair groups.

#### 10 min. Tracking rehearsal

Review Follow supplied touch route before independent route, day 65. **Ask.** [[s04-P66]] Use practice-66.md: three and three scattered squares, five supplied ticks. Follow the adult's existing line; restore its one missing visit. Count six, one touch and one tick per square. Model only the familiar route action; teach nothing new. One volunteer, 45 seconds. Review 10-frame and five-and-some, day 26; place the same six beside the picture as five then one if helpful. No operation signs.

#### 15 min. Connected work

Review Partner turns, day 1. Fifteen simultaneous pairs, 45 seconds each then swap; reset/repeat. One follows the supplied route, partner points to matches without naming a total first. **Ask.** [[s04-P66-mix]] Alternate familiar three-and-three/six and four-and-four/eight corrections.

Check: one visit per square, none missing or counted twice.

Every child returns a corrected paper record to their own folder. Immediate feedback; no speed score, new strategy or self-invented practice route.

#### 12 min. Centers and tidy

Review Counting centers, day 1; Counted-uncounted boundary, day 12. First five minutes receive days 64/65's actual remaining unit 3 component. Set one matching fresh response case from the private answer key: position [[s04-P66-u3-position]], boundary/corners [[s04-P66-u3-features]], closure [[s04-P66-u3-close]], fit [[s04-P66-u3-fit]], attributes [[s04-P66-u3-attribute]], length/height [[s04-P66-u3-length]], heft [[s04-P66-u3-heft]], capacity [[s04-P66-u3-capacity]]. Review position words, day 45; side/corner, day 48; length, day 51; height/weight/capacity, day 53. Hear at most six matching single asks, 45 seconds each plus thirty seconds reset. No concurrent teacher-led group; other gaps remain not yet seen. Adult pours over tray/dries spills; unavailable apparatus leaves capacity pending.

Meanwhile everyone else alternates familiar within-five corrections: [[s04-P66-game5]] and [[s04-P66-game4]], fifteen simultaneous pairs, 45 seconds each then swap. Use the supplied partial cards on the response panel, not loose-group invention. Next five minutes repeat familiar route corrections; the teacher rejoins. Keep dated paper, feedback and revised work. Last two minutes tidy/count pieces in.

#### 8 min. Exit ticket

First reveal exit-66.md at each child's own turn: one boot and seven scattered boots, no supplied route. **Ask.** [[s04-X66]] Read exact stem aloud. Everyone marks their chosen tracking on the half slip. Hear roster 13 to 18 only, six times 45 seconds = 4.5 minutes; one minute launches, two allow concurrent paper marks, half a minute collects. Quiet work while waiting; no public counts or printed keys.



After class, thirty papers times twenty seconds = ten teacher minutes to mark, plus five minutes for game and unit 3 notes, ten seconds per child. Use shown, shown with help, not yet seen; record heard names and help separately. Unheard speech stays pending. Today's fresh case may establish an aligned earlier missing component without another ask; it never proves earlier speech. Return all recorded practice, unit 3 notes and exit feedback day 67 Return and repair. Unscored practice stays in folders.

### Other rooms

Hand-copy original paths and exit masters. Large paper squares replace counters; drawn joined 5-frames replace printing. No device needed; one shared screen may enlarge teaching only. Broad pencils, raised boundaries and child-directed adult movement/scribing support access. Never remove children.

### At home

**Swap.** Draw routes and cut large squares instead of counters; draw joined frames if needed.

**Skip.** Class rotations/repeats. If unit 3 feedback remains, replace Count with one matching fresh response; keep other gaps recorded.

- **5 min. Count.** Count one to ten together, then five to ten.
- **7 min. Return.** Give day 65 feedback; move five squares once across a drawn boundary.
- **10 min. Rehearse.** [[s04-P66]] [[s04-P66-mix]] Follow supplied paths; repair omitted visits.
  **Say.** "Repair this supplied counting route." Expect: six visits, each square once; the other record has eight.
- **8 min. Exit ticket.** [[s04-X66]] First show reserved boot pictures with no route. Read stem; child marks alone. Keep paper and words; return feedback tomorrow.

### Shorter or longer

Shorter: fewer repeated pair rounds; retain repair, rehearsal and exit. Longer: follow the same supplied route again and check each visit, within ten.

### Words and supports

Review put together, add and altogether, day 64; square, day 45. Read all print aloud at 18 point, no independent reading. Counts may use speech, signs or usual communication aid. Passing public talk is allowed; record access separately from mathematical help.

### Tomorrow

Day 67 returns day 66's exit. A visibly untouched boot suggests error A; move every square once and retry a fresh supplied layout, not the boot card. Then show joining through actions and a supplied sound record; explicitly teach no arrival and one arrival.
