# Day 148: I can see parts in a domino.

## Teacher page

### Before class

Open key-teacher.md privately for evidence and today's teacher-only practice key. Print corrected student practice and sealed exit master. Lay out materials; fill observation names. Read all print aloud; say "Invented for practice." For the exit, draw four dots beneath a removable right-half flap; begin open. Put other reserved cards away. Demonstrate center cues before private observations.

### The day

#### 5 min. Warm-up counting

Whole class: Review Oral tens to one hundred and Echo supplied start then continue, day 104. [[s08-Q148]] [[steps:s08-Q148]] Echoed partial stretches are practice; no independent full recital. Repeat a missed word with its object action.

#### 5 min. Return and repair

The opening follows Counting: Return and repair, five minutes; Domino model, five; Connected work, ten. Total: twenty minutes.

Return the full practice packet: `s08-G147-1`, `s08-G147-2`, `s08-G147-3`, `s08-G147-4`, `s08-G147-5`, `s08-G147-6`, `s08-P147-1`, `s08-P147-2`, `s08-Q147`, `s08-R147`, `s08-RK147`. Preserve original marks with feedback.

Return all day 147 papers. Review Return and repair. If day 147's practice showed visible called hidden, error M, [[s08-R148]]: [[steps:s08-R148]] More than a third means whole class; otherwise group. Joining exit cannot establish M; its error L belongs in Connected work.

#### 5 min. Domino model

Name two-half dot card a domino. Review part and whole, day 87. [[s08-P148-1]] [[steps:s08-P148-1]] Check second unhidden card: [[s08-P148-3]] [[steps:s08-P148-3]] Compare its whole with the first card's three. Then [[s08-P148-2]]: [[steps:s08-P148-2]] If many reject zero, error O, touch empty mat. No covered domino in teaching.

#### 10 min. Connected work

If many of day 147's tickets recorded only a part, error L, first five: [[s08-RL148]] [[steps:s08-RL148]] Otherwise all ten for partial domino-sort corrections. Partners repair supplied totals, switching pointer/recorder after 45 seconds. Each marks own page. Repeat only zero/three and zero/four cards. No independent covered removal recall.

#### 30 min. Counting observations

Use day 146's F2 counting record for today's previously unheard children. Retain each child's first attempt and actual help.

Assigned roster 21 to 30: [[s08-F2-ones]] then, after finishing or recording pending, [[s08-F2-tens]]. Two separate private asks with count-record.md; remove group cues. Ten times three minutes: two ones, 45 seconds tens, 15 transition. Child marks completion pictures; marks never prove unheard sequence. Keep separate components; unfinished stays pending, never rushed or replaced by choral work.

Others play five minutes: Review Counting centers, Partner turns and Paper count-dot record, day 1; Mixed untimed within-five supplied-record game, day 71. Fifteen pairs use [[s08-G148-1]] [[s08-G148-2]] [[s08-G148-3]] [[s08-G148-4]] [[s08-G148-5]] [[s08-G148-6]]. Teacher reads cards beforehand. Three 90-second rounds, maker/checker swap after 45 seconds, thirty seconds tidy. Each records three quantities; immediate feedback compares supplied pictures. No speed ranking. Use the shared nonzero-addend cards `s08-G135-7` `s08-G135-8` `s08-G135-9` `s08-G135-10` from game-addition-cards.md in the same three rounds: two additions and one removal per child. Open section 8.1's private packet for their supplied-picture keys. These fixed cards return for rehearsal, with no extra rounds.

Check: Match each result to supplied picture.

Unassigned time: three independent minutes revising day 147 counting feedback, then quiet repeated supplied practice with demonstrated picture cues. Collect every paper. Teacher stays with assigned counts. Partners choose next supplied card when one is called; tidy during unassigned time.

#### 5 min. Exit ticket

Show exit-148.md only now. Display both halves of its one/four domino, then cover four-dot half without removing it. Child records remaining part. All five must be seen first; printed cover alone cannot establish starting whole. Read [[s08-X148]] exactly. All thirty mark independently or direct adult mark. At most two 45-second observations embedded in three paper minutes; thirty seconds collection fits five. Record actual names heard; no added oral requirement.

Review Written component feedback before later revision and score, day 115. After class: fifteen teacher minutes for exits, thirty seconds each; fifteen for practice packets; ten for window picture feedback. Use shown, shown with help, not yet seen only; access and mathematical help separate. Return every paper day 149; retain original evidence and later revisions. 

### Other rooms

Paper and objects carry every task. Hand-draw masters without printer. Shared screen may enlarge instruction; remove for observations. Adult marks follow child direction; access help noted separately.

### At home

**Swap.** Draw cards/masters; use large paper squares, folded cover and crayon.

**Skip.** Rotations; finish unheard count components only, no repeat recital.

- **3 min. Count.** Echo short stretches together.
- **5 min. Show.** [[s08-P148-1]] **Say.** "Repair this empty-and-three domino total." Expect three from empty and three. Point to both halves.
- **5 min. Game and repair.** Follow yesterday's feedback, then supplied game pictures.
- **12 min. Paper and count.** [[s08-P148-2]] **Say.** "Correct this three-remove-three result." Expect zero after all three leave. Complete unheard count components without cues; retain originals.
- **5 min. Exit ticket.** [[s08-X148]] Show all five dots on unseen one/four card, then cover four-dot half. Read exactly. Child marks alone; expect one remaining. Save for tomorrow.

### Shorter or longer

Shorter: remove five unassessed paper-repeat minutes, preserving game, revision, observations, model and exit. Longer: rearrange same permitted practice quantity. No reserved case or larger arithmetic.

### Words and supports

Review count, number word, keep track, day 1; counter, day 3; group, day 6; zero, day 30; add/take away, days 64/68; expression, equation, equals, day 78; part/whole, day 87; 5-frame/10-frame, days 3/26. Use objects/gestures. Read all print aloud at 18 point; accept home language, signs, tactile dots, directed adult marks. Public talk may be passed; judge mathematics, not handwriting.

### Tomorrow

Day 149 returns every paper. If day 148 tickets confuse covered/remaining, error M, repair fresh supplied within-four cover in Return and repair. If no M need, observed practice error O gets five-minute empty-mat repair; others pending. Count feedback gets three independent center revision minutes. Next supplied value sorts, frames by choice, first ten private facts.
