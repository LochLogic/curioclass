# Day 149: I can sort facts by their value.

## Teacher page

### Before class

Open teacher-key.md privately for evidence and today's teacher-only answer key for practice. Print the student page as corrected partial practice and today's sealed exit master. Lay out listed materials. Read every printed word aloud; say "Invented for practice." Fill actual names beside assigned roster numbers. Put other reserved cards away. Read paper cues before centers; private answers stay out of peers' hearing.

### The day

#### 5 min. Counting

Whole class: Review Oral tens to one hundred and Echo supplied start then continue, day 104. [[s08-Q149]] [[steps:s08-Q149]] Echoed partial stretches are practice; no independent full recital. Repeat a missed word with its object action.

#### 5 min. Return and repair

Return the full practice packet: `s08-G148-1`, `s08-G148-2`, `s08-G148-3`, `s08-G148-4`, `s08-G148-5`, `s08-G148-6`, `s08-P148-1`, `s08-P148-2`, `s08-Q148`, `s08-R148`, `s08-RL148`, `s08-P148-3`. Preserve original marks with feedback.

Return all day 148 papers. Review Return and repair. If many of day 148's tickets confuse hidden and remaining, error M, [[s08-R149]]: [[steps:s08-R149]] If no M need, address observed error O with [[s08-P149-2]]. One five-minute priority; other needs pending. Whole class above a third, otherwise group. Counting feedback gets independent center revision.

#### 5 min. Fact model

Review expression, add, take away and equals. Withdraw supplied frames; optional frames remain child's choice, help recorded. [[s08-P149-1]] [[steps:s08-P149-1]] Check objects before changing started sort. [[s08-P149-2]] [[steps:s08-P149-2]] Counting all is valid; it does not alone show fluent recall.

#### 5 min. Connected work

Pairs repair supplied placements and empty-mat label. Pointer/recorder each gets 45 seconds, simultaneously across pairs. Keep individual marks and immediate partner feedback. Objects, then picture, then expression. If many ignore operation, repeat its action. Never start blank piles or introduce new arithmetic.

#### 35 min. Fluency observations

Assigned roster 1 to 10, after practice: privately read [[s08-F1a]], [[s08-F1b]], [[s08-F1c]], [[s08-F1d]], waiting after each. Use fact-record.md's four quantity boxes, counters optional. Four 45-second asks plus 15 transition = 3.25 minutes; ten need 32.5, leaving 2.5 setup/tidy. No supplied solutions, peer coaching or child-facing timer. Record accuracy/help by item; separate just knows, quick strategy, counts all notes. Four facts cannot establish every fact's fluency. Unfinished stays pending.

Others play five minutes: Review Counting centers, Partner turns and Paper count-dot record, day 1; Mixed untimed within-five supplied-record game, day 71. Fifteen pairs use [[s08-G149-1]] [[s08-G149-2]] [[s08-G149-3]] [[s08-G149-4]] [[s08-G149-5]] [[s08-G149-6]]. Teacher reads cards beforehand. Three 90-second rounds, maker/checker swap after 45 seconds, thirty seconds tidy. Each records three quantities; immediate feedback compares supplied pictures. No speed ranking.

Check: Match each result to supplied picture.

Unassigned time: three independent minutes revising day 148 counting feedback, then quiet supplied partial-practice repetitions. Preserve original strategy/help and actual changes; never recollect secure component. Teacher remains with private observations.

#### 5 min. Exit ticket

Show exit-149.md only now; read expression as four minus two. Child links to one value picture; all choices visible, no elimination cues. Read [[s08-X149]] exactly. All thirty mark independently or direct adult mark. At most two 45-second observations embedded in three paper minutes; thirty seconds collection fits five. Record actual names heard; no added oral requirement.

Review Written component feedback before later revision and score, day 115. After class: fifteen teacher minutes for exits, thirty seconds each; fifteen for practice packets; ten for window picture feedback. Use shown, shown with help, not yet seen only; access and mathematical help separate. Return every paper day 150; retain original evidence and later revisions. 

### Other rooms

Paper and objects carry every task. Hand-draw masters without printer. Shared screen may enlarge instruction; remove for observations. Adult marks follow child direction; access help noted separately.

### At home

**Swap.** Draw masters; use large paper squares, folded cover and crayon. Frames optional.

**Skip.** Rotations; observe four facts once across days 149 to 151.

- **3 min. Count.** Echo short stretches.
- **5 min. Show.** [[s08-P149-1]] **Say.** "Repair these two swapped value placements." Expect both corrections: three minus two with one dot; four plus zero with four dots. Child changes supplied links.
- **5 min. Game and repair.** Play supplied game pictures; revise yesterday's feedback.
- **12 min. Paper and facts.** [[s08-P149-2]] **Say.** "Correct this five-remove-five label." Expect zero. Ask four private fact prompts once, answers out of view; child draws quantities, counters optional. Keep strategy notes.
- **5 min. Exit ticket.** [[s08-X149]] Show unseen card/choices; read four minus two. Child links alone; expect two dots. Save feedback for tomorrow.

### Shorter or longer

Shorter: remove five unassessed paper-repeat minutes, preserving game, revision, observations, model and exit. Longer: rearrange same permitted practice quantity. No reserved case or larger arithmetic.

### Words and supports

Review count, number word, keep track, day 1; counter, day 3; group, day 6; zero, day 30; add/take away, days 64/68; expression, equation, equals, day 78; part/whole, day 87; 5-frame/10-frame, days 3/26. Use objects/gestures. Read all print aloud at 18 point; accept home language, signs, tactile dots, directed adult marks. Public talk may be passed; judge mathematics, not handwriting.

### Tomorrow

Day 150 returns every paper. If day 149 tickets ignore removal or join, error C only when observed, five Return and repair minutes use fresh triangles. Fact feedback gets three independent center revision minutes. Next familiar result/strategy claims, then next ten private facts.
