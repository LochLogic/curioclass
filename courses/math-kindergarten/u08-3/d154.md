# Day 154: I can repair number work.

## Teacher page

### Before class

Open today's teacher-only answer key (d154-key, generated from items.csv) privately, plus teacher-key.md for carried evidence. Read all print aloud. Say "Invented for practice." Record actual names heard, original response, access support and mathematical help separately. Reserve transfer materials until their named part. Draw only each assigned exit stimulus from its item setup on the top of that child's blank half-sheet; leave Exit box below. Read the stem aloud, never print a key. Keep these sheets covered until Exit ticket.

### The day

#### 5 min. Counting

Day 153 brought new products; day 152 supplied number needs. Review [[sC-P154-count]]. Use written day 146 loose-ones model. Echo a missed decade stretch; distinguish a repaired transition from a full count. No new sequence judgment.

#### 5 min. Game

[[sC-P154-gamea]] [[sC-P154-gameb]] Fifteen pairs verify supplied pictures with counters. Three 90-second rounds, swapping maker/checker after 45 seconds; thirty seconds tidy. Everyone marks quantities on scrap paper. Feedback compares supplied picture, not speed.
Check: Match the objects to the supplied result.

#### 5 min. Revision

Return day 153's assessment: partner and comparison/shape products with written picture feedback. Three independent revision minutes, two for collection. First judgment afterward. Preserve original responses.

#### 40 min. Groups

Act on day 152 numeral/count/teen needs: error L mismatches labels, error J passes the request, error P replaces ten ones by one mark and day 150 s08-X150/day 151 arithmetic needs. Three 13-minute slots plus one minute transition. Choose one priority per child, ten children per slot; one slot each, never all gaps at once. If more than ten share a need, use one whole-class slot and use later slots for other needs. Queue unresolved needs for days 156 to 160.

Count group: [[sC-K154-1]] [[steps:sC-K154-1]] Separate numeral formation from object tracking. Teen group: [[sC-K154-2]] [[steps:sC-K154-2]] Show ten individual ones, not a ten treated as one counter. Fact group: [[sC-K154-3]] [[steps:sC-K154-3]] Move objects out for removal. Correct errors from unit 8 by its lettered actions; no secure check replay. Other children repeat supplied practice on paper, keeping independent transfer unseen.

Each slot: four minutes model, six supported practice, three independent rehearsal. Hear two named children per slot, one 45-second practice ask each, within six practice minutes; six heard overall. Others all mark paper. Unheard explanations stay pending.

#### 5 min. Exit ticket

Use ONE assigned fresh prompt: [[sC-X154-1]] count, [[sC-X154-2]] teen, [[sC-X154-3]] removal, [[sC-X154-4]] tens or [[sC-X154-5]] joining. Read each active group's single stem aloud, point to its unseen stimulus, then all mark the half-sheet Exit box independently. Five groups need at most one minute directions, three marking, one collection; no added oral interview. The matched transfer records only its component, not full fluency or a full sequence. After class: fifteen teacher minutes for written picture feedback, plus fifteen for eligible earlier judgments. Return fresh papers day 155 Revision before judgment.

### Other rooms

Objects and paper carry every task. A shared screen only enlarges pictures. Offer tactile outlines, home language, signs or child-directed adult marks. Public talk may be passed; unheard explanations stay pending.

### At home

**Swap.** Use scrap squares, a drawn frame, folded envelope and crayon. No screen needed; draw only the assigned transfer's picture.

**Skip.** Group rotation and unneeded branches.

- **13 min. Repair.** Choose the matching example. [[sC-K154-2]] **Say.** "Correct this twelve drawing." Expect ten individual ones and two more; use the other example if that is the need.
- **5 min. Game.** [[sC-P154-gamea]] [[sC-P154-gameb]] Verify supplied pictures; mark results on scrap paper.
- **5 min. Exit ticket.** Choose only the route matching the selected group: [[sC-X154-1]] [[sC-X154-2]] [[sC-X154-3]] [[sC-X154-4]] [[sC-X154-5]]. Read that one stem aloud; child marks the assigned half-sheet alone. Use its teacher answer afterward. Keep original response/help; written picture feedback afterward, independent revision tomorrow before judgment.
