# Physical groups, teacher setup

Cut one hundred large paper squares, arrange ten loose groups of ten actual ones. Keep each square separate. This is a concrete teacher-use model, not a printed route. No number labels above twenty. Move a single square with each spoken ones word; at sixty-nine to seventy finish the seventh group and start seventy-one in the next. Move one whole group for each tens word, keeping its ten ones visible. Echo short stretches and compare their repeated ones words. Never use this model as F2 cues. Child marks a blank sketch after handling.
