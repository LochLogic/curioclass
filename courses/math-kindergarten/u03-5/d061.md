# Day 61: I can make the same whole with different pieces.

## Teacher page

### Before class

Keep teacher-key.md private. Set practice-records.md, practice-61.md; select repair-61-K.md or u03-4/repair-60-N.md. Reserve packet-61.md/exit-61.md at identical scale. Prepare assessment-composition.md/assessment-composition-pieces.md at same scale, no seam supplied. Set reserved display/labels/tub, pretested heft/pour pieces, water/tray/towel. Adult cuts/pours; read aloud.

### The day

#### 5 min. Warm-up: oral count

Review count and keep track, day 1. **Ask.** [[s03-W61]] Touch or move each of 8 squares once. Count together to ten, supported toward twenty; no timer. Review Paper count-dot record, day 1: mark one dot per square on scrap paper.

#### 5 min. Return and repair

Review Return and repair, day 2. Return day 60's tickets and practice feedback. Return day 60's written tasks s03-P60-mat and s03-P60-fills with recorded feedback; correction uses this same priority slot. Return day 60 conference feedback. For overlap, error K, [[s03-F61-K]] with repair-61-K.md. For an unmatched day 60 hexagon, error x, trace and turn a different six-sided practice boundary, then repair one missing side mark on a fresh outline. For observed B/N in practice instead [[s03-F61-corners]]: overlay fresh square/slanted-tile corners, rotate square to show unchanged corners. No exit choices. One action only; queue others. More than ten of thirty: whole class; otherwise small group while others revise familiar paper. Keep original/helped versions separate.

#### 12 min. F4 and connected corrections

Reveal reserved nonsquare outline/diagonal halves. Six independent minutes total: [[s03-F4-fill]], then separately [[s03-F4-seam]]. Trace original outside/seam; keep before feedback. Remaining six review compose/gap/overlap, day 60. **Ask.** [[s03-P61-hexagon]] Wait, replace one triangle in supplied five-triangle partial hexagon. Review Partner turns, day 1: fifteen concurrent pairs, two 45-second turns plus thirty seconds handling within six minutes. Follow completed fills' outside, never independently fill two outlines. [[s03-P61-count]] Count six triangles; compare day 60's three pieces by pairing, review more/fewer, day 21.

#### 28 min. Final conferences and centers

Review Counting centers and Partner turns, day 1. Roster 19 to 24 only. Read separately: [[s03-F1-talk-61]], [[s03-F2-talk-61]], [[s03-F5-talk-61]], [[s03-F6-weight-61]], [[s03-F6-capacity-61]]. Show oral pieces first at that child's turn. No writing in spoken prompts; teacher scribes. F1 uses viewing arrow; F2 names actual labels, accepting square also as rectangle. Tub attributes concern same real tub. Child hefts sealed tubs/swaps hands, then directs adult's full tall-to-empty-wide cup pour over tray; stop at rim, dry spills/floor immediately.

Five 45-second asks plus thirty seconds setup/reset: 4.25 minutes per child, 25.5 for six; 2.5 reserve. Use reserve for pauses/unclear methods, never rush. Unfinished components pending for day 63. Others use familiar practice panels/returned corrections; no water centers or teacher interruptions. Retain originals. Credit names/relationships/method only when heard/observed, never weight/capacity from pictures. Write feedback after class for next-day revision.

#### 2 min. Tidy

Collect practice concurrently in table trays. Keep reserved papers separate; adult empties/dries water area and checks floor.

#### 8 min. Exit ticket

Reveal packet-61.md and two equal square outlines on exit-61.md, identical printing scale. Fit/trace both fills/seams, different pieces/same outside; hear six. **Ask.** [[s03-X61]] Exact stem aloud; response format adds no ask. Launch/concurrent paper 2.5 minutes, roster 7 to 12 six 45-second turns 4.5 minutes, collection one minute. Private teacher-key.md. Scale: shown, shown with help, not yet seen; record heard date/help, unheard components pending. Thirty slips at twenty seconds: ten teacher minutes after class; five more for conferences. Return day 62 in Return and repair. No credit for unheard speech.

### Other rooms

Hand-copy exact panels/exit before class. Paper shapes/strips replace blocks/straws; folded paper replaces clay. No device needed; one shared screen can enlarge teaching. Tactile boundaries/usual communication aids, adult follows child directions; record access separately from math help. Capacity requires real cups, water/tray/towel; otherwise pending. No glass, food, tasting, small joins or body comparisons.

### At home

**Swap.** Hand-draw panels; paper pieces replace blocks. Real sealed tubs/cups, water/tray/towel; adult pours.

**Skip.** Class rotations/repeated centers.

- **3 min. Count.** Touch eight squares, mark dots.
- **5 min. Repair.** Return day 60 feedback; fix one familiar partial join.
- **7 min. Practice.** [[s03-P61-hexagon]]
  **Say.** "Fix this partial hexagon design." Expect: six triangles complete hexagon.
- **5 min. Records.** Keep class fill/seam paper. If absent, use same outline/pieces independently once, then keep original.
- **2 min. Tidy.** Clear practice.
- **8 min. Exit ticket.** [[s03-X61]] Reveal reserved square outlines/packets, identical scale. Read exactly; child fills/traces alone. Expect: same square, four small squares or two triangles. Record help, return feedback tomorrow.

### Shorter or longer

Shorter: fewer center repetitions; preserve independent work, feedback and exit. Longer: repeat same partial correction, check joins. Never practice reserved cases.

### Words and supports

Review shape names/positions, day 45; side/corner, day 48; join, day 51; turn, day 47; length, day 51; height/weight/capacity, day 53, where used. Review compose, gap, overlap, outline, same whole and different pieces, day 60. Read all print aloud at 18 point. Public talk may be passed; no child models error. Frame: "This edge meets ___." Remove frames for checks.

### Tomorrow

Day 62 returns day 61 tickets in Return and repair: E, gap, or K, overlap, gets one partial-puzzle correction. Feedback and revision holds F4/conference feedback for separate five minutes; preserve original/revision. Then own art, no partner-picture analysis before exit.
