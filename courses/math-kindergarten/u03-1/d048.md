# Day 48: Sides, corners and lengths

## Teacher page

### Before class

Keep teacher-key.md private. Prepare practice-48.md, repair-48-B.md, the student-page Exit box and exit-48.md; keep both checks covered. Set large paper squares, adult-cut practice shapes and broad pencils. Prepare the covered observation master and retained paper marks for today's named children only. Use the viewing arrow for positions. Read child print aloud at 18 point; draw copies if needed. Keep all other assessment panels covered. Large intact pieces only; no mouth contact.

### The day

#### 5 min. Warm-up: oral count

Review counted/uncounted and keep track, day 12. Five squares, [[s03-W48]]: move each across the counting boundary once, then make matching dots. Oral count to ten, supported toward twenty. No timer.

#### 5 min. Return and repair

Review Return and repair, day 2. Return day 47's exit ticket, written task records and heard notes with feedback: one minute return, one model, two concurrent corrections, one collection. If many rejected the turned square, use [[s03-F48-B]] on the separate repair card. Review turn, day 47: rotate the square onto its tracing, tracking each corner. Correct the wrong claim on paper. More than ten of thirty: class repair; otherwise group while others revise familiar traces. Everybody returns a correction. Other letters stay queued. No paired square/rectangle comparison.

#### 8 min. Model sides and corners

Review straight/curved and boundary, day 46. A side is one straight boundary part; a corner is where sides join. Show one broad triangle, then one regular hexagon. **Ask.** [[s03-K48-sides]] then [[s03-K48-corners]]. Mark a start so the first part is not counted twice. Name hexagon across regular and irregular examples: six sides, not necessarily six equal sides. Review equal, day 22; here it describes side lengths. **Ask.** [[s03-K48-equal]] Move the strip along each side without stretching. Show the wide rectangle alone: [[s03-K48-rectangle]]. Opposite sides fit, adjacent ones do not. A folded paper corner fits each corner. A square is a rectangle with all four sides equal. Pictures are invented for practice.

#### 12 min. Connected feature correction

First five minutes: uncover the student-page Exit box, reproducing check-48.md, only now. **Ask.** [[s03-C48]] All independently mark one shared feature in the Exit box while turns proceed; hear children 19 to 24, six 45-second responses plus half a minute launch/collection. Record one shared feature, not a difference. Return this paper with today's exit on day 49.

Seven minutes remain for familiar single-card corrections: [[s03-P48-boundary]] fixes a missing side mark and [[s03-P48-circle]] traces one curved boundary. Fifteen pairs run two concurrent two-minute rounds; three minutes allow independent marks and collection. No square/rectangle paired comparison practice.

#### 20 min. Centers

Review Counting centers and Paper count-dot record, day 1. Others repeat the supplied single-card feature corrections and five-square dot records independently.

Use assessment-display.md and viewing arrow for F1 cells 19 to 36 for children 4 to 6, child first then above, below, beside, next to, in front of, behind. Indicate one target and read its one master prompt. Let the child mark that target and respond; scribe words without supplying them. Eighteen 45-second turns plus 1.5 minutes setup take fifteen minutes. The six component rows are s03-F1-48-1, s03-F1-48-2, s03-F1-48-3, s03-F1-48-4, s03-F1-48-5, s03-F1-48-6. Keep other children on familiar paper; never show this display in practice.

Children 1 to 3 use their first five independent center minutes to revise day 47 F1 picture marks from written feedback while the teacher hears children 4 to 6. Do not repeat secure speech. Five remaining teacher minutes launch/collect; preserve original and revised marks.

#### 2 min. Tidy

Concurrent table trays collect strips/cards. Keep corrections with each child's practice.

#### 8 min. Exit ticket

Reveal exit-48.md for the first time. **Ask.** [[s03-X48]] Read exactly; one comparison requested. Explain format: marks on the contrasting sides show one difference. Supply no feature or name. One minute launch, two concurrent paper minutes, six 45-second comparisons from children 19 to 24, half a minute collection. Others keep finished slips face down. Record names/help, not unheard reasons. After class, allow fifteen teacher minutes: thirty packets at thirty seconds each for C48, exit, practice and heard-note feedback. Use shown, shown with help, not yet seen; unheard words stay not yet seen. Return daily work in day 49 Return and repair, F1 feedback in its first five independent center minutes.

### Other rooms

All work has a paper path. Hand-copy these same panels before class if printing is unavailable. No device turns; one shared screen may enlarge teaching drawings only. Keep reserved exits covered until the independent turn.

### At home

**Swap.** Draw practice shapes; cut a broad side-length strip and fold a paper corner.

**Skip.** Class rotations and completed F1 turns.

- **3 min. Count.** Touch five squares once each; make five dots.
- **5 min. Model.** Trace one triangle, then one hexagon; mark sides/corners from a start dot. Check equal hexagon sides with the strip. Show the rectangle alone with its two long sides.
  **Say.** "Fix the side marks." Expect six separate marks on the irregular hexagon.
- **9 min. Practice.** First [[s03-C48]] alone: uncover the Exit box, read exactly, retain shared-feature marks and words. Then repair the single hexagon and trace the circle. Revise yesterday's F1 picture feedback without repeating the oral check.
- **5 min. Repair.** Turn the practice square over its tracing; correct yesterday's claim if needed.
- **8 min. Exit ticket.** [[s03-X48]] First reveal exit-48.md. Read exactly; child marks independently. Expect one side-length contrast: all square sides equal, rectangle long/short sides. Note help; give feedback tomorrow.

### Shorter or longer

Shorter: reduce center repetitions, keeping the model, priority repair and independent exit. Longer: repeat the same practice with a partner describing a feature; no reserved cards.

### Words and supports

Side, corner; review boundary, straight, curved and turn. Review equal as lengths that fit the same strip. Use large side marks and corner dots, not color. Folded paper supports corner comparison without angle measurement. A scribe records words but does not choose features.

### Tomorrow

Day 49 applies known boundary features to self-chosen sorts. Its Return and repair uses error B, turned square rejected, on a separate tile; record feature-count gaps descriptively and queue one if more urgent. Return every comparison with feedback, without supplying an unheard explanation.
