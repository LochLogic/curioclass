# Day 45: Move it and say where

## Teacher page

### Before class

Send family.md. Keep teacher-key.md private. Set flat shape cards, viewing arrow, cup and block box facing one viewer. Set nine large paper squares for retrieval. Use u03-1/practice-records.md to select practice-45.md panels reproduced below. Keep exit-45.md covered. Gather day 43 feedback and day 44 first-made work, revisions and number records. Read all print aloud; child print is 18 point. Adult cuts large intact pieces; keep pieces out of mouths.

### The day

#### 3 min. Hook

Say Rin and these pictures are invented for practice. Rin moves one circle card beside a block box; everyone faces the arrow. Post the unit question: What is the same and what is different about these shapes and things?

**Ask.** [[s03-K45-hook]] Accept a gesture; at most two volunteers, passing allowed.

#### 5 min. Warm-up: oral count

Review count and keep track, day 12. Model one touch per square before pairs use [[s03-W45]] with five squares. Pairs work concurrently; choral counting to ten, supported toward twenty, is rehearsal, never individual evidence.

#### 5 min. Retrieval

Review numeral, day 30, and unchanged quantity, day 32. Nine squares: [[s03-R45-count]], then [[s03-R45-numeral]]. Spread the same nine; [[s03-R45-still]]. One prompt at a time; all work concurrently, writing on the blank reverse of practice-records.md. Observe tracking; no thirty-child interview. Retrieval, not final evidence. Review Counting mat, day 1, and Hand-drawn paired 5-frames as a 10-frame, day 26; offer one supported try, then withdraw the supplied frame.

#### 7 min. Model positions

Use the circle card for the movement commands. Name five flat cards: circle, triangle, square, rectangle, hexagon. Circle now names a round flat shape, beyond the counting arrangement reviewed from day 27. Use the cup for all six separate moves, resetting each time. Above is higher; below is lower; beside and next to mean alongside. In front is nearer this viewer; behind is farther, possibly hidden. Keep the viewer fixed.

**Ask.** [[s03-P45-positions]] [[s03-P45-position-below]] [[s03-P45-position-beside]] [[s03-P45-position-next-to]] [[s03-P45-position-in-front-of]] [[s03-P45-position-behind]] Give six commands separately, then demonstrate each; no static folder scene.

#### 5 min. Connected placements

Review Partner turns, day 1. Fifteen concurrent pairs use above/below in round one, beside/next to in round two: four 45-second turns plus two handling minutes. Adult reads each command; child moves a card and records its route on paper. If placements reverse, move alongside the viewer and demonstrate again.

#### 10 min. Unit 2 Return and repair

Return day 43's exit ticket and written task records, plus day 44's assessment work first made yesterday and observation notes. Review Return and repair, day 2. First five minutes: return one minute, model one priority counting/numeral correction for one, revise concurrently for two, collect for one. Review Try a tracking support, day 5, if tracking failed. Others revise their familiar number paper. First-made work is revised before judgment.

Five minutes: fresh four-square retry [[s03-R45-retry-count]], then [[s03-R45-retry-numeral]] on the blank reverse. Keep original, feedback and revision. Keep day 44 priorities pending unless addressed: error D, requested stop; error E, zero; error G, category order; error H, one more; error I, extras; error J, quantity; error K, tracking. This number retry cannot close sorting/comparison gaps. No completed secure interview is repeated.

#### 15 min. Centers

Review Counting centers and Paper count-dot record, day 1. Use [[s03-P45-count]] on the five-square picture: one square lacks its dot. Children repair it, then repeat front/behind movement commands with cup and card. Teacher checks tracking/numerals while others work independently. Practice stays in the folder; not final evidence.

#### 2 min. Tidy

Return table trays concurrently. Keep retrieval paper separate from shape evidence.

#### 8 min. Exit ticket

Reveal only exit-45.md. **Ask.** [[s03-X45]] Read its exact stem. Explain format: draw the badge's location against the blank folder. No demonstration or word cue. One minute launch, two concurrent paper minutes, six 45-second turns for children 1 to 6, half a minute collection. Other children keep slips face down after marking. Record names/help, never an unheard word. After class, give fifteen teacher minutes: thirty packets at thirty seconds each for paper marks and heard notes. Use shown, shown with help, not yet seen; unheard language stays not yet seen. Return all work in day 46 Return and repair.

### Other rooms

All work has a paper path. Hand-copy these same panels before class if printing is unavailable. No device turns; one shared screen may enlarge teaching drawings only. Keep reserved exits covered until the independent turn.

### At home

**Swap.** Large scrap-paper shapes replace blocks; draw the cup and arrow if needed.

**Skip.** Class rotations and any completed interview.

- **3 min. Count.** Touch five squares together, then nine. Help your child write 9 and spread the same nine.
  **Say.** "Does this numeral still fit?" Expect yes, still nine.
- **5 min. Model.** Move a card above, below, beside, next to, in front of and behind a cup, one command at a time, from one seat.
- **9 min. Practice.** Your child follows the same six commands and draws each movement. Correct one returned number paper before trying four fresh squares and its numeral.
- **5 min. Repair.** Fix the missing counting dot on the practice picture.
- **8 min. Exit ticket.** [[s03-X45]] First reveal exit-45.md. Read its stem; child draws alone. Expect behind the folder. Record help; return feedback tomorrow.

### Shorter or longer

Shorter: reduce center repetitions, keeping the model, priority repair and independent exit. Longer: repeat the same practice with a partner describing a feature; no reserved cards.

### Words and supports

Say while touching single cards: shape is an outline; flat lies on the page. Circle is round and closed; triangle has three joined straight parts; square has four equal straight parts and corners like this page; rectangle has four corners like this page, including squares; hexagon has six joined straight parts. Echo names with gestures. Position words: above, below, beside, next to, in front of, behind. Use the same viewing place. Review numeral and keep track. Large tactile cards, signing and child-directed adult movement are access supports. Record mathematical help separately; a scribe supplies no position word.

### Tomorrow

Day 46 describes visible shape features. Its Return and repair returns today's tickets: error A, front/behind reversed, fixes the viewer and moves a card across a cup; error J, above/below reversed, traces upward/downward from a shelf. One five-minute priority, other letter queued. Its separate ten-minute Unit 2 response continues day 44's revisions and remaining number needs.
