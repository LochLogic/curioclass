# Day 78: I can connect signs to actions.

## Teacher page

### Before class

Keep teacher-key.md private; generated answer key holds new practice steps. Prepare student pages, practice-78.md, counters, frames, mats, record.md and thirty covered exit-78.md half slips. Adult cuts large pieces; count in/out, no mouthing. Replace unsafe pieces with drawn marks. Never move children as objects. Read all print aloud at 18 point; no independent reading.

### The day

For worked and repair rows, read scene first; reveal solution steps after the ask.

#### 5 min. Warm-up: Oral count

Review count and keep track, day 1; total, day 19; Paper count-dot record, day 1. **Ask.** [[s04-K-count-78]] Count together first, then continue from the supplied word. No individual round or required counting-on strategy.

#### 10 min. Return and repair

Review Return and repair, day 2. Return day 77's exit and recorded practice feedback. If day 77's tickets showed the matching action, select one priority. **Ask.** [[s04-F-78]] Then [[steps:s04-F-78]] Five guided minutes and five for a fresh supplied-cue retry. More than ten sharing it: class repair; otherwise one group while peers correct familiar paper. No extra group or check replay.

#### 10 min. Signs and equality

Review add, day 64; take away/subtract/remain, day 68. **Ask.** [[s04-K-join-78]] Then [[steps:s04-K-join-78]] Next **Ask.** [[s04-K-take-78]] Then [[steps:s04-K-take-78]] Show only the day 78 block of expression-cards.md beside supplied models. Review equal, day 22. Name expression, plus, minus, equation and equals through objects, drawings and symbols; children use each name while pointing to its meaning. Two brief demonstrations; no individual round.

#### 15 min. Connected work

Review Partner turns, day 1: fifteen simultaneous pairs, 45 seconds each then swap. Complete supplied two-and-three action/sign before equation; never select finished actions from expressions. **Ask.** [[s04-W78]] Then [[steps:s04-W78]]. Build both remaining quantities beside supplied removal drawing, finish signs, read both orders. Error D rejects result-left solely for order; pair equal quantities to repair. Retain corrected paper; return feedback day 79 Return and repair.

#### 12 min. Centers and tidy

Review Counting centers, day 1; Mixed untimed within-five supplied-record game, day 71. **Ask.** [[s04-P-game-78]] Then [[steps:s04-P-game-78]] First five minutes use the two familiar cases with immediate partner/model feedback, no timer or ranking. Next five repeat today's partial square record. Last two tidy and count pieces in. Unscored paper stays in the folder.

#### 8 min. Exit ticket

First show exit-78.md at each child's own turn. Say "Invented for practice." Read exact stimulus from private key, then **Ask.** [[s04-X78]] Read exact stem. All children mark the action and its incoming group on paper. Hear roster 25 to 30 only: six times 45 seconds = 4.5 minutes; reading, concurrent marking and collection get 3.5. No public answer or practice frame.

Carry pending components for s04-X74, s04-X75, s04-X76, s04-X77 only when this fresh evidence fits. No extra ask or old check repeated; unheard explanations stay pending. Use shown, shown with help, not yet seen; log names heard and access separately from mathematical help.

After class: thirty papers times twenty seconds = ten teacher marking minutes. Return exit and recorded practice feedback day 79 Return and repair.

### Other rooms

Unscored corrected practice stays in the folder. Recorded observations return in the next named feedback slot.

Hand-copy original masters. Large paper squares replace counters, drawn frames replace printing, folded paper replaces mats/cards. No device needed; one shared screen may enlarge teaching only.

### At home

**Swap.** Adult-cut squares, folded mats and drawn frames replace class equipment. Hand-copy original masters.

**Skip.** Class rotations and repeated centers.

- **3 min. Count.** Count through ten, then from today's supplied word.
- **5 min. Return.** Use day 77 feedback with one supplied square correction.
- **7 min. Together.** [[s04-K-join-78]] then [[s04-K-take-78]]. Read each scene; ask before showing steps. Match squares across equals; read both equation orders.
  **Say.** "What does plus show here?" Expect: three squares joining two.
- **7 min. Practice.** [[s04-W78]] Child finishes signs beside the supplied removal model. Swap roles for one familiar game round; retain paper.
- **8 min. Exit ticket.** [[s04-X78]] Read exact fresh stimulus from private key, then stem. Child marks alone; keep paper and words.

### Shorter or longer

Shorter: reduce familiar repetitions; retain repair, core connections, paper evidence and exit. Longer: rearrange supplied incomplete square model, correct same missing component; stay within ten.

### Words and supports

Review square, day 45; counter, day 3; group and mark, day 6; total, day 19; altogether, day 64. Review 10-frame, day 26; One counter stands for one story object, day 71. Read all print aloud. Offer high contrast, tactile boundaries, broad pencils, usual communication aids and child-directed movement/scribing. Public talk may be passed; record access separately from mathematical help. An expression uses numbers and a sign to name a quantity. An equation says two quantities are equal. Plus + joins here; minus - removes here; equals = means the same quantity on both sides. Say each name while pointing to the squares or sign it names.

### Tomorrow

Day 79 returns day 78's exit and s04-W78 feedback. Error H: retain originals when pieces join. Error B: enclose both groups. Error D: pair quantities across either equation order. Choose one priority in Return and repair, connect models to equations, then collect independent paper records.
