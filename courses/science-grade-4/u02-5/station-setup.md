# Day 36 private station setup

TEACHER ONLY, pretest before the assessment. Four sequential five-minute observations replace simultaneous rotations. Keep all cases hidden beforehand. Use two seated waves of fifteen with thirty-second repeats; adult reads whole-degree thermometer marks aloud. Keep writing time inside each five-minute station.

1. Sound: separate supports and covered receiving drum. Add opaque card blocking direct view only, touching neither support. Compare gentle sound and silence; no physical bridge. Contain grains inside a clear catch enclosure. Everyone present wears fitted eye protection throughout setup, use and cleanup. Without it, use O and record missing live sound evidence. Check rice allergies beforehand or use paper.
2. Light: adult-cut opaque stripe pattern over fresh cloth; compare exposed/shaded regions from a common start. Pre-expose safely. Adult measures each marked surface spot with the same 1-degree instrument before removing the patterned card. No sun viewing or lenses.
3. Heat: palm-warm source spoon; remove hand, then contact a cooler spoon. Keep a third untouched. Adult records each start/finish at the same contact position. Pretest for a resolved difference; no hot water.
4. Current: new lamp circuit with two independently folded-foil breaks in series. Adult demonstrates neither, either one, both closed. Load always remains in loop. Disconnect before changing connections and at any warming. No outlets.

Use assessment-fallback.md only if needed; no live observation point for supplied records. Day 38 offers one preselected feasible live-mode retry. Five-minute cleanup disconnects, counts, brushes grains and wipes goggles/hands/tables.
