# Day 51: Record two quiet tests

## Teacher page

### Before class

Prepare day 48 source and day 50 proposal, strip, assembly and exit feedback. Print integrated pages, separate slips and private generated answers. Pretest both assembled systems and timer. Mark fixed sender/receiver positions. Keep future cases sealed. Prepare fallback T separately. Do not replace the assembled BEND/ROLL/PRESS meanings with different words.

### Safety and set-up

One active kit, six teams of five. Gentle taps, ears back, stop for discomfort. Keep the walking route clear. No liquids, loose striking pieces or light handling. Adult services equipment. Five cleanup minutes include adult wiping and storage.

### The day

#### 10 min. Return and revision

Return both day 50 exit responses. Review day 48 code key and day 49 message boundary. For five minutes, use [[s03-P51-return]]; if many, more than ten, show error E, revisit the vertical strip and between-message gaps. Others revise independently. Spend two minutes revising day 48 source/research notes, three on day 50 proposals, strips and assembly. Review grade 3 second-color revision: preserve observations and initials. Keep unresolved needs visible.

#### 20 min. Quiet tests

Review accuracy and duration from day 49. Five messages must arrive correctly within thirty seconds. Use BEND, ROLL, PRESS, ROLL, BEND with both assembled systems. Receiver hides the sent column, records detected messages and uses ? for unclear signals before comparing. These familiar-sequence trials cannot establish unfamiliar-message performance.

Use [[s03-P51-log]]. Six three-minute visits take eighteen minutes: two runs, each at most thirty seconds; two minutes to check, reset and copy results. Swap sender/receiver roles between systems; record actual roles. Everyone records both runs. Waiting teams check their own keys. Start timing at the first signal; stop after the final received response. Round to whole seconds. Interrupted or boundary-time readings are unclear, never automatic passes. Use two contingency minutes for one retry, retaining both readings. If still unclear, announce fallback T as invented for practice; analyze separately without practical-performance credit.

#### 5 min. Reconcile records

Each child checks every sent/received pair against the actual run. Preserve errors and disagreements. Attach code, position, condition and role labels. Review the grade 3 design cycle: define, sketch, build, test, compare. Add today's test date to the question board and pattern chart. No supplied acceptance-table rehearsal.

#### 5 min. Cleanup

Adult counts, wipes and stores kit for two minutes. Children file individually identified logs and original proposals for three. Keep failures, including missing firsthand evidence.

#### 5 min. Exit E51

Reveal [[s03-X51]] only now. Each child answers on a half slip. Collect all slips and logs. After class allow thirty times thirty seconds, fifteen minutes, per set: exit marking and log feedback take thirty minutes total. Use shown, shown with help, not yet seen by component. Return both sets on day 52.

### Other rooms

No printer: copy log fields; conceal the exit until its slot. No kit: use fallback T, announced invented; leave practical evidence missing. A board replaces projection.

### At home

**Swap.** Copy the fields. Without equipment, read fallback T as invented. Use its durations; do not time the child.

**Skip.** Team rotation and public sharing.

- **10 min. Return.** Revise day 48 notes and day 50 records; do [[s03-P51-return]].
  **Say.** "What must both ends share?" Expect symbol meanings, order and message boundaries.
- **15 min. Tests.** Send both systems gently. Complete [[s03-P51-log]]. Mark unmeasured durations unavailable. Read supplied durations separately as invented.
- **5 min. Keep evidence.** Check received messages, retain errors, then store equipment and papers.
- **5 min. Exit ticket.** Reveal [[s03-X51]]; child answers alone.

### Shorter or longer

Shorten waiting-team annotations, keeping both runs, complete logs and exit. Extend by naming the familiar-sequence limitation.

### Words and supports

Review accuracy, duration, code key and message boundary. Condition means the test setting, here quiet. Read neutrally; a scribe records personal observations. Frame: "My reading was unclear because ___."

### Tomorrow

Day 52 returns day 51's exit and logs. If error C favors speed over correct reception, use five Return minutes. Repeat both systems with conversation at the same positions. Compare complete records, preserving failures.

### Credit

Ours. Background: Source U3-patterns and Source U3-design.
