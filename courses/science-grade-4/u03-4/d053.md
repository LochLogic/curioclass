# Day 53: Compare evidence and try a fresh case

## Teacher page

### Before class

Return day 52 annotated logs, review response and exit. Print integrated fields and separate slips. Fold or cover the transfer portion until its slot; do not rehearse it. Keep generated answers and future cases private. Prepare a feedback form for each child's transfer, recording components without supplying answers.

### Safety and set-up

Paper work only. Leave kit stored. Allow passing in public talk. No personal experience is requested. Final filing takes five minutes; no equipment cleanup is needed.

### The day

#### 5 min. Return and repair

Return day 52's exit and review response. Use [[s03-P53-return]]. If many, more than ten, show error D, review their own actual logs and restrict the claim to tested conditions. Others mark their evidence limits. Do not demonstrate a near/far omission case or today's transfer.

#### 10 min. Personal comparison notes

Return day 52 annotated both-condition logs. Review grade 3 criterion, a way to check the need is met, and limit; review day 24 constraint, another word for limit. Review day 49 accuracy and duration. Use [[s03-P53-compare]]. Each child writes separate criterion/evidence notes and one failure/change link from personal logs. Partners each take one optional forty-five-second turn asking for evidence; silent exchange is available. Review day 27 retest: changed designs need fresh tests. If no failure occurred, state that limit and propose a condition to investigate; never invent a failure. Keep notes individually identified. No combined recommendation/peer-risk example.

#### 20 min. Item 2 transfer

Reveal the sealed dock transfer packet, integrated below. Say the record is invented for practice. Independently complete [[s03-T53-alternatives]], [[s03-T53-comparison]], [[s03-T53-trials]], [[s03-T53-improvement]], [[s03-T53-encode]], [[s03-T53-decode]] and [[s03-T53-voice]]. Read directions neutrally. No peers, apparatus or reasoning feedback. The shared record appears once. A scribe records only the child's thinking. Collect originals for component feedback after class; return day 54 for private revision. No points today.

#### 5 min. File evidence

Identify day 48 research, day 50 personal proposals/peer response, days 51/52 actual logs and today's comparison notes. Save for day 54 revision and first scoring on day 55. Keep invented analysis apart from missing practical performance. Add a dated evidence location to the question board and pattern chart.

#### 5 min. Exit E53

Reveal [[s03-X53]]. Each child answers independently on the half slip. Collect notes, transfer and exits. After class allow thirty times thirty seconds for exits, the same for personal notes, and ninety seconds each for seven-component transfer feedback: seventy-five minutes total. Use shown, shown with help, not yet seen by component. Return all day 54. Record error C for explicitly ignoring correct reception; error D for assuming changed pauses need no test.

### Other rooms

No printer: copy integrated fields; reveal the reserved case only at its slot. A board can show teaching logs. Keep the independent packet separate from shared discussion.

### At home

**Swap.** Copy fields and cover the reserved case. Adult supplies a peer evidence question.

**Skip.** Public reports and group filing.

- **5 min. Return.** Do [[s03-P53-return]].
- **5 min. Notes.** Complete [[s03-P53-compare]] from retained logs.
  **Say.** "Which recorded failure would your change address?" Expect a specific link, or an honest statement that none occurred.
- **20 min. Transfer.** Child independently does the seven transfer rows, [[s03-T53-alternatives]] through [[s03-T53-voice]]. Read neutrally; save originals for feedback and next-day revision.
- **5 min. Exit ticket.** Reveal [[s03-X53]]; child answers alone.

### Shorter or longer

Shorten peer talk, preserving personal notes, all transfer components and exit. Extend notes by identifying an untested condition, with no new practical claim.

### Words and supports

Review criterion, constraint, accuracy, duration, encode and decode. Read labels without interpreting them. Accept labeled sketches or dictated personal reasoning. Frame: "The record shows ___. The change could ___."

### Tomorrow

Day 54 returns day 53's exit and notes. Errors C and D share five Return minutes; error F gets a separate five-minute failure/change repair. Return component-only dock feedback for ten private revision minutes. Keep originals; no peer model of the reserved response.

### Credit

Ours. Background: Source U3-patterns and Source U3-design.
