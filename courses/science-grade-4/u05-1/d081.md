# Day 81: Change a model when evidence changes

## Teacher page

### Before class

Read teacher-only-exit-key.md; X81 requires both new evidence types, not unprinted coastal evidence. Set unit 5 record sheet, Map fallback U overlays, original day 77 display, movable feature and question strips, parallel repair packets and map row audit and tally sheets. The unfamiliar teaching map pair is W on today's student page. Keep U2 covered: its case resembles today's held exit. Cover exit-81.md. Return day 80 tallies.

### Safety and set-up

Paper only. No disaster disclosure; public talk may be passed.

### The day

#### 10 min. Return and repair

Return day 80 exits and tallies. If many show error B, first five minutes use [[s05-P-ocean-81]]. If error C persists, next five use [[s05-P-selection-81]]. Review days 77 to 80 keys, belts and selected records. Confer on missing exception evidence during independent map work, using the child's old paper after today's exit if necessary. Never introduce today's reserved model as a repair.

#### 5 min. Aligned overlays

The planned map plotter does not exist; use paper throughout. Announce W is invented for practice. **Ask.** [[s05-P-align-81]]. Expect matching north rows. Fold the sheet to compare land and seafloor columns without rotating either. This tests an association; alignment alone proves no cause. Review day 79's distinction between coast and continental edge.

#### 15 min. Unfamiliar maps

Read W's own keys, reviewing day 78 relief. Alone, [[s05-P-tag-81]], using the displayed map row audit and tally sheets as the tag layout. Write on Side 2. W supplies coastal land relief and volcanoes beside a trench, not ocean earthquakes and interior mountains. Children attach support/challenge tags to their actual day 77 strips. Leave unsupported features uncertain. Teacher does not supply an exclusive model to repair. Few error B/C misses use a short conference within these minutes.

#### 10 min. Revision from evidence

Review day 8's second-color revision, keeping original observations. Pairs each take 45 seconds simultaneously to negotiate strip positions. Alone, [[s05-P-revise-81]]; a justified keep or uncertainty note counts. Hear rotating six, 45 seconds each, 4.5 minutes. Preserve original and changed displays. All submit student pages, evidence tags and one reason; return day 82 with notes. Practice revises chosen tags, not a supplied coastline-only model.

#### 5 min. Exit ticket

Reveal exit-81.md now: [[s05-X81]]. Four minutes alone, one collection. Require evidence from both printed maps, distinguishing mountain and earthquake symbols. Do not infer earthquakes just from mountains.

### Other rooms

No printer/projector: copy W's paired columns before class and conceal the separate D/E case. No second color: box changed tags and retain the original.

### At home

**Swap.** Copy W and strips without printer/projector. Box revisions without another color. Adult takes the partner role.

**Skip.** Public sharing and second repair route.

- **5 min. Repair.** Use [[s05-P-ocean-81]] if needed.
- **5 min. Align.** Do [[s05-P-align-81]].
- **10 min. Tags.** Do [[s05-P-tag-81]] using the child's original strip.
  **Say.** "What does this tag support?" Expect W's located volcano evidence, not a cause.
- **10 min. Change.** Do [[s05-P-revise-81]], keeping the original visible.
- **5 min. Exit ticket.** Reveal D/E; child answers [[s05-X81]] alone.

### Shorter or longer

Shorten public sharing, retaining every child's tag, reason and exit. Extend by specifying evidence a blank cannot supply.

### Words and supports

Review evidence, model, ridge, trench and continental edge. Read keys aloud without selecting evidence. A scribe follows the child's instructions.

### Tomorrow

After class: 30 times 20 seconds, ten minutes, for X81 feedback. Use shown, shown with help, not yet seen on unit 5 record sheet. Return day 82 with all evidence tags. Error B locates an ocean event; unresolved error C revisits selection limits, five minutes each. Then locate the printed dated event and sort source coverage.
