# Day 117: Repair a missing link

## Teacher page

### Before class

Read teacher-only keys. Return both assessments with component feedback. Route each child by first missing component: light, sensing, plant or animal. For complete work choose the least secure explanation. Prepare only that child's fresh prompt, concealed. Set familiar record excerpts beside repair cards; omit earlier questions and signal meanings. Keep first scores, revisions and fresh feedback separate. Paper only; no handling organisms or apparatus.

### The day

#### 5 min. Return feedback

Return day 115's assessment for two minutes and day 116's assessment for three. Review the established independent-work routine. Children locate their flagged component. Keep original 0/1/2 scores on assessment-record.md. Explain routing and second-color revision, reviewing grade 3's section 6.4 second-color revision routine. No self-marking or new assessment score.

#### 10 min. Targeted repair

Four groups work simultaneously on [[s06-P117-repair]], two five-minute moves from repair-cards.md. Teacher leads the largest group throughout. Partners use familiar excerpts in other groups. Light: source-on/off for errors A/B, then flash removal for C or blocked segment for I. Sensing: receiving/processing/action for D, then Signal S's remembered meaning for E. Plant: source card U with transport for F, then rootless limit for H or flower event order for G. Animal: intake/digestion for F, then familiar reproduction structures. Review each named unit 6 link; never rehearse fresh-route cases. If records are absent or unclear, preserve unclear entries and use supplied L, S or P, announced invented for practice.

#### 20 min. Revise and verify

Children complete [[s06-P117-revise]] on returned work in a second color. Teacher verifies the other three groups for five minutes each, then unresolved papers for five. Use exact familiar-card contrasts for additional letters. Review day 104's internal/external distinction and day 105's four functions. Accept evidence-linked revisions, not organ lists. Do not claim every child was heard; all return paper revisions. Keep these in folders after Handoff.

#### 5 min. Fresh explanation R117

Give each child only one assigned prompt: [[s06-X117-light]], [[s06-X117-sense]], [[s06-X117-plant]] or [[s06-X117-animal]]. Announce invented for practice. Attach the prompt in the Exit box. Read its exact stem neutrally. Children explain independently with concise sentences or labeled links. Keep familiar repair cards closed. This is fresh formative evidence, without an assessment rescore.

#### 5 min. Handoff

Review and return thirty fresh papers at ten seconds each: check the repaired link and add one private written next-step cue. No individual speaking round. Mark only the formative record, using shown, shown with help, not yet seen. Return repair/revision annotations within the same handoff. File originals, component feedback, revisions and fresh responses separately; attach unresolved needs for course checks 118 to 120.

### Other rooms

No printer: copy exact assigned prompt on covered paper; draw familiar labels for repair. The child receives only one fresh case.

### At home

**Swap.** Use a different pencil mark instead of a second color. Copy only the assigned prompt.

**Skip.** Group routing and teacher hearing rounds.

- **5 min. Feedback.** Find one missing link together.
- **10 min. Repair.** Use [[s06-P117-repair]] with the familiar card.
  **Say.** "Which link is missing?" Expect the link named in feedback.
- **10 min. Revise.** Child does [[s06-P117-revise]], keeping first ideas visible.
- **5 min. Exit ticket.** Reveal only the assigned [[s06-X117-light]], [[s06-X117-sense]], [[s06-X117-plant]] or [[s06-X117-animal]]. Child answers alone. Review it privately and keep it with the revisions.

### Shorter or longer

Shorten repeated reports, retaining targeted repair and fresh explanation. Longer: suggest another observation that could test the repaired link, unscored.

### Words and supports

Review reflect, information, internal, external, evidence and the four functions. Read prompts; enlarge labels. A faithful scribe preserves independent scientific links. Public talk may be passed.

### Tomorrow

Day 118 audits new town hazard advice and repairs a light-path model. Carry unresolved component notes into course checks 118 to 120 without reteaching during independent checks. Today's papers return in Handoff; original assessment marks remain separate.
