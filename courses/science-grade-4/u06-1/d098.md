# Day 98: Which evidence supports this label?

## Teacher page

### Before class

Read today's teacher-only item keys in items.csv and wrongs.csv. Set light condition sheet and Light L, separate model labels, cat picture sequence and unit 6 formative record. Return day 97 papers with notes. Pretest a flashlight on the wooden block, below eye level. Keep aisles lit; no sun, lasers or eye-directed beams. Keep spoon tickets private. No splash/flying hazard from intact dry apparatus; no goggles needed.

### The day

#### 10 min. Return and repair

Return day 97's shine tickets, darkness Exit boxes, component responses and individual notes. If many day 97 papers show error B, use five minutes reviewing separate Light L source-off and blocked-view rows: an open view cannot provide illumination. Review grade 1's light shines on it.

For error C use five minutes, [[s06-P98-repair]]. Review day 97's reflection labels: flash supplies light; cat shine returns light. Match labels without a combined animal explanation. Ready children locate relevant observations. Preserve initial models.

#### 10 min. Evidence audit

Teacher lights a wooden block; children observe the lit patch. Aim at another face of the block and note the changed patch. Do not claim a classroom object disappears when the flashlight turns; ambient light remains. Children do [[s06-P98]], attaching an observation to one separate source, object or eye label.

**Ask.** Which observation supports this single label? Expect a located record: the lit patch identifies illumination, or Light L's blocked-view row supports light reaching the eye. The complete path is a model inferred from evidence, not a visible line in the air. No kit: use supplied Light L, explicitly invented for practice. If the patch is unclear, mark unclear and use L; infer no light-level numbers.

#### 15 min. Visual explanation workshop

Use isolated familiar labels, never an integrated practice drawing. [[s06-P98-talk]]. Children add their observation locator, then pairs take two 45-second turns while pointing to one label. Review grade 3's evidence-and-reason routine: an observation must support what the label claims. Teacher hears a rotating six at 45 seconds each, 4.5 minutes during work. Record names; public talk may be passed. All thirty submit tags and notes, including those not heard. Spend remaining time checking whether each reason actually supports its label.

#### 5 min. Question handoff

Review the question board routine. [[s06-P98-handoff]], using the original invented cat sequence. Light labels address seeing; receiving a rustle and guiding a head turn still need explanation. Keep that question open for day 99. No brain pathway is supplied today. Adult switches off and stores the flashlight while children finish their notes.

#### 5 min. Exit E98

Reveal [[s06-X98]], individually on paper. The spoon case and evidence-linked complete drawing are first seen now. Neutral reading and faithful scribing only. Collect tickets, evidence tags and component responses. Look for illumination, reflection, incoming eye light and evidence linkage. Error A sends light from the eye; error B retains seeing without illumination. Use only shown, shown with help, not yet seen; missing evidence is described.

### Other rooms

No kit: use invented supplied L for tags. No printer: copy separate prompts and observation tags; cover the spoon exit. A projector is optional.

### At home

**Swap.** Use invented Light L without apparatus. Copy labels and prompts without a printer.

**Skip.** Group presentations and speaking rotation.

- **8 min. Return.** Child reads feedback and does [[s06-P98-repair]].
- **10 min. Evidence.** Child uses one label and [[s06-P98]].
  **Say.** "Which observation supports this label?" Expect a located row and a connection to that label's job. Keep labels separate.
- **7 min. Explain.** Child points while answering [[s06-P98-talk]], then does [[s06-P98-handoff]]. Leave the action question open.
- **5 min. Exit ticket.** Reveal [[s06-X98]]. Child draws and explains independently. Collect the first response.

### Shorter or longer

Shorten repeated label rehearsal; retain feedback and the independent exit. Extend by identifying one observation that cannot support a chosen label.

### Words and supports

Review source, reflect and receiver. Offer enlarged labels, tactile pointers and faithful scribing. Accept home-language explanations; retain individual evidence.

### Tomorrow

After class read all papers: 30 times 60 seconds, 30 minutes. Return day 98's tickets, component notes and evidence tags in day 99's Return and repair. Errors A/B receive five minutes each using paper records. Then extend the model to sense organ, brain and action; no light apparatus is promised.
