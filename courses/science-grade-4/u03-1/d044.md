# Day 44: Separate a point from a pattern

## Teacher page

### Before class

Read teacher-key.md and today's generated item key privately. Print today's fields and correct teaching feature strips; cover Side 2. Inspect nonlatex rope. Mark a clear floor zone; adult wears goggles and holds both ends without releasing. No wrapping or stepping across rope. Prepare written notes on day 43 papers and day 42's initial exit. Lay out retained still tub drawings and the unnumbered comparison strip.

### The day

#### 10 min. Return and repair

Return day 43 s03-X43 and s03-P43-table, plus day 42 s03-X42. Return s03-P43-source, s03-P43-receiver and s03-P43-signal with written notes, no added slot. Review local movement from day 42, five minutes for error A: demonstrate a held point moving nearby as a disturbance passes. Keep returned exit diagrams covered during teaching. Five minutes error B: use correct isolated height and spacing strips, measuring neither numerically. If many, more than ten, show either error, lead that move; ready children label correct features.

#### 15 min. Rope observations

Adult alone makes small repeating sideways floor-rope motions beside a marker. Explain that this floor view turns the water sketch sideways; it is an analogy. Observe first, then point to separate correct features. Review rest position, peak, trough, amplitude and wavelength from day 42. A peak is farthest on one side of rest; a trough is farthest opposite. Model a qualitative distance from rest and then matching-peak spacing. Use an unnumbered strip, no geometry terms or numbers.

Children do [[s03-P44-labels]], with separate label fields. Watch for error B's height-spacing coupling; point to the distances separately. Retry blurred motion once within this slot; then announce paper wave strips as invented for practice. Preserve unclear actual notes separately.

#### 10 min. Water connection

Review grade 3 revision: add a second color while keeping original observations. Children annotate their single day 42 still sketch using today's correct feature labels. Keep a rest line; compare it with the observation sheet and fallback W only when needed. Do not construct paired faulty models.

**Ask.** [[s03-P44-travel]]. Expect the pattern travels while marked material moves locally. Everyone writes; hear rotating six, 45 seconds each within five minutes. Any child may pass. Add evidence tags to the question board and pattern chart, leaving unsupported answers open.

#### 5 min. Cleanup

Adult stops and stores rope safely and washes hands, two minutes. Observers gather dry strips and file drawings, three. Nobody crosses a moving rope.

#### 5 min. Exit E44

Uncover Side 2 for the first time. Announce invented for practice. Each child independently completes [[s03-X44]] on the half slip. Collect all thirty. After class: 30 × 25 seconds, 12.5 minutes exit marking; 30 × 15 seconds, 7.5 minutes practice notes. Use only shown, shown with help, not yet seen for each component.

### Other rooms

No rope: use correct teaching strips, explicitly supplied evidence. No printer: copy isolated features first; reveal reserved records only at exit. A board replaces a projector.

### At home

**Swap.** Without rope use correct teaching strips, labeled invented for practice. Box revisions without a second color. Copy fields and frames without printing. Point at paper without a projector.

**Skip.** Public sharing.

- **10 min. Repair.** Read day 43 feedback; separate height, spacing and nearby movement using correct features.
- **10 min. Label.** Do [[s03-P44-labels]]. Adult alone demonstrates rope if safe; otherwise use paper.
- **10 min. Connect.** Annotate the original still tub sketch. Do [[s03-P44-travel]], then put equipment away.
  **Say.** "Which motion travels?" Expect: the pattern and energy; marked material moves nearby.
- **5 min. Exit ticket.** Reveal reserved records. Give [[s03-X44]] alone.

### Shorter or longer

Shorten public sharing; keep both repairs and exit. Extend by identifying a limit of a still drawing.

### Words and supports

Review wave labels and energy arrows from day 42. Review second-color revision from grade 3. Enlarge single features; read neutrally. A scribe records the child's decisions.

### Tomorrow

Day 45 compares coil and rope movement. Return s03-X44, s03-P44-labels and s03-P44-travel. Error A sends material onward; error B makes wider spacing taller. Its Return and repair reserves five minutes for each, using isolated correct features.
