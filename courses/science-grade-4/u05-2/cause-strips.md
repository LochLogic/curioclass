# Separate causal strips

Invented for practice. Cut along the table rows.
Use one hazard at a time. Keep later assessment cases hidden.

| Hazard | Design/action | Possible effect |
|---|---|---|
| Shaking | Braced model | Fewer model falls |
| Eruption information | Message received, then protective action | Less exposure |
| Tsunami warning | Usable route outside the hazard zone | Less exposure |
| Water entering a path | Diversion beside the path | Less path wetting |
