# Day 91: Agree on claims that the evidence supports

## Teacher page

### Before class

Read teacher-only-exit-key.md and generated practice answers. Prepare unit 5 record sheet, parallel repair packets, day 90 hearing notes and tickets. Lay out movable feature and question strips, cause and action strips, warning interval and coverage strips. Use unfamiliar teaching map pair W from day 81, not U2. Set U overlays, original display and retained teaching test records beside blank consensus tags. Hide reserved items; cover Exit box.

### The day

#### 10 min. Return and repair

Return day 90's written task, hearing notes and exit tickets. If many show error D on day 90's exit, use five minutes to annotate an observed failure. Use the other five for unresolved error F or error I from day 89, one move per child, [[s05-P91-repair]]. Ready children tag question-board uncertainties. Portfolio stays with teacher for day 92; return only a descriptive revision note today.

#### 15 min. Map consensus

Review days 77 to 81 keys, ridge, trench and belt. Review grade 3's observation/inference and exception words. Teach consensus as an evidence-supported account the class can revise. Review the pattern-chart routine from unit 3, using this unit's map display.

**Ask.** [[s05-K91-tag]] before [[steps:s05-K91-tag]]. Read separate U keys. Pairs do [[s05-P91-tags]] using U and W, invented for practice; no new multi-region table. Tag supported observations, changed labels and open explanations. Hear six volunteers, 45 seconds each, 4.5 minutes; anyone may pass. Keep original strips beside revised tags. If errors A/H persist, trace relief with its own key. Errors B/C use locators and record limits; map association alone proves no cause or safety.

#### 15 min. Protection consensus

Separately review actual test records and T's warning chain from day 89. Review hazard, design, harm arrows. Preserve failed or unreadable readings; supplied records remain labeled invented. Partners each take 45 seconds to check an evidence locator. Alone, [[s05-P91-protect]] on a protection-only strip. Add usable delivery/action links where needed. Collect all separate consensus notes. Compare original and final displays, keeping map patterns apart from protection causes. No combined map/design explanation or higher-flow claim verdict in practice.

#### 5 min. Exit ticket

Reveal the new record now. Four minutes independently: [[s05-X91-map]] on the half slip and [[s05-X91-design]] in the paper Exit box. One minute collects both. No answers shown before collection.

### Other rooms

No printer/projector: copy U/W teaching evidence and blanks before class. Keep reserved stems covered. Box revised tags if only one pencil color is available.

### At home

**Swap.** Copy U/W diagrams and tags without a printer. Adult takes the partner role.

**Skip.** Public consensus hearing.

- **5 min. Repair.** Complete the selected move in [[s05-P91-repair]].
- **12 min. Map tags.** Do [[s05-K91-tag]] then [[s05-P91-tags]].
  **Say.** "Where is the evidence for your tag?" Expect a located feature or its own key.
- **13 min. Protection.** Child does [[s05-P91-protect]] on a separate strip.
- **5 min. Exit ticket.** Reveal the new record. Child answers [[s05-X91-map]] and [[s05-X91-design]] alone.

### Shorter or longer

Shorten public sharing; keep both consensus records and exit. Extend by tagging an unanswered board question.

### Words and supports

Review ridge, trench, belt, exception, observation and inference. Review consensus from day 13: an account supported by shared evidence. Enlarge maps; neutral reading/scribing preserves independent reasoning.

### Tomorrow

After class, read both E91 papers diagnostically: 30 times 30 seconds, 15 minutes. Use shown, shown with help, not yet seen on unit 5 record sheet. Practice feedback: 30 times 15 seconds, 7.5 minutes. Return all notes and both exit papers day 93 Read feedback. Errors A/B/C join map routes; errors D/E join conditions. Day 92 is independent assessment: no E91 repair, no additional trial or portfolio rewrite.
