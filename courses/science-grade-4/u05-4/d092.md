# Day 92: Use maps and records on new cases

## Teacher page

### Before class

Read teacher-only-key.md and component look-fors. Prepare reserved assessment packet as today's student page, unit 5 record sheet and unit 5 assessment record. Hold day 90's revised portfolio and feedback sheet from day 88. Remove teaching displays and keys from view. Check symbol clarity, aligned maps and accessible print. Prepare table collection envelopes. Do not distribute the separate assessment master as well.

### The day

#### 3 min. Launch

Distribute the unseen packet. Say all cases and numbers are invented for practice. Children work independently. Read directions neutrally, without evidence selection, examples or hints. No repair of day 91's exit. Explain that previously submitted portfolio work needs no new response today.

#### 20 min. Item 1

Alone, [[s05-E1-table]] then [[s05-E1-account]] using paired land and seafloor maps. Both layers repeat event symbols; count each event once. Give neutral reading, enlarged/tactile maps or dictation of the child's own words. Do not interpret a symbol for the child. Preserve independent evidence of map reading, patterns and inference limits.

#### 18 min. Item 2

Alone, [[s05-E2]]. Children use the new options, costs, two-condition records and warning/access information. No practical rotation or spoken checking queue. Offer extra blank writing space with the same packet if needed; it contains no added questions. Do not steer recommendations toward the teacher sample.

#### 4 min. Collection

Collect 30 papers in table envelopes, about six seconds each plus one minute checking. Match them privately to retained day 90 revisions for [[s05-E3-portfolio]]. No additional portfolio sitting task. Record absence, inaccessible evidence or unattempted components as unavailable, never infer a science error from language alone.

### Other rooms

No printer/projector: prepare identical individual copies of maps, keys and tables before class. Read from a neutral copy. The paper path stays independent.

### At home

**Swap.** Copy both maps and tables without a printer. Give a blank extra page if needed.

**Skip.** Class collection and public discussion.

- **40 min. Assessment.** Child answers [[s05-E1-table]], [[s05-E1-account]] and [[s05-E2]] independently. Keep [[s05-E3-portfolio]] with the earlier revised work; write nothing new for it. Read words neutrally without selecting evidence.
- **5 min. Collect.** Keep original answers and portfolio together. Adult reads the private answers afterward. Save component feedback for day 93; do not correct the child's work now.

### Shorter or longer

Retain both independent tasks. Use access accommodations or another sitting for unfinished work, recorded as such; never coach. Extra time adds no new questions.

### Words and supports

Only neutral reading, enlarged symbols and faithful scribing. No teaching frames or science reminders today.

### Tomorrow

After class, mark with teacher-only-key.md: about four minutes per child, 120 minutes, untested. Use one scale on unit 5 assessment record: 2 complete, 1 relevant incomplete, 0 absent/incorrect; unavailable evidence blank with a note. E1 has six components /12; E2 six /12; portfolio two /4, scored once. Keep /24 new-case and /4 portfolio separate. Actual and invented record reasoning can count; invented records cannot establish firsthand observation.

Return day 92's assessment, portfolio and day 91's diagnostic notes on day 93 Read feedback. Route errors A/B/G/H to relief/belts, error C to limits, errors D/E to conditions, errors F/I to warnings. Day 93 revises once with dated notes beside first marks.

### Credit

Ours. Source U5-own supplies all invented assessment cases and records.
