# Day 90: Use feedback to strengthen a protection argument

## Teacher page

### Before class

Read teacher-only-exit-key.md and generated practice answers. Prepare unit 5 record sheet, parallel repair packets, warning interval and coverage strips, cause and action strips, flood logs and Flood fallback W. Return day 88 portfolio and feedback sheet with descriptive notes. Set day 89 delivery/action records and both exit papers beside them. Prepare only today's section 5.4 reserved half-slip exits. Keep teacher answers private.

### The day

#### 10 min. Return and repair

Return day 89's written task, delivery/action record and both exit papers. If many show error F on day 89's exit, rebuild T's delivered-message/action chain, five minutes. If error I appears, join delay before travel, five minutes. [[s05-P90-repair]] records the selected move. Review day 89 coverage and intervals; monitoring misses get a brief work-time conference. Ready children read portfolio feedback.

#### 15 min. Portfolio revision

Return day 88's comparison and improvement feedback. Alone, [[s05-P90-revise]] on the portfolio and feedback sheet. Review grade 3's routine: revise in a second color, keeping original observations. Box revisions if another color is unavailable. Compare the same design under both conditions; distinguish measured results from W, invented for practice. Confer on one evidence link per child while others revise. Never change an observation to make a design succeed. Collect originals and revisions; no new trial or score today.

#### 15 min. Evidence hearing

Review T's stream/footpath diagram and day 88 logs. Review grade 3's tradeoff: holding more and opening easily can pull against each other. Here, protection can use space or materials. Review hazard, design, harm arrows and the design-cycle chart from day 84.

Pairs prepare [[s05-P90-hearing]] on separate cause and action strips, one solution at a time. Partner turns: 45 seconds each, simultaneously. **Ask.** Who remains exposed with this choice? Expect the protection's uncovered hazard or access limit, supported by a card or record. Hear six volunteers, 45 seconds each, 4.5 minutes; anyone may pass. Collect all hearing notes. If error D persists, point to the observed failure without rehearsing today's reserved combination argument. No package table or combined written response in practice.

#### 5 min. Exit ticket

Reveal the new settlement record for the first time. Four minutes alone for [[s05-X90]], one minute collecting. Read neutrally; do not suggest a combination.

### Other rooms

No printer/projector: copy teaching diagrams and reserved stem separately. Box revisions without another color. No personal routes or accounts.

### At home

**Swap.** Copy T, strips and exit without a printer. Box changes without another color. Adult is the discussion partner.

**Skip.** Public hearing.

- **5 min. Repair.** Child completes the needed part of [[s05-P90-repair]].
- **15 min. Revise.** Return day 88 feedback. Child does [[s05-P90-revise]] beside the original.
- **10 min. Evidence.** Child does [[s05-P90-hearing]] using one protection at a time.
  **Say.** "Who remains exposed?" Expect a hazard or access gap supported by the record.
- **5 min. Exit ticket.** Reveal the new record. Child answers [[s05-X90]] alone.

### Shorter or longer

Shorten sharing, preserving portfolio revision and exit. Extend by naming a condition needing another test.

### Words and supports

Review tradeoff, coverage and condition. Neutral reading or scribing keeps the child's reasoning. Offer home-language rehearsal.

### Tomorrow

After class, mark X90: 30 times 30 seconds, 15 minutes, on unit 5 record sheet using shown, shown with help, not yet seen. Practice notes: 30 times 15 seconds, 7.5 minutes. Return all written work day 91, except the collected portfolio retained for day 92's first score. Error D uses one five-minute failure annotation; unresolved error F or error I uses the other five-minute move. Day 91 builds separate consensus displays.
