# Section 2.2 private keys

TEACHER ONLY. Keep this piece separate from all child pages. Read privately in Before class. All cases/counts described as invented are supplied practice records, never promised measurements. These keys were solved cold for data entry; the independent answer-key read follows.

## s02-X20

Shape: finish a one-terminal diagram with transfer caption.

Prompt: Invented for practice. This lamp is dark. Complete the drawing with an energy-path caption.

Key and look-fors: Connect the free lamp terminal to the other cell terminal, making a complete loop through the lamp. Current carries stored battery energy to light.

Use the formative categories on record.md, one cell per component; never point scores.

## s02-X21

Shape: circuit and comparison design controlling competing sound.

Prompt: Invented for practice. A report says one lead powered a buzzer because sound was heard. A nearby buzzer also sounded. Draw the circuit and comparison needed to test this report.

Key and look-fors: Draw a complete loop through both cell terminals and the target buzzer. Silence the nearby buzzer; compare target sound with its path complete and interrupted. Require the control; hearing nearby sound proves no target path.

Use the formative categories on record.md, one cell per component; never point scores.

## s02-X22

Shape: explain unexpected light by relocating a bypassed switch.

Prompt: Invented for practice. A lamp loop has an uncut wire. A switch joins two points on that wire. The lamp stays lit when the switch opens. Explain this result with a corrected switch drawing.

Key and look-fors: The intact wire still completes the path when the parallel switch opens. Put the switch in a gap in that wire, so opening interrupts the loop.

Use the formative categories on record.md, one cell per component; never point scores.

## s02-X23

Shape: integrated four-mode model revision and input comparison.

Prompt: Invented for practice. Pedaling turns a generator. Current reaches a lamp and speaker. The beam warms cloth. The warmer casing touches a cooler clip. Sound moves a separate receiver. Revise an energy-path model for these four transfers, comparing its input with our crank.

Key and look-fors: Current to lamp/speaker; light to cloth; heat warmer casing to cooler clip; sound to receiver. Pedaling and cranking supply motion converted to electrical energy. No energy is created.

Use the formative categories on record.md, one cell per component; never point scores.

## Practice tasks, private answers

### s02-P20-1

Complete conducting path through the lamp and both cell terminals. Initial actual personal manipulation; record failed/no-turn opportunity honestly. This is performance, not a missing-wire drawing.

### s02-P21-1

Sound when complete, silence when interrupted if equipment works. Record actual failures. Current transfers stored cell energy to sound; no neighboring-source comparison task.

### s02-P22-1

Closed switch completes loop; open switch interrupts output. Use actual test evidence. No bypass diagram or switch relocation.

### s02-P23-1

Drum: sound; sunlit cloth: light; palm-to-spoon: heat; complete lamp circuit: current. Explain generator conversion orally with the familiar crank, not the pedal account.
