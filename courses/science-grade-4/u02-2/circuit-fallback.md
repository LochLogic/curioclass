# Circuit teaching fallback

TEACHER ONLY. Invented for practice, record C. Complete path through one load and both terminals: lamp lit. Interrupt that path at one connection: lamp dark.

Disconnect failed equipment first. Adult checks compatibility and connections once; retry inside work time. If unresolved, label this supplied record separately and mark personal wiring not yet seen. One shared set reaches ten children per day on days 20 to 22. Keep names/initials on the turn record. Tool cards never substitute for actual wiring.
