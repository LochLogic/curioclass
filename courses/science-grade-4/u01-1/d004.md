# Day 4: What pattern do our trials show?

## Teacher page

### Before class

Use the Teacher-only key below; exclude it from child copies. Prepare day 3's exit tickets and trial tables with feedback. Lay out retained trial records, question board, ruler, demonstration pencil and class record book. Draw a blank class line plot with whole-centimeter intervals. Copy the covered disk display panels below. Keep these and the data key teacher-only until the exit. Separate measured records from day 1's R.

### Safety and set-up

Paper and a stationary ruler only; no rolling station or protection needed. Keep the demonstration pencil on the table.

### The day

Other practice stays in folders; discuss it without collecting.

#### 10 min. Return and repair

Return day 3's exit and s01-Pr3. If many show error H, spend five minutes on [[s01-P4]], counting ruler intervals from start to finish. The next five address error B: label ruler readings as distance in centimeters. Everyone responds; others act on individual feedback. Trial tables stay in folders.

#### 5 min. Trial replay

Read retained trial records one roll at a time; children locate each matching entry. Preserve any flagged or unreadable trial. This paper replay supplies the planned explanation work without a device. If evidence fails, read R as invented for practice, separately from actual records. Do not pretend a model supplies observations.

#### 10 min. Build the display

Review day 3's line plot. Complete [[s01-Pr4]]: each child selects a table row and places its mark on a small plot. Build the shared plot, using separate slower and faster rows along one distance axis. Match each mark to its trial; stack repeats. Retain outliers. Teacher checks rows and marks as children work. No completed two-display inference card is practiced.

#### 15 min. Revise the class explanation

First compare controlled repeated effects, without supplying the answer.

**Ask.** [[s01-K4]]

After children find the pattern, name motion energy: energy an object has because it is moving.

[[steps:s01-K4]]

For overlap, say these results need further checking; use separately labeled R to discuss a clear pattern. Do not change real records. Review cause and effect and grade 3 claim, evidence and reason. Children annotate one observed cup change, rather than write a complete explanation. Hear the next six for 45 seconds each within five minutes; record names. Collect all annotations for day 5. Revisit which board questions the evidence answers.

#### 5 min. Exit ticket

Reveal the disk panels now. Say invented for practice. Read [[s01-X4]] exactly; independent paper. Mark afterward: 30 times 25 seconds, twelve and a half minutes with the teacher-only key. Use shown, shown with help, not yet seen. Error A claims equal energy; error B treats distance as energy units. Return day 5; blank work gets a conference.

Also review the 30 collected practice pages after class: 15 seconds each, seven and a half minutes. Add one specific next step; discuss other practice without collecting it.

### Other rooms

No devices are needed. No printer: copy the blank plot and covered exit panel onto paper. Missing class records: use R with its invented label.

### At home

**Swap.** No class records: use day 1's R, invented for practice. No printer: copy plots and covered panel.

**Skip.** Public sharing and class plot assembly.

- **8 min. Return.** Read feedback; do [[s01-P4]].
- **8 min. Plot.** Read records one by one; do [[s01-Pr4]].
- **9 min. Explain.** Discuss [[s01-K4]].
  **Say.** "What repeats after faster rolls?" Expect: greater cup motion in the controlled record; it supports more motion energy.
- **5 min. Exit ticket.** Reveal both disk displays; [[s01-X4]], alone.

### Shorter or longer

Shorter: reduce public reports, preserving individual plotting and the energy discussion. Longer: identify a changed condition that could weaken the claim.

### Words and supports

Review distance and line plot. Motion energy: energy of a moving object. Read displays aloud neutrally; enlarge marks or use a scribe. Any child may pass in talk.

### Tomorrow

Day 5 returns day 4's exit and annotations. If many show error A, contrast repeated effects for five minutes; error B gets five minutes labeling distance. Then connect evidence and energy passing at contact through an oral frame.
