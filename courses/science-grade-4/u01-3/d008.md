# Day 8: What did both objects do?

## Teacher page

### Before class

Read the linked opener and both teacher-only key pieces. Prepare day 7 feedback. Use question-cards.md for repair, car-arrows.md for correct labels and collision-log.md for observations. Retain the question board. Keep the shared can-and-cork exit covered. Pretest cars, blocks and containment; set room-wide protection and six cleaning places. Keep car-record-c.md separate from measured observations.

### Safety and set-up

Use day 7's gentle contained floor rolls. Everyone present wears impact eye protection through setup and cleanup, or use C. No throwing or tasting. Count objects; stop rolls for adult retrieval, broken containment or missing protection.

### The day

Collect every page for day 9 feedback, then keep it in the folder. Use one record scale: shown, shown with help, not yet seen.

#### 15 min. Return and repair

Return day 7's exit and both student page sides, including s01-Pr7, s01-K7, s01-Ke7, s01-Pq7 and s01-Po7. If many show error F, spend five minutes naming a visible outcome with [[s01-Pr8]]. Error C gets five minutes following changed motion to its energy destination. Error J gets five minutes locating the block's contact push. More than ten misses triggers shared repair; others use feedback. Blank work gets a conference. Keep today's exit covered.

#### 15 min. Compare collisions

Three-minute protected setup; six two-minute trials, alternating slower and faster. Keep car, block, surface, block start and contact alignment fixed. Two handlers and four observers form today's rotating six. Every child uses the collision-log.md table reproduced on side 1 for [[s01-P8]]. Before each roll, partners state an oral expectation. Record actual approach speed and both motions. Keep failed rows; retry once within a trial slot. If unresolved, use separate C events, saying invented for practice. Push lines alone cannot establish speed. Keep real and invented records separate.

#### 5 min. Update from evidence

**Ask.** [[s01-Pu8]]

Review grade 3: revise the record in a second color, keeping the original observations and initials. Partners each take one 45-second turn: compare an expectation with a marked observation. Hear the next six at 45 seconds each while others work in pairs. Allow public passing. Annotate class destinations during these reports, retaining any continuing car motion. Collect every page for day 9.

#### 5 min. Cleanup

Stop rolls; count and pack cars and blocks. Clear lane. Wipe and bag protection. Keep records, including unclear rows. Six captains each clean five student pairs; the adult cleans their own. Use two minutes to pack and three to clean, following wipe directions.

#### 5 min. Exit ticket

Reveal panel now. Say invented for practice; read [[s01-X8]] exactly. Children revise alone on paper. Mark after class: 30 times 30 seconds, fifteen minutes; all page responses take 30 times 20 seconds, ten minutes. Add one written next step; return the full page with its ticket day 9.

### Other rooms

No kit or protection: read C one event at a time, predicting before each reveal. No printer: copy blank log and keep exit panel covered. A scribe records the child's choices.

### At home

**Swap.** No kit or protection: use C, invented for practice. No second color: add a star. No printer: copy six log rows; hide panel.

**Skip.** Roster and live trials.

- **5 min. Return.** Use feedback and [[s01-Pr8]].
- **12 min. Compare.** Reveal C events separately; do [[s01-P8]]. Predict before each reveal.
- **8 min. Update.** Do [[s01-Pu8]], keeping first marks.
  **Say.** "What changed in each object's motion?" Expect: in C, car slows and block starts moving.
- **5 min. Exit ticket.** Reveal panel; [[s01-X8]], alone.

### Shorter or longer

Shorter: omit public reports, retaining six records, evidence note and exit. Longer: explain why changing the block weakens the comparison.

### Words and supports

Review: prediction, observation, contact, transfer, destination, motion energy. Read logs aloud; describe both motions. Offer a scribe and high-contrast added marks.

### Tomorrow

Day 9 returns day 8's exit and records. Error C needs a receiving destination, five minutes. Error I needs observed and expected separated, five minutes. Then record chronological listening events alongside motion. Carry the heard roster forward.
