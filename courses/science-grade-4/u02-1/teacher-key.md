# Section 2.1 private keys

## s02-R1

Shape: matched-patch prediction with sunlight reason.

Prompt: Invented for practice. Identical cloth squares start equally cool. One stays in sunlight; one stays shaded. Predict which warms more, using a sunlight reason.

Key and look-fors: The sunlit square should warm more because sunlight warms its surface. No grade 4 vocabulary required.

## s02-X16

Shape: initial model plus unsupported-claim test question.

Prompt: Invented for practice. A sealed handle torch lights while its handle turns. Report B claims light continues afterward, without observations. Draw an initial energy-path idea using recorded effects. Include a question that tests Report B.

Key and look-fors: Show observed handle motion and light; uncertain inner steps allowed. Ask whether light continues after turning stops. Do not treat continued light as observed. Conversion vocabulary is not required.

## s02-X17

Shape: rank rival records with a controlled-path reason.

Prompt: Invented for practice. A speaker sounds beside paper fringes. Record A: fringes move on the shared board. Record B: separate supports; fringes move during sound, remaining still during silence. Explain which record better supports sound transfer across the gap.

Key and look-fors: B: separate supports reduce a contact path through the board. Sound/silence comparison links receiver movement to sound. A alone leaves the support path unresolved.

Use the formative categories on record.md, one cell per component; never point scores.

## s02-X18

Shape: three-path drawing with warming-evidence caption.

Prompt: Invented for practice. Both patches start at 21 degrees Celsius. Pale patch in sunlight: 26 degrees; dark patch in shade: 22 degrees. A screen lets some light through; its patch has no temperature reading. Draw lit, blocked and partly transmitted paths with a warming-evidence caption.

Key and look-fors: Light reaches the sunlit patch; opaque shade blocks the direct path; some light passes the screen. The sunlit patch warms five degrees versus one in shade from equal starts, supporting sunlight transfer. Screened temperature is unknown.

Use the formative categories on record.md, one cell per component; never point scores.

## s02-X19

Shape: reverse a supplied clip-to-lid model using comparison evidence.

Prompt: Invented for practice. A warmed clip touches a cooler metal lid. The clip cools while the lid warms. An untouched matching lid stays unchanged. A model points from lid to clip: metal supplies warmth. Revise this arrow using the comparison.

Key and look-fors: Point from warmer clip to cooler lid. Clip cooling and recipient warming, unlike the untouched lid, support this direction. Metal does not supply warmth independently.

Use the formative categories on record.md, one cell per component; never point scores.
