# Day 6: Which observations support an explanation?

## Teacher page

### Before class

Use the Teacher-only key below; exclude it from child copies. Prepare day 5's exit and evidence notes with a next step. Lay out retained trial records, question board and class record book. Copy the complete statements and evidence strips on side 2. Keep hoop panels covered and data key teacher-only. Use day 1's R separately if marble records fail.

### Safety and set-up

Paper only; the tire is an invented record, not live equipment. No cutting or collision station.

### The day

#### 5 min. Return and repair

Return day 5's exit and [[s01-Pn5]] notes. If many show error A, use [[s01-P6]] and the marble record: unchanged object does not mean equal motion energy at different speeds. Others act on feedback. Blank work gets a conference. Review the same record scale: shown, shown with help, not yet seen.

#### 10 min. Read the tire case

Read the invented case and the two complete oral explanations on side 1, without selecting one.

**Ask.** [[s01-K6]]

[[steps:s01-K6]]

Pairs point to what each explanation does. Review day 5's transfer: energy passes between objects and changes motion at contact. Do not offer an incomplete draft or model written strengthening.

#### 15 min. Match evidence

Use [[s01-Pm6]] with the side 2 strips. Each child first matches independently, then each partner explains a choice in 45 seconds. Teacher checks relationships during work using the teacher-only key; do not print matches on child pages. Same tire supports a fair comparison, not equal energy. If many confuse these, contrast the purpose of a fixed condition with an observed repeated effect. No full written explanation is drafted or revised.

#### 10 min. Say the link

Two 45-second turns per partner, four turns total three minutes: state a supported claim, then explain why the matched observation supports it. Teacher hears six, 45 seconds each, within five minutes; record names, including any missed earlier turn. Others continue orally and add the brief evidence note requested in [[s01-Pm6]]. Passing publicly is allowed; offer private talk. Collect every child's matching page for day 7. Add the unanswered destination question to the question board, a review routine.

#### 5 min. Exit ticket

First reveal the hoop panel now. Say invented for practice. Read [[s01-X6]] exactly; each child strengthens the unseen explanation independently on paper. Mark after class: 30 times 25 seconds, twelve and a half minutes, with the teacher-only key. Error A claims unchanged energy; error B treats tube travel as energy. Return day 7, with ten repair minutes already routed.

### Other rooms

No device or live kit is needed. No printer: copy complete statements and strips, keeping the hoop panel separate and covered. Unreadable marble records: use R as invented for practice.

### At home

**Swap.** No class records: use day 1's R, invented for practice. No printer: copy statements and strips.

**Skip.** Public sharing and roster turns.

- **5 min. Return.** Read feedback; do [[s01-P6]].
- **8 min. Compare.** Read [[s01-K6]] and the two complete explanations.
  **Say.** "Which explains how motion changes?" Expect: A, using energy passing at contact, rather than repeating the claim.
- **12 min. Match.** Do [[s01-Pm6]]; take turns explaining matches.
- **5 min. Exit ticket.** Reveal the hoop panel; [[s01-X6]], alone.

### Shorter or longer

Shorter: fewer public reports; retain individual matches, oral reasons and exit. Longer: explain why the fixed-condition strip cannot establish an energy quantity.

### Words and supports

Review: transfer, motion energy, evidence, fair test. Read all strips aloud. Use large labels or a scribe; children supply their own ideas. No written explanation frame before the exit.

### Tomorrow

Day 7 returns day 6's exit and matching page in Return and repair: error A five minutes, error B five. More than ten misses triggers the shared repair; others use individual feedback. Then retrieve contact pushes, ask a testable collision question and predict motion changes. Carry the destination question forward.
