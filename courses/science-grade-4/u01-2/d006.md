# Day 6: Which observations support an explanation?

## Teacher page

### Before class

Read the opener and today's teacher-only key below; use the shared key for the exit. Prepare day 5 feedback. Use tire-statements.md for the statement sort and evidence matching. Retain the question board and anchor records; use ramp-record-r.md separately if needed. Keep the shared hoop exit covered. Use the shared tire record once, beside today's sort and matching statements. Use the same class record sheet.

### Safety and set-up

Paper only; the tire is an invented record, not live equipment. No cutting or collision station.

### The day

Collect each student page for feedback next lesson. Review one scale: shown, shown with help, not yet seen. More than ten misses is many.

#### 5 min. Return and repair

Return day 5's exit and evidence page: s01-P5, s01-K5, s01-Pm5, s01-Pn5 and s01-Pr5. If many show error A, use [[s01-P6]] and the marble record: unchanged object does not mean equal motion energy at different speeds. Others act on feedback. Blank work gets a conference. Review the same record scale: shown, shown with help, not yet seen.

#### 10 min. Read the tire case

Read the tire record from tire-statements.md aloud as invented for practice. Children sort the three supplied statements on side 1.

**Ask.** [[s01-K6]]

[[steps:s01-K6]]

Pairs point to the two observed changes and the energy account. Review day 5's transfer: energy passes between objects and changes motion at contact. 

#### 15 min. Match evidence

Use the shared tire record with today's side 2 statements for [[s01-Pm6]]. Each child first matches independently, then each partner explains a choice in 45 seconds. Teacher checks relationships during work using the teacher-only key; do not print matches on child pages. Same tire supports a fair comparison, not equal energy. If many confuse these, contrast the purpose of a fixed condition with an observed repeated effect. Each child keeps the matched evidence attached to its claim.

#### 10 min. Say the link

Two 45-second turns per partner, four turns total three minutes: state a supported claim, then explain why the matched observation supports it. Teacher hears six, 45 seconds each, within five minutes; record names, including any missed earlier turn. Others continue orally, pointing to the evidence chosen in [[s01-Pm6]]. Passing publicly is allowed; offer private talk. Collect both sides of every child's page for day 7. Add the unanswered destination question to the question board, a review routine.

#### 5 min. Exit ticket

First reveal the hoop panel now. Say invented for practice. Read [[s01-X6]] exactly; each child strengthens the unseen explanation independently on paper. Mark after class: 30 times 25 seconds, twelve and a half minutes, with the teacher-only key. Error A claims unchanged energy; error B treats tube travel as energy. Return day 7, with ten repair minutes already routed.

Also review the 30 collected practice pages after class: 15 seconds each, seven and a half minutes. Add one specific next step; return the whole page in Return and repair next lesson.

### Other rooms

No device or live kit is needed. No printer: copy complete statements and strips, keeping the hoop panel separate and covered. Unreadable marble records: use R as invented for practice.

### At home

**Swap.** No class records: use ramp-record-r.md, invented for practice. No printer: copy statements and strips.

**Skip.** Public sharing and roster turns.

- **5 min. Return.** Read feedback; do [[s01-P6]].
- **8 min. Compare.** Read the tire record and sort [[s01-K6]].
  **Say.** "Which statement explains the change?" Expect: energy passed into card motion; the other two describe observations.
- **12 min. Match.** Do [[s01-Pm6]]; take turns explaining matches.
- **5 min. Exit ticket.** Reveal the hoop panel; [[s01-X6]], alone.

### Shorter or longer

Shorter: fewer public reports; retain individual matches, oral reasons and exit. Longer: explain why the fixed-condition strip cannot establish an energy quantity.

### Words and supports

Review: transfer, motion energy, evidence, fair test. Read the shared tire record aloud once; point back to it during matching. Use large labels or a scribe; children supply their own ideas. No written explanation frame before the exit.

### Tomorrow

Day 7 returns day 6's exit and matching page in Return and repair: error A five minutes, error B five. More than ten misses triggers the shared repair; others use individual feedback. Then retrieve contact pushes, ask a testable collision question and predict motion changes. Carry the destination question forward.
