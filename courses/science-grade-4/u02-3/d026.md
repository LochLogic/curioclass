# Day 26: Testing every opening

## Teacher page

### Before class

Read private keys and today's Teacher-only key. Retrieve day 25 papers and six labeled devices. Check insulation, cell ratings and smooth contacts without changing designs. Retain Personal signal plan. Prepare All-opening test log within today's student page, no printed Name line. Mark the original back-wall point and quiet lane. Conceal Day 26 exit ticket. Set out storage trays and wiping supplies.

### Safety and set-up

Low-voltage cells only, never outlets. Disconnect before adjustments; buzzer stays in the loop. Adult immediately disconnects warm wires. Smooth foil edges; sound away from ears. Two handlers per active kit, others beyond the boundary. Nothing tasted.

### The day

#### 5 min. Return and repair

Return day 25's ticket, s02-P25-1, s02-P25-repair and s02-P25-observe, with individual s02-X25-build feedback. Review return and repair. Alone, do [[s02-P26-repair]]. If many tickets show error B, trace through both terminals before any test. Many means more than ten of thirty. Preserve original drawings.

#### 5 min. Test preparation

Review grade 3 fair test: keep the same, change one thing, watch one thing. Reuse day 24 criterion and fixed point. Review day 25 distinction between a brief check and reliability. Each team numbers its operators. Adult verifies safe parts. Introduce the blank All-opening test log for [[s02-P26-1]]; model filling column headings, never a competing-log verdict.

#### 20 min. Test lane

Six three-minute slots plus two transition minutes. Five children each operate one opening for 30 seconds; 30 seconds reset per team. A second handler watches contacts. Teacher remains at the marked listening point and signals detection visibly. All other buzzers stay disconnected; active team members each record all five openings. Other teams silently prepare logs. Preserve sound, silence and unclear results, plus contact/lead observations. Disconnect between teams. No design changes during a trial set. If a reading fails, write unclear and describe it; never invent a detection or silently rerun until success.

#### 5 min. Interpret

Children finish [[s02-P26-1]] alone. Compare their complete log with five detected openings in five. **Ask.** Which recorded row supports your result? Expect the child's actual row and a criterion-linked conclusion. Each partner takes one 45-second turn, unjudged. If many omit failures, return to their own blank row and mark missing, not an imagined outcome. Current-path evidence links the design to sound.

#### 5 min. Exit ticket

Reveal [[s02-X26]] now, exactly printed. Four minutes alone, one collect. After class: thirty tickets times 75 seconds, about 38 minutes; thirty logs times 45 seconds, about 23 minutes. Use shown, shown with help, not yet seen per look-for on the formative record. Blank work gets a conference. Return papers day 27.

#### 5 min. Cleanup

Disconnect, count/store parts and wipe hands/tables. Teacher checks every stored device is disconnected.

### Other rooms

No printer: copy blank log and exact exit at its turn. No projector needed. With one shared kit, keep the same six slots but identify it as shared-device evidence, not each team's design. No kit or unresolved hardware fault: say and use the supplied record on side 2, invented for practice. Interpret it with the same criterion; mark personal operation not yet seen. An adult checks faulty hardware once within work time before using paper.

### At home

**Swap.** No printer: copy the log. No kit: read the invented record on side 2; personal operation remains not observed.

**Skip.** Group slots and public turns.

- **5 min. Repair.** Return day 25 papers; do [[s02-P26-repair]].
- **20 min. Test.** Do [[s02-P26-1]]. Adult listens from the fixed point. Child operates five openings, recording every result and contact condition. Disconnect before adjustments. Count/store parts and wipe within this block.
- **5 min. Interpret.** Compare the full log with the original criterion.
  **Say.** "Which row supports that?" Expect a real row, including silence or unclear when observed.
- **5 min. Exit ticket.** Reveal [[s02-X26]]. Child answers alone. Save papers for day 27.

### Shorter or longer

Shorter: reduce discussion, keeping every trial and exit. Longer: annotate an existing uncertain reading without replacing it.

### Words and supports

Review fair test, current, criterion and terminal. Use visible adult detection signals for access; distinguish them from sound observations. Permit dictation and public passing.

### Tomorrow

Day 27 returns all papers and uses failures to plan refinement. Error C, no success criterion, needs comparing actual outcomes with the defined result before changes.
