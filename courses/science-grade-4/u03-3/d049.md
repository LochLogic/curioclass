# Day 49: Propose two complete rules

## Teacher page

### Before class

Prepare written notes on day 48 exit, return/design responses and three-cell/voice work. Keep source/research originals for day 51 feedback. Print today's integrated proposal tables and private answer key. Cover Side 2 until proposal time; hold the reserved exit separately. Prepare correct three-symbol teaching meanings: cross means paper, stripes means cloth, zigzag means box. No equipment trial today.

### The day

#### 5 min. Return and repair

Return day 48 s03-X48, s03-P48-return, s03-P48-design, s03-P48-encode, s03-P48-decode and s03-P48-voice with private notes. Return any completed s03-P48-fallback with its written note in the same slot; no extra repair minutes. Review its encode/decode distinction. If many, more than ten, showed error E, present the correct teaching meanings from Before class. Children point between each symbol and meaning before rereading their notes. Never replay the failed-speech exit. Others trace day 48's familiar complete chain. Keep source/research feedback for day 51.

#### 10 min. Criteria and limits

For the first five minutes, address day 48 error D if needed: review the actual quiet/conversation notes without predicting other positions. Invented R stays labeled invented for practice. A quiet detection cannot establish conversation performance. Otherwise inspect missing or unclear entries.

Review grade 3 need, criterion and limit in its words: who needs what, so that; a way to check the need is met; the most we allow. Review constraint as unit 2's word for limit. Agree five correctly received messages within thirty seconds, using paper and the shared gentle sound or steady-light kit along a marked route. Post agreed criteria on the question board and pattern chart. Teach accuracy: number correct; duration: elapsed sending time. Time systems during later trials, never children. **Ask.** [[s03-P49-criteria]]. Children write independently. Error C ignores correctness; error F substitutes appearance.

#### 5 min. Code teaching

Review grade 1 message, signal, sender and receiver. State the complete teaching rule before any use. **Ask.** [[s03-P49-tap-rule]]. Demonstrate gently on the desk: one beat between taps, four silent beats between messages. Teach message boundary: an agreed gap separating messages. Partners each read their written complete rule once, thirty seconds each. These message words label information; children do not perform the actions. No hidden number-pattern rule is required.

#### 20 min. Generate and compare

Reveal Side 2. Each child spends twelve minutes on [[s03-P49-proposals]]: two complete three-message tables, one card system and one gentle-sound system. Review proposals as possible designs, not proven performance. Include distinct patterns, agreed boundaries and feasible materials. Partners each have one optional 45-second comparison turn, then record one suggestion and whether to use it, with a reason. Finish personal labels. Hear a rotating six at 45 seconds each within five minutes, while everyone writes. If many omit meanings, error E, point to the table's three rows; for error F, point to reception criterion. Collect every personal table. No two-message drawings or faulty-system repair during practice.

#### 5 min. Exit E49

Reveal [[s03-X49]] for the first time. Children draw independently on half slips. After class allow thirty times thirty seconds, fifteen minutes exit marking, and thirty times forty-five seconds, 22.5 minutes proposal feedback. Use only shown, shown with help, not yet seen by component. Retain untested labels.

### Other rooms

No printer: copy today's tables and reveal exit later. No equipment: still propose feasible paper and sound systems; mark them untested. A board replaces projection.

### At home

**Swap.** Copy tables without printing. Use desk taps for the teaching demonstration. No kit: plan paper/sound systems without claiming performance.

**Skip.** Public rotation and team selection.

- **5 min. Return.** Read day 48 feedback. Review the familiar complete decoding rule.
- **5 min. Criteria.** Do [[s03-P49-criteria]]. Review which conditions were actually observed.
  **Say.** "What checks the need?" Expect correct reception within the stated duration.
- **5 min. Rule.** Do [[s03-P49-tap-rule]]. Demonstrate short gaps and longer silence.
- **15 min. Propose.** Child completes [[s03-P49-proposals]] alone, then explains both rules. Adult suggests a change; child records a response.
  **Say.** "How can the receiver distinguish messages?" Expect different patterns and agreed boundaries.
- **5 min. Exit ticket.** Give [[s03-X49]] alone.

### Shorter or longer

Shorten public comparisons, retaining both personal tables and the exit. Extend by predicting one specific possible confusion to test later, without claiming it occurred.

### Words and supports

Review need, criterion, limit and code key. New: accuracy, duration, message boundary. Read neutrally; a scribe records the child's own proposals. Frame: "Our rule means ___. The receiver needs ___."

### Tomorrow

Day 50 returns s03-X49 and all three practice rows. Repair the commonest error E, missing agreement, or error F, appearance replacing reception, in five minutes. Give other gaps written prompts during fresh proposals. Children then exchange suggestions and assemble two systems; actual comparisons begin day 51.
