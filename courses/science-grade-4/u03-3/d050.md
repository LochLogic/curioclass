# Day 50: Use suggestions and assemble systems

## Teacher page

### Before class

Print today's integrated fields and private generated answer key. Prepare written notes on day 49 s03-X49 and all three practice rows. Keep the Exit box covered and half slips separate. Inspect the covered drum; mark clear walking positions. Lay out duplicate card stock for six teams. No liquids, projectiles or light handling today; no added eye protection needed. Reserve future test records.

### The day

#### 5 min. Return and repair

Return day 49 s03-X49, s03-P49-criteria, s03-P49-tap-rule and s03-P49-proposals. Review its accuracy, duration and message boundary. If many, more than ten, show error E or error F, repair the commonest: review the correct three-message tap rule for agreement, or contrast reception criterion with decoration. Others receive written prompts during fresh proposals. Never repair a boundaryless system before today's independent Exit box.

#### 10 min. Fresh proposals and peer response

Review grade 3 need, criterion and limit. Review day 48 account notes without revising their source feedback yet. Individually make two fresh three-message tables, five minutes, using [[s03-P50-proposals]]. Pair children across teams: each takes one optional 45-second turn explaining a proposal and requesting a reception suggestion. Each writes the suggestion, response and reason; silent written exchange is available. Retain both personal alternatives before team selection. Watch for error F, prettier means better, and error E, missing agreement; use criterion or rule prompts without supplying proposals.

#### 5 min. Picture strip

Review day 48 encode, decode, digit, code key and reading order. Use only vertical three-cell strips today. Children complete [[s03-P50-encode]] and [[s03-P50-decode]] before the worked steps. [[steps:s03-P50-encode]] [[steps:s03-P50-decode]]

Add the familiar encode/send/receive/decode chain to the pattern chart. These arrows trace information handling, separately from nearby material-motion and energy-travel arrows. Shared symbol meanings and order let the receiver recover the pattern; reception still needs testing.

#### 15 min. Assemble

Allow three setup minutes to select one card system and one gentle-sound system per team. Six teams visit the shared kit for two minutes each; waiting teams make duplicate cards and complete personal keys. Everyone answers [[s03-P50-assemble]]. Keep all BEND/ROLL/PRESS meanings, boundaries and materials visible in each complete rule. Read through rules quietly; no measured performance claim today. Record both selected rule types on the question board. Actual comparisons wait until day 51. Adult controls the drum; use gentle taps, keep ears back, stop for discomfort, and walk along the clear route. If unavailable, construct cards and draw the sound apparatus, labeling it unbuilt and untested.

#### 5 min. Cleanup

Count/store kit and cards for two minutes; file identified personal proposals and keys for three. Keep originals with peer notes. Every child's work receives feedback, including children not heard publicly.

#### 5 min. Exit E50

Reveal [[s03-X50a]] on its half slip and [[s03-X50b]] in the student-page Exit box. Everyone works independently; no key or peer model. Collect both. After class allow thirty times forty-five seconds, 22.5 minutes exit marking, plus thirty times sixty seconds, thirty minutes proposal/assembly feedback. Record only shown, shown with help, not yet seen by component. Give written prompts for day 51 revision.

### Other rooms

No printer: copy fields; conceal both exit tasks until needed. No kit: label paper plans untested. A board replaces projection. Do not invent actual performance results.

### At home

**Swap.** Copy fields without printing. No drum: use gentle taps on a closed box. No kit: construct paper plans and label sound apparatus unbuilt.

**Skip.** Team rotation and public sharing.

- **5 min. Return.** Review day 49 feedback and correct teaching rule.
- **10 min. Propose.** Child does [[s03-P50-proposals]]; adult supplies one reception suggestion.
  **Say.** "What might the receiver confuse?" Expect a named pattern or boundary concern.
- **5 min. Strip.** Do [[s03-P50-encode]] and [[s03-P50-decode]] with top-first rules.
- **10 min. Assemble.** Do [[s03-P50-assemble]]. Put materials away; keep personal keys.
  **Say.** "How are repeats separated?" Expect an agreed boundary, different from within-message gaps.
- **5 min. Exit ticket.** Reveal [[s03-X50a]] and [[s03-X50b]]; child answers alone.

### Shorter or longer

Shorten public exchange, keeping each personal suggestion, both systems and both exit tasks. Extend by predicting one confusion for tomorrow's trial, marking it a prediction.

### Words and supports

Review accuracy, duration, encode, decode and message boundary. A scribe records personal decisions. Frame: "I used the suggestion because ________________________________________." Allow tactile card patterns and neutral reading.

### Tomorrow

Day 51 returns both day 50 exit responses. If error E drops order or boundaries, repair for five minutes in Return. Source notes from day 48 take two minutes; day 50 proposals/strips/assembly take three revision minutes with written feedback. Test both selected systems in quiet and record every sent/received message and duration. Keep personal proposals for first scoring on day 55.
