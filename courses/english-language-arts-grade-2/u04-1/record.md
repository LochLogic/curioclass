# Unit 4 record sheet: how can people help pollinators thrive?

Write each child's name down the left. The rotating children for each day are the ones you hear for that day's exit and oral card; a child outside the group is "not yet heard", never "missed". Each exit column is one look-for in the exit: write 2 when the child does it alone, 1 when it was shown with help, and 0 when it is not yet seen. Leave a cell blank if you did not observe it. A child may pass; leave the cell blank and try another day.

The check columns (days 129, 130 and 137) and the end-of-unit columns use the same marks. Write the date in the cell for any later attempt. On the reading checks keep two marks for reading: one for alone and one for with help. The oral reading cycles 20 to 26 each have a column for the oral card and one for the written check sheet. Marks never name a child as an example of a mistake, and the sheet stays in your folder.
