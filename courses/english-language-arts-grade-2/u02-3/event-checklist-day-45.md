# Five-box event checklist (day 45)

A card with five boxes in a row, each with a place for a pencil mark: **Time word and action**, **A thought**, **A feeling**, **A closing that fits**, **A capital and an end mark**. Partners check each other's writing against the boxes and say "Your ending fits because ___". Partners hold the card; it returns in sections 2.6 and 2.7.
