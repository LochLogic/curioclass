# Reading Card 4

*invented for practice*

Amy and Ben clean the tools at the tap. They rinse each spade with water. They stop before the bucket is empty. Ben carries the tools to the shed. Amy checks that every spade is dry. They leave a note on the shed door: "Dry each tool before it goes in." The next pair reads the note before starting. Now each pair knows how to put the tools away.

*Picture: A shed with its door open, three spades hung inside, and a bucket beside the tap outside.*
