# The Return Shelf

*invented for practice*

A return shelf holds books that pupils have finished reading. After reading, pupils put each book on this shelf with its cover facing out. This lets another reader see its title. A label hangs over the shelf. Each book has a title card tucked inside. If a card is missing, the pupil takes a blank card and writes the book's title. The cards help the class match each book to its name.

Three book covers face the reader, the label hangs above the shelf and blank cards lie beside it. The arrow shows movement and order and adds no new factual answer.*
