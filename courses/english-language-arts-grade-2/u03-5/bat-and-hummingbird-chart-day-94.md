# Bat and hummingbird column chart (day 94)

A chart with two columns, **Bat** and **Hummingbird**, and three rows for the kinds of fact the day uses: when it feeds, how it reaches the nectar, which flowers it likes. Slips are placed in the rows; how pollen moves stays for later. The class then asks which row differs most.
