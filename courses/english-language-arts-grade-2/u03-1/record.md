# Unit 3 record sheet: how plants and pollinators help each other

Write each child's name down the left. The rotating six for each day are the children you hear for that day's exit and oral card; a child outside the six is "not yet heard", never "missed". Each exit column is one look-for in the exit: write 2 when the child does it alone, 1 when it was shown with help, and 0 when it is not yet seen. Leave a cell blank if you did not observe it. A child may pass; leave the cell blank and try another day.

The end-of-unit columns use the same marks. Write the date in the cell for any later attempt. On check days keep two marks for reading: one for alone and one for with help. Marks never name a child as an example of a mistake, and the sheet stays in your folder.
