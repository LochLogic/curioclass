# Grammar card (days 69 and 70)

The child's card for the day 69 grammar items, with a ruled line under each prompt. The six prompts are printed in order.

1. Write one sentence about the people at the display, using a word that names a group.
2. Write a sentence about a track that uses the plural of foot.
3. Write a sentence about Jo acting alone, using herself, that is not about drawing.
4. Write the past of take in a sentence about Jo.
5. Write one sentence that describes the label.
6. Write one sentence that tells how Jo wrote the label.

Keep the card out of teaching. Day 70 returns it with one marked item for the child to fix.
