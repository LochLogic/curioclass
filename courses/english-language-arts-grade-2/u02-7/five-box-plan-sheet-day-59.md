# Five-box plan sheet (days 59 to 63)

A sheet with five boxes in a row, each with room for a few words and a small picture: **First (a time word)**, **What I did (an action)**, **What I wondered (a thought)**, **How I felt (a feeling)**, **How it ended (a closing)**. An arrow runs from the last box back to the first, with the words "Does the end answer the start?" Each child fills it from their find card and says each box to a partner; the partner checks the arrow.
