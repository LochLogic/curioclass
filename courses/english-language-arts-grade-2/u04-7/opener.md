# Unit 4.7: Steps, facts and a plan for a pot (days 143 to 146)

## What the section does
The class reads 05-d (Planning a Flower Pot) and learns why each step in a short list must come before the next. Children then find facts that help an opinion, draft a packet, revise it after feedback and edit it. The foundations block moves from cycle 24 to cycle 25.

## How the days run
- Day 143: read 05-d, order step strips and say why; cycle 24 written check.
- Day 144: find facts that help; draft a packet; start cycle 25.
- Day 145: pair feedback, group critique, revision.
- Day 146: shared writing, edit the packet.

## The ideas at an adult's level
A set of steps is a chain of causes: each step changes something that the next step needs. A fact helps an opinion when it explains why the opinion is a good idea. A critique names one thing that works, one question and one idea.

## The errors in plain words
- Steps stated in order with no reason why (because it is next).
- A fact that does not help the opinion.
- A reason with no link word, or no ending.
