# Teacher key for day 27 language samples

Keep with the teacher before class. For E, voice this line as a fictional sailor speaking to a friend:
“I seen the gull.” Students see the matching crew log. In each private turn ask, “How would you report your
sighting to the crew?” Save the actual spoken line and a separate writing sample.

| Part | Look for | Written cue if that component needs another attempt |
|---|---|---|
| A | They, subjective. Them, objective. Theirs, possessive. | Locate the person acting, the person called or the ownership. |
| B | “I myself carried the mat.” Myself emphasizes Lee as the carrier. | Remove the emphasis and see whether the subject stays. |
| C | “Then we waited” keeps the team speaking. “I filled them” points back to the tires. | Locate the speaker or match the number of the noun. |
| D | “Wrap the jug in felt before putting it inside the bucket.” Accept an equally clear equivalent. | Name what needs padding. |
| E | A new completed sighting uses “saw,” checked against the log. Accept a fitting different sighting in each mode. | Find the completed-action form in the model and choose it for the crew. |

Give each pupil one dated cue per component still owed. Mark the evidence source and any pending first turn.
Use the private retry on day 29. Leave a component pending when an independent retry is still due.
