# Teacher key for day 29 language retries

Keep with the teacher before class. Use the written cue, then issue only the held card the student needs.
If an independent response is still missing after the block, date it and carry the original cue forward.

| Part | Key and look-for |
|---|---|
| A | We, subjective. Us, objective. Ours, possessive. |
| B | “The twins themselves mixed the dye.” Themselves emphasizes the twins. |
| C | “We wanted” keeps both walkers as the speakers. “Their paddles” matches the plural owners. |
| D | “The strap tore when the badge caught on it.” Accept any unambiguous equivalent. |
| E | Report a different completed task with “did.” The minutes give a reference for a completed action. |

For E, voice the fictional speaker’s friendly line, “They done the count.” Let the student read the
minutes on the card. For a private spoken turn, ask “How would you report another completed task aloud
at the meeting?” Give the reference question on a separate written slip. Take both modes when both
are owed. Record the actual mode and response. An example is “The stewards did the tally before
lunch.” Reserve this example for the teacher.
