# Controlling narrative time

## Pace, sentence choices and feedback

Review sentence combining from grade 4. Check that the same events and actors survive a change. Compare different released versions for pace. Review that a transition links events in time. A compressed routine gives a key moment more room. Separate brief beats can make a pause felt. Ask pupils to select between released examples before they work privately in their own drafts.

## Before class

Set out the dated diagnostic draft, the editor practice text, the device log and the sealed exit leaves. Keep the three word probe cards and key separate. Dictate the words before showing print. Check the prior word logs and retain spelling, each actual oral reading and strategy evidence separately. On day 75, use a new practice passage for the managed exchange before releasing the exit and keep the discussion record distinct from source-note and device evidence.

## Classroom device and paper routes

Demonstrate entry, editing, saving and reopening on day 73. On day 75, have each pupil use the teacher-managed class exchange under a pupil code. With paper, rehearse the steps and schedule the missing online action. Record each completed action privately and link the original, cue and correction. Release the day 76 language passage in Language. Return written feedback before the next day. Use another registered passage for instruction if the alternative is unavailable, and keep any unmatched check pending.
