# Comparing information and preparing discussion

## Reading and talk

A historical count describes a place and a time. An uncertain result can justify another question. Review the discussion moves: mark a detail, listen, ask for detail, link the reply and explain what became clearer. Show how a title lets someone find a source again.

## Before class

Prepare dated report leaves, source notes, heading tabs, role cards and closed packet A. Offer the quiet plot privately before storm material. Keep the word-page entries closed until each child records the first context and word-part answers. Then switch between matching print and accessible digital entries. Record which format each child actually used.

Use six groups of five for day 51. Hear one group closely and send pending private samples to days 52 and 53. Give feedback to every child. If a note copies the source, cover the original, restate the idea and then check it. If the group simply agrees, ask what a detail adds to a peer's idea.
