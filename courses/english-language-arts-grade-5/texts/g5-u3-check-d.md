# The Pond Reopening and Two Garden Proposals

## D1. The Pupil’s Note

I wrote this on Monday as the school pond reopened. Every class could visit at last. Children watched the frogs from the new platform.

## D2. The Caretaker’s Note

I wrote this on Friday after checking the platform. The pond reopened on Monday. The platform holds only six children, so some classes waited at the back.

## D3. Seeds and Flowers

Store the garden seeds in dry jars because moisture can spoil them. The seeds in a damp envelope grew mold. Keep some flowers through autumn because insects still need food. Bees visited the last blooms after the vegetable harvest.

## D4. Teacher Read-Aloud: The Garden Path

Add a handrail beside the steep garden steps because walkers need a steady grip. Yesterday a volunteer stumbled where there was nothing to hold. Move the tool rack away from the narrow path because carried tools block passage. Two gardeners had to turn sideways to pass a spade handle.

## Teacher notes

Keep this set sealed until day 118. Give D1 to D3 in print. Keep D4 on the teacher copy and read it twice. Use the prompts and scoring anchors in section 3.8.
