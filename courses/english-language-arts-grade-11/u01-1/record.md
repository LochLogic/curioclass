# Unit 1 record sheet: Brown, the Mather account and the word check

Write each student's name down the left. The R columns are the readiness looks of days 1 to 5: note the support a student used, no score. Each E column is one exit, with one cell for each look-for: tick it when the student meets it on paper. The end columns are the unit check on days 14 and 15, scored 2 (met), 1 (partly met) or 0 (not met). Leave a cell blank when it was not observed, and date any later attempt. Add a tick in the margin for each support a student used (S and Q key, family card, entry card, roles card).
