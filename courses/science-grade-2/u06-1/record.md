# Unit 6 record sheet: our class list

Write each child's name down the left. Each X column is one exit, with one tick: shown (S), shown with help (H) or not yet seen (N), and the error letter if a gap shows. Days 60 to 62 are never scored. Days 63 and 64 are observed and keep one record for each child: drawing, working model and trial record, stored together. The ten components are scored on the retained day 64 version, on day 65 before class: 2 when shown on their own, 1 when shown with help, 0 when not yet seen. Keep a watched column and a heard column so that every child is watched once and a rotating six are heard each day. Never write 0 for a part not yet taught. Bat work is unscored practice. A child may pass and show an answer privately; leave the cell blank.
