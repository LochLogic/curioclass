# Unit 2 record sheet: our class list

Write each child's name down the left. Each E column is one exit, with one tick for each look-for listed under the table: shown (S), shown with help (H) or not yet seen (N), and the error letter if a gap shows. Days 23 to 25 are the end of the unit: one cell for each look-for, scored 2 when shown on their own, 1 when shown with help, 0 when not yet seen. Never write 0 for a part not yet taught. Put the date in any cell tried again on day 26. A child may pass and show an answer privately; leave the cell blank.
