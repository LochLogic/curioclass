# Day 25 packet: two screens

A reserved packet printed only on day 25. Read the directions once. Children read only labels and the key. Print "invented for practice" on each record. No people in any picture.

## The problem

Two screens protect the same soil strip in equal wind trials. The problem needs a loss of at most 5 centimeters in each run.

## Bars

- Screen P: first run 1, second run 7.
- Screen Q: first run 4, second run 4.

## Tasks

1. Say what screen P does well.
2. Say what screen P does poorly.
3. Say what screen Q does well.
4. Say what screen Q does poorly.
5. Mark each of the four runs as at or under the limit, or over it.
6. Choose one screen for this problem. On your barrier model, draw the retreat records of screen P and screen Q against the limit line, and say why you chose it.
