# Record sheet with a heard column, days 57 to 59

Write each child's name down the left. One column for each item, with one tick: shown (S), shown with help (H) or not yet seen (N), and the error letter if a gap shows. Keep a watched column and a heard column so that Today's six are heard each day. Record retries apart and never rescore an earlier day. Never write a mark for a part not yet taught. A child may pass; leave the cell blank.
