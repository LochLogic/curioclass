# Unit 7 record sheet: our class list

Write each child's name down the left. Each X column is one exit, with one tick: shown (S), shown with help (H) or not yet seen (N), and the error letter if a gap shows. Days 66 to 71 are practice and are never scored. Day 72 is the unit's one unaided record, each child's own paper. The ten components are scored once on the retained revised version after day 73, with the original attached: 2 when shown on their own, 1 when shown with help, 0 when not yet seen. Keep a watched column and a heard column so that a rotating six are heard each day and the sheet names who. Never write 0 for a part not yet taught. A child may pass and show an answer privately; leave the cell blank.
