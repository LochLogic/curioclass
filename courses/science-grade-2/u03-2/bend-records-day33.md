# Invented bend records (day 33, fallback)

Drawing style: plain black line drawing on white, thick lines, no shading, no brand names, no printed words except where a card says so. Children in any picture are of different ages, skin tones and hair, shown as simple figures. Say aloud that every picture is invented for practice, and print "invented for practice" beneath each one. Used if the strips fail. Read it as if the class had measured it.

| Strip | Drop at the middle (cm) |
| --- | --- |
| card | 2 |
| plastic | 6 |
| fabric | 9 |

**Key (teacher):** Card dropped the least, so it stays most level. Fabric dropped the most, so it bends the most. A greater drop is more bend, not more stiff.
