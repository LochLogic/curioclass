# Unit 3 record sheet: a chapter-book series

Write each child's name down the left. The rotating six for each day are the children you hear for that day's exit or conference; a child outside the six is "not yet heard", never "missed". Each exit column is one look-for in the exit: write 2 when the child does it alone, 1 when it was shown with help, and 0 when it is not yet seen. Leave a cell blank if you did not observe it. A child may pass; mark "passed", never a zero.

The end-of-unit columns use the same marks: the check packets on days 85, 92 and 99, the review and discussion audit on day 106, the scene audit on day 113, the transfer items on 114 and 115, the oral readings on 117 and 118 and the report on 119. Write the date in the cell for any later attempt. A revised answer is marked in its own column beside the first, never over it. The discussion days (89, 98 and 106) hold five boxes for each child.

Marks never name a child as an example of a mistake, and the sheet stays in your folder.
