# Word check response sheet (day 105)

Print one for each child, one side. The class writes silently while each child is called to the teacher's table for twenty seconds. The sheet is kept for the day 106 word record; written feedback is given the same evening.

Part 1: write the six words the teacher reads.

1. ____________  2. ____________  3. ____________  4. ____________  5. ____________  6. ____________

Part 2: the teacher reads three base words and says the longer word each one makes. Write each longer word and say what changed in the base.

____________________________________________

____________________________________________

____________________________________________

Part 3: read this silently. Invented for practice.

Mira carried the unfinished map to the garden. The helpful group was waiting happily. She rested by the tree.

What does un- do to the word finished? ____________________
What does -ful add to the word help? ____________________

Teacher key, not printed: un- means not, so unfinished means not finished; -ful means full of, so helpful means full of help. At the table the teacher records each child reading four irregular words and one longer word; that record is the day 106 word record.
