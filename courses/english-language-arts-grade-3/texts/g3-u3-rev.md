Teacher note. The model is about an invented series, not the unit books, so children cannot copy facts. It has an opinion, two reasons from changes in the books, link words (First, Second, As a result, Also, For these reasons) and a closing line, in the order of O01. Weak review: the reason repeats the opinion (I) and the last line is unrelated (K). Title capitals follow the rule taught on 102.

# A Book Review Model and a Weak Review

Model review (complete)

The Lantern Lane Friends
Book 1: The Lantern Lane Friends: The Lost Key
Book 2: The Lantern Lane Friends: The Big Swap

I recommend The Lantern Lane Friends to readers who like friends solving problems together. First, the main character changes from one book to the next. In The Lost Key, Mina keeps every worry to herself, but in The Big Swap she asks her friends for help. This shows that a character can grow. Second, the problems get bigger. The lost key only closes one small shed, while the swap changes the whole street. As a result, I wanted to read both books in one weekend. Also, the setting stays the same, so I could notice what was different. For these reasons, you should start with The Lost Key and then read The Big Swap.

Weak review (to be revised)

I like The Lantern Lane Friends. It is a good series because it is good. I think it is good because I really like it. My cousin has a dog named Biscuit.
