# Exit cards, days 146 to 149

Say aloud each time: "This card is made up for practice." Print "invented for practice" in small letters at the foot of every card. Plain black line drawings on white, thick lines, no shading. Every exit is one ask; read each card twice before the children answer. On 146 the teacher reads the listen line aloud once; it is not printed on the child's page. Answers and wrong answers are in items.csv and wrongs.csv, not here.

- **Day 146 (s04-X146), Exit.** Invented for practice. Listen: "The bus yard saves water. The crew turns off the hose between washes." Ask: Write the main idea and one detail in two sentences.
- **Day 146 (s04-X146b), Exit, second card.** Invented for practice. Script line: "Fill a bottle. [Pause before reuse.] Reuse it." Ask: Write what your voice does at the bracket.
- **Day 146 (s04-X146c), practice, spoken then written in the Exit box.** Invented for practice. Listener: "What does scrub mean?" Ask: Answer in one complete sentence.
- **Day 147 (s04-X147), Exit.** Invented for practice. Listener: "I know the tank is full. I do not know when staff rinse it." Source: "Staff rinse the tank after each storm." Ask: Write the first key point for this listener.
- **Day 148 (s04-X148), Exit.** Invented for practice. Source: "Workers check the gate handle each week. A stiff handle can stop the gate from closing." Ask: Write a short script piece. Give a beginning and the handle fact. Join the fact to why it matters with a link word. End with a closing.
- **Day 149 (s04-X149), Exit.** Invented for practice. Cue plan: "Read aloud [slow down], then hurry the last fact." Peer: "I lost that fact." Ask: Write the plan line again so the listener keeps the last fact.

Every exit sheet prints the card and the ask only, with a ruled space for the answer. The look-fors live in items.csv and the record sheet, never on the child's page.
