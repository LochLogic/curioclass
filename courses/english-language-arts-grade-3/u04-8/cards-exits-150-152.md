# Exit cards, days 150 to 152

Say aloud each time: "This card is made up for practice." Print "invented for practice" in small letters at the foot of every card. Plain black line drawings on white, thick lines, no shading. Every exit is one ask; read each card twice before the children answer. Answers and wrong answers are in items.csv and wrongs.csv, not here.

- **Day 150 (s04-X150), Exit.** Invented for practice. Address line: "Pine Ridge ME 04000." Ask: Write it again with the comma in the right place.
- **Day 150 (s04-X150b), practice, written in the Exit box.** Invented for practice. Words: "bucket" and "conservation". Ask: Write a sentence that says which word names an idea you cannot touch.
- **Day 150 (s04-X150c), practice, written in the Exit box.** Invented for practice. Line: "One calf drank. Two calf drank." Ask: Write the line again with the plural right.
- **Day 151 (s04-X151), Exit.** Invented for practice. Letter: "A filter has a paper layer. A filter has a cloth layer." Source: "A foam layer in a small home filter catches bits." Ask: Write one sentence for the foam layer. Join it to the other filter facts with a link word.
- **Day 151 (s04-X151b), practice, written in the Exit box.** Invented for practice. Envelope: "Water Group, 8 Elm Road, Maple Grove NH 03000." Ask: Write the last line again with its comma.
- **Day 152 (s04-X152), Exit, unscored.** Invented for practice. Reader: "I need the step's purpose before the invitation." Source: "Staff inspect a cover to find damage." Ask: Write one letter sentence that gives the purpose.
- **Day 152 (s04-X152b), practice, written in the Exit box.** Invented for practice. Words: "cover" and "care". Ask: Write a sentence that says which word is an abstract noun.
- **Day 152 (s04-X152c), Exit, second card, unscored.** Invented for practice. Address line: "Alder Glen WA 98000." Ask: Write it again with the comma in the right place.

Every exit sheet prints the card and the ask only, with a ruled space for the answer. The look-fors live in items.csv and the record sheet, never on the child's page.
