# Note card

Print two to a page, one for each note, for every child. Plain boxes, ruled.

- Box 1: **Body**
- Box 2: **Habitat**
- Box 3: **Survival**
- A line at the foot: **Source:** ______________________ page or heading ________

One brief note goes under the one box it belongs to. The source line is always filled in.
