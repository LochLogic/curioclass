# Voice and retelling chart (day 27)

A wall chart and a sheet for each pair. The text is cut into six parts. Children mark each part W if the words are Washington's own, or R if they are the retelling.

| Part | Marked W or R | A clue from the words |
|---|---|---|
| 1. The two paragraphs before "Booker wanted more than anything" | | |
| 2. The paragraph that begins "Booker wanted more than anything", up to the first quoted line | | |
| 3. The first quoted line | | |
| 4. The sentence about the word devour, and what follows to the second quoted line | | |
| 5. The second quoted line, and the school paragraph before the third | | |
| 6. The third quoted line, and the last paragraph | | |

## Phrase table (for the nonliteral phrase)

| The words say | It means here |
|---|---|
| | |

Say aloud: "A line is Washington's own account if it says I and sits in quotation marks. It is the retelling if it tells about him."

Say once on day 27: "Account" means his own telling of events here. It is not a bank, and it is not a story told by someone else.
