# Exit cards, days 14 to 19

Say aloud each time: "This card is made up for practice." Print "invented for practice" in small letters at the foot of every card. Plain black line drawings on white, thick lines, no shading. Every exit is one ask; read each card twice before the children write. Answers and wrong answers are in items.csv.

- **Day 16 (s01-X16).** This strip is invented for practice. Read: "The class recycling box: Paper goes into the blue box. The box was moved by the window last week. A helper takes the full box to the big bin." Ask: Write a short paragraph about how the class recycles paper. Use only the facts that belong.
- **Day 17 (s01-X17).** This text is invented for practice. Read (aloud once, and printed): "Few roads reach the farms at Reed Lake. The book boat ties up at the dock each Saturday, so families can borrow books." Ask: Write one question for the expert about what keeps readers from books here.
- **Day 19 (s01-X19).** This sidebar is invented for practice. Read: "A caption is a short explanation below a picture. A useful caption names the place. Copying means making a copy." Ask: Explain what useful means in the sidebar, using its -ful ending.
