# Unit 4 record sheet: water and what we can do about it

Write each child's name down the left. The rotating six for each day are the children you hear for that day's exit or conference; a child outside the six is "not yet heard", never "missed". Each exit column is one look-for in the exit: write 2 when the child does it alone, 1 when it was shown with help, and 0 when it is not yet seen. Leave a cell blank if you did not observe it. A child may pass; mark "passed", never a zero.

The end-of-unit columns use the same marks: the check passages on days 124, 131 and 135, the essay and research folder audits on 144 and 145, the letter and skills folder audit on 152, the audio and typed-work audit on 153, the comparison and portfolio card on 154, and the discussion and listening audit on 156. Write the date in the cell for any later attempt. A revised answer is marked in its own column beside the first, never over it. The discussion days (130 and 141) hold five boxes for each child.

Marks never name a child as an example of a mistake, and the sheet stays in your folder.
