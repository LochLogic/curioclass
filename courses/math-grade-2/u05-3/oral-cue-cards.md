# Private counting cues

**1.** Start at 698. Count four numbers, including 698.

**2.** From 288, say the next three counts by 5.

**3.** From 467, say the next three counts by 10.

**4.** From 276, say the next three counts by 100.

Allow one minute for all four cues, including the roster marks. Use the private assessment key separately. Accept a pass and leave the unfinished part open.
