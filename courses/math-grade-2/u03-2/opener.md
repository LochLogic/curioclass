# Comparing lengths and customary units

Review the labeled tape diagram and unknown equation from unit 2. Use aligned starts and model which quantity is missing before choosing a calculation. On the rods a known excess can help find a covered length. Retain unit labels and connect a comparison drawing to either addition or subtraction. Give the short exit in its separate picture.

Introduce an inch with a verified length. Compare it with a centimeter using a common start. Have children estimate a straight object before uncovering a ruler, then try following a rim with flexible tape. Paper squares and a verified narrow paper tape work in place of tiles and a device. Use a verified foot strip or a yardstick with foot marks for the longer benchmark, and set long borders flat on supported tables. On the same span, more short units and fewer long units reach the same endpoints. Keep the construction of a yardstick for the later section. Describe both tool readings from one object. Keep conversions for later.

Read a torn scale by counting spaces between two available readings. A start label is a position. It marks the first boundary of the measured span. Shifting both endpoints the same way preserves the distance. Give the checked partial paper tape when a classroom ruler is unavailable.

Return the previous exit, then choose the planned five-minute repairs. Bracket only the excess for error H, shade spaces for error C, and regroup the new ten for error M. Lay the parts end to end for error G. Overlay inch and centimeter references for error I, trace the curve for error J, close gaps for error A and match both covers to the same endpoints for error D. Use small groups or parallel pictured repairs as needed. Hear six in Pairs or Centers and date missed turns. In Before class list the private exit ticket key and the applicable repair or center key.
