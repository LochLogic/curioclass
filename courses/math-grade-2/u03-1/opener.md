# From equal pieces to metric tools

Start with a full cover of equal units. The first unit begins at the edge and each new unit touches the previous one. Show the hook and the three retrieval pictures before the measured cases. Order three strips from the same start and mark the extra span on the pennant picture. Use day 40’s prerequisite repair and day 41’s fresh check when needed. Return the earlier unit’s work in its scheduled rounds. Send the family note on day 39.

Model a centimeter using a verified centimeter cube edge or an actual-size paper tab. On day 41 use **End-to-end length iteration** again. Draw at each join, keep zero at the first boundary and lift the units. Children can read how many equal spaces extend from zero to the endpoint. Review **Fixed comparison strip** by aligning one marked piece with each edge in turn. Compare two lengths by finding only the part after the shorter edge ends.

A benchmark is a known length to picture along an edge. Foretell a length before showing a measuring tool. On the longer tabletop edge, compare a short ruler with a verified meter stick and choose a tool that fits. Keep sticks flat. Adults cut and check all paper tools at actual size and lay long work along supported surfaces. Use paper tabs, cardboard and verified paper scales without a kit. If an actual-size reference fails its check, replace it with a verified one or date the need to check the measurement later.

Private feedback uses the register. Close seams for error A, reset the start to zero for error B, shade spaces for error C, match the same endpoints using two unit sizes for error D and bracket only the extra for error H. Keep the first paper mark and date actual hearings. Hear six at 45 seconds each and use 30 seconds for switches. Read all exit cues aloud. Keep physical test stock and the exit masters together until their day. In Before class list the private exit ticket key and any applicable private retrieval or repair key.
