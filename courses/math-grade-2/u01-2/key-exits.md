# Exit ticket key

Keep this copy with the teacher.

- **s01-X7.** Flags 3, drums 1, hats 4, cups 2. Every icon takes one equal cell.
  Every icon is filed once. the chart uses one same-size cell per icon
  Error G. The paper groups are not reconciled with the whole.
  Error C. The place size varies with the appearance of the icon.
- **s01-X8.** One cloth zipper.
  Indicates one zipper from the cloth row; a single mark or an equivalent dictated answer is sufficient.
  Error C. Treats a thick outline as two units.
  Error C. Sizes the unit by its appearance.
- **s01-X9.** 3, or a bracket covering the three unmatched cells.
  Error E. Joins the lengths rather than finding the unmatched span.
  Error D. Reads the flat bar from tick 1 instead of 0.
- **s01-X10.** Cross 7, bend 2, stop 0, arrow 4; label and keep the empty stop row. Same cells from zero.
  All four counts match their labels in the new order. one equal cell per response from zero
  Error D. The tick at 1 is used as the baseline.
  Error C. Applies a two-cell unit in just one row.
- **s01-X11a.** A question comparing the ridged and smooth counts, for example, “How many more are ridged than smooth?”
  The question asks for an excess or a shortfall. it refers to the ridged and smooth bars
  Error E. Treats a comparison question as a combined total.
- **s01-X11b.** 7
  Error E. Joins the two lengths.
  Error D. Reads smooth from 1 and ridged from 0.
