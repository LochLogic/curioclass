# Section 1.2 opener: Representing and questioning data

## The mathematical work

Review grade 1 category counts. Bring back day 1’s data pictures using fresh examples.
Separate grouping from counting. A category is a group under one label. Make one tally
per object and account for the whole set. In a picture graph each mark stands for one
response. Place the sample key outside the counted rows. In a bar graph the length
from zero gives the count. Run a finger along the first interval from zero to one before
reading the endpoint. An empty category still keeps its label.

On day 10 keep one set of counts fixed while students make both graphs. Ask them to
find one category in both forms. On day 11 give a total question, a missing-part question
and a difference question separately. Cover or recover a part within the total and use
matching when comparing. Retain the child’s graphs and the first split of the fixed whole.

## If a first mark needs repair

For error C match each object to one equal place. For D trace from zero to one. For E
align starts and mark only the extra length. For G check that the listed parts make the
whole. Return the papers as scheduled and use fresh cases for repairs. Inspect all
papers and hear one reason from the rotating six. Treat the method as evidence for a
letter and keep uncertain arithmetic slips open.

## Before the section

Prepare the tally chart, paper symbol cards, single-unit grid, practice graph pair and
question cards. Use four drawn boxes for bins, scrap-paper marks for symbols and ruled
boxes for a grid. Use the classroom object cards and fallback counts if needed. If a
class tally matches a held graph case, use the prepared practice case. Keep the day 7
survey neutral, anonymous and about which classroom objects to sort first. Later both
graphs must keep the same tally.
