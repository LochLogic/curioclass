# Private exit key

### s05-X74

100, or one hundred. Select ten strips; five stay loose. Look for ten selected strips and a hundred label on that bundle. Accept matching marks instead of cuts.

Ten on a band of ten strips. Error A. Counts each ten-strip as one. Leaves the band empty, calling the stock fifteen ones. Error A. Treats the strips as single ones.

### s05-X75

Seven hundred-grids labeled 700. No tens or ones remain. Accept seven sketched grids or seven directed grid marks and a numeral that holds both empty places.

Seven grids labeled 70. Error C. Keeps only one zero after naming two empty places. Labels the seven grids as seven ones. Error B. Treats the hundreds digit as ones.

### s05-X76

646 with digit values 600, 40, 6. Match each digit to its value even though the trays are scrambled. Accept the values drawn on or next to the label.

Writes 6, 40, 6 under 646. Error B. Assigns face value to the hundreds digit. Writes 600, 4, 6 under 646. Error B. Assigns face value to the tens digit.

### s05-X77

The zero shows no ones and keeps the 7 in tens, worth 70. In 87 the 7 is worth seven ones. Accept arrows and place marks that show how erasing the zero moves the seven to the ones place.

Marks 870 and 87 as the same amount. Error C. Treats the missing placeholder as harmless. Labels both 7s as seven ones. Error B. Uses the digit face value in both places.

### s05-X78

582 = 500 + 80 + 2. Look for the three values adding to the target; accept a reordered exact expansion.

5 + 8 + 2 Error D. Uses the digit face values. 500 + 8 + 2 Error D. Treats eight tens as eight ones.

### s05-X78-numeral

934. Look for 9 in hundreds, 3 in tens and 4 in ones.

16 Error D. Adds 4, 9 and 3 as ones.
