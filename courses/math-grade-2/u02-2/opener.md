# Section 2.2 opener: Exchanging a ten to subtract

## The mathematics

Review exchange from earlier grades. Here one ten is traded for ten ones. Match the
units before removing anything. Mark the canceled rod when the ten loose ones appear.
Compare one subtraction needing the trade with one that can remove all its ones as
they are. Extend from one-digit to two-digit subtrahends. Record the new parts as
an equality and connect subtracting with adding on to find the same missing part.

On day 27 explain that each number being added is an addend. Keep its mark visible
when making useful groups. The same parts can total more than 100 when four two-digit
numbers are added. Draw a hundred as ten tens. On day 28 compare two complete
records: exchanging before either removal, or taking the tens first and exchanging
before taking the ones. Both remove the same amounts. Withdraw the supplied pieces.

## Returns and preparation

Review Return and repair with private cues. Error B calls for rebuilding the
whole starting amount. For error C cancel one rod as ten ones appear. For error G
tick each original number once. For error H tie a reason to the paper mark.
Set out the paper bank trays, rods, loose squares, pairing cards, started drawings,
finished traces and exit tickets. Fold scrap for trays and draw marked rods or
unit dots if needed. Cut paper away from students before class and keep it on tables.
Read each cue aloud, including any request for a private reason.
