# Survey judgment guide

Keep this copy with the teacher.

Use each group’s retained tally. Mark each of the five components separately.

- **s01-G1.** Use the group’s four-category tally. Draw one equal symbol per response and keep all four labels.
  Four labels match the tally. one equal symbol per response. zero categories stay labeled
  Error C. The picture units vary by category.
- **s01-G2.** Use the same group tally. Shade one equal cell per response from zero and keep all four labels.
  Four labels match the tally. cell lengths agree with the tally from zero. a zero row stays labeled
  Error D. Starts after the first unit interval.
  Error C. Changes the unit between categories.
- **s01-G3.** Circle count plus triangle count.
  Correct result from the group tally.
  Error F. The child used a difference without identifying the requested combined amount.
- **s01-G4.** Total votes minus circle votes, or the sum of the other three categories.
  Correct result from the group tally.
  Error F. The removed category is treated as an additional part.
- **s01-G5.** Subtract the smaller count from the greater. Equal counts give 0.
  Correct result from the group tally.
  Error E. Combines the two categories instead of comparing their bar lengths.
