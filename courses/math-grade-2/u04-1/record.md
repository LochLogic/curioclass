# Unit 4 evidence record



Use privately. Copy the hearing log for the class and the evidence grid for each child. Each day hear six at 45 seconds each, with 30 seconds for notes and switches. Start with anyone missed from the previous rotation. Public talk may be passed. Enter actual names and dates. Every child gets private feedback on their first paper.

Use shown, shown with help or not yet seen. Note any support and assign an error letter only when the marks support it. Keep the dated first and revised pictures. Use a separate evidence row for each cue. F also needs a brief note on accuracy and efficient strategy. Record Q1 and Q4 once, using each for the length and story evidence. F and Q are maintenance. R or S, N and D supply the unit score.

For the final return, take two five-minute rounds per day. Fill freed teacher slots from F, C, G, H and I in order. Other groups may follow pictured moves and complete an independent recheck. Retain each recheck and date the actual private feedback.
