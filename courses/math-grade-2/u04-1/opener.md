# Whole numbers as lengths from zero



Build the ruler-built whole-number line by repeating one paper edge end to end. Mark the joins, then name zero as the start. Review length unit and interval. An interval has a length; a tick mark names a position. On a cropped scale, find a known label and count spaces away from it. Put the ruler away on day 60. On day 62 use both endpoints to estimate a point before lifting the cover.

Send the family note on day 58. Use the hook ruler and line, retrieval strip, equal paper units, tabletop strip and cards, and the line masters on their named day. A repeated paper edge stands in for a ruler or loose units. Handwrite missing cards, use a pencil tip as a pointer, and keep pre-cut paper on a supervised tabletop. Adults cut stock and clear loose materials from walkways.

For error A, cover each traveled space once with a paper unit. For error B, rebuild consecutive spaces with one repeated edge. Use the first strip and its fresh recheck on their named days. Run Unit 3's private return rounds separately on days 58 and 59. Use the Unit 3 register, first papers and the Fresh-object estimate recheck again when needed. Hold an unfinished station before releasing its key.

Read every exit cue aloud. Print the pictured exit master at half-letter size, two per Letter sheet. In Before class name the private exit ticket key, the strip key and any needed repair key. Hear six at 45 seconds each, plus 30 seconds for notes and switches. Log the heard names and dates separately from paper marks, carry missed names into the next rotation and return all first marks privately.
