# Unit 4 record sheet: our class list

Write each child's name down the left. Use one scale in every cell: S for shown, H for shown with help, N for not yet seen. Each E column is one spoken exit and has a cell for each look-for listed under the table; a child may point, say, draw or act it out. The Heard column is for days 32 to 43, on which you heard that child's reason (about six children a day, rotating). The End columns are the observations on day 41 (the N items, in order), day 42 (the M items) and day 43 (the C items), one cell for each look-for. Only a child's first unaided try at the sitting counts. Never write N for a part you did not see; leave the cell blank and try another day. Write H when you read a card, steadied a page or placed a mark for the child, and say so. Day 43 caption revisions never change an End cell, and the day 40 and 43 exits are not scored.
