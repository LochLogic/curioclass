# Unit 3 record sheet: our class list

Write each child's name down the left. Use one scale in every cell: S for shown, H for shown with help, N for not yet seen. Each E column is one spoken exit and has a cell for each look-for listed under the table; a child may point, say or act it out. The Heard column is for days 20 to 28, on which you heard that child's reason (about six children a day, rotating). The End columns are the observations on day 27 (P1a to P2c, in order) and day 28 (M1a to M3b, in order), one cell for each look-for, and only a child's first unaided try at the sitting counts. Never write N for a part you did not see; leave the cell blank and try another day. Write H when you steadied the page, read the card or helped place the bumper, and say so. A design that missed is a true result, not an N. Day 28 caption revisions never change an End cell, and the day 28 exits are response, not scored.
