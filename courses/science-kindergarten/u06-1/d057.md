# Day 57: If we do this, what changes?

## Teacher page

### Before class

The day before, wash and dry one bottle for each group; take off loose labels; check edges and small parts. Set a bottle and five reused sheets at each group. Key: key-exits-55-58.

### Safety and set-up

Samples are clean: no glass, sharp edges or choking-size parts. Children handle only these.

### The day

#### 2 min. Return and repair

If many gave error C in day 56's exit, show the turtle picture with shrubs, then the bagged litter: litter tucked in shrubs is still litter; a grown-up bags it.

#### 2 min. A new frame

Teach the frame as new: "If we ___, then ___" says what we do and what changes. Model one: "If we put the bottle in the bin, then the bottle is not on the ground." Children say it with you, pointing to the arrow on the class drawing.

#### 7 min. Clean objects

Say once: "These samples are clean and the case is invented." Each group takes turns, 1 minute each for five children, with the bottle or the blank side of a sheet. The child shows the chosen action, a pick-up with the bottle in the bin, a sheet turned over, or the bottle in the bin that takes it, and says "If we ___, then ___." The rest draw the arrow on a sheet. Hear one child in each group.

#### 8 min. Draw it

Each child draws the chosen action and the effect it changes. Scribe a label for six children as they dictate it.

#### 4 min. Revise

Revise the class drawing and sentence from what was said. Name the effect by part: land, water, air or a living thing. Keep "might" where we did not see it. We have not counted again, so no claim yet.

#### 3 min. Exit

Say it is invented. Show the classroom corner. Ask [[s06-X57a]]; all touch at once. Ask [[s06-X57b]]; hear three, 30 seconds each. Errors B and C are in the key.

#### 4 min. Clean-up

Samples boxed; wipes for everyone.

### Other rooms

Drawn bins and bottles on scrap paper; each child still shows the action with a drawing.

### At home

**Swap.** No bottle: use any clean container and a used sheet.

**Skip.** The group turns and the class chart.

- **10 min. Show it.** Your child shows the action with the clean container or the blank side of a sheet.
  **Say.** "If we do this, then what changes?" Expect: less litter or less new paper.
- **10 min. Draw it.** Your child draws the action and what it changes.
- **5 min. Exit ticket.** [[s06-X57a]] [[s06-X57b]] Say it is invented.

### Shorter or longer

Shorter: one child in each group shows; the rest watch. Keep the drawing and the exit. Longer: a second effect.

### Words and supports

Words: reuse, recycle, litter. Frames: "If we ___, then ___." "It might ___." Pointing, dictation and any home language count.

### Tomorrow

Day 58 hears this exit first. If many gave error B, set a sheet blank side up beside a fresh sheet; if many gave error C, show an adult-bagged pick-up beside shrubs. Then the class says what its action would change in a corner it has not seen.
