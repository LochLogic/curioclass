# Day 5: Start, rule and domain

## Teacher page

### Before class

Cut the situation cards, one card for each pair. Return day 4's exit ticket with the error letters marked. Print the student page and the paper exit ticket. Open the answer key and the record sheet. Draw an input line from 0 to 8 on the board.

### The day

#### 5 min. Warm-up

Alone: [[s01-P5-1]] and [[s01-P5-2]]. It is practice only.

**Ask.** For c(2), how many halvings have you done from the start? Expect: two, because c(0) is the start.

If many made error B or C on day 4's exit (100, 80, 60, 40, or b(3) = 64), redo the table of [[s01-P5-2]] together, writing the number of steps from the start above each term.

#### 10 min. Worked example: starting term and recurrence

Students try [[s01-K5-1]] before you model it.

**Ask.** What do you need to know before you can find m(2)? Expect: the rule and a starting term, m(1).

[[steps:s01-K5-1]]

Name the three parts on the board: the starting value, the recurrence and the domain. The domain is the set of inputs that are allowed.

#### 8 min. Why the start matters

Students do [[s01-K5-2]] and write the two sequences side by side.

**Ask.** Does the recurrence alone tell you which sequence is meant? Expect: no; the start is part of the definition. A rule with no start is error D.

#### 8 min. Domain

Mark the allowed inputs of m on the input line: the integers 1, 2, 3 and so on. Students do [[s01-P5-4]], then [[s01-P5-6]].

**Ask.** Why is 2.5 not an input here? Expect: the inputs are counted positions, and there is no position 2.5.

Allowing an input such as 1.5 is error A; place three proposed inputs on or off the line. In [[s01-P5-6]] the domain stops where the situation does: a domain can be limited by what the situation allows.

#### 7 min. Two seeds

Students try [[s01-K5-3]] before you model it. Write the pairs (n, w(n)) in a table on the board yourself, and students copy them.

**Ask.** Does any input appear twice in the list? Expect: no. The rule needs two earlier terms, but each input still has exactly one term. Saying it is not a function is error I.

[[steps:s01-K5-3]]

#### 7 min. Pairs write

Each pair takes one situation card and writes its starting value or values, recurrence and domain, then one sentence on why a different start would give a different sequence: [[s01-W5]]. A pair writes one sheet, and you record it for both partners. Read it after class by its three look-fors and return it at the start of day 6 for a revision note. The exit that follows is the individual measure.

#### 5 min. Exit ticket

[[s01-X5]], alone, on paper. Collect. After class, record the four look-fors, three for part (a) and one for part (b), on the record sheet.

### Other rooms

No device is needed. Without a printer, copy the four cards onto the board. With one projector, show the pairs only after students have written their answers on paper.

### At home

**Swap.** No printer: copy one situation card onto paper. No input line on a board: draw one on paper.

**Skip.** The pair work and the exchange of cards.

- **5 min. Warm-up.** Do [[s01-P5-1]] and [[s01-P5-2]] alone.
- **8 min. Example.** Try [[s01-K5-1]], then read its answer together.
  **Say.** "What do you need before you can find the next term?" Expect: the rule and a starting term.
- **6 min. Start and domain.** Do [[s01-K5-2]] and [[s01-P5-4]].
  **Say.** "Why is 1.5 not an input?" Expect: the inputs are the whole numbers 1, 2, 3 and so on.
- **6 min. Two seeds.** Try [[s01-K5-3]].
- **8 min. Write.** Define the sequence for one situation card in [[s01-W5]].
- **5 min. Exit ticket.** [[s01-X5]], alone. Keep it for tomorrow.

### Shorter or longer

Shorter: skip [[s01-P5-6]]; keep the two-seed example and the exit. Longer: ask for two different sequences that both begin 1, 2, 4, and what more would say which is meant.

### Words and supports

Starting value: the first term, written with its input. Recurrence: a rule that builds each term from earlier terms. Domain: the inputs that are allowed. Frames: "The starting value is __ and the recurrence is __." "The domain is the integers __." "A different start gives a different sequence because __."

### Tomorrow

The exit tells you who gives a recurrence with no starting value (error D), who allows an input such as 2.5 (error A), who counts four stops as three (error C: v(4) = 46) and who runs the domain past stop 8 (no letter). If many made error A, D or I, day 6 opens with that repair for the whole class, the most common first, in seven minutes; a different start under one rule for D, an input line for A, and index and term pairs for I. Day 6 first returns the written task for a revision note, in three minutes. Day 6 then connects a recurrence to its table and graph.
