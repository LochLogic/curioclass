# Unit 1 record sheet: sequences and functions

Write each student's name down the left. The R columns are the day 1 start-of-year check: mark each item right,
partly or not yet, and write the error letter beside a miss. It is practice, not a score. Each E column is one exit
ticket: one tick when the answer matches the key. The day 1 and day 5 exits are judged, so they take one tick for
each look-for. W5 is the day 5 written task, one tick for each of its three look-fors; a pair writes one sheet, so record it for both partners. The day 5 exit, X5, is the individual measure, with four look-fors. The End columns are the day 13
unit assessment, one tick for each part or look-for (item 3 scores its six components apart). Leave a cell blank
until it is seen. Put the date in a cell for a retry after day 13.
