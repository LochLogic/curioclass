# Day 4: One rule, repeated

## Teacher page

### Before class

Cut the rule cards, six to an envelope for each pair. Set out graph paper and rulers, and a graphing calculator if you have one. Return day 3's exit ticket with the error letters marked. Print the student page and the paper exit ticket. Open the answer key and the record sheet.

### The day

#### 5 min. Warm-up

Alone: [[s01-P4-7]]. It is practice only.

**Ask.** In g(5) = 11, which number is the input? Expect: 5. Reading g(5) as g times 5 is error G.

If many made error B on day 3's exit (P(3) = -10, from subtracting the last change of 20), put day 3's tables X and Y side by side on the board and ask for the differences and the ratios of each. Table X has equal differences; table Y has equal ratios.

#### 8 min. Worked example: one rule, repeated

Students try [[s01-K4-1]] before you model it. No new idea is taught today; the work is to apply one rule again and again and to check the plot.

**Ask.** Which number do you use to get each next term of S? Expect: the term before it, multiplied by 4.

[[steps:s01-K4-1]]

**Ask.** Is (2, 48) on the graph of S, and how do you know? Expect: yes, because the term at n = 2 is 48; read the pair as (n, term).

#### 25 min. Practice with fading prompts

Students work alone on the six rule cards: [[s01-P4-1]], [[s01-P4-2]], [[s01-P4-3]], [[s01-P4-4]], [[s01-P4-5]] and [[s01-P4-6]]. For each, they build a table, plot the points on graph paper, and write the last term in the table on Side 2. Cards 1 and 2 come with a table frame, cards 3 and 4 give only the start and the rule, and cards 5 and 6 give the rule in words. The prompts fade one step at a time. Cards 2, 3 and 6 name a scale for the plot. Card 5 goes below 0, so the axis must too, and it also asks how many terms are positive.

A graphing calculator may check a table or a plot, for about ten minutes inside this part; a hand table and plot do the same job and give the same evidence. No student is timed and no speed is recorded.

Confer with students who stall on cards 3 and 4 by asking them to read the start and the rule aloud. Watch for adding on cards 2, 3, 4 and 6, which multiply (error B), and for a table that starts at n = 1 (error C). Keep the plots; they stay in the folder.

#### 7 min. Check and fix

Students swap Side 2 and plots with a partner and check cards 3 and 6 only, each finding one value or point to question. Then students do [[s01-F4-1]] alone.

Check: Each table starts with the given start at n = 0, and each next term follows from the one before it by the rule; each plotted point is (n, term).

**Ask.** The table was set up for n = 0, so where does the start go? Expect: at n = 0, with the first step giving n = 1.

#### 5 min. Exit ticket

[[s01-X4]], alone, on paper. Collect. After class, record it against the key and mark the error letters.

### Other rooms

No device is needed. Without a printer, copy the six cards onto the board. Without graph paper, rule a grid on plain paper. A calculator is optional.

### At home

**Swap.** No graph paper: rule a grid on plain paper. No calculator: work each table by hand.

**Skip.** The partner swap, and cards 5 and 6.

- **4 min. Warm-up.** Do [[s01-P4-7]] alone.
- **7 min. Example.** Try [[s01-K4-1]], then read its answer together.
  **Say.** "Which number gives each next term?" Expect: the term before it, plus 6 for R and times 4 for S.
- **14 min. Cards.** Do cards 1 to 4 from the rule cards sheet: a table, then plot the dots.
  **Say.** "The table begins at n = 0, so where does the start go?" Expect: at n = 0.
- **5 min. Fix.** Do [[s01-F4-1]] together.
- **5 min. Exit ticket.** [[s01-X4]], alone. Keep it for tomorrow.

### Shorter or longer

Shorter: do cards 1, 3 and 5 only. Longer: make a card of your own that starts at 10, and ask a partner for its term at n = 4.

### Words and supports

Rule: what you do to a term to get the next one. Start: the first term, here the term at n = 0. Frames: "The start is __ and each next term is __ the term before." "The point at n = __ is (__, __)." Accept a table filled in without a sentence.

### Tomorrow

The exit tells you who subtracts 20 or 16 each time from the 0.8 pattern (error B: 100, 80, 60, 40, or accepting the point (3, 48)) and who is one step short (error C: b(3) = 64). Day 5 begins with the exit back. If many made error B or C on day 4's exit, day 5's warm-up redoes one table from a rule, counting steps from the start. Day 5 then writes a start, a rule and the allowed inputs for a sequence.
