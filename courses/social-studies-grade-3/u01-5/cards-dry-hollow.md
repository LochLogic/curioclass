# Dry Hollow Card (day 17, teacher's model)

Invented for practice. Dry Hollow is a made-up valley. The families there hold a work day each spring to clear the creek bed. Because they clear it, the creek runs in the summer. Model: This group holds a spring work day, so the creek runs.
