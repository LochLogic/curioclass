# Unit 5 record sheet: colonies and the Native nations

Write each child's name down the left, one row for each child, and keep one marking scale: shown, shown with help, not yet seen. Never write a count of reminders.

Columns: one tick and a note for each exit E90 to E121, heard from the day's six children, rotating through the class; the retained records on days 90, 93, 95, 96, 100 to 103, 106 to 108, 110, 113, 116 to 118 (practice first, revised after the written note, scored on the revision only); the day 105 prompts M1 to M8; the day 119 timeline; and the day 120 prompts Q1 to Q8d and R1 to R9. For each look-for score 2 when the child shows it alone, 1 when it needs a content prompt, 0 when it is missing; leave blank when not seen.

Write the six children heard in each rotating round in a note column, so no child is passed over. A child may pass; try again another day and put the date in the cell. Day 121's fresh task is not scored on this sheet. Write only what help was used.
