# Unit 4 record sheet: the Native nations of our region

Write each child's name down the left, one row for each child, and keep one marking scale: shown, shown with help, not yet seen. Never write a count of reminders.

Columns: one tick and a note for each exit E72 to E87, heard from the day's six children, rotating through the class; the written tasks on days 76, 82, 83, 85 and 86; and the day 88 prompts Q1 to Q9b, one cell for each look-for: 2 when the child shows it alone, 1 when it needs a content prompt, 0 when it is missing; leave blank when not seen.

Record rows: Q9 and Q9b come from the day 72 card revised in a new colour on day 87, scored after the written note and not before. The first card is practice until then. Write the six children heard in each rotating round in a note column, so no child is passed over.

Day 89's fresh redo is not scored on this sheet. Write only what help was used. A child may pass; try again another day and put the date in the cell.
