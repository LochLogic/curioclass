# Fresh map for the legend trace, made up, for practice

No nation is on this map. It is a made-up island with a made-up key.

```
   +---------------------------+
   |   ~~~~ sea ~~~~           |
   |        .:::::.            |
   |       :: marsh ::      /\ |
   |        '::::::'       /\ |
   |                  (*)      |
   +---------------------------+
   Key:  ::::  = marsh      /\  = hill      (*) = a lookout
```

Say: "The map shows ______; I can find it because the key says ______."
