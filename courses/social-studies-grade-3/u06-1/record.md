# Unit 6 record sheet: founding ideas

Write each child's name down the left, one row for each child, and keep one marking scale: shown, shown with help, not yet seen. Never write a count of reminders.

Columns: the readiness page of day 124 (RD1 and RD1b, access look, no score); one tick and a note for each exit from E125 to E134 and E136, heard from the day's six children where it is spoken and read from the half slip where it is written; the retained records on days 125, 126, 127, 128, 129, 130, 131, 132 and 133 (practice first; the day 125, 128 and 131 records and the day 134 strip are revised after the written note and scored on the revision only); and the day 135 prompts Q1 to Q5e and R1 to R4b. For each look-for score 2 when the child shows it alone, 1 when it needs a content prompt, 0 when it is missing; leave blank when not seen.

Write the six children heard in each rotating round in a note column, so no child is passed over. A child may pass; try again another day and put the date in the cell. Day 136's fresh task is not scored on this sheet. Write only what help was used.
