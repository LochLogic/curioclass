# Written move cards (day 24)

For the groups not with the teacher. One card for each of the error letters. Each says what a wrong idea is and what to do.

- A: continent, ocean and hemisphere are three kinds of words. Check which kind the question asks for.
- B: a color gives a symbol no meaning. Read the legend.
- C: north is where the arrow points. Find the arrow first.
- D: a bar is a length, not a step. Lay a strip along it.
- E: warm does not mean wet. Look at rain separately.
- F: a region holds states; a state is one place; a river is a landform. Say which you are naming.
- G: what you can see does not prove more than the source says. Say what the source shows.
- H: a name or title is not the reason. Say what the person did.
- I: blank land on a map was not empty. Say the map does not show it.
- J: some disagreements can be checked. Ask what each reading could be checked against.
- K: a claim needs a detail from a source. Add one.
- L: a grid cell is letter first, then number.
- M: nations live today. Use the present tense.
- N: each nation has its own practices. Name the one nation.
- O: answer the question that was asked. Read it again.
- P: a list of features is not a relationship. Say how one helps explain the other.
- Q: people change land. Say what they changed and why.
- R: a new thing does not end everything before it. Ask what stayed.
- S: a region needs all its states. Check the key list.
