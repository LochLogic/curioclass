# Feedback cue sheet (days 21 and 22)

The teacher's written cue on each child's day 10 map, day 2 record and day 20 question record. Use one cue for each piece, never a grade. Stems: Add the part that says what each symbol means. Name who else might care and why. Write one fact the question needs. Make the north arrow point the way north is on this page. A cue never names another child.
