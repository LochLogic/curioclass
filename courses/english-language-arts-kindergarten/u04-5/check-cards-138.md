# Check sheet, day 138 (O1, the reason a writer gives)

The check uses page 2 of Planting Together (texts/gk-u4-02-b.md), which the class heard once and has not worked on. Do not read or teach it again before the check. Read it aloud once. Each group of five has two and a half minutes of this page and the opinion question together.

**Page 2.** Say: "The class wants to decide where to put its pot." Ask: "Which reason from the writer helps us choose?" Right: a good place gets sunlight and has room to grow, and a tree in a good place can grow well.

A liking ("I like blue") given as the reason is error C. Give one prompt a child and never the answer; a prompted answer is marked shown with help. Marks: shown, shown with help, not yet seen.
