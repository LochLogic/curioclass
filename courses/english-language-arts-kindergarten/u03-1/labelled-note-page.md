# Labelled note page

A notebook page used from day 83 and again on days 85 and 87.

- A large drawing box at the top.
- Under it, one label line. The teacher writes the label the child says (the topic name).
- Under that, one dictation line. The teacher writes one fact the child says from the reading.
- At the foot, a small box marked with a book picture for a sticker or a drawn mark showing which reading the fact came from.

Child: Name ______________________

Draw it here:

[ drawing box ]

Label: ______________________

My fact: ______________________________________________

Where it came from: [ book picture ]

A room with nothing: rule a sheet of paper into a box and two lines.
