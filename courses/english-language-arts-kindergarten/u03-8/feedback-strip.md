# Four-note feedback strip

A narrow strip stapled to the collage page and read to the child on day 114. One strip, one next step. Circle one, read aloud by the teacher:

- Name the tree.
- Add one fact from a card.
- Draw the arrow.
- Show the card line.

The teacher writes the step and reads it aloud. The child adds it before the page is shared. The strip stays with the page.

A room with nothing: cut a strip of paper and write the four steps by hand.
