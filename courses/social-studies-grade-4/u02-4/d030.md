# Day 30: Producers need connections

## Teacher page

### Before class
Read opener.md and teacher-only key-exits.md alongside the generated answer key. Use the generated answer key for current rows. Prepare practice-30.md within the student page, the printing-chain.md input card, and sealed exit-30.md half slips. Withhold the one-group cards. Bring all day 29 papers with one feedback priority. Display question-board.md; prepare record.md.

### The day
#### 5 min. Return and repair
Return day 29's s02-X29, s02-P29-R, s02-P29, s02-P29b and s02-P29q. Review critique: use order, supporting detail and accuracy criteria, not liking. If many showed error H or error D, use [[s02-P30-R]] with everyone; otherwise one group. Others read their feedback. Review the one-line criterion cue: revise below the first answer; only revision is scored. Continue this one priority during Trade work.

#### 10 min. Trade and choice retrieval
First five minutes, alone: [[s02-P30a]] and [[s02-P30b]]. Review grade 3 trade: goods move from where they are made to where they are sold. Review opportunity cost: the next-best thing given up, not the price or every choice. Last five: if many confuse chosen and forgone, use [[s02-P30-R2]]; otherwise partners rehearse their component labels. All scenes are made up.

#### 8 min. Specialized links
Review specialize: a business that makes mostly one kind of thing. This describes producers, not every resident. Show only the input card.
**Ask.** [[s02-K30-K]]
Then reveal [[steps:s02-K30-K]]. Review grade 3 relies on: a buyer needs the good a supplier sends. Producers can buy inputs instead of making everything themselves. Exchange can let linked producers make more. Establish reliance on purchases separately: a seller needs customers' orders. Name needing each other interdependence, a new word here. More output may require more input deliveries.

#### 12 min. Trade work
First five minutes extend the day 29 priority using the fresh symbol repair; others begin [[s02-P30]]. Next seven: pairs point to input and buyer labels, then each marks [[s02-P30-L]] independently. Keep this a single interrupted link. Each partner has one 45-second turn, simultaneously across pairs; no teacher queue. Collect all papers; add a supported trade connection to question-board.md.

#### 5 min. Exit ticket
Distribute the unseen half slip, exactly [[s02-X30]], for independent paper answers. Read neutrally or take dictation without hints. Collect all. After class allow 30 times 45 seconds, 22.5 minutes, for exits, plus 30 times 45 seconds for practice. In record.md use shown, shown with help, not yet seen per component; record access separately. Return every paper on day 31.

### Other rooms
Copy the input chain and blank page onto paper. No screen is needed. Keep the exit separate.

### At home
**Swap.** No copies: draw the input chain and copy blank response fields. Keep the exit hidden.
**Skip.** Class collection and public sharing.
- **5 min. Feedback.** Read day 29 feedback; use [[s02-P30-R]].
- **10 min. Choices.** Your child answers [[s02-P30a]] and [[s02-P30b]]. Use [[s02-P30-R2]] if needed.
- **8 min. Links.** Point along the input card. Use [[s02-K30-K]], then its steps. Explain input as something used to make a product. Introduce interdependence as needing each other.
- **7 min. Work.** Your child labels [[s02-P30]] and marks [[s02-P30-L]]. **Say.** "Which delivery does the shop need?" Expect paper from its supplier.
- **5 min. Exit ticket.** Give [[s02-X30]] alone; retain the paper for tomorrow's feedback.

### Shorter or longer
Shorter: reduce partner sharing; keep the repair, input interruption and exit. Longer: explain an existing label more precisely.

### Words and supports
Review trade, specialize, opportunity cost, buyer and relies on. Input: something used to make a product. Interdependence: needing each other. Allow pointing, enlargement and dictation; distinguish reasoning from grammar. Public passing is allowed.

### Tomorrow
Day 31 reads trade arrows. Return s02-X30 and every practice paper. Error E, goods listed without a needed link, or error O, making everything alone, gets one fresh input repair in Return and repair, extended in Map work.
