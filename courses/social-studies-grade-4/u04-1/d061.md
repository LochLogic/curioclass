# Day 61: What can this source add?

## Teacher page
### Before class
Return day 60 papers with one private priority. Keep teacher-key.md and the generated key separate. Use practice-61.md as a teacher master; student pages carry stimuli and response spaces. Add the factual object card to Voyage Accounts only after teaching. Hold exit-61.md unseen.

### The day
#### 5 min. Return and repair
Return day 60's exit tickets, practice pages and checked source logs. Review Return and repair: one priority, no public mistake examples. If day 60's exit showed error R, use [[s04-P61-5]]. Expect the librarian needing the date. Other children reread their own cue. Error C: reread the inhabited-island summary, distinguishing Columbus's claim from consent. Retrieval misses: review firsthand observation versus later explanation.

#### 8 min. Teaching first
Whole class: review artifact from grade 3 day 108, an object made and used long ago. Introduce archaeology as study through material evidence; a later caption describes a find, not the object itself. Read Source CAMP's original whetstone summary. **Ask.** [[s04-P61-1]] Expect a question about tools used or maintained, never everyone's thoughts. Model linking the sharpening use to that question after responses.

Review maps from unit 1 and drawings from grade 3 day 108. Separately model geographic information, an imagined scene and a reported meal. An illustration is a made picture; a journal records events over time. Review primary/secondary sources from grade 3 day 73. Neither old age nor firsthand status guarantees accuracy.

#### 17 min. Evidence work
First five finish the opening priority. Use [[s04-P61-6]] as a fresh reader-need retry; otherwise retry the contribution question with the cook entry. One priority per child, not every register error.

Then children work alone on [[s04-P61-2]], [[s04-P61-3]] and [[s04-P61-4]], one source at a time. **Ask.** [[s04-P61-3]] Expect that the artist heard the story later, so the drawing's date cannot establish witnessing. Error A needs access evidence; error B needs a bounded contribution; error S needs what the source adds, beyond naming its kind. Review source logs from day 19; use [[s04-P61-7]] for one source, not a combined account. Fifteen pairs each take 45 seconds explaining one answer, 90 seconds total. Collect logs for ungraded feedback; return them on day 62.

#### 5 min. Question board
Review the board routine from day 60. Group B's six each explain one existing answer for 45 seconds, 4.5 minutes total; public pass allowed. Add one bounded source contribution under the sources question. Collect every page for private feedback. Cover teaching materials.

#### 5 min. Exit ticket
Reveal exit-61.md with its complete stimulus. Alone, children answer [[s04-X61-1]] on the half slip; allow neutral reading or child-directed dictation. After class: thirty times seventy-five seconds, 37.5 minutes, for practice and exit marking. Record object and journal contributions separately using shown, shown with help, not yet seen. All papers return on day 62.

### Other rooms
No screen: paper suffices. No printer: copy teaching and the covered exit separately, including each stimulus.

  **Say.** Who needs the date? Expect the librarian checking a historical label.

- **12 min. Evidence.** Retry [[s04-P61-6]], then use [[s04-P61-2]], [[s04-P61-3]] and [[s04-P61-4]]. Take one source at a time.
  **Say.** Does the drawing's date prove witnessing? Expect no; the artist heard the story later.
- **5 min. Board.** Use [[s04-P61-7]] in the source log.
- **5 min. Exit ticket.** Reveal [[s04-X61-1]] with its records. Let your child answer independently. Consult the key afterward; return papers next lesson.

### Shorter or longer
Shorter: omit repeated reports. Protect every source kind and exit. Longer: explain another limit on one source.

### Words and supports
Review artifact and source. Use archaeology, illustration and journal as explained above. Neutral reading and dictation preserve reasoning.

### Tomorrow
Day 62 uses inside clues for source fields. If day 61's exit shows errors B or S, repair bounded contributions; error A from practice needs maker-access evidence. Share Return and repair and Clue work's first five minutes.
