# Day 63: Recognizing source clues

## Teacher page
### Before class
Return day 62 papers with one cue each. Keep teacher-key.md and the generated key separate. Cover the entire exit master, images included. Use practice-63.md only as an oral-message master. Today's student sheet has choices and marking spaces, no key. All messages and images are made up.

### The day
#### 5 min. Return and repair

Return day 62's written tasks: s04-P62-1, s04-P62-2, s04-P62-3, s04-P62-4, s04-P62-5, s04-P62-6, s04-P62-7, s04-P62-8, s04-P62-9. Use the existing private cue and repair time.

Return day 62's exit tickets, practice pages and checked source logs. Review source-sourcing from day 62: maker, date, audience, purpose. If day 62's exit showed error H, read the made-up message, "Cargo counters, count the sacks." Use [[s04-P63-4]]. The addressed readers are cargo counters, not today's class. Error M: identify the requested action, not the message's label. Use no revision or prose drafting. Public pass allowed.

#### 10 min. Recall sets
Whole class: review internal clues from day 62. Read practice-63.md's three messages separately: paddles notice, mapmaker request, fog log. Children mark [[s04-P63-1]], [[s04-P63-2]], [[s04-P63-3]] on their choice grid. Give feedback after each, before the next message.

**Ask.** [[s04-P63-1]] Expect guide repairs, supported by bringing paddles to the bench. **Ask.** [[s04-P63-2]] Expect mapmaker, the addressed reader. **Ask.** [[s04-P63-3]] Expect reported conditions, not everyone's opinion. Review bounded contributions from day 61. No new source model or term is introduced.

#### 15 min. Recall work
First five finish the opening priority. Read a fresh made-up message: "Take the evening watch; Pat takes the morning watch." Children independently choose [[s04-P63-5]]. Expect assigning watches, supported by taking turns on watch. Check this brief retry within the ten allocated repair minutes, without rewriting returned prose.

Then fifteen pairs explain one previously marked oral clue, 45 seconds per child, 90 seconds total. Rehear the three messages in reverse order; children point to their choices, receiving immediate feedback. Use retained logs only to recall the earlier audience/purpose prompts; add no prose. A content cue is recorded as help, not independent evidence.

#### 5 min. Question board
Review the board routine from day 60. Group D's six each explain one already marked clue for 45 seconds: 4.5 minutes. Public pass allowed. Record names; collect every student's choice sheet for private written feedback. Cover practice before the exit. No public speed or accuracy score.

#### 5 min. Exit ticket
Reveal exit-63.md and its two images only now. Read [[s04-X63-1]] exactly. Explain shoal neutrally as shallow water if needed, without pointing to a purpose clue. Children underline independently on the half slip, or direct a scribe. After class allow thirty times sixty seconds, 30 minutes, for papers and component records. Use shown, shown with help, not yet seen separately for each image. All papers return on day 64.

### Other rooms
No screen: use paper. No printer: hand-copy both covered exit images, including every label and caption. A text-only replacement loses the image task.

  **Say.** Which words support that choice? Expect an action or addressed reader from that message.

### Shorter or longer
Shorter: omit repeated rounds. Protect feedback, repair and exit. Longer: rehear messages with choices reversed; keep the same evidence requirement.

### Words and supports
Review internal clue, audience, purpose and journal. Read neutrally; enlarge images or accept child-directed marking. No personal information is requested.

### Tomorrow
Day 64 studies Norse voyage evidence and encounter limits. If day 63's exit shows error M, repair inside-purpose evidence; error H needs intended-reader clues. All papers return in Return and repair, with Evidence work's first five minutes sharing one priority.
