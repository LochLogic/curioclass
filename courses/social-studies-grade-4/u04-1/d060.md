# Day 60: Whose questions matter?

## Teacher page
### Before class
Keep exit-60.md covered and keys separate. Print packet fronts and family note. Prepare the board's four question strips. Read day 59's retained moves; choose one priority per child. Copy no held source into teaching. The student page replaces duplicate response copies of practice-60.md.

### The day
#### 5 min. Return and repair
Day 59 left unresolved components in folders. Review Return and repair from grade 3 day 32: take one next move. Children reread their cue privately. Review primary and secondary sources from grade 3 day 73: relation to the question matters, not age. Use [[s04-P60-3]] as ungraded retrieval. Teacher checks guide feedback, not mastery ratings. Then explain witnessing versus later explanation.

#### 8 min. Teaching first
Whole class: read the two packet openings, original summaries of Source LOC and Source TAINO. Columbus's possession claim does not establish consent. The confederation describes ancestors' Caribbean homelands and living Taíno people. Never speak as a Native person. All invented records and readers are made up.

Review supporting question from grade 3 day 141: a smaller question helping the big one. Post the full unit question. **Ask.** [[s04-P60-4]] Expect inhabited-place evidence, not empty land. Model choosing [[s04-P60-1]] after children try; evidence can answer land-control questions, not settle taste.

#### 17 min. Question work
First five: finish one retrieval priority; children independently try fresh [[s04-P60-7]], then receive feedback. Supply the Penobscot fisheries reminder below independently, without claiming grade 4 taught it. Review qualified claims from day 48: evidence supports limited statements.

Then [[s04-P60-2]] distinguishes a reader's work from preference. Expect the editor checking dates. Fifteen parallel pairs each take 45 seconds explaining a choice, 90 seconds total. Use [[s04-P60-5]] to sort the four board strips, then co-write their questions together. Review source logs from day 19; use [[s04-P60-6]], leaving unknown fields blank. Collect logs with the pages; return them on day 61 with feedback, without a grade.

#### 5 min. Question board
Review the question-board routine from grade 3 day 2. Post sources, aims, effects and shared-years questions with their days. Group A's six each explain one existing choice for 45 seconds: 4.5 minutes. Public pass allowed. Collect everyone's page; written feedback reaches all. Cover teaching before exits.

#### 5 min. Exit ticket
Reveal exit-60.md only now. Each child answers [[s04-X60-1]] and [[s04-X60-2]] independently on its half slip; neutral reading and child-directed dictation available. After class allow thirty times eighty seconds, 40 minutes, for papers and component records. Use shown, shown with help, not yet seen; keep question and reader-need evidence separate. Return all papers on day 61.
