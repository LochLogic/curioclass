### The day
#### 5 min. Return and repair

Return day 61's written tasks: s04-P61-1, s04-P61-2, s04-P61-3, s04-P61-4, s04-P61-5, s04-P61-6, s04-P61-7. Use the existing private cue and repair time.

Return day 61's exit tickets, practice pages and checked source logs. Review Return and repair: one priority. If day 61's exit showed error B or S, use [[s04-P62-5]]: activity evidence supports tool care, not happiness. For error A compare imagined versus witnessed access, then retry [[s04-P62-6]] independently. Everyone receives a written cue; no public child examples. Review firsthand participant evidence and secondhand explanation from grade 3 day 73.

#### 8 min. Teaching first
Whole class: review source-sourcing from grade 3 day 126: maker, date, audience, purpose. Explain recorder and adapter as later people preserving or summarizing earlier words. Our adaptation date is not the old document date.

Read the prologue summary, then [[s04-P62-1]]. Columbus reported the voyage; Las Casas later recorded an abstract. Show the separate park-history summary for [[s04-P62-2]]; it explains past events through later research. Do not claim either source speaks for everyone.

Model one field on each separate card: [[s04-P62-7]], then [[s04-P62-8]]. Ask before revealing the teacher answer. Never combine the fields into a completed letter record.

#### 17 min. Clue work
First five finish one opening repair, including a fresh independent retry if needed. Others match the separate maker/date cards without a combined record.

Introduce internal clue: evidence inside the source. **Ask.** [[s04-P62-3]] Expect dock crews, supported by the addressed words. **Ask.** [[s04-P62-4]] Expect tracking supplies or arranging replacement lids, supported by stored barrels or the replacement request. Model possible purpose, not certainty from a title. Children answer independently, then fifteen parallel pairs each explain one clue for 45 seconds, 90 seconds total. Review logs from day 19; use [[s04-P62-9]], leaving other fields blank. Collect logs for ungraded feedback; return them on day 63.

#### 5 min. Question board
Review the board routine from day 60. Group C's six each explain one existing clue choice for 45 seconds: 4.5 minutes total. Public pass allowed. Record how inside evidence helps sourcing. Collect all pages for written feedback; cover teaching cards before exit.

#### 5 min. Exit ticket
Reveal the rope-letter master only now. Individually answer [[s04-X62-1]] and [[s04-X62-2]] in its blank cells; neutral reading or child-directed dictation available. After class allow thirty times ninety seconds, 45 minutes, for papers and component records. Use shown, shown with help, not yet seen separately for maker/date and each clue-supported inference. All papers return on day 63.
