# Day 41 teacher-only answer key

Keep this sheet separate from every student packet.
Use one scale per component: shown; shown with help; not yet seen.
Access support is separate from content help. No points or totals.

Record columns: assigned route; repair components; exit judgment; exit map evidence; access/help; speaker names; next step. Only the assigned route is marked.

## C1-K41-1

Key: triangles mark hills; waves mark water. Repair this record: triangles mean water.

Triangles mark hills in the supplied teaching key.

Teaching sequence: Read this key: triangles mark hills; waves mark water.; Match the record to the key.; Replace water with hills.

Samples, first shows the component, second needs work: Triangles mark hills in the supplied teaching key. | Triangles mean water.

Wrong: Triangles mean water. Error A. The supplied teaching key says hills.

## C1-K41-2

Each bar represents 50 kilometers. Repair this record: 3 bars mean 3 kilometers.

Each bar is 50 kilometers; 3 bars represent 150 kilometers.

Teaching sequence: Read 50 kilometers on each bar.; Add 50+50+50.; Write 150 kilometers.

Samples, first shows the component, second needs work: Each bar is 50 kilometers; 3 bars represent 150 kilometers. | 3 kilometers.

Wrong: 3 kilometers. Error M. Count represented units, not bars.

## C1-K41-3

Repair this made-up grid record: latitude first means a column number.

Latitude is read from the north/south margin; longitude from the east/west margin. The point is their crossing.

Teaching sequence: Read the north/south label first.; Read the east/west label second.; Follow both lines to their crossing.

Samples, first shows the component, second needs work: Latitude is read from the north/south margin; longitude from the east/west margin. The point is their crossing. | Latitude is the column number.

Wrong: Latitude is the column number. Error G. Use the labeled margin, not a letter-grid habit.

## C1-K41-4

Repair this made-up claim: a path map proves the garden smells nicest.

A path map shows paths; it cannot establish nicest smell.

Teaching sequence: Identify what the map records: paths.; Identify the claim: a preference about smell.; Keep the claim separate from the map evidence.

Samples, first shows the component, second needs work: A path map shows paths; it cannot establish nicest smell. | A path map proves nicest smell.

Wrong: A path map proves nicest smell. Error C. The source does not record that preference.
