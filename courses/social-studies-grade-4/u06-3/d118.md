# Day 118: Western map categories

## Teacher page
### Before class
Prepare day 117 returns. Print student pages, practice-118-park and practice-118-site. Use practice-118 as an annotation master. Cover cards-118's river sentence and water image; use only park, site and made-up landmark text. Withdraw completed layers. Trace the park outline for lake annotation. Hold all Washington sources. Trace the exit response boundary and calibration bar onto half slips. Keep keys separate; use generated item keys for marking.

### The day
#### 5 min. Return and repair
Return day 117's exit and practice, including physical and climate annotations and retry. Review Return and repair. If many showed error F, use [[s06-R118]] as a Mescalero reminder. Error E revises one practice key. For error S, reread cards-117's statement that the army forced movement; correct the practice date label. Give one priority; further needs use the first five Layer work minutes.

#### 5 min. Recall checklist
Review the four-part map card and physical feature. Withdraw completed layers; supply only a blank checklist: title, direction, scale, key, source-based location. No model is shown. Read selected cards-118 text. Draw a made-up coast-rock silhouette; it identifies no real rock. Crater Lake is a water feature; its national park is a protected place. Fort Clatsop is the historic-site example.

#### 18 min. Layer work
Independently answer [[s06-P118-1]] from park, site and made-up rock examples. Use [[s06-P118-2]] to annotate the lake locator on its own outline. Keep categories separate; no four-category inset is practiced. Sources locate features; pictures alone do not determine categories. Hear six different children, 45 seconds each, 4.5 minutes within work. Use practice prompts; record names. All submit paper; public passing is allowed. If many list unlocated names, compare one annotation with its source position before revision.

#### 10 min. Exit ticket
Cover practice. Reveal exit-118-stimulus now. Children complete [[s06-X118]] on the traced half-slip response using four held source layers. Add conventions, including a scale label matching the calibration bar. Read neutrally; accept exact dictated locations. Do not show a model. Collect responses.

#### 2 min. Close
Collect layers and checklist. Tomorrow returns one map gap and begins fresh regional and familiar-place records.

### Other rooms
No printer: trace supplied outlines at matching size. Use selected printed evidence instead of live pages. Keep the held water source separate.

### At home
**Swap.** No printer: trace matching outlines; copy the blank checklist.
**Skip.** Public observations.
- **5 min. Return and repair.** Return day 117 paper. Repair one component.
- **5 min. Recall checklist.** Cover completed work. Read only selected park, site and made-up landmark text.
- **15 min. Layer work.** Use [[s06-P118-1]] and [[s06-P118-2]] independently.
  **Say.** "Which source supports the historic-site label?" Expect: the Fort Clatsop source.
- **10 min. Exit ticket.** Cover practice. Reveal held Washington sources. Your child completes [[s06-X118]] independently.

### Shorter or longer
Shorter: omit public observations. Longer: compare one annotation with its source position and category.

### Words and supports
Review physical feature, legend, map-scale and day 25's landmark word. A landmark helps identify a place. A historic site preserves evidence of history. Read neutrally; enlarge source and response together. Exact dictation preserves choices.

### Tomorrow
Mark thirty packets at one minute each, thirty minutes after class. Use shown, shown with help, not yet seen per component. Day 119 returns day 118's exit and practice during Return and retrieve. Error E mismatches symbols; error L guesses locations; error R lists features. Repair one combined gap in six minutes. Remaining needs go to day 121, without coaching day 120's independent revision.
