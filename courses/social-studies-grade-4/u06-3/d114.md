# Day 114: Northeast map layers

## Teacher page
### Before class
Print cards-114 and student pages. Cover the bar comparison's answer labels until responses finish. Use practice-114 as an annotation master, without duplicating prompts. Trace the held response boundary and calibration bar onto half slips at source size; omit its printed footer to leave conventions space. Hold exit sources. Keep keys separate; use generated item keys for marking. Prepare day 113's practice, retries and exit returns.

### The day
#### 5 min. Return and repair
Return day 113's exit tickets and written tasks: s06-X113a, s06-X113b, s06-P113-1, s06-P113-2, s06-R113-D, s06-R113-O, s06-R113-P. Review Return and repair: one priority. If many showed error L, use [[s06-R114]]. Error N uses [[s06-F114]]. Review independence, declaring separation, and ratification, formal constitutional agreement, from days 88 and 112. Further needs use the first five Layer work minutes.

#### 7 min. Recall map parts
Review grade 3's four-part map card: title, legend, north arrow, scale bar. Review physical feature: a land or water place that nature made. A compass rose gives directions. Introduce layer: a map sheet showing one information kind. Review map-scale; align source and response boundaries before copying. Supply an empty square: count east from its lower-left corner, then north. This procedure supports later grids.

#### 18 min. Layer work
Review Boston as a source-location reminder from day 113. Children answer [[s06-P114-1]] with the covered-label bars, then [[s06-P114-2]] on a separate traced capital outline. Add a matching key there; keep size proofs separate. No complete inset is modeled. Hear six individual component observations, 45 seconds each, within work: 4.5 minutes. Use the practice prompts; record names. Public passing is allowed. Everyone submits paper. If many confuse symbols, match one mark with its key before revision.

#### 8 min. Exit ticket
Cover practice. Reveal exit-114-stimulus now. Children use its cities, water and land sources for [[s06-X114a]] on the half slip. The response boundary and calibration bar retain source size. Children add title, direction, scale label and key. Put [[s06-X114b]] in the student Exit box. Read neutrally; a scribe records choices without coaching. Collect both pieces.

#### 2 min. Close
Collect practice for feedback. Return to the question board: maps need located evidence. Tomorrow uses a Southeast water layer.

### Other rooms
No printer: trace supplied outlines and bars at matching size. Keep held sources separate. Printed evidence replaces live pages.

### At home
**Swap.** No printer: trace supplied boundaries and bars at matching size.
**Skip.** Public observations.
- **5 min. Return and repair.** Return day 113 paper. Use one assigned retry.
- **7 min. Recall map parts.** Read the map card together.
- **15 min. Layer work.** Cover answer labels. Use [[s06-P114-1]], then [[s06-P114-2]].
  **Say.** "How must a bar change when its map doubles?" Expect: double together.
- **8 min. Exit ticket.** Cover practice. Reveal the held sources. Your child completes [[s06-X114a]] and [[s06-X114b]] independently.

### Shorter or longer
Shorter: omit public observations. Longer: compare source and response boundaries before checking conventions.

### Words and supports
Review legend, physical feature, capital and map-scale. Layer means a map sheet showing one information kind. Read labels aloud; enlarge source and response together. Dictation preserves paper choices.

### Tomorrow
Mark thirty packets at one minute each, thirty minutes after class. Use shown, shown with help, not yet seen per component on record. Day 115 returns all paper. Error E mismatches symbols; error Q keeps an old bar; error R lists unlocated features. Choose one opening priority; finish others in Layer work.
