# Day 115: A Southeast water layer

## Teacher page
### Before class
Print cards-115 and student pages. Use practice-115 as an annotation master. Trace practice-115-water's outline for student work. Prepare a separate practice key: a wavy line means river. Trace held response boundaries and calibration bars onto half slips at source size. Hold exit sources. Keep keys separate; use generated item keys for marking. Prepare day 114 returns, including its scale Exit box.

### The day
#### 5 min. Return and repair
Return day 114's exit tickets and written tasks: s06-X114a, s06-X114b, s06-P114-1, s06-P114-2, s06-R114, s06-F114. Review Return and repair. If many showed error E, use [[s06-R115]]. For error Q, compare practice-114-bars, yesterday's original and doubled bars. For error R, locate one practice mark from its source. Each child repairs one priority. Further needs use the first five Layer work minutes.

#### 5 min. Recall source transfer
Review source-sourcing: maker, date, audience and purpose, from grade 3. Name the classroom layer's maker, Curio Class; geographic data makers appear in source-index. The classroom map is undated, for students, to locate features. Review the four-part map card. Read only the Chattahoochee teaching source; keep the exit arrangement hidden.

#### 20 min. Layer work
Children independently complete [[s06-P115-1]] on the water outline. Give the separate wavy-line key for [[s06-P115-2]]. Keep key proof separate from geographic transfer. Preserve western-border relationships; do not guess from a name. Hear a different six children for 45 seconds each, 4.5 minutes within work. Use the practice prompts; record names. Everyone submits paper; public passing is allowed. If many misplace the line, align matching boundaries before revision.

#### 8 min. Exit ticket
Cover practice. Reveal exit-115-stimulus now. Children complete [[s06-X115]] using its city, water and land layers. They add conventions on the traced half-slip response. The calibration bar matches the source bar; children label its distance. Read without hints. A neutral scribe records chosen locations. Collect responses for feedback, not portfolio scores.

#### 2 min. Close
Collect separate layers. Tomorrow distinguishes resources from farming and processing.

### Other rooms
No printer: trace source and response at matching size. Copy the separate key. Printed attributed sources replace live pages.

### At home
**Swap.** No printer: trace supplied outlines at matching size.
**Skip.** Public observations.
- **5 min. Return and repair.** Return day 114 work. Repair one component.
- **5 min. Recall source transfer.** Read the teaching source together.
- **17 min. Layer work.** Your child completes [[s06-P115-1]] and [[s06-P115-2]].
  **Say.** "Where does the source place the water line?" Expect: beside Georgia's western boundary.
- **8 min. Exit ticket.** Cover practice. Reveal held sources. Your child completes [[s06-X115]] independently.

### Shorter or longer
Shorter: omit public observations. Longer: compare source and response boundaries around the water line.

### Words and supports
Review legend, map-scale and physical feature. Read labels neutrally. Enlarge source and response together; offer tactile boundaries and exact dictation.

### Tomorrow
Mark thirty packets at one minute each, thirty minutes after class. Use shown, shown with help, not yet seen per component. Day 116 returns all paper. Error E mismatches keys; error L guesses locations; error Q mismatches map and bar. One priority uses the opening; others use Layer work.
