# Day 81: Kinds of growth

## Teacher page
### Before class
Set out cards-081.md, practice-081.md master, record.md, question-board.md, source-log.md, growth-map.md, timeline.md and teaching-locator.png. Return day 80 papers with one private cue. Keep teacher-key.md, current generated keys and exit-081-sources.md adult-only. Hold exit-081.md and exit-081-stimulus.md separately until Exit ticket; trace verified outlines if needed.

### The day
#### 5 min. Return and repair
Return day 80's exit, practice and question-board papers. If more than a third show error U, model timed log versus cover color, then assign [[s05-F81-1]]. For error L, use [[s05-F81-2]] with the made-up yard plan. Retrieval gaps use [[s05-F81-3]] or [[s05-F81-4]]. Choose one priority per child. Few misses: small group; others read their written cue. Never stack meetings.

#### 8 min. Teaching first
Explain territory as land under a government's control, distinct from state membership. Use [[s05-K81-1]] before explaining: admission means joining as a state. Purchase transfers a government's claim for payment. Annexation adds land to claimed control; treaty means agreement between governments. None alone proves residents agreed. Review homeland before showing political outlines.
Read separate cards: Louisiana, purchase, 1803; Oregon, boundary agreement, 1846; Alaska, purchase, 1867; Hawaii, annexation, 1898; Puerto Rico, war and treaty transfer, 1898. Present these separately, without a completed location/date/method grid. Model pointing to Alaska on the locator, then cover it before the date match. Keep the exit locator unseen.

#### 17 min. Map work
First five minutes finish the priority repair; cover the model before the assigned F81 response. Review cardinal directions, legend and map scale. With north up, left is west. Measure the invented bar only: each whole bar means 30 kilometers. Children first answer [[s05-P81-1]] and [[s05-P81-2]]; discuss west and 60 kilometers afterward. Never measure the historical locator.
Review timeline: equal gaps mean equal years. Children use [[s05-P81-3]] for two separate date matches, then place one card on timeline.md. Use [[s05-P81-4]] separately on Growth Map notes. Fifteen pairs each take 45 seconds per child, 90 seconds total, pointing to their one region. Review source log: record maker, date and detail. No combined four-region response.

#### 5 min. Question board
Review the board's borders question. Six new volunteers read one map or date match, 45 seconds each, 4.5 minutes. Passing is allowed. Record names; collect every child's papers. Day 82 returns all work with private feedback.

#### 5 min. Exit ticket
Cover models. Reveal exit-081-stimulus.md and the half slip. Read this new source orientation: "Vermont lies between New York and New Hampshire." Children independently answer [[s05-X81-1]] and [[s05-X81-2]]. The first mark belongs on the source map. Neutral reading or exact dictation is access. After class allow thirty minutes for thirty exits, plus fifteen for practice and board papers. Use shown, shown with help, not yet seen; retrieval remains ungraded.

### Shorter or longer
Shorter: one date match; protect repair and exit. Longer: explain why a map needs a maker.

### Words and supports
Review homeland, directions, legend, timeline and source log. Define new status words separately. Read labels neutrally; distinguish language support from content help.
