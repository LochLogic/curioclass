# Day 99: Linking gains and effects

## Teacher page
### Before class
Prepare student pages, blank branches.md and sealed exit pieces. Keep teacher-key.md, current generated key and exit-099-sources.md adult-only. Bring all day 98 work. Use cards-099.md as a master. Cover completed causal organizers; retain blank headings and nonreserved notes. The bridge case stays sealed until the exit.

### The day
#### 5 min. Return and repair
Return all day 98 written tasks, repairs, source logs, maps and tickets. Review Return and repair: one priority. If many day 98 tickets showed error A, use [[s05-F99-1]]; error H uses [[s05-F99-2]]. Say these cases are made up. More than a third means whole class; otherwise small group. Others use written cues.

#### 5 min. Recall criteria
Review cause: helps explain why something happens; effect: a change that follows. Review grade 3's cause-effect chain: Because ___, they moved ___. Afterward ___. Review reasoning: how a detail supports a claim. Retrieve criteria from checklist.md, without a worked chain. A date places an event; it cannot explain the mechanism by itself.

#### 20 min. Link work
First five minutes finish the priority repair with fresh [[s05-F99-3]] or [[s05-F99-4]]. Alone, read the two separate summaries. Use [[s05-P99-1]] and [[s05-P99-2]], each on its own branches.md record. Consult earlier map and timeline notes only as reminders. Review source-log.md: maker, date, detail and question. Annotate a supporting detail and a limit for each single arrow. Do not combine them into an argument. If many arrows merely repeat dates, return to the action changing access or control; leave the other link independent.

#### 5 min. Question board
Review question-board.md. **Ask.** Which detail supports your existing link? Six rotating children may read one annotation, 45 seconds each, 4.5 minutes total. Record names; passing is allowed. Collect everyone's annotations, repairs and board notes, including those not heard.

#### 5 min. Exit ticket
Cover practice. Say the River Crossing records are made up. Reveal exit-099-stimulus.md and exit-099.md. Children answer [[s05-X99-1]] independently on paper. Read neutrally or scribe exactly. After class allow thirty minutes for thirty tickets, one minute each, plus fifteen for other papers. Review record.md's component scale: shown, shown with help, not yet seen. Return all work day 100.

### Other rooms
No printer: copy the short summaries and blank arrow headings. Trace the exit picture separately and keep it covered. No projector: point to paper. Printed records replace live pages.

### At home
**Swap.** Copy texts and blank headings if printing is unavailable. Trace the bridge picture separately.
**Skip.** Public turns and repeated sharing.
- **5 min. Return and repair.** Return day 98 papers; select one repair.
- **5 min. Recall criteria.** Review cause, effect and supporting evidence.
- **20 min. Link work.** Finish the matching fresh retry. Your child completes [[s05-P99-1]] and [[s05-P99-2]] on separate records.
  **Say.** "Which action changed the national claims?" Expect: the Oregon boundary agreement.
- **5 min. Exit ticket.** Cover practice. Say the new bridge records are made up. Reveal them with [[s05-X99-1]]. Your child answers alone; discuss afterward.

### Shorter or longer
Shorter: reduce public sharing. Keep both separate links, repair and exit. Longer: identify what one source cannot establish.

### Words and supports
Review treaty: agreement between governments; purchase: paying for another government's claim. Read neutrally; allow exact dictation and home-language rehearsal. No personal reports.

### Tomorrow
Day 100 supports claims using source details. Return all day 99 papers. Error H gives only a date; error O reverses event order; error R treats unequal effects as equal. Use one isolated link, ordering or group-effect repair, then a fresh retry in Closing work.

### Credit
Ours. Original historical summaries use Sources s05-OR and s05-AK. Bridge records and all repairs are made up.
