# Day 156: Drafting a proposal

## Teacher page
### Before class
Prepare cards-156 directions, integrated proposal-sheet fields, evidence-sheet columns and feedback-sheet cues. Read opener and teacher-key; use current generated answers. Return day 155 papers privately. Print the short FL2/JP summaries on Side 2. Hold the exit back.

### The day
#### 10 min. Return and repair
Return day 155's s07-X155, s07-X155b, s07-RET155, s07-P155 and s07-F155. Review Return and repair. If many showed error H, liking as evidence, compare [[s07-K156-R]] for five minutes, then everyone attempts fresh [[s07-F156]] for five. Otherwise meet up to six while others follow written cues. Error R gets a private source-label reminder. Collect retries for day 157.

#### 5 min. Plan components
Review proposal, a plan the class could try, and sourcing: who made it, when and why. Using [[s07-P156]], children independently label reader, chosen hazard, supporting detail and unresolved limit on proposal-sheet fields. Keep cards-156, evidence-sheet and locator nearby. Say the school cases are made up; actual local advice stays unknown.

#### 21 min. Draft
Children draft alone. Review policy-headings: fill only documented stages; mark other stages unknown. Review Florida/Japan records separately, never as a paired comparison. Select one applicable principle and state a local difference. A school message request is not housing reconstruction or a statewide code. Review feasibility: fit authority, time and means. Teacher confers by component without supplying sentences; children retain their choices. Review question-board: keep the request tied to a public need. Collect drafts unscored. After class, allow thirty drafts times two minutes, sixty minutes, for private feedback-sheet cues on evidence, policy, location/authority, challenge/opportunity and feasibility. Return before revision tomorrow.

#### 4 min. Exit ticket
First reveal [[s07-X156]] alone on a half-slip; say it is made up. Three minutes independent, one to collect. Read neutrally or scribe exactly. After class, thirty times forty seconds, twenty minutes. Use record's sole scale: shown, shown with help, not yet seen. Return exit and draft feedback on day 157.

### Other rooms
Copy the brief sources and blank fields. No live advice page or screen is required.

### At home
**Swap.** Copy records and proposal fields onto paper.
**Skip.** The class board and public sharing.
- **10 min. Repair.** Return day 155 work. Compare [[s07-K156-R]], then try [[s07-F156]].
- **5 min. Plan.** Your child labels the chosen reader, need, detail and limit.
- **21 min. Draft.** Complete [[s07-P156]] independently, using one record at a time.
  **Say.** "Which detail supports this request?" Expect a source detail connected to the chosen need. Write a private cue for each checklist component afterward. Save it for tomorrow.
- **4 min. Exit ticket.** Give [[s07-X156]] before its answer. Keep every paper.

### Shorter or longer
Trim recopying, not source reasoning or feedback. Longer: name another consequence needing evidence.

### Words and supports
Review challenge, difficulty, and opportunity, a possible improvement. Review feasibility and sourcing. Allow exact dictation and enlarged lines; assess ideas separately from language fluency.

### Tomorrow
Day 157 revises the draft after written feedback. If many show error Q, limits prevent progress, use five Read feedback minutes and the first five Revise minutes for a fresh component repair. Return all day 156 papers; retain fifteen minutes for independent revision.

### Credit
Ours. Original summaries and made-up cases; factual source records are in sources.csv.
