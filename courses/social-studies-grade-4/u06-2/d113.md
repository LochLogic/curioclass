# Day 113: Public places and public records

## Teacher page
### Before class
Print cards-113 with work-113, practice-113, record, source-index and student pages. Trace work-113's boundary into side 2's response box at matching size, omitting dots and names. Keep readable source labels at 14 point. Hold exit-113-stimulus and exit-113. Keep teacher-key and generated item keys separate; use the fuller generated practice keys. Prepare day 112 returns. Everyone may use the supplied Massachusetts public-state case; no local visitor or live page is needed.

### The day
#### 5 min. Return and repair
Return day 112's exit tickets and day 112's written tasks: the function matches, historical claims, source examples and assigned retries. Return the optional challenge if completed. Review Return and repair. If many showed error D, assign [[s06-R113-D]]; error O uses [[s06-R113-O]]; error P uses [[s06-R113-P]]. Each child takes one fresh paper retry. Complete another need in the first five Local work minutes; others start source labels independently.

#### 5 min. Recall sources
Review source-sourcing: maker, date, audience, purpose, from grade 3. Read Work Strip A and its source label aloud. It serves public-place study, without home reports. Review capital, where government meets, from day 108. Use Boston and Worcester as public places, regardless of where anyone lives. Record B stays covered. Review ratification's meaning from day 112 without giving its held local date or comparing event records.

#### 20 min. Local work
Children use [[s06-P113-1]] to transfer two public-place dots onto the supplied blank outline. Consult A throughout; locate the state on its labeled reference. Then complete [[s06-P113-2]] on practice-113. Copy its source label's maker and link; add date, audience and purpose in the student table. Map reading gets about ten minutes. Hear six individual source-location observations, 45 seconds each, during independent work. Record names; children may pass publicly. All children submit paper for feedback. Do not rehearse region/date completion or an independence/ratification comparison.

#### 7 min. Exit ticket
Cover A and practice. Reveal exit-113-stimulus, the supplied Massachusetts Record B, now. Review region from day 107 by reading B's own classroom grouping key. Children complete [[s06-X113a]] and [[s06-X113b]] on the half slip; no admission-card placement is added. These tasks use B's dated records, not A's geography. Read neutrally; record dictated answers exactly. Collect all paper for after-class marking and return on day 114.

#### 3 min. Close
Collect maps and source cards as practice, not scored portfolio work. Add the public-state card to the unit folder after feedback. Tomorrow builds map layers using sources.

### Other rooms
No printer: trace source and response boundaries at matching sizes. Copy A's label and hold B separately. The printed public-place case replaces unavailable local sources.

### At home
**Swap.** No printer: trace matching outlines and copy the source label.
**Skip.** Six public observations.
- **5 min. Return and repair.** Return day 112 paper. Use one assigned retry.
- **5 min. Recall sources.** Read A and its source label.
  **Say.** "Who made this map?" Expect: Curio Class, using credited public geographic data.
- **18 min. Local work.** Use [[s06-P113-1]] on side 2. Complete [[s06-P113-2]] on practice-113 and fill the source table. Point to each source detail together.
- **7 min. Exit ticket.** Cover A and practice. Reveal Record B. Your child answers [[s06-X113a]] and [[s06-X113b]] alone.

### Shorter or longer
Shorter: omit public observations. Longer: explain which A detail supports each public-place dot.

### Words and supports
Review source-sourcing, capital, region and ratification. Review day 88's independence: declaring separation from another country. Read labels neutrally; supply enlarged matching outlines. A scribe marks only the child's chosen position. No personal-location report is required.

### Tomorrow
After class, mark thirty packets at 45 seconds each, 22.5 minutes outside the lesson. Use shown, shown with help, not yet seen per component on record. Day 114 returns day 113's practice and exit in Return and repair. Error L checks B's region key; error N separates independence from constitutional agreement. Choose one priority and fresh retry; further needs use the first five Layer work minutes. Construct Northeast map layers next.
