# Section 3.5 opener

## What this section does

Days 55 to 59, forty minutes each. Day 55 organizes taught evidence. Day 56 repairs two supplied linked paragraphs under a given method claim. It does not rehearse a complete independent argument. On56 reduce the frame to headings. Day57 retrieves isolated components without drafting, revising or editing. Keep all assessment evidence and response cards unseen. Give no content repair on 58; access supports are neutral. On59 use four sequential five-minute groups, then a fresh paper component for every child.

## Before class

Print the named masters below and teacher-key.md. Keep keys separate. Every teaching day uses `exit: half`, thirty paper slips. Use the source records and local photos, never a live visit as a hinge. Dates without a supplied source date stay undated. Read original captions neutrally. Do not show completed check answers or held photographs early.

## Errors and repair

Priority letters: F/G/H/I/E/B/N. Use the unit record and teacher key. One scale: shown, shown with help, not yet seen. Keep each component separate; never total labels. Access supports are not content help. Blank means unobserved, not failure. Record content prompting.

Return each exit next day, except 57 returns for content repair on 59. Five Return and repair minutes plus the first five work minutes hold one priority per child. Alternatives share these slots. If more than ten of thirty miss, use the contrast with the class; otherwise meet the priority group while others follow written moves. Retry a fresh partial component. Papers and written moves reach everyone.

## Talk and safety

Six single 45-second adult asks take 4.5 minutes. Rotate names on the record; a public pass is allowed. Fifteen parallel pairs need 1.5 minutes for one turn per child. Never queue thirty explanations in five minutes. All judged responses here are paper or child-directed scribing; there is no deferred oral scoring queue.

Do not request ancestry, family history, money, religion, bodies or immigration status. Do not ask a child to represent a nation. No sacred stories, designs, interiors, burials, human remains, real digging, artifact handling or identity role play. Invented situations are made up, never invented Native people or nations.

## Other rooms and source fallback

No devices: share teaching print and give each child a response page. No printer: draw teaching schematics, clearly labeled illustrations, and hand-copy stems. Photograph checks still use these locally saved photographs, enlarged if needed; never silently replace a photo with a drawing. If a display fails, use individual print. If a web page changes, use these original sourced public summaries. Neutral image descriptions name visible shapes only. At home one adult reads neutrally and keeps held cards covered.

## What to keep

Children retain logs and practice in folders. Teacher holds reserved envelopes and the private record. Handbacks.csv names the receiving day and protected part. Shared print need not be recopied each day. Assessment evidence returns on day 59; retry feedback returns on day 60. Unresolved components remain named in the folder.

During day 59 Reflection inspect six fresh papers, 45 seconds each. Give the others a printed cue for identifying a relevant detail, without self-scoring. Mark the remaining papers after class. Return all retries with one private written move during the first minute of day 60 Return and repair.
