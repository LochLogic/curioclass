# Day 54: Protecting evidence and its context

## Teacher page

### Before class
Read the keys; use today's data key for s03-X54a. A written location record can survive removal. Keep s03 exit 54 covered. Retrieve s03 site practice and s03 preservation practice. Return day 53 papers with one priority cue. Select six unheard names on s03 record. The inventory and visitor action are made up; no objects are handled.

### The day

#### 5 min. Return and repair
Return all day 53 papers, including every written task. If many day 53 tickets showed error P, use [[s03-P54-R]] together. Error G gets [[s03-P54-R2]] instead. Otherwise meet the priority group; others revise returned author labels. Review the difference between visible form and a maker's identity. Finish in Preservation work's first five minutes.

#### 5 min. Recall preservation
Review preserve, descendants and archaeological context from day 52. Context includes recorded position and relationships; source-setting context also includes maker and audience. Recall earlier Native communities belong in American history and living nations continue. Refer to the taught source labels without composing a combined two-site account. Nothing new is introduced.

#### 20 min. Preservation work
First five minutes finish priority repairs. Children independently check the unchanged inventory with [[s03-P54a]]. Compare each object label with its recorded square and layer. Review day 43's careful-record routine. Keeping an accurate record lets another person check an interpretation. Do not introduce a removal scenario.

Put the inventory aside. Pairs consult taught notes, then each child corrects [[s03-P54b]] and [[s03-P54c]] independently. Source 42B supplies earlier farming communities and living descendants; Source 47A supplies attributed Osage history. Keep the two corrections separate, not a two-site essay. A stronger correction includes a sourced detail rather than simply reversing the statement.

Address error M with earlier Native history; error G with living communities. For error F, return to complete, unchanged location records and careful care. Collect all pages for descriptive feedback. Do not ask about a child's family, ancestry or beliefs.

#### 5 min. Question board
Review the board routine. Partners each explain one correction for 45 seconds, 1.5 minutes in parallel. During this block hear six staggered single 45-second turns, 4.5 minutes; public pass allowed. Continue repairs instead if needed. Everyone submits corrections. Post one preservation reason drawn from the taught notes.

#### 5 min. Exit ticket
Reveal s03 exit 54's invented visitor action and separate descendant statement: [[s03-X54a]] [[s03-X54b]]. Each child answers independently on paper. A person's role may identify whom the child means. After class allow 30 times 35 seconds, 17.5 minutes, plus ten minutes for practice feedback. Record shown, shown with help, not yet seen per component, access support separately. Return all papers on day 55.

### Other rooms
No screen: use retained print. No printer: copy the unchanged inventory and separate exit case onto paper. Preserve all square/layer labels. There is no real digging, collecting or artifact handling.

### Shorter or longer
Shorter: omit public sharing, keeping inventory, both corrections and exit. Longer: add a second sourced detail to one correction without writing a combined site account.

### Words and supports
Review preserve, descendant and archaeological context. Read labels neutrally. Accept oral rehearsal before independent writing, or child-directed dictation. No child speaks as a Native person or represents a nation.

Return all day 54 papers in Return and repair and Evidence work's first five minutes. More than ten misses: shared priority repair; otherwise a group.
