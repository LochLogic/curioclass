# Day 28: Present a finding

## Teacher page

### Before class
Read opener.md, teacher-only key-exits.md and the generated answer key. Prepare the named print pieces and thirty seated finding slots on speaking-roster.md. Bring day 27 papers and written draft cues. Student page incorporates practice-28.md and today's listener-slips.md fields. Keep exit-28.md and moss-town.svg hidden. Retain source-log.md, topic-notes.md and report-frame.md in individual folders; display question-board.md.

### The day
#### 5 min. Warm-up, Return and repair
Return day 27's s02-X27, s02-P27, s02-P27-R and s02-P27-S with written feedback. If many showed error C, preference as proof, use [[s02-P28-R]]. For error L, checkable treated as true, use [[s02-P28-B]]. For error D, unsupported evidence, trace one own-draft source detail. These classroom records are made up. Review opinion: a liking is not a reason. Choose one priority only; finish it during Listener work. Others locate sources silently.

#### 3 min. Prepare to listen
Review finding: an answer supported by research evidence. Review listener question in grade 2's words: a question asking where a fact came from, "Which page says that?" First two minutes: pairs ask one question each and answer for 45 seconds each, simultaneously. Record [[s02-P28q]] during the later silent work. Last minute: open sources and assign finding slots. Public passing becomes a private desk response, within the same slot.

#### 25 min. Present findings
Use [[s02-P28]]. Teacher visits seated children in roster order. Thirty times 45 seconds is 22.5 minutes, leaving 2.5 minutes for transitions and roster marks; use neighboring desks. Each child names a finding, source and supporting detail. Record a brief evidence cue and content/access help. Others silently finish listener records and source checks. No extra questions enter this queue. Use signing, pointing with explanation or an aid in the same slot; keep the same look-fors. Findings receive feedback, not final judgments.

#### 5 min. Listener work
Finish the day 27 priority with the repair group; others complete their own s02-P28q records. Collect every student page and finding cue. Revisit the question-board.md research question without another speaking queue. Write one oral-feedback cue before day 29. After class allow 30 times one minute, 30 minutes, for listener records and oral cues.

#### 2 min. Exit ticket
Reveal exit-28.md and its map, exactly [[s02-X28]]. Everyone writes independently. Neutral reading or dictation is available. Collect all half slips; mark afterward, 30 times 30 seconds, 15 minutes. Use shown, shown with help, not yet seen for each component, recording access separately.

### Other rooms
Use retained paper sources and the incorporated listener fields. Copy the exit map only onto the hidden half slip. No recording device is needed.

### At home
**Swap.** No copies: copy today's blank listener fields and hidden exit map.
**Skip.** Class roster and waiting for other speakers.
- **5 min. Return.** Read feedback; use [[s02-P28-R]] or [[s02-P28-B]] for one priority.
- **5 min. Prepare.** Find the source for one finding.
- **10 min. Present.** Complete [[s02-P28]]. **Say.** "Which page says that?" Expect a relevant source detail. Your child records [[s02-P28q]].
- **12 min. Listener work.** Finish the record and priority repair. Write one helpful cue for tomorrow.
- **3 min. Exit ticket.** Reveal [[s02-X28]]. Your child answers alone; discuss afterward.

### Shorter or longer
Shorter: omit optional board sharing; preserve every finding slot. Longer: locate a second source detail supporting an existing finding.

### Words and supports
Review source, finding and listener question. Sources stay open; allow neutral reading, enlargement or dictation. Judge evidence separately from speaking fluency.

### Tomorrow
Day 29 uses written report and oral feedback before revision. Return s02-X28, s02-P28, s02-P28q and both repair papers. Error D, a statement contradicted by its map, gets one fresh symbol/source repair within Read feedback and repair's five minutes. Reports receive separate order and detail peer notes before the accuracy exit; only revised performance is judged.

### Credit
Ours. Classroom records and the exit town are made up.
