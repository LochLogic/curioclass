# Day 110: States and separate ocean views

## Teacher page
### Before class
Teacher answers: key-teacher.md, kept separate. Print cards-110, atlas-southwest, atlas-west, their reference maps and island-reference. Print only short index columns and island rows; cover reference boilerplate. Keep map titles and keys. Print student pages and half-slip exit-110; hold exit-110-stimulus and exit-110-ocean. Prepare day 109 returns, Midwest index, record and source-index. Keep teacher-key and generated item keys private. Draw a global grid: equator, zero meridian, 30-degree intervals, hemisphere directions. Show one island point at a time.

### The day
#### 5 min. Return and repair
Return day 109's exit tickets and every written task. Review Return and repair. If many showed error L, trace one index-to-map relationship with [[s06-R110-1]], then take a fresh written retry. Other misses use the first five Locator work minutes. Review capital and region while reading the supplied headings.

#### 8 min. Teaching first
Read cards-110. Review territory, land governed within a larger country, from day 81; capital district from day 109.
**Ask.** [[s06-K110-inset]]
Then reveal [[steps:s06-K110-inset]]. Insets need not be enlarged; they can show a distant area separately.
**Ask.** [[s06-K110-ocean]]
Then show [[steps:s06-K110-ocean]] on the grid. Review day 12's latitude, longitude and hemisphere notation. Adult reads decimals as rounded whole degrees; children need not compute rounding. A location dot cannot establish voting rights. Midway and Wake are territories; their separate label here distinguishes them from inhabited territories.

#### 17 min. Locator work
Children fill fifteen separate capital strips, [[s06-P110-1]], tracing each S and C mark first. Southwest is on side 1; West continues on side 2. Allow about ten minutes. During the remaining seven, read island-reference's seven rows one at a time. For each, place one labelled point on the global grid, inspect its ocean/hemispheres, then erase it. Children point and trace the source row, without a combined response map. Use [[s06-P110-2]] for Wake's status only. First five minutes permit other repairs. Hear six single 45-second observations during work; record names, allow passing. Everyone submits paper.

#### 8 min. Exit ticket
Reveal exit-110-stimulus now. Use [[s06-X110a]] and [[s06-X110b]]. Children label the mainland outline and island dots; write the explanation on the half slip. Keep reference strips available, covering teaching examples. These held ocean boxes are first seen now. Neutral reading or exact dictation preserves the paper task. Accept accurate relative locations, without requiring coordinate writing. After class, mark all work: 30 times 45 seconds, 22.5 minutes. Use shown, shown with help, not yet seen per component; return on day 111.

#### 2 min. Close
File locator notes after collection. The question board next turns to dated state records.

### Other rooms
No printer: trace supplied maps together at matching sizes. Draw the same global grid on paper; use one island point at a time. No device is needed.

### At home
**Swap.** No printer: trace supplied maps and copy the capital strips. Draw the global grid.
**Skip.** Class reports.
- **5 min. Return and repair.** Return day 109 work and use [[s06-R110-1]] if needed.
- **8 min. Teaching first.** Use [[s06-K110-inset]] and [[s06-K110-ocean]], then their explanations.
  **Say.** "Does a separate view change state status?" Expect: no.
- **15 min. Locator work.** Use [[s06-P110-1]]. Read island-reference together, one point at a time. Use [[s06-P110-2]].
- **8 min. Exit ticket.** Cover demonstrations. Reveal exit-110-stimulus. Your child answers [[s06-X110a]] and [[s06-X110b]] alone, using reference strips.

### Shorter or longer
Shorter: omit public sampling, keeping all locations and exit. Longer: verify one point's hemispheres through its source row.

### Words and supports
Review atlas, index, state, capital and map key. Supply enlarged maps and neutral reading. A scribe labels only where the child directs; content help is recorded separately.

### Tomorrow
Day 111 returns day 110's practice and exit in Return and repair. Error B connects an inset with its ocean; error L checks position; error M checks status. Choose one priority. Then build an admission-date timeline.
