# Day 109: Two more regional indexes

## Teacher page
### Before class
Print cards-109, atlas-southeast, atlas-midwest, reference-southeast-mainland and reference-midwest-mainland. Fold coordinate columns out of view. Print student pages and half-slip exit-109; hold exit-109-stimulus. Bring atlas-northeast for repair. Keep teacher-key and generated item keys separate. Prepare day 108 returns, source-index and record.

### The day
#### 5 min. Return and repair
Return day 108's strips and exit with one cue each. Review Return and repair. If many showed error K, use [[s06-R109-key]]; error L uses [[s06-R109-boundary]]. Choose one priority, with a fresh written retry. Review capital, region and political-map borders as needed. Other needs share the first five Locator work minutes.

#### 8 min. Teaching first
Review day 108's atlas and index route. Southeast and Midwest are classroom groupings containing states. Read cards-109.
**Ask.** [[s06-K109-lookup]]
Then show [[steps:s06-K109-lookup]]. Demonstrate only this one lookup, not a completed regional outline.
**Ask.** [[s06-K109-dc]]
Read the district label afterward. Washington, D.C. is the national capital district, not a state; its government study comes later. Source s06-dc supplies this distinction.

#### 18 min. Locator work
Use two nine-minute sets. Children fill the fourteen Southeast strips, [[s06-P109-1]], then twelve Midwest strips, [[s06-P109-2]]. Each time, find the S boundary mark and C capital mark before writing. About 35 seconds per entry fits each set; there is no speed score. Partners point simultaneously; nobody waits through 26 public turns. Teacher gives other repairs during the first five minutes. Each child keeps an individual response; the paired exit arrangement remains covered.

#### 3 min. Question board
Review day 107's location question. Hear six single 25-second source reports, two-and-a-half minutes total. Record names and allow passing. Everyone submits the page, including children not heard. No extra written question is added.

#### 6 min. Exit ticket
Reveal exit-109-stimulus only now. Children answer [[s06-X109a]] and [[s06-X109b]] on paper. On the fresh outline, write each state name inside its boundary and its capital beside a dot. Add its region name in the slip's corresponding response space. The index and classroom region headings remain available. Neutral reading or exact dictation preserves independence. Mark after class: 30 times 45 seconds for today's work, 22.5 minutes. Return on day 110 using shown, shown with help, not yet seen per component.

### Other rooms
No printer: trace supplied maps at matching sizes and copy short index columns. Keep held outlines separate. No device is needed.

### At home
**Swap.** No printer: trace the maps and copy the short strips.
**Skip.** Class reports.
- **5 min. Return and repair.** Return day 108 work. Choose one repair row.
- **8 min. Teaching first.** Use [[s06-K109-lookup]] and [[s06-K109-dc]]. Read explanations afterward.
  **Say.** "What does the index heading tell us?" Expect: which regional source we are using.
- **17 min. Locator work.** Use [[s06-P109-1]] and [[s06-P109-2]]. Trace separate entries together. Cover examples.
- **6 min. Exit ticket.** Reveal exit-109-stimulus. Your child answers [[s06-X109a]] and [[s06-X109b]] alone. Keep the short indexes available.

### Shorter or longer
Shorter: omit public reports, keeping all entries and exit. Longer: trace a state boundary to verify a difficult S mark.

### Words and supports
Review state, capital, region, atlas, index and map key in day 108's meanings. Enlarge maps; a neutral scribe may label where the child directs. Do not guess from print size.

### Tomorrow
Day 110 returns day 109's practice and exit. If many show error L, repair one locator relationship. Then find Southwest and West states and island locations, using status labels.

### Credit
Ours. Geographic sources and s06-dc have URLs and checked status in source-index.
