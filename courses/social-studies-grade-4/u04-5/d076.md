# Day 76: Support an emphasis with reasons

## Teacher page
### Before class
Return all day 75 papers with one priority cue. Print teacher-key.md separately. Keep exit-76.md and its map covered. Set out teaching cards 76, claim sheets, source logs, both packets, voyage map, aim-effect branches and question board. Use today's page instead of the old practice master; its historical records are real summaries, not invented testimony.

### The day
#### 5 min. Return and repair
If day 75's exit showed error I, use [[s04-P76-3]]. Error K uses [[s04-P76-4]]. Choose one priority per child, with written feedback for everyone. More than a third missing: whole-class repair; otherwise meet a group. Review relevant detail and day 67's origin check separately, never the held two-record claim.

#### 5 min. Recall criteria
Review grade 3's claim sheet and reasoning: how a detail supports a claim. Review grade 3's rule: a second source needs a different maker; two details from one book are one source. Different makers can still copy. Display blank claim, source, detail, reason and limit headings only. Cover completed models.

#### 20 min. Writing work
First five finish the repair and independently try [[s04-P76-5]] for error I or [[s04-P76-6]] for error K. Children then use [[s04-P76-1]] on lined paper. Use yesterday's Source CAMP whetstone record and Source CARTIER riches commission. No new historical source is introduced. Review already taught packet notes beside map and aim-effect branches; today's task concerns emphasis, not the assessment's change-and-continuity argument.

**Ask.** [[s04-P76-1]] Expect a supported emphasis on everyday work and voyage aims; accept other supported emphasis using these sources. Require a detail and connecting reason from each, plus a limit. Children write alone, then share in fifteen parallel pairs, 45 seconds per child, 90 seconds total. They may pass; all submit writing. No completed model is shown.

#### 5 min. Source audit
Use [[s04-P76-2]]. Review day 62's source-log headings. Children identify each institution, record and actual detail. Look for error J, titles without evidence; error W, one source counted twice; error V, an event list without a claim. Collect and cover paragraphs, claim sheets and logs.

#### 5 min. Exit ticket
Reveal the complete made-up island records and map now. Read [[s04-X76-1]] exactly. Children answer alone on the half slip. After class, allow two minutes per child for all judged papers: sixty minutes for thirty, untested. Use shown, shown with help, not yet seen; unobserved stays blank. Return on day 77.

### Other rooms
No printer: copy the two source summaries, blank headings and separate covered island records. Copy the map's houses and paths. Children still write on paper.

### At home
**Swap.** No printer: copy the taught summaries and covered exit records, including the map.
**Skip.** Public sharing and repeated partner turns.
- **5 min. Return.** Return day 75 papers. Choose one repair, then its fresh retry.
- **5 min. Recall.** Read blank claim-sheet headings.
- **15 min. Writing.** Your child uses [[s04-P76-1]] with yesterday's two sources.
  **Say.** "How does each detail change the emphasis?" Expect everyday work and voyage aims, with connecting reasons.
- **5 min. Audit.** Use [[s04-P76-2]]; check each source's origin together.
- **5 min. Exit ticket.** Reveal exit-76.md and its map. Your child answers [[s04-X76-1]] alone. Consult the private key afterward; return next lesson.

### Shorter or longer
Shorter: reduce repeated sharing; protect both paragraphs, repair and exit. Longer: explain another defensible emphasis orally.

### Words and supports
Review claim, reasoning, limit and consent. Allow oral rehearsal, neutral reading and exact dictation. Provide blank headings, never a completed claim.

### Tomorrow
Day 77 returns day 76's papers. Error N needs missing agreement evidence; error J needs a detail. Observed errors V and W need claim/detail and origin classification. Share one priority across Return and repair and Recall work's first five minutes. No prose revision on this fluency day.
