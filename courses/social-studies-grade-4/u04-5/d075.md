# Day 75: Choose useful evidence

## Teacher page
### Before class
Return day 74 papers with one priority cue. Print teacher-key.md separately. Current generated item keys govern corrected rows. Keep exit-75.md covered. Set out unit 4 teaching cards 75, claim sheets, source logs, both packets, voyage map and aim-effect branches. Prepare group A's six names and the question board. Copy today's invented repair records. Use existing source notes with today's student page.

### The day
#### 5 min. Return and repair
Pick up day 74's shared-years comparison. If day 74's exit showed error G, use [[s04-P75-4]]; error P, [[s04-P75-5]]; error T, [[s04-P75-6]]. Each child attempts only the assigned priority. More than a third missing: whole-class repair; otherwise meet a group. Return every judged paper.

#### 5 min. Recall criteria
Review grade 3's claim sheet: claim, two sources with makers, a detail from each, a limit. Review reasoning: how a detail supports a claim. Review day 67's corroboration: a copy adds nothing. Different makers still may copy. Show blank headings, without a new model. Children select the supporting question their evidence will address.

#### 20 min. Evidence work
First five finish the assigned repair with its source labels or proportional measure visible, then independently try [[s04-P75-8]], [[s04-P75-9]] or [[s04-P75-10]], matching the priority. Alone, children answer [[s04-P75-1]], [[s04-P75-2]], [[s04-P75-3]] and [[s04-P75-7]]. Expect whetstone, riches commission, copied index and the possession report. The invented copying chain is made up; historical summaries are attributed accounts.

The already taught opening Voyage Accounts report supplies Columbus evidence, giving three voyages. Review the taught Norse uncertainty: material presence does not locate an encounter. Children organize isolated details under blank claim-sheet headings. Consult already taught Voyage Accounts and Living Peoples cards, map and aim-effect branches; record source origins separately in the source log. These are reminder materials, never held exits. No full encounter explanation or change-and-continuity argument is rehearsed. Collect pages, sheets and logs.

#### 5 min. Question board
Review day 60's routine. **Ask.** [[s04-P75-3]] Group A's six explain the dependency label, 45 seconds each, 4.5 minutes. Passing is allowed. All submit paper; note six names on the component record. Point their chosen evidence toward the unit question. Cover teaching materials.

#### 5 min. Exit ticket
Reveal the complete exit-75.md only now. Say its records are made up. Read [[s04-X75-1]] exactly; children answer alone on the half slip. Mark all judged papers after class: thirty children times ninety seconds, 45 minutes, untested. Use shown, shown with help, not yet seen; leave unobserved blank. Return on day 76.

### Other rooms
No printer: copy the practice records and a separate, covered complete exit on scrap paper. Read neutrally while children write. No device is needed.

### At home
**Swap.** No printer: copy today's records and a separate covered exit.
**Skip.** The public rotation.
- **5 min. Return.** Return day 74 papers. Choose one repair question.
- **5 min. Recall.** Read the blank claim-sheet headings together.
- **15 min. Evidence.** Your child uses the four practice questions and taught packet cards.
  **Say.** "Which entry depends on the repair register?" Expect the copied index.
- **5 min. Organize.** Your child files relevant details under one supporting question.
- **5 min. Exit ticket.** Reveal exit-75.md. Your child answers [[s04-X75-1]] alone. Consult the private key afterward; return next lesson.

### Shorter or longer
Shorter: reduce extra packet browsing, keeping each practice item and repair. Longer: find a different relevant detail in a taught source.

### Words and supports
Review claim, reasoning, limit, source-sourcing, interval and simultaneous. Read neutrally; record a dictated response exactly. Public talk may be passed.

### Tomorrow
Day 76 returns day 75's papers. Error I needs relevance rather than preference; error K needs an origin check. Share one priority across Return and repair and Writing work's first five minutes. Then write and share two linked practice paragraphs.
