# Day 69: Places and different decisions

## Teacher page
### Before class
Return day 68's exit ticket and written tasks with one cue. Keep the complete exit and inset covered. Use only practice-69.md's source footer; today's page replaces its old tasks. Print the generated answer key separately. Lay out map and branch sheets. The cart record is made up. No conquest role play, sacred designs, graphic images or personal disclosures.

### The day
#### 5 min. Return and repair
If day 68's exit showed error E, use the made-up cart record and [[s04-P69-4]]. Capacity does not establish equal access. For error L, review day 66's multiple harms and use [[s04-P69-5]]; expect forced labor or violence, Source HARMS. More than a third missing: whole-class repair; otherwise meet a group while others start the page. Choose one priority.

#### 8 min. Teaching first
Introduce Cortés as a Spanish expedition leader in 1519. Conquest means taking control by force. Locate three labels separately on the accumulating map: coast, inland Tlaxcala, Tenochtitlan. Use Sources ROUTE69 and MEXICO. Tell the journey once: coast, through Tlaxcala, toward Tenochtitlan. Keep labels separate; children trace only the unseen exit inset.

Review alliance: an agreement between groups to help one another, grade 3 day 103. Teach ally, defender and siege using the page's role definitions. Source MEXICO records Spanish invasion, Tlaxcalteca alliances and resistance at Tenochtitlan in 1521. Keep named forces on separate labels. Some Tlaxcalteca leaders disagreed about alliance. Neither Cortés alone nor one Native side explains events, error Q. Never assign imagined thoughts to a community.

#### 17 min. Route work
First five finish the priority repair. [[s04-P69-6]] supplies a fresh access retry; for error L, retry [[s04-P69-5]] after feedback.

Children independently answer [[s04-P69-1]] and [[s04-P69-2]], separating a location word from role meanings. Then read the single-source disagreement note. **Ask.** [[s04-P69-3]] Expect no: the recorded disagreement defeats unanimity. No practice traces the held journey or explains all siege participants.

Fifteen parallel pairs explain that disagreement clue, 45 seconds each, 90 seconds total. Review source-sourcing from day 62: maker, date, audience, purpose. The source is an undated university exhibit for public readers; no invented publication date. Review day 68's aim-effect branches without adding a conquest explanation. Retain today's source note in the Voyage Accounts packet; collect responses and source logs.

#### 5 min. Question board
Review day 60's board routine. Group E's six explain their disagreement answer, 45 seconds each, 4.5 minutes; public pass allowed. Record names. Every child submits paper. Cover examples.

#### 5 min. Exit ticket
Reveal the complete exit-69.md and inset now. Read [[s04-X69-1]] and [[s04-X69-2]] exactly. Children trace and write independently on the half slip. After class, thirty times sixty seconds, 30 minutes, covers all judged papers. Use shown, shown with help, not yet seen per component; unobserved stays blank. Return all papers on day 70.
