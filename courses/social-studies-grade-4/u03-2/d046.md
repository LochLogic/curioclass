# Day 46: Presence and a possible journey

## Teacher page

### Before class
Read both teacher-only keys. Return day 45 exits and practice with one priority cue. Keep s03 exit 46 covered, caption included. Retain this student page as s03 migration evidence. Use its corrected place name and response spaces. Choose six unheard names on the s03 record.

### The day

#### 5 min. Return and repair
Return every written task from day 45. Review its separate crossing and passage questions. If many day 45 tickets showed error C, use [[s03-P46-R]] together; otherwise meet that group. Others correct returned classifications from written feedback. Finish the priority repair in Evidence work's first five minutes. Do not reuse the exit inset.

#### 8 min. Dated evidence model
Read the Nipéhe summary on side 1, Source 46A. Review archaeologist and artifact from day 43: researchers study material evidence, including made objects. Stone points support people's presence by a period. They do not record the first arrival.

**Ask.** [[s03-K46-1]] Wait, then reveal [[steps:s03-K46-1]]. Review day 45's theory and migration. Coastal travel follows the coast, possibly using boats. A Beringia crossing could precede coastal travel; land and coast need not compete at every segment. Source 46B supports this possibility. A journey claim needs dated evidence along the proposed journey, not just one location. Review limit: what evidence cannot show.

#### 17 min. Evidence work
First five minutes finish repairs. Children classify [[s03-P46-1]], [[s03-P46-2]] and [[s03-P46-3]] alone, then compare in pairs. Each has a 45-second turn, 1.5 minutes in parallel. Teacher feedback separates a report, a possibility and an unsupported conclusion.

On the retained route sheet, trace a hypothetical land-plus-coast sequence. Label it illustration, never a recorded trip. Review the source log from day 42 with [[s03-P46-S]]. Collect all classifications and log entries.

#### 5 min. Question board
Review the board routine. Everyone answers [[s03-P46-Q]]. Hear six single 45-second observations, 4.5 minutes, allowing a pass. Use written notes instead if repairs need attention. Record the difference between a dated find and a traced journey.

#### 5 min. Exit ticket
Uncover the Friedkin caption for the first time: [[s03-X46a]] [[s03-X46b]]. Children answer independently on s03 exit 46. After class allow 30 times 30 seconds, 15 minutes, for both components, plus ten minutes for practice feedback. Use shown, shown with help, not yet seen; distinguish access from content help. Return every paper on day 47.

### Shorter or longer
Shorter: omit public sharing, keeping written notes. Longer: explain which word makes a supplied claim too strong.

### Words and supports
Observation: what a record reports. Possibility: something evidence leaves open. Overreach: a conclusion beyond evidence. Uncertainty: something evidence leaves unknown. Review theory and limit. Read neutrally or accept child-directed dictation.
