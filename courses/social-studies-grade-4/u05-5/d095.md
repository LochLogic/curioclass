# Day 95: A purchase and people's choices

## Teacher page
### Before class
Prepare pages, cards-095.md master and sealed exit-095.md. Keep teacher-key.md and exit-095-sources.md separate. Use the current generated key for repairs and revised practice samples. Bring every day 94 paper and board note. Cover Side 2 until Purchase work. Show only Alaska's inset on teaching-locator.png.

### The day
#### 5 min. Return and repair
Return day 94 tickets, practice, repairs and board notes with private cues. Review Return and repair: choose one priority. If many day 94 tickets showed error J, use [[s05-F95-1]]. Error O uses [[s05-F95-2]] instead. Review cause: it precedes and helps explain an effect. More than a third means whole class; otherwise small group. Others read written cues. Continue the same priority in Purchase work.

#### 8 min. Teaching first
Read the national-participant card. Review purchase: paying for another government's claim. Point to Alaska's inset; it shows location, not residents' agreement. **Ask.** [[s05-P95-1]] Wait, then model [[steps:s05-P95-1]]. Keep date recall separate: 1867. Review consent: people agreeing to how decisions are made. A national negotiator cannot stand for every resident. Explain Alaska Native peoples are distinct peoples, not one nation. Land-rights advocacy means working to defend rights to land. Read the separate later advocacy card; hold the protest captions for the exit.

#### 17 min. Purchase work
First five minutes finish the priority with [[s05-F95-3]] or [[s05-F95-4]]. Others use written feedback. Alone, complete [[s05-P95-2]]. Use the participant response and advocacy label separately, without composing a paired change/consent explanation. Fifteen simultaneous pairs rehearse their labels, 45 seconds each child, 90 seconds total; then revise alone. Review source makers using the supplied attributions. Watch for treating land-rights advocacy as a purchase participant; redirect to the card's later date.

#### 5 min. Question board
Review question-board.md and its growth question. Six rotating volunteers share an existing practice response, 45 seconds each, 4.5 minutes. Record names; passing is allowed. Collect everyone's paper for day 96 feedback.

#### 5 min. Exit ticket
Cover practice. Reveal exit-095.md and its paired captions for the first time. Read Tlingit as a specific Alaska Native people's name without explaining their response. Children answer [[s05-X95-1]] independently on paper. Read neutrally or scribe exactly. After class allow thirty minutes for thirty tickets, one minute each, plus thirty for other papers. Review record.md's component scale: shown, shown with help, not yet seen. Return all work day 96.
