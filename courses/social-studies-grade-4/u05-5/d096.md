# Day 96: Government, opposition and annexation

## Teacher page
### Before class
Prepare pages, cards-096.md master and sealed exit pieces. Keep teacher-key.md and exit-096-sources.md adult-only. Use the current generated key for revised practice and repairs. Bring all day 95 work. Cover Side 2 until Source work. The exit line's year marks are evenly spaced; children add event labels there.

### The day
#### 5 min. Return and repair
Return day 95 tickets, practice, repairs and board notes. Hand back written tasks s05-P95-1 and s05-P95-2 with private feedback. Review Return and repair: one priority. If many day 95 tickets showed error B, use [[s05-F96-1]]. Error T uses [[s05-F96-2]] instead. Review consent: people agreeing to how decisions are made. More than a third means whole class; otherwise small group. Others read private written cues. Continue in Source work.

#### 8 min. Teaching first
Read the separate event notes aloud. Explain overthrow as removal of a government from power. Name Queen Liliuokalani and the businessmen who overthrew her government, supported by United States forces. Review annexation: adding land to a country's claimed control; admission: joining as a state. Keep meanings separate from historical dates. Native Hawaiians opposed annexation through organized public action. Read Silva's attribution. **Ask.** [[s05-P96-1]] Wait, then model [[steps:s05-P96-1]]. Distinguish a later scholar from participants. Do not place historical events on a practice timeline.

#### 17 min. Source work
First five minutes finish the priority with [[s05-F96-3]] or [[s05-F96-4]]. Others read written cues. Review petition: a written request to officials, taught in grade 3. Alone, annotate [[s05-P96-2]], naming an organization and its action. Then match separate meanings in [[s05-P96-3]]. Fifteen simultaneous pairs rehearse one annotation, 45 seconds each child, 90 seconds total; revise alone. Watch for reversing the organizations' opposition. Point back to Silva's account; never speak for all Native Hawaiians. Keep Queen protest evidence sealed.

#### 5 min. Question board
Review question-board.md and the growth question. Six rotating volunteers share an existing annotation, 45 seconds each, 4.5 minutes. Record names; passing is allowed. Collect every child's page for day 97 feedback.

#### 5 min. Exit ticket
Cover practice. Review equal gaps for equal years without modeling event placement. Reveal exit-096-stimulus.md and exit-096.md. Children independently answer [[s05-X96-1]] and [[s05-X96-2]] on paper. Read neutrally or scribe exactly. After class allow thirty minutes for thirty tickets, one minute each, plus thirty for other papers. Review record.md's scale: shown, shown with help, not yet seen. Return all work day 97.
