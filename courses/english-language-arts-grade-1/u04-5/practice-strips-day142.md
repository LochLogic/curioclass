# Point card and practice strips

One point card and four strips for sorting under it. Two strips are reasons from the page; two are practice strips marked "invented for practice" in small letters at the foot.

- Point card: Making windows visible is a way to protect birds.
- Page strip: A bird sees trees in the glass.
- Page strip: Marks show a bird that the glass is there.
- Practice strip: Some windows have curtains.
- Practice strip: A bird hits glass because it sees trees.

The class points to which strips are a reason for the point and which is set aside. These practice strips are never exit cards.
