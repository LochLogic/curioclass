# Exit cards, days 148 to 152

Print "invented for practice" in small letters at the foot of every card. Plain black line drawings on white, thick lines, no shading, no printed words except the foot line and any word a card says is printed. Children do not read the cards; you read the lines aloud.

## Day 148 card (s04-X148a, W.1.2)

This card is invented for practice. Show the card and read it aloud: "Our class has a mailbox. We put notes in the slot. We check the box each day." Show three pictures: a plan with the mailbox as topic and two detail boxes (put notes in, check the box), a plan with the slot as topic, a plan with only a note drawn. Say: "Which plan shows the main topic and two details?" Hear the day's rotating six.

**Right answer:** The plan with the mailbox as topic and two details.

## Day 148 card (s04-X148b, W.1.2)

This card is invented for practice. The same card stays in view; read it again if the child asks: "Our class has a mailbox. We put notes in the slot. We check the box each day." Say: "Say a closing for this page." Hear the day's rotating six.

**Right answer:** "Our mailbox helps us share notes."
