# Day 65 feedback note cards

Two note cards for the shared moon-poem model, read aloud by the teacher while Pip plays the writer.

- **A kind, specific, helpful note.** Adds a detail the writer can use, for example "Tell where the moon walks."
- **A change-of-topic note.** Asks about something else, for example "What did you eat today?"

The class points to the note that helps the writer and says why. Pip then says one thing to add. No child plays the writer in a way that could embarrass them.
