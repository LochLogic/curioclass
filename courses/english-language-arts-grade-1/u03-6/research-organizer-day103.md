# Day 103 research organizer

One page. Top box: the question ("How does the beak help the bird get food?"). Below it two note boxes, each with a line for the note and a small box for the source label. Beside each note a "where I found it" box with four small pictures to circle: heading, label, glossary, contents. The child fills it from the notes folder; a partner checks each note against the page.
