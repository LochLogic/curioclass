# Day 87 annotated drawing sheet

A page with a big empty frame, two label lines and a source-note box at the foot. The child draws one bird foot from Feet That Help (sparrow, duck or hawk), copies two labels, and adds a source note with the label Feet That Help. Partners compare the drawing with the words and each child changes one detail, pointing to the sentence. The page keeps both versions side by side.
