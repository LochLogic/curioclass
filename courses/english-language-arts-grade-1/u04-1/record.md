# Unit 4 record sheet: caring for birds

Write each child's name down the left. The rotating six for each day are the children you hear for that day's spoken exit; a child outside the six is "not yet heard", never "missed". Each exit column is one look-for in the exit: write 2 when the child does it alone, 1 when it was shown with help, and 0 when it is not yet seen. Leave a cell blank if you did not observe it. A child may pass; leave the cell blank and try another day.

The end-of-unit columns (the check days and the last week) use the same marks. Write the date in the cell for any later attempt.

Marks never name a child as an example of a mistake, and the sheet stays in your folder.
