# Printing set sheets, days 120 to 124

Five dated sheets, one a day, for the foundations rotation: Aa to Ee on day 120, Ff to Jj on 121, Kk to Oo on 122, Pp to Tt on 123, Uu to Zz on 124. Each sheet shows the capital and the small form of each letter on a four-line page with a start dot and an arrow for each stroke, and a row of empty lines for the child to print. The sheets carry no words. Keep them in the record folder.
