# Unit 1 record sheet: our class list

Write each student's name down the left. The R columns are the day 1 readiness items: write A or B for a gap, no score. Each E column is one exit: one tick when the student meets the look-fors listed under the table, or the error letter if a gap shows. The End columns are the end-of-unit assessment: one cell for each look-for, 2 when met independently, 1 when partly met, 0 when not met, blank when not yet observed. Never write 0 for a part not yet taught. Put the date in any cell attempted again later.
