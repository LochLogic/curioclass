# Unit 2 record sheet: our class list

Write each child's name down the left. Use one scale in every cell: S for shown, H for shown with help, N for not yet seen. Each E column is one spoken exit and has a cell for each look-for listed under the table; a child may point, say, draw or act it out. The Heard column on each day is for the rotating six you heard give a reason. The End columns are the observation on days 20 and 21, one cell for each look-for, and only a child's own first try at the sitting counts. Never write N for a part you did not see; leave the cell blank and try another day. Write H when you steadied the cards or read a card aloud, and say so. The day 21 exit is not scored, and the day 21 response never changes an End cell.
