# Exit cards, days 48 to 51: teacher key

Not printed for children. Goes with cards-exits-48-51.md. A wrong touch with no letter is shown with help.

- X48a. Key: the flowerpot tap or the hand bell. The flashlight at the face is shown with help and the rule that light never points at eyes is said aloud again.
- X48b. Key: thumb down, no. Thumb up is error A.
- X48c. Key: send a message across the lawn without shouting, so the friend understands it. A device or "shout louder" is shown with help.
- X49a. Key: the cups with the straight string. The box with its top off is error B.
- X49b. Key: the string is straight and taped in both cups, so it can carry the shake. A reason not from the picture is shown with help.
- X50a. Key: the third, touching row. The gap row is error E. The row with a block on top is shown with help, no letter.
- X50b. Key: five crayons. A count that misses or repeats a crayon is shown with help, no letter.
- X50c. Key: the message: send wait at both marks, so only the distance changes. "The distance" is shown with help, no letter.
- X51a. Key: the second pair. The first pair is error D.
- X51b. Key: the third card. Stopping is error C; changing the signal is error D.
