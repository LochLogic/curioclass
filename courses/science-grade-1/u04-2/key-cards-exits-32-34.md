# Exit cards, days 32 and 34: teacher key

Not printed for children. Goes with cards-exits-32-34.md.

- s04-X32. Key: card 1. "Sound cannot move foil" is error B. The pressing hand is error C. Card 3 is shown with help, no letter.
- s04-X34a. Key: no, a fan was also blowing, so the sound is not the only thing that changed. Yes is shown with help, no letter (a fan is not a touch, so it is not error C). "No, because sound cannot move things" is error B.
- s04-X34b. Key: if the fringe moved with the sound on and not with it off, "it sounds, so it makes things shake"; if it did not move, the record does not show that arrow, and saying so is right. The other arrows are shown with help. "Sound cannot move things" is error B.
- s04-X34c. Key: "it shakes, so it sounds" or "it is held still, so it is quiet": either fits; ask the child to point to the free box or the held box. "The held cup still sounds" is error A. "It sounds, so it makes things shake" is shown with help.
