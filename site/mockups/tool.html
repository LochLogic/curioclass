A 5-minute start

  1. Project Practice mode. Ask the class to name any state they're sure of and find it together.
  2. Turn on labels for the region you're studying, then turn them off and try again.
  3. Students play Challenge on their own devices. Green means first try; red means it took a while.

Talk about it

  • Which states were hardest? Why might some states be harder to remember?
  • What patterns help you: shapes, neighbors, coastlines?
  • How would you split the map into regions, and why?
