title: Trace a program | Rastrea un programa
idea: Tracing means playing computer: run each line yourself and write down what changes. | Rastrear es jugar a ser la computadora: ejecuta cada línea tú mismo y anota lo que cambia.
example: score = 0, then score = score + 5, then score = score × 2. The table ends with score = 10. | score = 0, luego score = score + 5, luego score = score × 2. La tabla termina con score = 10.

- Table: Make a column for each [[variable]]. | Tabla: Haz una columna para cada [[variable]].
- One line: Read one line at a time, from the [[top]]. | Una línea: Lee una línea a la vez, desde [[arriba]].
- Update: When a value changes, cross out the old one and write the [[new]] one. | Actualiza: Cuando un valor cambia, tacha el viejo y escribe el [[nuevo]].
- Check the note: Does the [[comment]] tell the truth about what the code does? | Revisa la nota: ¿El [[comentario]] dice la verdad sobre lo que hace el código?
