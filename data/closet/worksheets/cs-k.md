# 1. Brush, Brush, Brush: Steps in Order
minutes: 20
materials: pencil, scissors, glue stick, crayons
ican: I can put the steps of a task in order.
directions: (Read aloud.) Listen to each card. Cut out the cards and glue them in order: first, next, then, last. Then write 1, 2, 3 or 4 under each picture.
pairs: robot-dance
mistakes: Children who glue "smile" first are thinking about the happy ending, not the order of doing. Act it out together with pretend brushes: "Can we brush before the toothpaste is on?" Watch for cards glued upside down; read each card aloud again before gluing.
notes: The cards are words, so read every card aloud and act each step out before anyone cuts. Children can add a tiny drawing to each card before cutting. Link it to computers: a computer, like a robot, follows steps in exactly the order we give them, so order matters. The picture part checks the same order with pictures: cup is 3, toothpaste is 1, smile is 4, toothbrush is 2.

## Warm up
example: (Read aloud.) Getting dressed: **first** socks, **then** shoes. Shoes first will not work!
choice: (Read aloud.) Which do you do first?
  - Put on your shoes.
  * Put on your socks.

## Main: Cut and glue the steps
sort: (Read aloud.) Glue each card in its box.
  - First: put toothpaste on the brush
  - Next: brush all your teeth
  - Then: spit and rinse
  - Last: smile!

## Stretch: Number the pictures
text: (Read aloud.) Write the step number under each picture: 1, 2, 3 or 4.
picword:
  - cup | {3}
  - toothpaste | {1}
  - face-happy | {4}
  - toothbrush | {2}

# 21. Class Vote: Favorite Fruit
minutes: 25
materials: pencil, crayons, 4 fruit pictures for the class vote
ican: I can count votes and tell which has the most.
directions: (Read aloud.) Each picture is one vote. Count Room 5's votes and write the number. Then our class votes: color one box for each vote, and circle the fruit with the most votes.
mistakes: Children often color from the wrong end or skip a box, which makes a bar look longer or shorter than it is. Have them start at the box marked 1 and color one box for each vote, touching each child's name or tally as they go. Some circle their own favorite fruit as "the most": point back to the boxes.
notes: The warm up uses Room 5's votes (apple 5, banana 3, grapes 7, cherries 4), so it has a fixed key. For the main part, hold a real class vote: put the four fruit pictures in the corners, each child stands by one, and count each group aloud together while children color one box per vote. Check the graphs against your own count; the fruit with the most votes is whichever row is longest, and a tie is a fine thing to talk about.

## Warm up: Room 5 voted
count: (Read aloud.) Count the votes for each fruit. Write the number.
  - 5 apple
  - 3 banana
  - 7 grapes
  - 4 cherries
choice: (Read aloud.) Which fruit got the most votes in Room 5?
  - apple
  - banana
  * grapes
  - cherries
