# 1. Code the Path: Bee to Flower
minutes: 25
materials: pencil, a small counter or eraser to be the bee
ican: I can write a program of arrows to move to a goal.
directions: (Read aloud.) Each arrow moves the bee one square. The bee cannot step on a rock. Write the fewest arrows that take the bee to the flower.
mistakes: The most common slip is mixing up left and right: let children put a counter on the bee square and slide it one square for each arrow they write. Another is writing one arrow for a whole row ("→" for three squares): each arrow is exactly one square.
notes: Each grid has one shortest path that avoids the rocks; any path that reaches the flower without touching a rock shows the idea, but ask for the fewest arrows. Grid 4 takes 6 arrows. Children can test each other's programs by "being the bee" on a floor grid of tape.

## Warm up
example: (Read aloud.) → moves right. ← moves left. ↑ moves up. ↓ moves down. bee, empty, empty, flower in a row: the program is → → →.
fill:
  - (Read aloud.) Which arrow moves the bee down? {↓}
  - (Read aloud.) Which arrow moves the bee left? {←}

## Main: Write the program
table: Grid 1 | column 1 | column 2 | column 3 | column 4
  - row 1 | bee | rock | |
  - row 2 | | rock | |
  - row 3 | | | flower |
  - row 4 | | | |
fill: Program: {↓ ↓ → →     }
table: Grid 2 | column 1 | column 2 | column 3 | column 4
  - row 1 | | | |
  - row 2 | | | flower |
  - row 3 | rock | | rock |
  - row 4 | bee | | |
fill: Program: {→ ↑ ↑ →     }
table: Grid 3 | column 1 | column 2 | column 3 | column 4
  - row 1 | | | rock | bee
  - row 2 | | rock | |
  - row 3 | | rock | | rock
  - row 4 | | flower | |
fill: Program: {↓ ← ↓ ↓ ←   }

## Stretch: Six arrows
table: Grid 4 | column 1 | column 2 | column 3 | column 4
  - row 1 | flower | | |
  - row 2 | rock | | |
  - row 3 | rock | | rock | rock
  - row 4 | rock | | | bee
fill: Program: {← ← ↑ ↑ ↑ ← }

# 5. Dance Move Program
minutes: 30
materials: pencil, a partner
ican: I can write a program of dance moves in order with picture symbols.
directions: (Read aloud.) Read the dance program with picture symbols. Then write your own 6-step dance with the quick symbols. Trade with a partner, act out each other's dance, and check each step.
mistakes: Children often draw two moves in one box; one box, one move, just like one arrow is one square. Some partners do the moves from memory instead of reading each box; have the reader point to each box as the dancer moves. Watch for programs that use only one move: the plan needs clap, jump and spin.
notes: Quick symbols are faster to draw than the pictures: )( for clap, an up arrow for jump, a circle arrow for spin. Warm up key: 2 claps; step 4 is spin; jump is step 3. A model program: clap, clap, jump, spin, jump, clap. The dance runs best in a clear space with partners facing each other; read "step 1, step 2" aloud like a beat. Any 6-step program with all three moves is correct; the partner check is the test.

## Warm up: Read the program
example: (Read aloud.) Quick symbols: clap = **)(**   jump = **↑**   spin = **↻**
picword:
  - clap | 1
  - clap | 2
  - jump | 3
  - spin | 4
fill:
  - (Read aloud.) How many claps? {2}
  - (Read aloud.) What move is step 4? {spin}
  - (Read aloud.) Which step is the jump? {3}

## Main: Write my dance
text: (Read aloud.) Draw one quick symbol in each box. Use clap, jump and spin at least one time each.
table: Step 1 | Step 2 | Step 3 | Step 4 | Step 5 | Step 6
  height: 0.9
  - | | | | |
note: Model: )( )( ↑ ↻ ↑ )( (clap, clap, jump, spin, jump, clap).

## Main: Trade and test
text: (Read aloud.) Your partner does your dance. Put a check if they did the right move, or an X if not.
table: Step 1 | Step 2 | Step 3 | Step 4 | Step 5 | Step 6
  height: 0.5
  - | | | | |
write: (Read aloud.) Did your partner do every step right? If not, which step was wrong, and why?
  lines: 2
  key: Answers vary. Example: Step 5 was wrong. My partner spun instead of jumping because my arrow looked like a circle, so I drew it again more clearly.

## Stretch
write: (Read aloud.) Find a part of your dance that repeats. Write it.
  lines: 1
  key: Answers vary. Example: clap, clap repeats at the start; or the dance has jump two times.

# 16. Computer Parts Review
minutes: 25
materials: pencil
ican: I can name computer parts, tell what they do, and choose a safe picture password.
directions: (Read aloud.) Write the name of each part under its picture. Match each part to its job. Then circle the safest picture password.
mistakes: Children often call the whole computer "the screen" or call the mouse "the clicker"; use the word bank and point to each part on a real computer. In the password question, some pick their pet because it is easy to remember; ask, "Who else knows your pet's name?"
notes: Word bank key: screen, keyboard, mouse, headphones. Jobs: screen shows words and pictures; keyboard types letters and numbers; mouse points and clicks. A strong picture password uses several different pictures in a secret order that is not about you, and you share it only with a trusted grown-up. Input parts (keyboard, mouse) send information into the computer; screens and headphones are output.

## Warm up: Label the parts
text: Word bank: **screen, keyboard, mouse, headphones**
picword:
  - computer | {screen}
  - keyboard | {keyboard}
  - computer-mouse | {mouse}
  - headphones | {headphones}

## Main: Match the jobs
match: (Read aloud.) Write the letter of each part's job.
  - screen = shows words and pictures
  - keyboard = types letters and numbers
  - mouse = points and clicks

## Main: Safe password
choice: (Read aloud.) Which picture password is the safest?
  - a picture of your pet cat
  - sun, sun, sun, sun
  * kite, drum, frog, cup, in a secret order
  - the first letter of your name

## Stretch
fill:
  - (Read aloud.) Two parts you use to tell the computer what to do: {keyboard} and {mouse}

# 22. When the Flag Is Tapped
minutes: 25
materials: pencil, crayons
ican: I can tell what a character does when its event happens.
directions: (Read aloud.) Each card shows a character and its code. The top line is the event: what makes the code start. Draw what the character does. Then answer the questions.
mistakes: Children often think every character moves when the flag is tapped. Point to the top line of each card: only code that starts with "When the flag is tapped" runs then. Some draw the event (a hand tapping) instead of the action; ask "What does the cat do?"
notes: An event is the thing that starts a script: tapping the flag, tapping a character, or pressing a key. Act the cards out: three children hold the cards, and they move only when you do their event. The stretch question is the big idea: tapping the flag starts only the cat.

## Warm up
example: (Read aloud.) An **event** starts the code. Card: When the flag is tapped, the dog says "Woof!" Tap the flag, and the dog says Woof.
choice: (Read aloud.) Card: When the flag is tapped, jump. What starts this code?
  * tapping the flag
  - jumping
  - clapping your hands

## Main: Three character cards
table: Card 1: Cat
  - When the flag is tapped
  - jump 2 times
  - say "Hi!"
draw: Draw the cat doing its code. | 1.4
fill: The cat jumps {2} times and says {Hi}.
table: Card 2: Dog
  - When the dog is tapped
  - spin around
  - say "Woof!"
draw: Draw the dog doing its code. | 1.4
choice: What makes the dog spin?
  - tapping the flag
  * tapping the dog
  - pressing the space key
table: Card 3: Fish
  - When the space key is pressed
  - swim up 1 step
  - blow 3 bubbles
draw: Draw the fish doing its code. | 1.4
fill: The fish blows {3} bubbles.

## Stretch
choice: (Read aloud.) You tap the flag. Who moves?
  * only the cat
  - the cat and the dog
  - all three

# 26. Make a Fair Kickball Rule
minutes: 30
materials: pencil, scissors, crayons
ican: I can make a fair rule for taking turns and test it.
directions: (Read aloud.) Draw and write a 3-step rule for taking turns kicking in kickball. Then cut out the 4 friend cards and test your rule: who kicks on each turn?
mistakes: Many first rules say "line up" but not what happens after a kick, so the same child kicks again; ask "Where does the kicker go next?" Children may let a card skip the line because that friend is fast or kicked well. A fair rule treats every card the same.
notes: Model rule: Step 1, pick a number card to make the line. Step 2, the first child in line kicks one time. Step 3, the kicker goes to the back of the line. With 4 friends and 8 kicks, each friend kicks 2 times. The model test (line order Ana, Bo, Cy, Dot): Ana, Bo, Cy, Dot, Ana, Bo, Cy, Dot. Any rule where every friend kicks the same number of times in 8 kicks passes the test. Bo's question is the big idea: a fair rule gives everyone the same chances, not the most turns to the best player.

## Warm up
choice: (Read aloud.) Which kickball rule is fair?
  - The fastest kid kicks every time.
  * Everyone kicks once in line order, then goes to the back.
  - Whoever yells the loudest kicks first.

## Main: My 3-step rule
chart: Draw it | Write it
  labels: Step 1; Step 2; Step 3
  height: 1.0
  key: Model: Step 1, pick a number card to make the line. Step 2, the first kid in line kicks one time. Step 3, the kicker goes to the back of the line.

## Main: Test the rule
cards: (Read aloud.) Cut out the friend cards. Line them up and follow your rule.
  plain: yes
  - **Ana** wants to go first.
  - **Bo** is the fastest runner.
  - **Cy** is new to kickball.
  - **Dot** kicked last at recess.
table: Kick | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8
  - Who kicks? | | | | | | | |
note: Model test (line order Ana, Bo, Cy, Dot): Ana, Bo, Cy, Dot, Ana, Bo, Cy, Dot.
fill:
  - (Read aloud.) 4 friends and 8 kicks. Each friend should kick {2} times.
  - (Read aloud.) Did every friend kick the same number of times? {yes}

## Stretch
write: (Read aloud.) Bo says, "I am the fastest, so I should kick more." Is that fair? Why?
  lines: 2
  key: No. A fair rule gives every player the same number of turns. Bo can still run fast when it is his turn.

# 37. With and Without the Device
minutes: 30
materials: pencil, crayons
ican: I can show how a worker does a job with a device and without one.
directions: (Read aloud.) Match each device to a tool that does the same job without a device. Then, for 4 jobs, draw the tool used with a device and the tool used without one.
mistakes: Children may draw the worker in both boxes and forget the tool; ask "What is in their hands?" Some think the job cannot be done at all without a device; talk about how people did it before (a paper map, adding on paper).
notes: Match key: map on a phone, paper map; calculator, adding with paper and pencil; timer on a tablet, sand timer; tablet book, paper book. Model drawings: bus driver, a map screen on the dashboard and a paper map; cashier, a barcode scanner and register, and a price list with paper and pencil; writer, a computer keyboard and a pencil with paper; teacher, a projector or smart board and a chalkboard or whiteboard. Accept any device and non-device pair that do the same job.

## Warm up
match: (Read aloud.) Match each device to a tool that does the same job.
  - map on a phone = paper map
  - calculator = adding with paper and pencil
  - timer on a tablet = sand timer
  - book on a tablet = paper book

## Main: Draw the tools
chart: With a device | Without a device
  labels: Bus driver; Cashier; Writer; Teacher
  height: 1.35
  key: Model: bus driver, map screen and paper map; cashier, barcode scanner and price list with pencil; writer, keyboard and pencil; teacher, smart board and chalkboard.

## Stretch
write: (Read aloud.) Pick one job. Write one good thing about the tool without a device.
  lines: 2
  key: Answers vary. Example: A paper map still works when the phone battery dies or there is no signal.
