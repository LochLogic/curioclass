## How to play
1. Make a code chart. Each three-letter codon stands for a letter: AUG = START, GCU = A, UUA = L, GAA = E, CAU = H, UCU = S, ACU = T, UAA = STOP.
2. Add more as you like, so each player can write a few words: GGU = G, CGU = R, AAU = N.
3. Each player writes a secret DNA strand, like TAC CGA AAT CTT ATT. The partner must write the matching mRNA (A pairs with U, T with A, C with G, G with C).
4. Then use the chart to read the mRNA three letters at a time.
5. Race to decode the message first. A correct decode scores two points.
6. Mutation round: change one letter of a strand. Does the message change? Is it still readable?

## What your child is learning
DNA holds instructions in a four-letter code. Cells copy it into mRNA and read it three letters at a time to build proteins; a single changed letter can change the result.

## Make it easier
Give the mRNA directly and only decode with the chart.

## Make it harder
Delete one letter instead of changing it. Why is a deletion usually worse?

## Cómo jugar
1. Hagan una tabla de código. Cada codón de tres letras representa una letra: AUG = INICIO, GCU = A, UUA = L, GAA = E, CAU = H, UCU = S, ACU = T, UAA = ALTO.
2. Agreguen más si quieren, para que cada jugador pueda escribir algunas palabras: GGU = G, CGU = R, AAU = N.
3. Cada jugador escribe una cadena secreta de ADN, como TAC CGA AAT CTT ATT. El compañero escribe el ARNm que le corresponde (A con U, T con A, C con G, G con C).
4. Luego usen la tabla para leer el ARNm de tres en tres letras.
5. Compitan para descifrar el mensaje primero. Descifrarlo bien gana dos puntos.
6. Ronda de mutación: cambien una letra de una cadena. ¿Cambia el mensaje? ¿Todavía se puede leer?

## Qué está aprendiendo
El ADN guarda instrucciones en un código de cuatro letras. La célula lo copia en ARNm y lo lee de tres en tres letras para formar proteínas; una sola letra cambiada puede cambiar el resultado.

## Más fácil
Den el ARNm directamente y solo descifren con la tabla.

## Más difícil
Borren una letra en lugar de cambiarla. ¿Por qué una eliminación casi siempre es peor?
